# 社内訓練ツール — UI試作

今回は **構造と軸の動きを確認するUI** です。電気と機械の入口、機械の中のレベル出し、機械選択、3D訓練画面を作成しました。

## 開き方

1. ZIPを展開してください。
2. `index.html` をブラウザで開いてください。
3. 「機械」→「工作機械のレベル出し」→機械を選択。

`index.html` はCSSとJavaScriptを含む1ファイルです。ネット接続なしで画面を表示できます。メーカー公式資料へのリンクを開く場合だけ通信が必要です。
スマホは端末のファイル閲覧アプリによってHTML内のJavaScriptが実行されない場合があります。その場合はHTMLを通常のブラウザで開ける環境やWebサーバーに配置してください。

## 今回操作できること

- 電気／機械のカテゴリと画面移動
- 7カテゴリの機械構造の選択
- マウス・指の左右ドラッグで3Dを左右回転
- 左回転／右回転／正面に戻すボタン
- 左右矢印キーで回転
- 部品名表示の切替
- X・Y・Z軸の矢印と、固定部品／動く部品の表示
- 軸別のスライダー操作と、一往復の動作デモ
- 固定門形の2方式、立形の標準／小型サイズの切替
- 5軸モデルのA・C旋回、2軸旋盤のY軸なし表示
- 上面配置図の支持点を選択し、3D上で強調
- 水準器を置く位置の選択UI

電気はテスターの使い方（DC電圧・抵抗・導通）の案内を表示します。上下回転、ズーム、カメラの移動はありません。

## 今回実装していないこと

- 支持点の高さ調整
- 機械の傾き・ねじれ・変形計算
- 水準器の数値・気泡の計算
- 加工精度への影響のシミュレーション
- メーカー別の据付手順・支持点・許容値

調整ボタンは無効化し、計算前の項目は「—」で表示しています。軸の位置表示は模型の端1／端2に対する割合で、NCの＋／−指令や実ストロークではありません。表示している高さ0.00 mmはUIの例です。3Dは外装を省いた構造模式図で、代表機のCADモデルではありません。

## 構成

- `index.html`：そのまま開けるUI（1ファイル）
- `src/index.html`：編集用のHTML
- `src/style.css`：編集用のデザイン
- `src/app.js`：機械一覧・3D模式図・画面移動
- `docs/machine_types.md`：分類・代表例・公式資料
- `docs/ui_scope.md`：今回の画面構成と実装範囲
- `docs/original_plan/`：添付されていた元の企画資料

編集するときは `src` 内を変更してください。ルートの `index.html` に反映するには `python3 build.py` を実行します。ビルドに追加ライブラリは不要です。

## UIを確認するときのポイント

入口の分け方、機械の並べ方、3Dと調整欄の配置、スマホでの縦並び、支持点の選び方を確認してください。UIを固めてから訓練計算を追加する構成です。


携帯では絵を常時表示し、操作と説明だけをスクロールします。電気の「テスターの使い方」には、端子・モード・接続順序を学ぶ模擬測定を追加しています。
