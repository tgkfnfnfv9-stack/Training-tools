# 社内訓練ツール

電気・機械の操作をブラウザで練習する、依存ライブラリ不要の訓練シミュレーターです。携帯では上の絵を常時表示し、下の操作・説明だけをスクロールします。

## 使い方

`index.html` をブラウザで開きます。GitHub Pagesからも利用できます。教材の操作はネット接続なしでも動き、公式資料へのリンクだけ通信が必要です。

### 機械 → 工作機械のレベル出し

- 7構造カテゴリ：立形片側コラム、横形MC、移動コラム、固定門形、移動門形、5軸テーブル旋回、2軸NC旋盤
- 立形の標準／小型、固定門形の長手／テーブルXY方式
- 絵を左右にドラッグ・矢印キーで模型を回転
- XYZAC部品移動、一往復の動作デモ、固定／可動部品の対応表
- 3・4・6・8支持点の高さ調整（−0.50〜＋0.50 mm、0.001 mm刻み）
- 右高・手前高・対角ねじれ・中間支持高の状態パターン（配置に該当するもの）
- 仮想支持寸法、水準器感度、手前／中央／奥の測定位置
- 新品／中古の固定乱数個体：ガイド真直度PVと軸間の固有直角差を抽選
- 新品95%は0.001〜0.020 mm、中古は60/30/10%の誤差帯（項目ごとの教材設定）
- 初期／現在／探索で得た参考最良を比較、残るガイド誤差を表示
- 固定300 mm基準の調整評価、手動調整と参考調整例の適用
- 支持高さ → 局所姿勢 → XY/XZ/YZの直角度の変化（角度・評価長でのµm換算）
- 小型4点支持のねじれとYZ/XZの変化、コラムの前倒れ・左右倒れ
- コラムの据付配置・可動軸位置による変化、端・中央の代表位置の比較
- 門形の左右コラムの前後倒れ差、旋盤の主軸Z基準とX方向の比較
- 最大1000倍の姿勢表示、剛体として傾くコラム・テーブル、分割した支持面マップ
- 補助の水準器、平均傾き・ねじれ・支持点の平面偏差、調整練習
- 個体の乱数種・支持高さ・コラム配置・軸位置のブラウザ自動保存とJSONの保存・読込（旧JSON対応）

小型機の例は「立形・片側コラム」→「小型（ロボドリル系）」→「ねじれと直角度を見る」。コラム位置の違いは「コラムの据付位置を変えて比較」を開いて左右・前後を変更します。

3点は平面、格子支持は双線形補間した学習用面です。工具側と案内側が参照位置の局所姿勢に従うと仮定し、その方向同士の直角度を計算します。共通平面の傾きだけでは新たな直角差は発生せず、個体固有の直角差は残ります。ガイド真直度PVは別の固定固有値として表示し、支持調整で修理できる扱いにはしません。抽選率は市場統計ではありません。参考最良はモデル内の探索例で、全球最適の証明ではありません。寸法・高さ・支持位置は実機仕様ではありません。剛性／荷重解析、実機加工誤差の予測、メーカー基準の合否判定は行いません。単位・式・限界は `docs/leveling-model.md` を参照してください。

### 電気 → テスターの使い方

- DC電圧：1.5／1.0 V、逆極性
- AC電圧：低電圧6 V実効値、向きの比較
- DC電流：3 V／120 Ωの理想回路、25 mA、直列接続
- 抵抗：100 Ω／1 kΩ／10 kΩ
- 導通：正常／断線、模擬ブザー表示
- 端子・モード・準備の確認、誤接続遮断、測定中ロック、終了手順、5教材の完了記録

電流端子の並列接続は遮断します。実機の商用電源や制御盤は教材対象外です。音は表示のみで、記録はページ再読込で初期化します。詳細は `docs/tester_basics.md` を参照してください。

## 編集・ビルド

`src` のHTML・CSS・JavaScriptを編集し、リポジトリのフォルダで実行します。

```sh
python3 build.py
```

ルートの `index.html` にすべての教材を埋め込みます。

|ファイル|用途|
|---|---|
|`src/app.js`|機械一覧・部品移動・3D描画・画面移動|
|`src/leveling.js`|純粋なレベル計算エンジン|
|`src/leveling-ui.js`|支持点・水準器・結果・練習・保存の連動|
|`src/machine-accuracy.js`|再現可能な個体抽選・固有方向・離散探索|
|`src/machine-accuracy-ui.js`|新品／中古・初期／現在／参考最良・練習評価|
|`src/accuracy-ui.js`|構造別の姿勢・直角度・コラム配置・代表位置比較|
|`src/tester.*`|電気教材|
|`docs/ui_scope.md`|画面・機能の一覧|
|`docs/verification.md`|検証方法・結果|
|`docs/qa-mobile.html`|携帯寸法のブラウザ確認用iframe|
|`tests/`|計算・動線・測定条件の検証|

```sh
node tests/check-leveling-engine.cjs
node tests/check-leveling-ui.cjs
node tests/check-accuracy-engine.cjs
node tests/check-accuracy-review.cjs
node tests/check-accuracy-render.cjs
node tests/check-mobile-navigation.cjs
node tests/check-electrical-full.cjs
node tests/check-tester-lesson.cjs
node tests/check-full-code-review.cjs
node tests/check-random-accuracy-review.cjs
```
