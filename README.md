# 社内訓練ツール

電気・機械の操作をブラウザで練習する、依存ライブラリ不要の訓練シミュレーターです。携帯では上の絵を常時表示し、下の操作・説明だけをスクロールします。PCの機械訓練でも左の模型と変化表示を常時見ながら、右の操作・説明をスクロールできます。

## 使い方

`index.html` をブラウザで開きます。GitHub Pagesからも利用できます。教材の操作はネット接続なしでも動き、公式資料へのリンクだけ通信が必要です。

### 機械 → 工作機械のレベル出し

- 7構造カテゴリ：立形片側コラム、横形MC、移動コラム、固定門形、移動門形、5軸テーブル旋回、2軸NC旋盤
- 立形の標準／小型、固定門形の長手／テーブルXY方式
- 絵を左右にドラッグ・矢印キーで模型を回転
- 模型直下の専用バーで軸を選択。全軸の色付き矢印と、選択軸で動く部品の同色表示（旋盤XZ、5軸XYZAC）
- 座標の目安は説明・操作欄の「3Dの表示設定・色の見方」に分離。X/Y/Zそれぞれの向きが模型の左右回転に追従し、部品名の説明線と重なりません（旋盤はX/Z、5軸のA/Cは模型の曲線矢印）
- 専用バーの「軸操作」を押すと、説明・操作欄の先頭に位置調整・一往復デモ・中央復帰・方式／サイズ切替を表示。開閉しても模型は隠れず、描画領域のサイズは変わりません
- 3・4・6・8支持点の高さ調整（−0.50〜＋0.50 mm、0.001 mm刻み）
- 右高・手前高・対角ねじれ・中間支持高の状態パターン（配置に該当するもの）
- 仮想支持寸法、水準器感度、手前／中央／奥の測定位置
- 新品／中古の固定乱数個体：ガイド真直度PVと軸間の固有直角差を抽選
- 新品95%は0.001〜0.020 mm、中古は60/30/10%の誤差帯（項目ごとの教材設定）
- 初期はランダムな据付レベル＋本体固有精度。粗レベル出し → 残る精度の確認 → 同じ支持点の微調整を先頭に表示
- 平均左右／前後レベルは各±0.02 mm/mを粗調整の教材目安とし、局所水準器・精度完了と区別
- 粗調整0.01 mm／微調整0.001 mmの切替はボタンの調整量だけを変更し、個体・支持高さ・比較基準を維持
- 本体の代表方向から固有倒れを導き、支持姿勢との合成倒れと内訳を表示。旋盤は主軸の水平面／上下方向差
- 抽選時の初期状態と現在の直角度・倒れ・ねじれを、同じ軸位置・寸法・評価長で比較
- 支持点を0.001 mm動かした変化量と、90°との差が小さく／大きくなったかを表示
- 参考最良の探索・固定300 mmの集約評価・自動適用は、手動学習の補助として確認
- 支持高さ → 局所姿勢 → XY/XZ/YZの直角度の変化（角度・評価長でのµm換算）
- 小型4点支持のねじれとYZ/XZの変化、コラムの前倒れ・左右倒れ
- コラムの据付配置・可動軸位置による変化、端・中央の代表位置の比較
- 門形の左右コラムの前後倒れ差、旋盤の主軸Z基準とX方向の比較
- 調整中に固定する最大1000倍の姿勢表示。固有方向＋支持姿勢で傾くコラム／主軸と、支持姿勢で傾くテーブル、分割支持面マップ
- 補助の水準器、平均傾き・ねじれ・支持点の平面偏差、調整練習
- 個体の乱数種・支持高さ・コラム配置・軸位置のブラウザ自動保存とJSONの保存・読込（旧JSON対応）

まず粗調整0.01 mmで支持点を動かし、平均レベルを目安へ近づけます。平均が揃っても本体の固有倒れ・直角差・ガイドPVは残るため、残る精度を確認し、微調整0.001 mmで同じ支持点を調整します。倍率が支持高さのたびに変わらないので、絵もレベル調整に合わせて変わります。倒れ・ねじれ・直角度は別の指標で、1つが小さくなっても他が大きくなる場合があります。小型機の例は「立形・片側コラム」→模型直下の「軸操作」→説明・操作欄の「この構造の方式／サイズ」で「小型（ロボドリル系）」を選択。軸を動かして端と中央を比べ、コラム位置の違いは「コラムの据付位置を変えて比較」で確認します。

「軸操作」を開くと説明・操作欄だけが先頭へ移り、閉じるボタンへフォーカスします。「閉じる」またはEscで専用バーへ戻ります。携帯の縦画面では説明・操作欄は下、横画面とPCでは右です。狭い横画面では軸選択バーが折り返し、各ボタンは44px以上を保ちます。

「模型の向き（座標の目安）」では各軸の方向を独立した小図で表示し、回転によって投影方向が一致しても線同士が重なりません。「軸の矢印を表示」をOFFにすると、模型の動作矢印と座標の目安がともに非表示になります。座標の目安は視点の向きだけを示し、NCの＋／−指令や支持姿勢・精度の表示ではありません。

3点は平面、格子支持は双線形補間した学習用面です。工具側と案内側が参照位置の局所姿勢に従うと仮定し、その方向同士の直角度を計算します。抽選した固有角度に支持による姿勢が重なるため、表示する直角度は調整で変化します。共通平面の傾きだけでは新たな直角差は発生せず、同じ参照姿勢の軸対は固有直角差を保ちます。ガイドPVはこのモデルで固定する固有の曲がり成分です。据付による案内真直度の変化は計算対象に含めていません。抽選率は市場統計ではありません。参考最良はモデル内の探索例で、全球最適の証明ではありません。寸法・高さ・支持位置は実機仕様ではありません。剛性／荷重解析、実機加工誤差の予測、メーカー基準の合否判定は行いません。単位・式・限界は `docs/leveling-model.md` を参照してください。

### 電気 → テスターの使い方

- DC電圧：1.5／1.0 V、逆極性
- AC電圧：低電圧6 V実効値、向きの比較
- DC電流：3 V／120 Ωの理想回路、25 mA、直列接続
- 抵抗：100 Ω／1 kΩ／10 kΩ
- 導通：正常／断線、模擬ブザー表示
- 端子・モード・準備の確認、誤接続遮断、測定中ロック、終了手順、5教材の完了記録

電流端子の並列接続は遮断します。実機の商用電源や制御盤は教材対象外です。音は表示のみで、記録はページ再読込で初期化します。詳細は `docs/tester_basics.md` を参照してください。

## 編集・ビルド

`src` のHTML・CSS・JavaScriptを編集し、リポジトリのフォルダで実行します。

```sh
python3 build.py
```

ルートの `index.html` にすべての教材を埋め込みます。

|ファイル|用途|
|---|---|
|`src/app.js`|機械一覧・部品移動・3D描画・画面移動|
|`src/leveling.js`|純粋なレベル計算エンジン|
|`src/leveling-ui.js`|支持点・水準器・結果・練習・保存の連動|
|`src/machine-accuracy.js`|再現可能な個体抽選・固有方向・離散探索|
|`src/machine-accuracy-ui.js`|新品／中古・初期／現在／参考最良・練習評価|
|`src/accuracy-ui.js`|構造別の姿勢・直角度・コラム配置・代表位置比較|
|`src/tester.*`|電気教材|
|`docs/ui_scope.md`|画面・機能の一覧|
|`docs/verification.md`|検証方法・結果|
|`docs/qa-mobile.html`|携帯寸法のブラウザ確認用iframe|
|`tests/`|計算・動線・測定条件の検証|

```sh
node tests/check-leveling-engine.cjs
node tests/check-leveling-ui.cjs
node tests/check-accuracy-engine.cjs
node tests/check-accuracy-review.cjs
node tests/check-accuracy-render.cjs
node tests/check-mobile-navigation.cjs
node tests/check-electrical-full.cjs
node tests/check-tester-lesson.cjs
node tests/check-full-code-review.cjs
node tests/check-random-accuracy-review.cjs
node tests/check-mechanical-audit.cjs
node tests/check-interface-audit.cjs
node tests/check-leveling-learning.cjs
node tests/check-3d-axis-controls.cjs
```

粗レベル出しと本体＋支持の合成姿勢の追加検証（既存14種類とは別）：

```sh
node tests/check-level-stages.cjs
node tests/check-canvas-labels.cjs
```

9構造／方式、独立したGram構成・支持勾配・四元数回転による合成姿勢、固定倍率と支持調整の連動、平均目安と残る精度、粗／微の量切替、矢印方向の固有成分1回と実可動部中心への追従、保存復元を確認します。

Canvasのラベル追加検証は、6つの実表示寸法・9構造／方式・4視点・各軸選択の672フレームで、全軸名の保持、文字背景の非重複、支持点の丸との非重複、画面内配置を確認します。狭い絵の部品名は最低20pxの間隔を保ち、選択軸の部品・ベース／コラムを優先して必要時だけ省略します。
