# 社内訓練ツール

電気・機械の操作をブラウザで練習する、依存ライブラリ不要の訓練シミュレーターです。携帯では上の機械と基準軸に対する直角図を常時表示し、下の操作・説明だけをスクロールします。PCの機械訓練でも左の模型と変化表示を常時見ながら、右の操作・説明をスクロールできます。

## 使い方

`index.html` をブラウザで開きます。GitHub Pagesからも利用できます。教材の操作はネット接続なしでも動き、公式資料へのリンクだけ通信が必要です。

### 機械 → 工作機械のレベル出し

- 構造・方式を選び、同じ個体のランダムな初期レベルと本体の固有精度から始めます。新品／中古の個体抽選を保持します。
- 「粗調整」は平均の左右・前後の高い側と気泡を確認。「精調整」は直角の変化と本体＋支持の合成姿勢を確認します。共通の支持点を「上げる」「下げる」で操作します。
- 学習画面は測定値・調整量・乱数種・単位・倍率の数字を示しません。旧数値入力と計算用DOMは非表示で保持し、旧詳細欄を開いても数字は表示されません。機種名の「5軸」「2軸」は残します。
- 新規開始は粗調整。粗／精の切替は操作量だけを0.01／0.001 mmへ変え、個体・支持高さ・初期比較を変えません。旧記録の調整量は読み込み時に保持します。
- 操作欄の表示は「上げた／下げた／未調整」です。「未調整」は水平・直角を意味しません。内部の支持高さは従来の−0.500〜＋0.500 mm、0.001 mm刻み、初期からの調整量入力APIを維持します。
- 固定表示のXY/XZ/YZ直角図に、破線の直角基準・薄い初期線・現在の色線・間の変化面を表示。XY/XZはX基準、YZはY基準、旋盤XZは主軸Z基準です。角度差を5000倍固定で拡大し、初期／現在の範囲外を明記します。
- 初期と現在は同じ今の軸位置・支持寸法・コラム配置・評価長で比較します。広がる／狭まる方向と、直角に近づく／離れる評価を分け、同じ剛体側や平面支持で変化しない関係はそのまま示します。
- 粗の手本は支持点を同じ高さへ、精の参考例は既存探索の支持高さを実際に適用します。手本と手動練習を区別し、ヒントは実評価が改善する候補だけを示します。
- 精調整を始めた状態からの総合評価を別に比較します。初期との差の図は累積比較なので、精調整の総合評価が改善しても、各直角が初期より良くなるとは限りません。
- 模型を左右ドラッグ／矢印キーで回転。半透明の部品名と支持点、色付き軸矢印、選択部品の同色表示、固定した姿勢の強調、支持面マップを保持します。
- 模型直下の専用バーで軸を選択。「軸操作」は独立してスクロールする説明欄に位置調整・デモ・中央復帰・方式切替を表示します。旋盤はXZ、5軸はXYZACです。
- 状態パターン、ねじれ・コラム姿勢の例、据付位置、同じ個体の別支持問題、別個体抽選、表示設定、構造説明、保存・読込を維持します。軸位置と据付位置の読み上げも方向で示します。

まず粗調整で平均の傾きを目安へ近づけ、精調整で直角と姿勢の釣り合いを比べます。粗の教材目安は平均左右／前後各±0.02 mm/m、精の目安は既存の参考最良との差です。精調整のために平均の傾きが少し動く場合があるので、粗完了を切替の条件にはしません。調整目安内は実機の合格や完全な直角を意味しません。本体の固有直角差・倒れ・ガイドPVや支持姿勢に残る誤差も確認します。

「軸操作」を開くと説明・操作欄だけが先頭へ移り、閉じるボタンへフォーカスします。「閉じる」またはEscで専用バーへ戻ります。携帯の縦画面では説明・操作欄は下、横画面とPCでは右です。小型機は「立形・片側コラム」の「この構造の方式／サイズ」で選びます。

「調整データを保存」は現在の個体・実支持高さ・寸法・配置・軸位置を従来形式のJSONで書き出します。非表示リンクを一時的に接続してダウンロードを開始し、除去後もBlobを30秒保持します。開始失敗時は再試行の案内を表示します。精調整開始時の画面比較は保存schemaへ追加せず、再読込・JSON読込・初期戻し・別支持問題・個体／計算条件の変更では破棄します。

3点支持は平面、格子支持は双線形補間した学習用面です。抽選した固有角度へ支持姿勢を重ね、工具側と案内側の相対方向を計算します。共通平面の傾きや同じ参照姿勢の軸対は直角差を変えません。固定ガイドの曲がり成分は支持調整で消えません。参考最良はモデル内の探索例です。寸法・支持点・抽選率は実機仕様や市場統計ではなく、剛性／荷重解析・加工誤差の予測・実機合否判定は扱いません。式と限界は `docs/leveling-model.md` を参照してください。

### 電気 → テスターの使い方

- DC電圧：1.5／1.0 V、逆極性
- AC電圧：低電圧6 V実効値、向きの比較
- DC電流：3 V／120 Ωの理想回路、25 mA、直列接続
- 抵抗：100 Ω／1 kΩ／10 kΩ
- 導通：正常／断線、模擬ブザー表示
- 端子・モード・準備の確認、誤接続遮断、測定中ロック、終了手順、5教材の完了記録

電流端子の並列接続は遮断します。実機の商用電源や制御盤は教材対象外です。音は表示のみで、記録はページ再読込で初期化します。詳細は `docs/tester_basics.md` を参照してください。

## 編集・ビルド

`src` のHTML・CSS・JavaScriptを編集し、リポジトリのフォルダで実行します。

```sh
python3 build.py
```

ルートの `index.html` にすべての教材を埋め込みます。

|ファイル|用途|
|---|---|
|`src/app.js`|機械一覧・部品移動・3D描画・画面移動|
|`src/leveling.js`|純粋なレベル計算エンジン|
|`src/leveling-ui.js`|支持点・水準器・結果・練習・保存の連動|
|`src/machine-accuracy.js`|再現可能な個体抽選・固有方向・離散探索|
|`src/machine-accuracy-ui.js`|新品／中古・初期／現在／参考最良・練習評価|
|`src/accuracy-ui.js`|構造別の姿勢・直角度・コラム配置・代表位置比較|
|`src/tester.*`|電気教材|
|`docs/ui_scope.md`|画面・機能の一覧|
|`docs/verification.md`|検証方法・結果|
|`docs/qa-mobile.html`|携帯寸法のブラウザ確認用iframe|
|`tests/`|計算・動線・測定条件の検証|

```sh
node tests/check-leveling-engine.cjs
node tests/check-leveling-ui.cjs
node tests/check-accuracy-engine.cjs
node tests/check-accuracy-review.cjs
node tests/check-accuracy-render.cjs
```

粗／精工程・半透明注釈・直角図の追加検証（既存14種類とは別）：
