# 社内訓練ツール

電気・機械の操作をブラウザで練習する、依存ライブラリ不要の訓練シミュレーターです。機械訓練の主画面は模型・水準器・直角図とレベル調整に集中し、細かな設定と説明は「☰ 設定」へまとめています。設定を開くと主画面が右へ縮小し、左のメニューだけをスクロールできます。全画面共通の移動バーからトップ・戻る・機種選択へ移動できます。

## 使い方

`index.html` をブラウザで開きます。GitHub Pagesからも利用できます。教材の操作はネット接続なしでも動き、公式資料へのリンクだけ通信が必要です。

### 機械 → 工作機械のレベル出し

- 構造・方式を選び、同じ個体のランダムな初期レベルと本体の固有精度から始めます。新品／中古の個体抽選を保持します。
- 機械の右の専用枠に平均レベルの水準器を常時表示。左右は横向き、前後は縦向き（上が奥、下が手前）で、気泡は平均で高い側へ動きます。説明・操作欄をスクロールしても一緒に確認できます。
- 「粗調整」は平均の左右・前後の高い側と気泡を確認。「微調整」は直角の変化と本体＋支持の合成姿勢を確認します。共通の支持点を「上げる」「下げる」で操作します。
- 主画面のXY/XZ/YZの3枠は、直角マスタに計器を当て、開始接触を0にした300 mmの仮想測定を表示します。＋は押込み増加、−は減少、1 µm刻み。実機の測定値やNC座標ではありません。詳細は[測定モデルと全19面の配置](docs/reference-scan-20261007.md)。
- 主画面は粗調整／微調整を選び、支持点を選んで共通の上下ボタンで操作します。粗は0.01 mm、微は0.001 mm。旧記録の調整量は読込時に保持し、共通上下操作時に選択段階の規定量へ揃えます。個体と初期比較は変えません。
- 詳しい段階の状態、実候補の方向、調整の手本は設定メニューで確認できます。主画面の調整欄には段階切替・支持点選択・上下操作だけを置きます。
- 内部の支持高さは従来の−0.500〜＋0.500 mm、0.001 mm刻み、初期からの調整量入力APIを維持します。選択した支持点だけを調整します。
- 既存の3枠に基準器・計器固定側・接触ゼロ・相対移動・押込み方向を表示。大きい見出しや新しい操作は追加せず、UIの配置は維持します。旋盤は主軸基準XZのみ、5軸はA=C=0で直線軸検査を表示します。
- 方向合わせと接触ゼロを区別します。支持や軸位置を変えるたび、配置とゼロを自動で取り直します。初期と現在は同じ区間でそれぞれゼロを取り、開閉説明で比較できます。
- 有限走査では基準器と計器の始点・終点の相対接触を計算します。従来の局所角度300 mm換算は別項目として開閉欄に残し、支持評価・参考探索・保存データの意味は変えません。
- 小型立形のY走査はテーブル上面の「測定P」の有限軌跡を使います。Pの高さに伴う姿勢変化の影響を含みます。他機種は代表接触点の局所送り方向を積分する教材モデルです。未知のガイド曲線は追加しません。1 µm未満の変化は丸めで同じ数字になる場合があります。
- 3枠の下の▽で配置説明を開き、閉じると元の支持操作位置へ戻ります。模型・固定水準器・上下操作は表示を保ちます。
- 初期と現在は同じ今の軸位置・支持寸法・コラム配置・評価長で比較します。広がる／狭まる方向と、直角に近づく／離れる評価を分け、同じ剛体側や平面支持で変化しない関係はそのまま示します。
- 粗の手本は支持点を同じ高さへ、精の参考例は既存探索の支持高さを実際に適用します。手本と手動練習を区別し、ヒントは実評価が改善する候補だけを示します。
- 精調整を始めた状態からの総合評価を別に比較します。初期との差の図は累積比較なので、精調整の総合評価が改善しても、各直角が初期より良くなるとは限りません。
- 模型を一本指／マウスの左右ドラッグ／左右矢印キーで回転。二本指のピンチ／マウスホイール／＋・−キーで模型だけを拡大・縮小します。Homeキーまたは表示設定の「模型の大きさを戻す」で標準表示へ戻せます。表示倍率は範囲を制限し、支持高さ・軸位置・精度・初期比較・保存JSONには作用しません。操作・説明欄のスクロールは独立しています。
- 半透明の部品名と支持点、色付き軸矢印、選択部品の同色表示、固定した姿勢の強調、支持面マップを保持します。
- 模型直下の専用バーで軸を選択。設定メニューの「軸位置・デモ」で位置調整・デモ・中央復帰、「方式・サイズ」で方式切替ができます。旋盤はXZ、5軸はXYZACです。
- 状態パターン、ねじれ・コラム姿勢の例、据付位置、同じ個体の別支持問題、別個体抽選、表示設定、構造説明、保存・読込を維持します。軸位置と据付位置の読み上げも方向で示します。

まず粗調整で平均の傾きを目安へ近づけ、精調整で直角と姿勢の釣り合いを比べます。粗の教材目安は平均左右／前後各±0.02 mm/m、精の目安は既存の参考最良との差です。精調整のために平均の傾きが少し動く場合があるので、粗完了を切替の条件にはしません。調整目安内は実機の合格や完全な直角を意味しません。本体の固有直角差・倒れ・ガイドPVや支持姿勢に残る誤差も確認します。

「☰ 設定」を開くと「機械の設定」へフォーカスし、主画面が右へ縮小します。「閉じる ×」・Esc・右側の主画面を押すと閉じ、通常表示へ戻ります。共通の移動バーは設定を開いたまま利用でき、Tabでも移動できます。縮小中は主画面の操作を止め、設定内で軸位置などを変更して模型で確認します。小型機は「方式・サイズ」の「この構造の方式／サイズ」で選びます。

「調整データを保存」は現在の個体・実支持高さ・寸法・配置・軸位置を、計算仕様ID付きJSONで書き出します。小型立形は `compact-asymmetric-bending-v4`、横形は `horizontal-guide-v2`、移動コラムは `travel-guide-v2`、旋盤は `lathe-carriage-v2`、門形2機種は `portal-shear-v2`、5軸は `connected-frames-v1` です。旧計算の記録は新模型へ無言適用せず、旧ブラウザー保存を残し、計算仕様が異なるJSONの読込を説明付きで拒否します。非表示リンクを一時的に接続してダウンロードを開始し、除去後もBlobを30秒保持します。開始失敗時は再試行の案内を表示します。精調整開始時の画面比較は保存schemaへ追加せず、再読込・JSON読込・初期戻し・別支持問題・個体／計算条件の変更では破棄します。

3点支持は平面、格子支持は双線形補間を基本とした学習用面です。小型立形は左右の相対剛性が異なる2モードの板曲げ近似を追加し、中央位置でもねじれから前後の相対姿勢が生じます。右端：左端の3：1は教材仮定であり、実機の同定値ではありません。抽選した固有角度へ支持姿勢を重ね、工具側と案内側の相対方向を計算します。共通平面の傾きや同じ参照姿勢の軸対は直角差を変えません。固定ガイドの曲がり成分は支持調整で消えません。参考最良はモデル内の探索例です。寸法・支持点・抽選率は実機仕様や市場統計ではなく、実機の剛性／荷重解析・加工誤差の予測・実機合否判定は扱いません。式と限界は `docs/leveling-model.md` を参照してください。

### 電気 → テスターの使い方

- DC電圧：1.5／1.0 V、逆極性
- AC電圧：低電圧6 V実効値、向きの比較
- DC電流：3 V／120 Ωの理想回路、25 mA、直列接続
- 抵抗：100 Ω／1 kΩ／10 kΩ
- 導通：正常／断線、模擬ブザー表示
- 端子・モード・準備の確認、誤接続遮断、測定中ロック、終了手順、5教材の完了記録

電流端子の並列接続は遮断します。実機の商用電源や制御盤は教材対象外です。音は表示のみで、記録はページ再読込で初期化します。詳細は `docs/tester_basics.md` を参照してください。

## 構造と精度表示の点検（2026年10月6日）

全7機種・4/8/6/15/8/3/6点を維持し、門形の左右柱天端と梁端を共通の幾何モデルへ変更しました。L3参考の15点はベッド9点・左右柱各3点を分けて姿勢を計算します。柱前後差から梁の水平ヨー、左右天端の高さ差から梁の傾きが生じ、X案内との相対姿勢をXY/XZへ反映します。操作名で精度を強制的に悪化させません。

移動コラム・移動門形のX送りは現在の走行案内を参照します。旋盤は主軸基準XZの比較とNC送りZの矢印を区別します。門形骨格は支持姿勢、固有差は軸矢印・直角図で表します。

追加の門形改修では、梁の案内Yを左右柱の天端を結ぶ方向、ラムZを左右柱の平均倒れの方向とし、両者を強制的に直交させません。柱の左右倒れや左右高さ差がYZへ伝わる、一定のせん断変形を許す幾何教材です。模型・案内方向・直角図で同じ変形写像を使い、調整の方向と初期誤差により改善・悪化の両方を表します。

梁の弾性ねじれ・剛性・荷重・支持接触は未解析です。左右柱の平均倒れを使うため、互いに逆向きの倒れが平均で相殺する場合や、Y/Z移動による荷重たわみ・位置ごとのねじれは再現しません。実機の変化量を予測するものではありません。5軸の3点支持は平面のためXYZ内部角は不変、A/C誤差は対象外です。

## 主軸ダイヤルの旋回測定（2026年10月6日）

小型立形・移動コラム・固定門形・移動門形・5軸の5機種では、上段のXY・XZ・YZ基準器測定図（300 mm仮想走査）の右隣に、主軸ダイヤル測定を同時表示します。直径300 mmの右・奥・左・手前の4点を、手前基準の符号付き整数µmで表示します。角度は画面・読み上げに出さず、手前を基準0として示します。4点のカードで確認する点を選択できます。丸いメーター、模型上のダイヤルと取付棒、自動で1周回す操作は表示せず、測定欄の高さを詰めて機械模型の表示領域を広げています。軸選択と動作軸の色・矢印も維持します。

狭い縦画面は直角3図を左に縦並び、ダイヤル4点を右に2×2で表示します。短い横画面は測定欄を画面幅全体に広げ、下に模型と調整欄を左右に配置します。調整欄の高さが足りない場合も、下げる／上げるは固定し、粗調整／微調整・支持点選択だけを内部スクロールできます。横形と旋盤にはダイヤル測定を表示しません。

主軸軸線とテーブル上面法線から計算します。NC送りのXY/XZ/YZ値を流用しません。手前を毎回ゼロとし、＋は測定子が押し込まれる側です。支持調整、テーブルの移動位置、コラムの前後・左右の姿勢差が反映されます。同じ剛体の共通回転は値を変えません。測定子が上面の外に出る点は「面外」とし、手前の基準点が外れると全点の数値を省略します。

機械模型には従来のワークとT溝模様を表示しますが、4点の計算対象は理想的なテーブル上面です。主軸軸線が既存の主軸側姿勢と一致する、上面は理想平面、ゲージは理想的という教材の仮定です。テーブル平面度、主軸回転振れ、接触力・取付たわみ・測定器誤差は再現しません。

追加4機種は既存の支持・送り・固有姿勢から主軸とテーブル上面を求めます。門形は既存の代表主軸方向に固有姿勢を含めますが、模型の外形は従来どおり支持姿勢を示す簡略形状です。5軸はA/Cの親子回転と有限テーブル面を反映し、Aの意図的な傾斜も測定値に含めます。Cで平面の傾きは変わらなくても、寸法により面外判定が変わる場合があります。

5軸の3点支持は平面モデルのため、A/Cが同じなら支持調整で機械全体が一緒に傾き、相対読みは変わりません。移動門形も主軸とテーブルが同じ姿勢となる位置では読みが変わらない場合があります。支持操作のたびに数値を強制的に悪化・変化させません。

測定表示と4点の選択は閲覧用状態で、個体・支持・軸位置の保存形式を変更しません。既存の直角度・水準器・固有誤差の計算と、小型立形の従来の4点読みは維持します。

## 旧・直角の立体基準図と方向表記（2026年10月6日）

以下は過去の実装記録です。現在の3枠は[2026年10月7日の有限仮想測定](docs/reference-scan-20261007.md)に更新しています。

XY・XZ・YZを板状の立体図で表示し、O（説明用ゼロ）、基準辺、比較方向、理想Iと現在P、300 mm換算点、＋／−を示します。機種ごとの軸配置に合わせ、門形のXは奥・Yは右、横形のYは上・Zは奥として図の投影と説明を対応させます。旋盤は主軸Z基準XZのみです。

上段の「基準図」で、下側のスクロール欄に詳しい方向・符号・仮想接触の説明を開けます。模型・水準器・測定値と下げる／上げるは固定領域に残ります。図のOは現在位置の局所軸方向を重ねる説明用始点であり、実機の参照位置を変更しません。＋は直角より広い、−は狭い。局所角度の300 mm換算を維持し、実際の300 mm走査・新しい測定子変位計算は行いません。

この表示変更では計算エンジン・保存形式・保存キー・支持配置を変更していません。詳細は[測定基準の仕様](docs/measurement-reference-20261006.md)を参照してください。
