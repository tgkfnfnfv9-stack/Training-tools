# ページ再入場の再抽選と小型立形YZの追加点検

作業開始時の公開mainは `97297100d21d6292567e664a7ccd1763e116d9de`、ローカルは `a61469d1dbc113bf38b28a2cac2c201b2ae0b10d`、作業ツリーはクリーン。前回の修正を保持したまま追加した。公開mainへの巻戻しは行っていない。

## 要望と変更

ユーザーの「ページ変わると、リセットして再抽選したい」に合わせ、機種画面への再入場、同機種の再選択、再読込後の機種選択、同機種の履歴復帰、ブラウザーキャッシュからの訓練復帰で、新しい個体・初期支持高さへリセットする。

設定の開閉、軸・支持操作、測定表示切替など、訓練画面内の操作では再抽選しない。異なる機種の古い履歴は従来どおり機種選択へ戻し、選び直した機種で新規開始する。JSONを明示的に保存・読込する機能は維持する。ブラウザーへの状態記録は続けるが、自動復元はしない。JSON形式・測定式・支持補間の変更はない。

原因コードは `src/leveling-ui.js` の `initializeLeveling` にあった自動復元と、`src/app.js` の `resumeOrOpenMachine` にあった同一機種の復帰処理。新規入場に統一した。旧説明「画面を切り替えても個体は変えない」も独立確認で検出し、画面内操作とページ再入場を区別する説明へ訂正した。

## 小型立形YZで再現した現象

ユーザーから「コラムが前倒れから後倒れになっても、YZの数字が改善しない」と具体的な指摘を受け、支持調整を掃引して再現した。

模型の前後倒れは床の鉛直に対する姿勢。一方、YZ有限測定は、開始位置の測定PのY送り接線へマスタを方向合わせし、奥側上端でゼロ、主軸頭のZを300 mm下へ動かした接触差である。主軸回転中心線の検査とは区別する。

同じ回転QをY方向uとZ方向vへ加えても、内積は `(Qu)・(Qv)=u・v`。接触の始終点と面・測定子も共通回転するため指示差が変わらない。床に対して柱を立てる操作と、Y/Zの相対誤差を直す操作は同じではない。

新品範囲の固有YZ成分+12 µm、XY=XZ=0、既定寸法・軸位置中央、対角支持成分±0.05 mmを固定した例：

|共通の前後傾斜用支持成分|柱の床基準前後倒れ（＋前／−後）|Y送り接線の上向き角|300 mm有限YZ|
|---|---:|---:|---:|
|+0.4 mm|+418.049 µrad|+376.453 µrad|−12.478625 µm|
|0 mm|+47.679 µrad|+6.083 µrad|−12.478625 µm|
|−0.4 mm|−322.691 µrad|−364.288 µrad|−12.478625 µm|

柱が前から後へ横切る一方、Y側も追従する。ここでYZが一定なのは、接触計算や符号の反転漏れではない。

さらに、現行の小型立形の曲げ仮定は初期の寸法・コラム配置・中央付近のYZに対する支持調整感度が小さい。上の固有成分+12 µmについて、各支持±0.5 mmの16組を比較した結果：

|X・Y位置（スライダー）|16組で観測した有限YZ値の幅|
|---|---:|
|0・0|−16.758080〜−7.179320 µm|
|+100・+100|−66.790624〜+42.829907 µm|
|−100・−100|−73.507473〜+49.596234 µm|

最終独立レビューでは、X=Y=0でもコラムXを−100へ移すと、対角支持成分−0.5／0／+0.5 mmで約−82.38／−12／+58.45 µmとなることを確認した。この指摘を受け、追加説明を「初期の寸法・コラム配置」に限定して再修正した。

16組の比較は連続した全調整域の極値証明ではない。「YZはどの位置でも改善できない」とも言えない。中央と端で大きく感度が変わること、中央では抽選誤差に対して支持調整の効果が小さいことが、今回の症状を説明する。

## YZについて修正したもの・変更しなかったもの

`src/accuracy-ui.js` の `bodyLeanNote` と `src/reference-measurement-ui.js` の小型YZ測定説明へ、床基準の柱倒れと相対測定の違い、共通傾斜で値が変わらないこと、初期の寸法・コラム配置・中央付近の弱い調整効果を追加した。大見出し・新しい操作は追加していない。

```text
従来：柱が前倒れ → 支持調整 → 後倒れ
      YZが変わらない理由が画面から分かりにくい

修正後：柱の床基準姿勢 ／ Y送りに対するZ送り を説明で区別
        共通傾斜ではYZ一定、中央の曲げ感度は小さいと明記
```

YZの数値を改善しやすくするための曲げ係数・固有誤差・計算式の変更はしていない。現在の説明修正によって調整可能幅そのものが増えたわけではない。新しい曲げモデルへの置換は別の仕様変更になる。

## 検証と限界

修正担当と独立確認担当を分離。ページ再抽選は全7機種の状態遷移と実ブラウザー操作、YZは独立幾何計算と実ブラウザーを用い、追加後に別担当が再確認した。最終結果・画像・ソース固定記録は [QAフォルダー](qa-yz-redraw-20261007/) を参照。

独立幾何テストは、曲率エネルギーを単項式積分して2つの曲げ係数を独立に解き、材料点Pを構成・差分微分してY接線を求め、面と測定子の交点からYZを求めた。既存の描画関数や符号表を期待値にしていない。ただし、2モードの変形形、剛性比3:1、ポアソン比0.3、取付高さ0.50 mなどの教材仮定を検証対象として共有しており、実機に妥当な仮定であることを実証するものではない。

現時点の分類：

- 一致：奥上ゼロ→下降、奥側接触・押込み符号、正負既知角度、捻れ、材料点接線と有限指示、共通回転不変性。
- 修正済み：ページ再入場の旧復元動作、復帰に関する古い説明、床基準の柱姿勢とYZ相対値の説明不足。
- 残るモデル上の制約：初期の寸法・コラム配置・中央付近のYZ調整感度が小さく、柱の見かけの前後倒れを直しても固有YZ誤差が残り得る。
- 未確認：実機の剛性・荷重・接触、実機での支持調整感度、全連続経路・全支持状態の最適値、NC/A/C方向適合。
