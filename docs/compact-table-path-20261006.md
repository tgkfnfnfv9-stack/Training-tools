# 小型立形：テーブル上面Pの送り角（2026-10-06）

この文書はv3時点の記録。後続のv4では、左右剛性差を仮定する前後曲げ近似を追加した。最新の仮定と検証は [compact-bending-20261006.md](compact-bending-20261006.md) を参照。

対象は小型立形・4点支持のみ。点検開始時のmainは `2bce8c259c13aee8edb5d6cd83da09963da3e443`。全7機種の構造点検は [structural-audit-20261006.md](structural-audit-20261006.md)、共通仕様は [leveling-model.md](leveling-model.md) を参照。

目的は、支持調整によるねじれと、移動中のサドル姿勢変化が測定点の送りへ及ぼす影響を学べるようにすること。機械の取付軸直角と、測定位置で観察する送り角を区別する。実機の変形量や精度検査結果を予測するモデルではない。

## 変更前の原因

`compact-saddle-v2` はXとYへ同じサドル姿勢を与えていた。同じ剛体回転は内積を保つため、両軸の内部取付角は支持調整で変わらない。この不変自体は幾何学的に正しい。

一方、サドルはY送りでベッド上を移動し、ねじれ面では位置に応じて左右の傾きが変わる。支持基準から離れたテーブル上の点は、その姿勢変化でも左右へ移動する。旧3Dはこの点の移動を既に描いていたが、直角図には同一時点のサドルの軸方向だけを使っていた。そのため、測定点の送りを観察する教材としては、模型運動と比較している量が一致していなかった。

Xテーブル送りでサドルのベッド参照までX移動させる旧処理へ戻す変更ではない。サドル参照はYだけに追従させたまま、その上の点の運動を評価する。

## 新しく比較する量

模型のテーブル上面中心に仮想測定点 **P** を置く。既存模型では上面の内部高さが `1.16`、支持姿勢の基準が `0.66` なので、その距離は `H=0.50 m`。これは既存の教材寸法から定義した距離で、メーカーのテーブル高さ・案内高さではない。Pはテーブルに固定された点であり、X/Y送りに追従する。

支持高さ、軸位置、固有誤差から、誇張前のPの位置を一つの運動写像として求める。そのX送り・Y送りによる局所接線を正規化し、それぞれX/Yの比較方向とする。Zは柱側の主軸頭送り方向を使う。

- XY：テーブル上面PのX送り接線とY送り接線の角度。
- XZ／YZ：Pの各送り接線と、柱側Z送り方向の角度。
- 300 mm比較：その位置での局所角度差を300 mmへ換算した量。実際に300 mm走査した軌跡の直線当てはめや、石定盤・直角定規を測った結果ではない。

したがって、表示は **テーブル上面Pの局所送り角を300 mm換算したもの（Abbeの影響を含む）** であり、Abbe補正済みの機械固有直角度ではない。保存済みの固有直角誤差そのものを支持調整で書き換えない。

## 採用する幾何学的仮定

共通の平均平面を適正な剛体回転として外側へ適用し、その中で支持面の残差高さ・残差姿勢を扱う。共通の傾きと部位間の変形を混同しない。固有誤差は運動写像に一度だけ合成する。同じ写像をP、模型の部品、軸方向と比較図へ使用し、表示の強調倍率や視点・ズームは精度計算に入れない。

固有誤差を除いた局所形は、Yサドルの基準位置を `S(q)`、姿勢を `R(q)`、X送りを `x` として、概ね次の関係で説明できる。

`P(x,q) = S(q) + R(q) [x,H,0]`

内部座標の並びは左右・上下・前後。Y送り接線には `S'(q)` だけでなく `R'(q)[x,H,0]` が含まれる。この後者を無視して、常に姿勢フレームの奥方向だけをY送り方向とすると、有限高さの影響が抜ける。

小さい傾きで左右勾配を `a(q)=∂h/∂x`（高さmm、水平距離m）とすると、Pの左右位置にはおよそ `−H*a(q)/1000` が入り、Y送りに伴う左右変化は `−H*a'(q)/1000` となる。これは独立した幾何的導出であり、支点名や操作回数からXYへ数値を追加する規則ではない。

四隅の左手前だけを `Δh` 上げ、他を0とした双線形面では、混合微分は `Δh/(幅×奥行)`。微小角・中央位置の一次近似は `δXY ≈ H*Δh/(幅×奥行)/1000` radとなる。ねじれが反転すれば符号が反転し、固有誤差との相殺によって改善も悪化も起こり得る。共通平面だけなら姿勢は位置によらず、追加のAbbe項は生じない。

## 実装前の独立確認

旧mainの誇張なし3Dから同一の点をX/Yへ微小移動させ、中央差分の方向を内積で比較した。支持はA左手前だけ `+0.01 mm`、固有誤差なし、幅 `2.08 m`、奥行 `2.16 m`、軸位置中央。

|点の基準面からの高さ|旧3Dから得たXY軌跡角|独立一次近似|
|---|---:|---:|
|0 m|一次項なし（有限角の高次項は残る）|0|
|0.50 m：テーブル上面|1.112885 µrad|1.112892 µrad|
|0.89 m：ワーク上面|1.980940 µrad|1.980947 µrad|

旧直角図のXYは同条件で0だった。この比較は欠落していた測定位置の影響を確認するためのもので、新実装の期待値を旧計算表示から作ったものではない。新実装の値は共通回転・残差の整理により有限角の高次項が異なり得るため、上表を無条件の完全一致値とはしない。

## 再現しない現象と検証条件

支持面は幾何補間であり、ベッド剛性、サドルの有限接触、荷重移動、取付部の弾性変形、摩擦、バックラッシュ、熱変位を解かない。独立した水平ヨー、実測されたガイド真直度曲線も追加しない。ワークの任意高さでの加工精度、定規と測定子の接触・定規自体の姿勢変化を含む実機検査手順全体は再現しない。

独立検証では、一様高さ変更・共通平面で内部角を維持すること、ねじれの符号反転、Hが0のときの一次項消失、逆操作による復元、固有誤差の保持を確認する。Pの移動を有限差分して比較方向と照合する。模型強調・回転・ズーム・画面切替が計算を変えないことと保存再現も確認する。

操作1回ごとに全ての表示数値が必ず変わるとは保証しない。方向成分がない操作、相殺、表示丸めによる不変を許容する。例えば平坦・固有誤差ゼロからAを粗調整1回だけ上げたとき、標準教材寸法のXYは約 `0.334 µm / 300 mm` 変わるが、整数µm表示は `0` のままとなる。計算値を強制的に1へ増やすことはしない。

数量の意味が変わるため小型立形の計算仕様を `compact-table-path-v3` に分ける。旧 `compact-saddle-v2` や `connected-frames-v1` の保存を無言で新しい意味へ読み替えず、旧保存は保持する。

## 構造確認担当の実装後再点検

`compactPathFrames` は双線形面と姿勢の解析微分からPの送り方向を求める。模型のワーク側とPマークは同じ位置写像を使い、Y矢印はその接線を示す。数値の微小差分を本体計算へ入れず、差分は独立した検証側で用いた。

- 固有誤差の有無、平坦・片隅上下・共通平面・純ねじれ・ねじれと共通平面、X/Yの端寄りと中央を組み合わせた144確認が成功した。実際の模型変換でPを微小移動させた中央差分からXY角を求め、計算角との差の最大は `7.60×10^-7 µrad` 未満。一様高さ加算でも各角度が保たれた。
- 固有誤差を含む平坦／ねじれに共通平面を追加した18確認が成功した。全軸対の角度差の最大は `7.47×10^-14 µrad` 未満。平均平面を外側の剛体回転へ分けたモデル内で、共通回転による架空の精度変化はない。
- 別の確認担当が作成した `tests/check-compact-table-path.cjs` を再実行し166確認成功。独立したねじれ式、高さ依存、模型接線と矢印、固有誤差保持、表示倍率の分離、粗調整1回の丸め、保存互換の扱いなどを確認した。

画面説明には、Pの高さが支持基準から0.50 mであること、Abbeの影響を含む局所送り角であること、300 mmの実走査や補正済み固有直角度ではないことが明記されている。以上は教材の幾何的整合性の確認であり、特定の工作機械の応答量との一致を検証したものではない。
