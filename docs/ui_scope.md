# UI試作の範囲

## 画面の流れ

1. トップ：電気／機械
2. 機械：工作機械のレベル出し
3. レベル出し：7カテゴリの構造カード
4. 訓練画面：3D模式図、支持点配置、水準器の配置、調整欄、結果欄

電気は準備中です。パンくずと「機械を選び直す」で前の画面へ戻れます。

## 訓練画面の配置

|領域|PC|スマホ|
|---|---|---|
|3D・構造説明|左側|上側|
|状態パターン・水準器|右側の上|3D・構造説明の後|
|支持点・高さ調整|右側の中央|水準器の後|
|調整による変化|右側の下|高さ調整の後|

3Dは左右回転のみです。上下の指操作はページのスクロールに使います。

## 3Dの前提

- ベース、コラム、主軸、テーブル、支持点の位置関係を示す模式図。
- 代表機の外観、寸法、実際の支持点配置を再現していません。
- 軸別の部品移動と一往復のデモを追加。レベル調整計算は未実装です。
- 支持点の数はUIで3点・4点・6点・8点を比較するための学習用設定です。
- 後で機種別の支持点データと調整計算を追加できるよう、機械情報を一覧で管理しています。

## 構造と軸の表示

ロボドリル系と標準立形を「立形・片側コラム」に統合。門形構造の立形と大型固定門形を「固定門形」に統合し、テーブルXY方式と長手テーブルX＋主軸側Y方式を切り替えます。構造の外観だけで移動方式を同一視しないため、方式は残しています。

軸は赤X・緑Y・青Zで表示。選んだ軸によって動く部品を同じ色で強調します。固定部は灰色、部品名には［固定］または所属軸を付記。スライダーと一往復デモは部品の親子関係に従って動きます。3Dの左右回転はカメラ視点の回転で、機械の軸移動とは別です。

詳しい軸割当は `axis_mapping.md` を参照してください。
