# 訓練機能と画面

## 画面遷移

トップから「機械 → レベル出し → 構造選択 → 訓練」、または「電気 → テスターの使い方 → 訓練」へ進みます。パンくずと各訓練の戻るボタンで戻れます。

|領域|PC|携帯|
|---|---|---|
|機械の3D・電気の接続図|左。機械訓練は模型と変化表示を常時表示|上に常時表示|
|操作と説明|機械訓練は右だけ独立スクロール。表示設定・構造説明・保存も同じ欄|下だけ独立スクロール|
|横向きの低い携帯|—|絵を左、操作を右|

機械の3Dは、絵を左右にドラッグするか矢印キーで回転します。模型直下の専用バーで軸を選び、「軸操作」を押すと説明・操作欄の先頭にメニューを表示します。Canvasは描画専用で、操作部品が機械・支持点・矢印を隠しません。メニューの開閉はCanvasの位置・サイズに影響せず、説明・操作欄だけが独立してスクロールします。以前の拡大縮小・回転の5ボタン列と、「どこが動く？どこが固定？」の説明カードはありません。支持点を操作中も、上の直角図で基準軸に対する現在の角度を確認できます。図はCanvasと分かれて機械を遮りません。機械の軸移動、視点回転、支持点高さの操作は別です。

320px幅でも軸選択の各ボタンは44px以上を確保し、狭い横向きの左領域では専用バーを折り返します。メニューを開く際は説明・操作欄だけを先頭へ移動し、「閉じる」にフォーカスします。「閉じる」・Esc・デモ開始・方式切替後は、模型直下の「軸操作」へフォーカスを戻します。

軸名・部品名の背景は約12〜15%、支持点の背景は通常15%／選択黄30%の不透明度で模型を透かします。文字と支持点の輪郭は読みやすく保ち、軸の矢印・選択部品の色・操作ボタンは維持します。

小さいCanvasでも支持点の丸と全軸名を優先します。軸名はCanvas全域の候補から重ならない場所へ配置し、部品名は最低20pxの間隔で選択軸の部品・ベース／コラムを優先、足りない部品名のみ省略します。構造・軸構成の説明は操作欄に残ります。

X/Y/Zの座標の目安は、模型Canvasから説明・操作欄の「模型の表示設定・色の見方」へ分離しています。「模型の向き（座標の目安）」では軸ごとに独立した固定viewBoxの小図を並べ、模型の左右回転に追従します。文字は各小図の上に固定し、方向線と重なりません。狭い欄では小図を折り返します。旋盤はX/Zの2枚、他はX/Y/Zの3枚で、5軸のA/Cは模型上の曲線矢印です。「軸の矢印を表示」のOFFは両方に反映されます。小図は視点の向きだけを示し、支持姿勢・固有精度・NCの＋／−指令は表しません。

操作・説明欄は「粗調整」「精調整」の独立パネルと共通の支持点操作です。新規は粗、保存記録は元の調整量から段階を推定します。タブ切替は操作量のみを変更し、個体・実支持高さ・初期の基準を維持。平均の目安未達でも精へ切り替えられます。

粗は平均左右／前後の高い側と気泡を示します。精は初期／現在の直角と変化面、合成倒れ・支持ねじれ、全代表位置の総合評価を示します。支持欄には現在段階・目安の状態・実候補の方向を短く表示し、支持カード内だけ上端へstickyで保持します。長い説明は各段階のパネルに残します。目安内は状態を優先し、単独候補がない場合は参考例を案内。上下ボタンのフォーカス移動は上端の案内分のスクロール余白を確保します。学習画面は精度値・操作量・seed・計算用評価長・倍率・閾値の数字を出さず、旧数値欄や入力はhiddenで非表示／非フォーカスにします。測定位置の専用目印「0」「O（0,0）」「300 mm」は表示します。JSONと計算DOMは保持します。

初期比較と精開始比較は別です。直角図は抽選時からの累積変化を同じ現在位置で計算。精開始時の総合評価はUIだけに保持し、読込・初期復帰・別支持問題・個体／条件変更で破棄します。全体評価が目安内でも各直角の改善や本体誤差の消失は宣言しません。

直角図は共通始点O（0,0）で測定のゼロを合わせ、測る軸に固定300 mmの比較終点を示します。測定方向はXYがY、XZがZ、YZがZ、旋盤XZはXです。白い点は理想の直角、色の点は現在の終点、点を結ぶ細線は理想との差。初期／現在を結ぶ変化面とは別です。始点合わせは初期精度ゼロを意味しません。固定長の局所角度の模式比較で、実NC座標・実移動・ガイドの全域走査を計算する図ではありません。固定図の高さと機械の描画領域を維持し、長い意味の説明は操作欄へ置きます。詳細図は軸対ごとの最小幅を確保し、狭い欄では図の中だけ横スクロール可能。キーボードで図へフォーカスして左右へ動かせ、旋盤の単独図へ不要な横スクロールは増やしません。

## 機械の機能

|機能|動作|
|---|---|
|構造選択|7カテゴリ、立形サイズ／固定門形方式を切替|
|部品移動|XYZACの所属軸・親子追従。全軸に同色の矢印、選択軸で動く部品を同色で強調。旋盤はXZのみ、5軸のACは曲線矢印|
|座標の目安|表示設定欄の軸別小図で模型の左右回転に追従。模型・部品名の説明線・他軸の方向線と重ならず、狭い欄は折り返し|
|軸操作|模型直下で軸を選択。説明・操作欄のメニューで選択軸の位置・動作確認・中央復帰・方式切替。閉じても軸位置を保持|
|支持点|3・4・6・8点を選択。上げる／下げると未調整／上げた／下げたの状態。内部入力は初期からの調整量、実支持高さ±0.500 mmへ変換|
|個体差|新品／中古、教材設定の確率でガイドPV・固有直角度を固定乱数抽選|
|合成姿勢|既存個体の固有方向＋支持姿勢で現在のコラム倒れを表示。初期成分・初期との差の数値は伏せる。旋盤は主軸の水平面／上下方向差|
|精度|固有軸方向＋支持姿勢の合成を保持。現在／初期の直角と変化、倒れ・ねじれを定性表示。現在値・初期値・差分の数値は非表示|
|直角図|固定表示の全XY/XZ/YZ。XY/XZはX、YZはYを基準に固定。旋盤はXZのみZ基準。始点0と測定軸の矢先・300 mm比較終点、白い理想点と色の現在点の差線。破線直角・薄線初期・色線現在・間の変化面、角度差5000倍固定、正は広い／負は狭い。初期／現在の表示限界は「図の範囲外」。支持点・軸位置に連動|
|初期との比較|内部では両方を同じ現在の軸位置・支持寸法・コラム配置・評価長で再計算し、初期値と差分は数値を伏せて定性的な増減を示す|
|固定成分|ガイドPVと固有直角差はこのモデル内部の固定成分として保持。個体の初期成分は数値を伏せる。据付による案内真直度の変化は計算対象外|
|代表比較|全直線軸27位置、旋盤9位置。角度表示の評価長と300mm調整判定は独立|
|プリセット|右高・手前高・対角ねじれ・中間支持高。該当しない配置は無効|
|寸法|既存の仮想寸法と保存記録を計算へ反映。数値入力はhidden|
|水準器|粗パネルに平均左右・前後の気泡。既存局所水準器と感度の計算DOMはhiddenで保持|
|測定位置|軸位置は方向を表示／読み上げ。旧局所測定位置の保存・計算を保持|
|3D高さ|mmをmへ換算。個体・寸法・配置から固定した倍率（最大1000倍）で本体代表方向＋支持姿勢を模式表示、支持調整と連動。矢印は固有方向を1回だけ合成し中心を実可動部へ追従。支持面分割マップ|
|結果|粗は平均方向・目安内、精は既存参考評価の目安・残る誤差。旧数値結果はhidden|
|幾何比較|既存換算・計算を保持。旧数値換算欄はhidden|
|学習|まず平均の粗レベルを整え、残る精度を見て同じ支持点を微調整。1支持点ずつ小さく調整し、倒れ・ねじれ・各直角度がどう変わるか理解。図と定性状態を見ながら調整。未調整は水平・直角を意味しない|
|補助練習|参考最良・自動適用・据付状態の出し直しは補助。300 mm集約評価で探索例との残る調整余地を判定|
|保存|機械・方式別にブラウザ自動保存、個体種・0.001mm刻みの高さ・参考最良・配置・軸位置のJSON保存／読込、旧データ移行|

## 電気の機能

DC電圧・AC電圧・DC電流・抵抗・導通の5教材。端子、モード、対象、向き、配線、準備、接続を変更できます。測定中は変更をロックし、解除後に設定を変えます。DC電流は直列接続と電源OFFの準備が必要で、並列接続は遮断します。

教材完了は基本操作を1回終えた記録です。値や向きの比較は追加練習。ページ内で保持し、全記録初期化または再読込でリセットします。

## 計算の意味

支持点を通る面を補間する学習モデルです。3点支持では必ず平面となり、ねじれと残差は0です。4点以上の補間面では、中間支持による局所傾きを全体平均や両端差だけで見落とさないよう判定します。

メーカー別のCAD・支持荷重・剛性・据付手順・許容値は、この仮想モデルに置き換えられません。実機を調整する場合は、その機種の据付仕様と別途の幾何精度検査を優先します。参考調査は `machine_types.md`、式とモデル限界は `leveling-model.md`、電気手順は `tester_basics.md` を参照してください。
