# 小型立形 YZ 誇張表示：実ブラウザー独立確認

`tests/browser-yz-exaggeration.cjs` を Chromium 実ブラウザーで実行。期待符号を直角図の描画符号表から生成せず、実際に描く柱の上下頂点差と測定材料点 P の Y 微小移動差から得た内積を比較した。

対象は初期寸法・中央位置、固有 XY=33、XZ=75、YZ=−15/0/+15 µm/300 mm、支持 A=−0.5/−0.1/0/+0.1/+0.5 mm、B=C=D=0 の15状態。ユーザー画像の個体データを復元したものではない。

## 修正前

開始コミット `5fd82a8` の公開用 HTML を `git show` で独立保存した。同ファイルの SHA-256 は `7d697c9dc34b8d13a8eb13f23395950bc66376c62c27f92d06d565a031e01710`。

90項目中74成功、16失敗。

- YZ固有差0、A正負4状態で実寸角と誇張角の符号が逆。
- YZ固有差−15/0/+15それぞれのA調整4区間、合計12区間すべてで、実寸角と誇張角の変化方向が逆。
- 旧版でも柱とZ矢印・実Z動作は平行。カメラ・ズーム・表示切替の測定値不変、支持選択、XYZデモの値追従は通過。

結果詳細：[browser-before/results.json](browser-before/results.json)。PC1280×900と携帯390×844の各3状態、合計6枚を同ディレクトリに保存。

## 確認範囲と限界

これは教材の実ブラウザー描画と計算の対応確認。Canvasに描く3D頂点を数値で比較し、側面投影を画像確認した。実機の弾性や剛性、NC指令の正方向の証明ではない。PCと携帯の画像は同一シミュレーション条件で比較し、ブラウザー表示倍率による実測値変更は許容しない。

## 修正後

最終安全案の SHA-256 は `2443620c9a497f7af5adad10922a1f66bf6b828b67065dbe2fcac1228a5acfbc`。

小型の3D模型は実寸の支持・固有姿勢を使い、チェックボックスは「直角図のずれを強調」へ変更。ON/OFFでは有限接触図と局所角度図のずれだけを強調する。実測値・全3D頂点・固定柱姿勢を変えない。他6機種の既存の模型強調は維持。

**107項目すべて成功**。修正前と共通の90項目に、最終仕様の追加17項目（小型のラベル、全頂点不変、有限図と局所角度図の変化、数字不変、他6機種の模型倍率維持と数値不変）を加えた。修正前16件の不一致はすべて解消。XYZ実デモで可動部の頂点が動き、固定コラムの上下頂点は不動。Z実移動とZ矢印は柱に平行。

結果詳細：[browser-after/results.json](browser-after/results.json)。同じ支持条件のPC・携帯6枚と、図強調ON/OFFおよび設定説明画像を保存。
