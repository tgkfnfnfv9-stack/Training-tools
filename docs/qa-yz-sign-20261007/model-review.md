# 小型立形 YZ：模型と支持 A 感度の独立再点検

開始ソース `5fd82a8`。この記録は前回の「共通回転だから問題なし」という結論を前提にせず、A 一点だけを上下した場合も調べた。ユーザー画像から支持高さ・位置を復元することはできない。以下は画像の表示値 XY +33 / XZ −75 / YZ +15 に一致する理想支持時の固有誤差を選んだ再現例であり、ユーザーの保存個体そのものではない。

## 新たに見つかった確定不一致

**誇張表示で、実際に描く柱と測定 P の Y 移動方向との直角差の符号・調整方向が逆転する。**

模型柱の上下頂点を `displayedModelPoint` で変換した差ベクトルと、模型に描く `compactTablePathPoint` の Y ±0.001 スライダー位置間の差ベクトルを正規化して内積を取った。カメラ投影も、直角図の符号表も期待値には使っていない。

既定寸法、X=Y=Z=0、固有 XY=33 / XZ=75 / YZ=0 µm/300 mm、B=C=D=0：

| A 高さ mm | 実寸 YZ µm | 実寸模型の Y·Z | 約299.653倍誇張模型の Y·Z |
|---:|---:|---:|---:|
| −0.5 | +1.19126061 | +0.00000397084 | −0.00063581041 |
| +0.5 | −1.18734832 | −0.00000395780 | +0.00177771635 |

実寸模型では `300000 × 内積` が仮想計器の読みと一致する。誇張時はどちらも符号が反対になった。画面投影の錯覚ではなく、3D メッシュと材料点移動の関係そのものの不一致。

固有 YZ=−15、他は同じ場合でも、A −0.5→+0.5 mm で実測定値は +16.191→+13.813 µm と改善するが、誇張模型の内積は +0.014352→+0.016750 と悪化する。符号だけ維持しても、操作に対する変化方向の保証にならない。

原因は、実寸の微小な角度差を表示する際、支持高さと固有角を約300倍してから非線形の姿勢合成・材料点微分を再計算すること。高次の交差項も増幅され、弱い YZ の一次効果を上回る。関係するコードは `compactSupportFrame`、`compactWorkVisualPoint`、`compactPathFrames` (`src/accuracy-ui.js`)、`displayPoseFrame`、`displayBodyFrame` (`src/leveling-ui.js`)。

再現スクリプト：[reproduce-exaggeration.cjs](reproduce-exaggeration.cjs)。開始ソースの結果：[model-before.jsonl](model-before.jsonl)。リポジトリルートで `node docs/qa-yz-sign-20261007/reproduce-exaggeration.cjs`。

回帰テスト：`tests/check-compact-yz-exaggeration.cjs`。実メッシュと材料点差分から、実寸読みとの一致、誇張による数値不変、誇張時の符号・調整方向を確認する。開始ソースでは `exaggeration reversed A adjustment effect` で失敗することを確認した。

## A 一点だけでも YZ 変化が弱い理由

固有 XY=33 / XZ=75 / YZ=−15 µm/300 mm、既定寸法と中央位置：

| A 高さ mm | 柱の床基準前倒れ角 µrad | Y 移動の上向き角 µrad | 実寸 YZ µm |
|---:|---:|---:|---:|
| −0.5 | +46.571 | +100.526 | +16.1913 |
| −0.1 | −30.664 | +20.104 | +15.2379 |
| 0 | −49.973 | 0 | +15.0000 |
| +0.1 | −69.281 | −20.103 | +14.7622 |
| +0.5 | −146.516 | −100.510 | +13.8127 |

A 操作には捻れも含まれるため「全体の傾斜だけ」と説明するのは不十分。しかし柱と Y 移動がほぼ一緒に傾くことは具体的数値でも確認できる。

現行支持面は正規化座標 X=x/a、Z=z/b を使い

`h = 座面平面 + t X Z + (1−X²)(q1 Z + q3 Z³)`。

柱とサドルがともに x=0 のとき、前後勾配差から `t X` と `q1` が消え、主に `3 q3 (Z柱²−Z台²)/b` が残る。A=+0.5 mm では q1=0.0158411 mm、q3=0.00310243 mm、柱の前後勾配 −0.0965433 mm/m、サドル −0.1005344 mm/m、差約+0.00399115 mm/m。これが弱い感度の主要因。実際の測定には P の高さによる接線変化と固有誤差も入る。

弱い感度は計器接触式の単純な符号ミスではなく、採用した2モード曲げ面と中央配置の性質。実機の剛性・荷重・接触を同定したモデルではないため、「実機でも調整が効かない」とは結論できない。

## 公開 main との区別

確認時の公開 main `97297100d21d6292567e664a7ccd1763e116d9de` と開始ローカル `5fd82a8` で、`src/leveling.js`、`src/machine-accuracy.js`、`src/reference-measurement.js` は同一。小型の上記支持・材料点・接線関数にもその間の計算変更はない。前回の説明修正だけでは、この誇張問題は解決していなかった。

## 未確認・限界

この確認は表示と教材内部計算の整合確認。実機の剛性、荷重、接触、個体の調整感度、NC 指令・A/C 正方向の証明ではない。ユーザー画像の正確な個体状態は不明。修正後の再検証は下に追記する。

## 最初の修正案の再確認（採用判定：再修正が必要）

小型の現在位置における実寸 XZ/YZ 角度を F 倍するよう、柱側表示姿勢を回転補正する案を確認した。上記15ケースの符号・調整方向回帰は成功した。しかし補正角が X/Y 位置に依存するため、テーブルだけ動かしたときに固定柱も回転する新しい問題があった。

固有33/75/−15、A=+0.5 mm、B=C=D=0、X=Z=0、誇張ONで、Y −100→+100 の操作だけで、柱上端模型座標が `[0.25396777,3.48864595,0.54152900]` から `[0.25392229,3.48916189,0.54720331]` へ変化した。約5.70 mmの架空移動。誇張した相対角を一致させるだけでは、「固定柱はテーブル操作で動かない」という機械構造との整合を満たさない。

追加回帰 `tests/check-compact-fixed-column.cjs` は実際の柱上下頂点でこの不変性を確認する。最初の修正案では誇張ON時に失敗する。実寸モードでは不変。修正担当へ再修正を依頼済み。

## 最終安全案の独立再確認

最初の補正案は採用せず、小型3D模型・軸矢印・材料点の姿勢倍率を1に固定する案を再確認した。微小な違いの強調は既存の局所角度図と有限測定図へ限定する。表示数値には倍率を掛けず、機械計算・接触計算・保存仕様も変更しない。これにより固定柱に架空の移動を加えず、誇張による逆転を除去する。支持操作に対する実寸の弱い感度そのものは残る。

確認した生成 HTML SHA-256（説明の追加訂正前）：`73634492afd49bec380b00a18f54d2a72562199323671ee18312fa2fd19aa237`。

独立再実行：

- `check-compact-fixed-column.cjs`：18ケース、X/Y位置変更で固定柱上下頂点が不動。
