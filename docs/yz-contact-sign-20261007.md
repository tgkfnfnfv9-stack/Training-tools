# YZ接触側の独立手計算（2026-10-07）

測定実装を見る前に接触幾何を導出し、その後にコードと照合した。今回の検証は、接触側・走査方向・押込み指示の符号を対象とする。支持曲げモデルの感度や実機の再現性を証明するものではない。製品の計算式は変更していない。

## 現配置と結論

内部座標の上を +y、機械の奥を +z とする。直角マスタの測定面 S を z=0、計器本体を奥側 z=10 mm、測定子を手前方向 −z に置く。上でゼロを取り、主軸頭を下へ300 mm移動する。

マスタに対して柱の上端が手前になる前倒れ角を θ>0 と定義すると、Z上方向は `(0, cosθ, −sinθ)`。下降すると本体の奥向き移動は `+300 sinθ mm`。本体がS面から離れ、測定子が伸びるので、押込み＋の指示値は

`I = −300000 sinθ µm`。

| 基準器に対する柱の倒れ | 現配置：奥側から接触 | 反対側：手前から接触 |
| --- | ---: | ---: |
| 前倒れ θ=+0.0001 rad | −29.99999995 µm | +29.99999995 µm |
| 後倒れ θ=−0.0001 rad | +29.99999995 µm | −29.99999995 µm |
| θ=0 | 0 µm | 0 µm |

反対側では本体を z=−10 mm、測定子を +z に置く。ユーザーの「前倒れで下降すると＋、後倒れで−」はこの反対側配置で成立する。現配置の数値だけを符号反転すると、接触側・図・押込み＋の定義との整合が崩れる。

## 床に対する倒れとの区別

上のθは基準器に対する相対角である。コラム、Y送り、マスタが同じだけ床に対して傾く場合、コラムの見た目は変わっても相対角は変わらない。共通の剛体回転・並進を全接触配置に加えても指示が変わらないことをテストした。誇張表示された模型の2D投影から相対角を直接決めることはできない。

## コードとの照合

- `src/reference-measurement-ui.js` の `referenceSetup`：小型立形YZは上・奥側でゼロ、下へ相対走査。
- 同 `referenceScan`：開始本体は `normal×0.01`、測定子は `−normal`。YZのnormalはY送り方向。
- `src/reference-measurement.js` の `compare`：`(開始伸び−終了伸び)×1e6` が押込み増分。

これらは独立手計算と一致する。`tests/check-yz-contact-side.cjs` は理想・正負の倒れを両接触側から検証し、同じ固定配置での始終点交換と再ゼロ、共通剛体回転・並進も確認する。合計18件の数値照合に成功した。始終点交換は方向合わせを取り直さず行っている。

## 説明の訂正

今回の応答冒頭で、接触側を確かめず「前倒れで下降すると＋という理解に合う」と述べたのは誤りだった。独立手計算により、現配置では前倒れ−／後倒れ＋であると訂正した。過去のテスト成功や説明を期待値の根拠には使っていない。

公開mainとローカルの接触計算式に差がないことは親担当の比較結果による。本担当は上記接触式と配置の独立検証のみを担当した。
