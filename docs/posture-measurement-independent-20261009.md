# 横形・旋盤の独立幾何確認（2026-10-09 開始）

修正担当とは別担当が、最新 main `cbdcf81` の未修正コピーと作業版を比較した。アプリソースは変更していない。既存の符号表、旧テスト期待値、描画変換、支持・測定計算関数を期待値として呼んでいない。

## 独立期待値の作り方

[新しい検算スクリプト](../tests/check-posture-measurement-independent-20261009.cjs) は入力支持高さから格子4隅の形状関数を作り、支持高さを最小二乗平面と残差に分ける。残差面の二方向接線から座面法線と正規直交基底を作り、平面傾斜を外側の共通剛体回転として合成する。主軸台・コラム・パレット・往復台の座標と有限腕をこの別実装で求め、面接触・円筒接触を距離の二分法で解く。本番の接触は解析式なので、解法も共有していない。

乱数分布そのものは検査対象外。理想個体と `used / seed 123456` の固有角度・固定偏心を入力として保持し、支持操作で再抽選しない。支持の±0.001/±0.010 mm、正負の平面、`h=±.01xz` / `±.05xz mm`、ねじれ＋平面、標準寸法と非標準寸法、軸端・非対称位置・補間境界を検査した。

採用された横形マスタは320×320×50 mm。Rの最初の接触基準点をパレット上面から50 mm高く置く。これは全姿勢で「脚高さ50 mm」を意味しない。XY/XZ/YZの姿勢により、基準点と有限厚マスタの下端・脚の高さは異なる。具体的な配置は修正記録と同じ寸法パラメータを入力し、その先の姿勢・接触を独立算出した。

- XY/XZのRは頭固定腕をXへ300 mm、YZのRはYへ300 mm送る。
- 始終点が等指示になるRの方向を決め、その直角S面へ別の頭固定腕を取り付ける。
- XYは頭Y、XZ/YZはパレットZを300 mm送る。Sの始点でゼロ、途中は再ゼロしない。
- 支持・軸位置等の変更後は方向合わせ・取付け・始点ゼロを取り直す。固定した器具の始終点だけを交換してゼロし直す場合と区別する。

有限走査の各17点に加え、支持格子の境界前・境界・境界後を照合した。全点の連続接触や器具全体の干渉検査を証明するものではない。

## 証拠と検証範囲

最終の数理再確認は **896状態＋最小走査20状態、604,222比較で不一致なし**。測定値と独立値の最大差は1.74e−9 µm、ねじれへ共通平面を足した代表全項目の最大変化は6.77e−10 µm。3D主要材料点は6,624座標を照合した。境界問題を見つける前の始終点中心検査の合格だけでは完了にせず、途中接触の拡張検査→再修正→再検査を行った。

さらに [独立表示検算](../tests/check-posture-visual-independent-20261009.cjs) で、実際の表示誇張倍率を入力倍率として別の支持面・剛体姿勢を組み直し、誇張on/off・正負ねじれ＋平面・軸両端・非標準寸法の32状態528座標を比較した。最大座標差8.89e−16 m、[不一致なし](posture-visual-independent-20261009.json)。本体の回転中心・腕の倍率適用とベッド/心押し座面が同じ共通写像に属することを、表示の計算関数を期待値にせず確認した。

同じ表示検算を[旧版にも実行](posture-visual-independent-before-20261009.json)すると最大座標差は約1.031 mmだった。これは誇張後の模型座標の差であり、実寸の据付誤差1.031 mmを意味しない。
