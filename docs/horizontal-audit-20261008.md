# 横形の移動・座標・直角・Z平行度：新規監査

作業開始のremote mainとローカルHEADは `b56dbbd5d69d3def476f86d09c23538e1a8c24fc`。元の `/workspace/Training-tools` はクリーンだった。新しい作業ブランチ `audit/horizontal-motion-20261008` と独立作業場所 `/workspace/Training-tools-horizontal-20261008` を作成し、構造修正・測定表示修正・独立幾何・実ブラウザーを別担当に分けた。新しいチャットを作成したという意味ではない。

対象は横形だけ。他6機種と保存形式、整数µm表示、固有精度のページを維持する。過去の成功テストは正解の根拠にせず、部材の材料点と計器・平面・円筒の相対運動を再計算した。

## まず何が動くか

| 操作 | 動く部材 | 模型の部材＋方向 | その操作だけでは動かない部材 |
|---|---|---|---|
| X | コラム＋主軸頭＋工具 | 右 | パレット |
| Y | 主軸頭＋工具 | 上 | コラム、パレット |
| Z | パレット台＋パレット＋ワーク | 奥・主軸側 | コラム、主軸頭 |

この＋はスライダーの部材位置であり、NC指令の＋ではない。カメラを回せば画面上の向きも変わる。横向きに見えるZ矢印だけを根拠に軸交換とは判断できない。主軸の回転中心線とパレットZ案内も別の方向である。

## 不一致と修正

| 判定 | 問題・確認結果 | 対応 |
|---|---|---|
| 表示不一致・修正 | 横形のY案内部とコラムが標準模型寸法で96 mm離れていた | 案内部の前面と主軸位置を保ち、後面だけをコラムへ延長。10 mm重なって接続 |
| 誤読原因・修正 | XYでは主軸頭がY移動するのに小図が「頭固定」 | 横形のみ「計器:頭」とし、取付先の意味を明示 |
| 誤読原因・修正 | 小図の矢印が部材移動か相対移動か分かりにくい | 横形の走査矢印に「相対」。詳細で動く部材・図の向きを説明 |
| 説明不足・修正 | XZ/YZとZ平行で計器と基準器の搭載先、取付高さが違う | 両方の既存詳細欄で対比。Z平行長手図の右は主軸側で、模型画面右とは限らない |
| 一致 | 理想状態、共通剛体傾斜、正負の捻れ、支持点の往復 | 独立接触式と現行数値が一致。符号反転・増幅変更はしない |
| 一致 | 捻れ中のX変化でYZが変わるがZ平行bがほぼ一定の例 | バー勾配と取付け腕の姿勢変化の相殺を独立式で確認。一般条件で不変という意味ではない |
| 未再現・モデル上の限界 | R面は代表案内方向へ合わせる。実計器をX送りしてR面を合わせる工程とは異なる | 差を詳細に明記。実際の器具取付点と有限方向合わせ工程を新設していない |
| 未確認 | 実EC-630の全寸法・NC右手系／メーカー指令正方向、荷重・弾性・干渉 | 検証済みとはしない |

変更前後の概略：

```text

       後：[主軸頭]─[Y案内─────────[コラム]]
                       接触前面と主軸鼻端は移動させない

       後：計器:頭   相対↑    （頭Yを上げる）

       Z平行：台上計器が奥へ → 頭のバーに対し主軸側
```

## 操作と数値の実例

ユーザーの画像から乱数seedや全支持高さは復元できないため、画像と同じ数値の再現とはしていない。実ブラウザーで固定した確認個体は `used / seed 123456`。値の順序は XY, XZ, YZ, Z平行a, Z平行b（µm）。

| 状態・操作 | 整数表示 | 解釈 |
|---|---|---|
| 平坦支持、軸中央 | +17, +8, +14, +8, +14 | 固有誤差が残る |
| 同じ状態から支持Bを0.010 mm上げる | +17, +9, +12, +9, +12 | 支持変更に応答 |
| Bを0.010 mm下げて戻す | +17, +8, +14, +8, +14 | 生の計算値まで復帰 |
| 平坦支持でX/Y/Zを各移動端へ | 整数表示は同じ | 位置で案内姿勢が変わらなければ必ず変動する必要はない |
| 捻れ `h=.05xz`、X−100 | +18, −1, +22, −20, +14 | コラムの座面姿勢と取付け腕が変わる |
| 同じ捻れ、X＋100 | +18, −1, +6, −20, +14 | YZとZ平行bを同じ測定と扱えない |
| 同じ捻れ、Y−100 | +18, −1, +14, −16, +14 | 計器の取付高さが下がる |
| 同じ捻れ、Y＋100 | +18, −1, +14, −25, +14 | 取付高さによる左右変位が大きくなる |

支持・軸変更ごとに器具配置・方向合わせ・接触ゼロを取り直す現行仕様である。これは、一度固定した現物の計器を保持して全軸を連続操作した指示履歴ではない。支持面の模型表示と実機の剛性・荷重解析も区別する。
