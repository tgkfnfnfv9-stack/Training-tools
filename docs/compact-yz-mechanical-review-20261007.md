# 小型立形 YZ：柱を前倒れから後倒れへ変えても読みが改善しない件

対象は一覧1番 `vertical` / `kind=compact`。機械確認担当による独立再点検。製品計算は変更していない。

## 結論

申告の挙動は再現する。しかし、現在の配置について、YZの押込み符号・上奥ゼロから下降・Z材料点移動と模型姿勢の不一致は検出しなかった。柱の床に対する倒れを変えるだけでは、テーブル側のY接線も同じ向きに傾くので、相対角を測るYZは改善しない。また、中央位置では現行2モード曲げ仮定のYZ感度が弱く、新品の範囲内の固有差でも十分打ち消せない例がある。

これは「単に中古個体の誤差が大きい」ためではない。後述の +12 µm 個体でも発生する。中央だけの調整可能範囲を、全位置での調整可能範囲とは扱えない。X/Y送り位置を変えると感度が大きく変わる。

## 独立計算

[独立テスト](../tests/check-compact-yz-independent.cjs) は、描画・方向表・`compactPathFrames` の出力を期待値に使わない。教材に宣言された曲げ仮定そのものを独立に評価した。

- 支持4点の高さを平面と対角振幅 `t=(h00+h11-h10-h01)/4` に分解。
- 残差面 `w=t X Z + (1-X²)(q1 Z + q3 Z³)`、`X=x/a,Z=z/b`。
- 曲率エネルギーを単項式の厳密積分で計算し、2×2連立式からq1/q3を求める。製品のGauss点・求めた係数は使わない。
- 残差勾配から右方向 `(1,w_x/1000,0)` と上向き法線 `(-w_x/1000,1,-w_z/1000)` を正規化して独立剛体基底を構成。
- サドル基準から高さ0.50 m、X送り分の腕長を持つ材料点Pを構成。PのY移動を5点差分で微分して、基準方向 `n=unit(dP/dY)` を得る。
- 柱座の姿勢と固有差からZ送り単位方向 `uZ` を構成。
- マスタS面を `n·p=0`、本体初期位置を `.01n`、測定子を `−n` とする。下降後の本体は `.01n−.3uZ`。光線と平面の交差から伸びを求める。

したがって、この静止姿勢のYZ配置では読みは `0.3(n·uZ)×10^6 µm`。これは符号表ではなく、「奥側の本体から手前へ出た測定子」「主軸頭下降」「押込み=伸びの減少」から導く。同じ配置の反対側測定では符号が逆になる。固定配置の始終点交換後に再ゼロしても符号が逆になる。

寸法3組、支持6組、軸/柱位置3組、固有差3組の162条件が一致。最大差 **0.000000451 µm**。理想0、純YZ固有差 ±60 µm はそれぞれ ∓59.9999996 µm。反対側・固定配置再ゼロ324条件も照合した。[数値結果](compact-yz-independent-20261007.json)

これは宣言された教材モデルの独立実装との一致であり、実機の曲げ剛性・接触・荷重解析の妥当性の証明ではない。

## 申告症状の再現（新品範囲内 +12 µm）

既定寸法2.08×2.16 m、XY/XZ固有差0、YZ固有差+12 µm、X=Y=Z=0、柱位置0。対角振幅を±0.05 mmのまま保ち、前後の共通傾斜だけ変えた。柱角は固有差を含む物理倍率1の姿勢で、前倒れが正。

| 支持1/2/3/4 mm | 柱の前倒れ角 µrad | Y材料点接線の上向き角 µrad | 有限YZ µm |
|---|---:|---:|---:|
| −.35 / −.45 / +.35 / +.45 | +418.049 | +376.453 | −12.478625 |
| +.05 / −.05 / −.05 / +.05 | +47.679 | +6.083 | −12.478625 |
| +.45 / +.35 / −.45 / −.35 | −322.691 | −364.288 | −12.478625 |

柱が前倒れから後倒れへ変わっても、Y接線も同じだけ変わっている。角度差は約41.596 µradのまま。床の鉛直に対する柱角だけをゼロにしても、YZの相対直角はゼロにならない。

## 中央でYZの調整感度が弱い理由

純鞍面 `w=kxz` なら前後勾配は `w_z=kx`。既定中央では柱座とサドル座がともにx=0なので、前後勾配差は0。一方、左右勾配 `w_x=kz` は柱とサドルの前後位置差で変わり、XZには大きく現れる。YZは2モードの非対称曲げで生じる小さい前後勾配差、材料Pの位置依存回転の寄与が主になる。

固有差0で支持1だけ+0.100 mmにすると、中央の有限値は XY **+3.338681**、XZ **−7.031250**、YZ **−0.239391 µm**。XY/XZに比べYZが小さいのはこの機構仮定と整合する。

固有YZ+12 µmを保ち、各支持±0.500 mmの端点16組を比較すると次の範囲だった。

| X/Yスライダー | 16組での最小YZ µm | 最大YZ µm |
|---|---:|---:|
| 0 / 0 | −16.758080 | −7.179320 |
| +100 / +100 | −66.790624 | +42.829907 |
| −100 / −100 | −73.507473 | +49.596234 |
| +100 / −100 | −70.598412 | +46.682413 |
| −100 / +100 | −77.362851 | +53.401211 |

**これは16端点の比較であり、非線形関数の全域極値の証明ではない。** また、ある軸位置でYZを0に近づけても、他位置・XY・XZが同時に改善する保証はない。X位置を変えるとサドル基準から材料Pまでの腕長が変わり、Y送り中の姿勢変化による上下変位が増減する。Pはサドル座そのものではない。

## 原因コードと表示上の論点

- `src/accuracy-ui.js` `compactTablePathPoint` / `compactPathFrames`：Yは高さ0.50 mの材料Pの移動接線。テーブル上面の水平線や床水平ではない。
- `src/accuracy-ui.js` `geometryModel` / `intrinsicBodyFrame`：柱/主軸頭姿勢は支持姿勢に固有差を重ねたもの。絶対鉛直と相対直角は別。
- `src/leveling.js` `compactBending`：右/左の相対曲げ剛性3:1、2モードの教材仮定。実機同定値ではない。
- `src/reference-measurement-ui.js` `referenceSetup` / `referenceScan`：YZは奥側から接触し、上でゼロ、主軸頭下降。固定マスタの方向合わせはその位置のY接線。現在のYZ走査ではサドル位置・柱姿勢は固定。

表示には「柱が床に対して真っすぐ」ではなく「Y送りに対してZ送りが直角」を見ること、中央でYZ感度が弱いことを明示する余地がある。符号反転や支持への感度を人工的に追加する修正は、この結果からは正当化されない。別の曲げモデル・固有差配分・測定位置を採用する場合は計算仕様の変更であり、別途説明が必要。
