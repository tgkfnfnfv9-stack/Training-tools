# タレット旋盤・独立確認（2026-10-09）

実装担当と別の担当が、`src/lathe-inspection.js`、`src/lathe-inspection-ui.js`、旋盤模型の分岐を確認した。製品ソースは編集せず、独立検算を `tests/check-lathe-independent-20261009.cjs` に追加した。

## 結果

**21,048比較成功。通常1,020状態、走査不足・ちょうど最小行程の20状態。** 独立期待値との最大差は `1.83881e-9 µm`。

実行：

```sh
node tests/check-lathe-independent-20261009.cjs
```

期待値は入力した6支持高さから双一次補間と最小二乗平面を独立に求め、共通回転・残差の局所回転・材料点の取付ベクトルを組み立てた。面の接触は符号付き距離の二分探索、穴の4点は円への距離の二分探索、加工径差は主軸軸線への外積距離から求めた。描画関数、`geometryModel`、製品の姿勢関数や表示の符号表は期待値に使っていない。固有誤差の振幅は同じ個体の固定入力として受け取り、乱数分布の実機妥当性まで認証してはいない。

確認範囲：

- 理想で0、正負の捻れ、各支持6点の±0.08 mm、一様傾斜、捻れへ共通剛体傾斜を加えた状態。
- X/Z両端、中央、長手支持補間境界の直前/直後、2種類の支持寸法。
- 理想個体と `used / seed 123456`。同じ個体の主軸TIRと保存profileが変わらない。
- 固定計器へ面が近づくと押込み＋、径差は半径差の2倍、同じ工具配置で始終点を交換すると径差が反転。
- X面の走査で現在Zを保持、Z面・加工の走査で現在Xを保持。
- a左/b上/c右/d下の円接触から、部材X芯差 `(c−a)/2`、高さ差 `(d−b)/2` を復元。
- 最小寸法で300 mmを確保できなければ数値を `null`、UIを「—」にし、始終点をスライダー範囲内に保つ。

## 独立レビューで見つけ、修正を再確認した点

| 問題 | 修正・再確認 |
|---|---|
| 穴芯図の左右が部材Xと逆 | 主軸からタレットを見ると内部＋zは図左。製品は円の画面横入力を `−dx` に修正。4点接触の独立期待値と一致し、部材Xは `(c−a)/2` |
| X/Zを共通始点で両方clamp | `xStart` と `zStart` を分離。走査していない軸の位置を保持することを全状態で確認 |
| BOTフラットの計算位置が12角外周の頂点 | 12角の位相を15°変え、前側に実フラットを作成。接触基準点を `[.23,1.5,-1.43]` へ。標準寸法で300 mm走査後の面内位置x=−.07は面のx範囲[−.09,.25]内 |
| 支持寸法を縮めると全軸行程が300 mm未満 | 全行程不足を検出し、該当のX面またはZ面/加工値を無効にする。支持幅0.5 m、奥行0.5 m、閾値ちょうど/直下を追加検証 |
| 孔の傾きまで解いているように読める | 穴芯は主軸直交面の円による偏心近似で、傾いた円筒の楕円断面は含まないと詳細へ明記 |

## 測定配置と公式資料の関係

[Haas ST Lathe Alignment – Indicating Zones](https://www.haascnc.com/service/troubleshooting-and-how-to/how-to/st-lathe-alignment-indicating-zones-.html) の配置では、タレット面XとBOTフラットZは主軸保持リング側の計器で動くタレット面を測る。穴芯は主軸側の計器を用い、所定X位置でホルダの内周を旋回する。この固定先・動く部材の関係を確認した。教材の一律300 mmはメーカーの検査距離そのものではない。

| 教材の項目 | 独立幾何上の意味 | レベルによる変化 |
|---|---|---|
| 主軸a/b TIR | 同じ固有偏心・傾きのバーを回した最大−最小 | 固有値を保持 |
| タレットX面 | 開始面法線へ計器を合わせ、同じ剛体のX方向へ300 mm移動 | `0.3 sin(固有面角)`。各回の方向合わせにより支持の共通姿勢は除かれる |
| BOT Zフラット | 固定計器に対し、0.84 m高さの面材料点と面法線がZ移動 | 支持位置による姿勢変化・取付高さを含む |
| 穴芯 | 固定の公称Xへ戻した穴材料点と主軸軸線の位置差 | 現在Z・支持・個体の軸方向差を反映。支持変更後も穴を主軸へ合わせ直さない |
| 片持ち加工径差 | aで半径25 mmを設定した同じ工具材料点から主軸軸線までの距離差×2 | 支持と固有主軸方向を反映 |
| 心押あり径差 | 主軸鼻端と心押中心を結ぶ直線に対する同じ工具の距離差×2 | 両端中心位置を使う幾何仮定。弾性解析ではない |

## 数値の独立例

標準寸法・軸中央、固有誤差なし。`h = ±0.05xz mm` の支持高さを入力。単位µm、整数表示前。

| 支持 | X面 | Zフラット | 芯差 部材X | 芯差 高さ | 片持ち径差 | 心押仮定の径差 |
|---|---:|---:|---:|---:|---:|---:|
| 理想 | 0 | 0 | 0 | 0 | 0 | 0 |
| 正捻れ | 0 | +12.600144 | −76.860112 | +1.271460 | +25.200085 | −13.745369 |
| 負捻れ | 0 | −12.599856 | +76.859887 | −1.278540 | −25.199914 | +13.745540 |

高さ0.84 mの点のZ移動に対し、一次の径方向変位は `−0.84×0.05×0.3/1000 m = −12.6 µm`。前側から測る固定計器の押込みは＋12.6 µm、外径の変化は約＋25.2 µmとなる。これは単純に角度へ倍率を掛けた値ではなく、実装と独立の材料点距離計算でも一致した。

正負の値が小数部まで完全な反対にならないのは、3次元回転・距離による二次成分を保持しているため。小さい残差は整数表示では同じ値になる。

## 残る限界

- 支持補間と剛体姿勢による教材。ベッドの弾性・荷重移動・接触圧・熱・測定力・切削力を解いていない。
- 面測定は無限平面の近似。縮小寸法で描画タレットの有限な面から測定子が外れる条件は判定しない。軸全行程不足の検出とは別の制限。
- 穴芯は円断面の偏心検査。孔軸の傾き、楕円断面、穴の深さ方向の芯差は対象外。
- 検査ブラケットの長さ・治具の干渉、回転割出し、実機のNC径指令符号をこの検算から保証しない。
- 「心押あり」の軸は両端中心を結ぶ直線。実際のチャック支持材の曲げ形状・加工径を予測する式ではない。
- 実ブラウザーの操作、保存読込、他6機種の画像比較、公開後確認は別担当の記録を参照。独立目視では1280 pxの両検査ページと320 pxの穴芯/加工図の表示を確認したが、その画像の取得版と最終公開版の同一性はブラウザー担当が管理する。

最小行程guardを含むソースで最終検算を実行し成功。確認時の生成HTML SHA256は `c0375aa2db3d1ec4268055e79cf1c79fae3d5cb48a821e1c36f3017ab1ef0007`。これらの合格は教材内の幾何整合を示し、特定Haas型式の精度・支持感度・実加工の認証ではない。
