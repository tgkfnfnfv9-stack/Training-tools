## まず測定配置を確定し、現実装と比較する

各測定を「マスタ」という一語で済ませないでください。基準となる物は直角マスタ、テーブル面、主軸固定バー、タレット面、穴などで異なります。ダイヤル本体・取付腕・測定子先端も別の点です。

全機種へ横形と同じ器具配置を強制しないこと。固有成分だけを表示する項目は、まずその定義と実際の測定で得る総指示との違いを確かめ、存在しない器具や測定方式を勝手に追加しないでください。

各機種×各測定で、最低限次を記録すること：

1. 基準器／被測定面の種類・取付先・取付位置・高さ・寸法・法線。
2. ダイヤル本体と腕の取付先・固定点・腕の長さ・測定子方向・初期伸び。
3. 固定部材と動く部材、内部xyz・機械XYZ・部材送り・NC指令符号・画面方向の区別。
4. R方向合わせの面、動かす側、有限送り区間、合わせ終わって固定される配置。
5. S本測定の面、動かす側、始点・終点・途中接触、ゼロ位置、押込みが増える方向。
6. 支持変更・軸変更・寸法変更・個体変更で何を取り付け直し、合わせ直し、ゼロにし直すか。
7. 計算値が瞬間のダイヤル指示か、再ゼロ後の有限区間の終点差か、回転TIRか、固有成分だけか。
8. 模型・小図・数式が同じ取付点と姿勢を使うか。描かれていない器具や仮想原点も明記する。

横形について維持する取付先は、**直角マスタをテーブル上、ダイヤルを主軸側**。**テストバーを主軸へ固定する場合はダイヤルをテーブル側**です。この所有関係だけからR/Sの面・走査軸・接触側を独断で決めないでください。

器具が実際に届く高さか、支持面に据わるか、全走査で有限面・バーに接触するかを確認すること。無限平面や長い剛体腕の式が解けるだけで、普通に取り付けた測定配置が成立したとは扱わないでください。3Dに器具を描く場合も、別取付けの複数検査を一つの器具として同時に描かないこと。

支持補間・剛体取付けは教材の仮定です。荷重による弾性変形、バーや腕の自重たわみ、測定力などの未実装条件を明記し、独立計算の一致と実機の再現確認を同一視しないでください。実機手順・寸法に根拠がある部分と、教材で仮定した部分を分けてください。

## 「付けたまま」と「再ゼロ後」を分けて調べる

今回の重点です。支持操作ごとに自動で腕・マスタ方向・原点を作り直す計算だけを見て、「付けたまま測ると変化しない」と結論づけないでください。

|比較|保持するもの|調べるもの|
|---|---|---|
|一度取り付けてから支持を変える|取付先の部材座標に固定したマスタ・腕・測定子方向、最初の接触ゼロ|支持変更後の相対移動・伸び・指示。接触を失ったら不成立と記録し、自動で接触を作り直さない|
|指定手順で再測定する|同じ個体・支持入力を使い、定義された工程だけやり直す|R再合わせ、付替え、位置戻し、始点再ゼロがそれぞれどの変化を除くか。現在UIがこちらならそう特定する|
|同じ固定配置を逆に走査する|基準器・取付け・接触側|上端で再ゼロして戻る場合と、下端のゼロを保持して戻る場合の違い|

固定するのは世界座標ではなく**取付先部材に対する配置**です。支持を変えたら、器具もその部材の剛体姿勢で運ばれます。最初のゼロの保持と、毎回の再ゼロを混ぜないこと。

現行の再取付け・再ゼロが正当な測定手順なら、その結果が不変であることもあり得ます。再ゼロを一律に廃止する依頼ではありません。一方、変化を隠す不適切な再合わせがあれば修正対象です。診断用の固定取付け計算と、ユーザーへ提供する測定仕様の変更を分けて説明してください。

## 支持から表示まで追う

`実ボタンの支持選択・粗微操作 → 保存支持高さ → 補間と共通/局所姿勢 → 基準器・計器の取付点/方向 → 相対運動 → 接触・伸び・ゼロ → 生値 → 整数表示 → 詳細/改善表示/保存読込`

不変に見える値は、次のどれかを実操作と独立計算で分類します。

|判定候補|必要な証拠|
|---|---|
|入力が届いていない|選択支持、保存高さ、操作量、更新イベントの前後|
|計算が固定・必要な支持差を落としている|支持が変わったのに参照姿勢/取付点が旧状態、または不要な相殺がある具体的経路|
|生値は変わるが表示が更新されない|同じ時刻の計算結果とDOM・キャッシュ・描画更新の食い違い|
|生値は変わるが整数は同じ|丸め前後の値と量。画面は整数µmを維持|
|測定幾何として不変|固定配置または指定の再ゼロ条件での独立導出と数値一致|
|固有成分として不変|何を固有値と定義しているか、支持を含む総指示とはどう違うか、個体が保持されている証拠|
|測定が成立しない|面外・ストローク・行程・バー長・接触喪失等。0や前の値で埋めない|

「丸めだから」「相殺するから」「固有値だから」は、確認前の説明に使わないこと。すべての数字を無理に変える係数・揺らぎ・符号反転を追加しないこと。保存個体の乱数を支持操作で再抽選しないこと。

## 現在分かっている重点箇所

- **横形の取付けと表示**：現公開は有限R合わせ後の300 mm測定。XY/YZは下ゼロ→頭Y上、XZはテーブルZ奥送りで計器はマスタから見て奥ゼロ→手前。上段は「測定の終点値」、詳細に現在位置と測定区間を表示する。Y下降中の連続指示ではない。支持の「下げる」とY下送りを混同しない。
- **絶対倒れと相対値**：同じ右倒れでもマスタとの相対傾きによりXYが＋/−/0となる独立例を確認済み。床に対するコラムの倒れだけで符号を決めない。ユーザー画像の−19は全入力が不明で同一再現していない。
- **横形の未解消点**：3DにR合わせ済みマスタ・計器・接触点がない。理想個体・平坦支持・標準寸法のアプリ世界座標yで、鼻端最低高さ2250 mmに対しXY/YZのS上端1630 mm。300 mm走査に必要な鼻端と計器本体の上下差は最低約920 mm、中央で約1220 mmで、腕の経路全長とは別。式の接触成立と取付けの妥当性を分けて修正する。寸法を変えれば腕による測定値も変わり得る。
- **横形YZの方式**：公開前の修正で、上面をテーブルZ送りで測る方法から、RをテーブルZ送りで合わせ、主軸側縦面を頭Yで測る方法へ変更した。取付先の指定だけでこの方式は一意に決まらない。現方式・旧方式のどちらかを過去の期待値だけで正解にしない。変更が必要なら面・送り・ゼロを先に示す。
- **小型立形**：直角測定と4方向の触れには、中央支持YZ差δに追加4δの回転を与えた「共通の仮想主軸姿勢」があり、支持応答を中央で約5倍にする。模型・局所角度・調整評価は元姿勢。単なる描画誇張ではない。存在を知らずに整合を認定せず、今回の測定目的との整合と必要性を調べる。既存5倍を正解と固定する必要も、新しい倍率で合わせ込む根拠もない。
- **移動コラム・門形**：移動する座、固定テーブル、案内の支持参照を取り違えない。固定門形はベッド9支持と左右柱各3支持、門のせん断形状と剛体計器腕を区別する。移動門形を固定門形と同じ所有関係にしない。
- **5軸**：直角測定はA/C非0で無効表示、触れは実A/C姿勢を反映、上面固有図はA=C=0基準という現実装。C→Aの親子変換、有限テーブル面、手前ゼロが面外のときの全点無効を確認する。意図した旋回角を直角誤差として消さない。
- **固有TIR・上面精度**：現実装は個体由来で支持を入力しない。これは「実際に付けたダイヤルの総指示」と同義ではない。何を表示しているかを点検し、固定値として妥当か、名称/測定配置との矛盾かを判定する。正当な固有成分を支持に連動させない。
- **旋盤**：面Xの不変を既存説明だけで承認しない。面Z・穴芯・バーは各所有関係と支持応答を追う。穴芯の公称XはスライダーXとは別で、支持操作ごと芯合わせしない現定義。面測定には無限平面近似があり、有限タレットからの脱落は未判定。穴径、バー長、腕、接触の有効性を調べる。
- **評価との違い**：横形の個別改善表示は有限測定に揃えたが、ほかの局所角度や総合目的は必ずしも同じ量ではない。主軸の触れ・固有TIR・上面値も総合評価の対象とは限らない。数値が別なら定義を区別し、誤った改善判定や逆符号併記を修正する。

- 新しい取付配置、測定軸、面、腕、接触、式、単位、正負。
- 器具を保持する工程と、R再合わせ・付替え・位置戻し・再ゼロする条件。
- 保存入力・個体・旧保存読込・再計算値への影響。必要なら計算モデルの版も整理する。

計算変更を禁止する依頼ではありません。通常の不具合修正は、根拠を示して進めてください。ただし、配置を勝手に変えた後に、その新配置に合わせた期待値だけで「正しい」としないこと。測定法の選択に必要な情報が不足している場合は、その点を特定し、独立して進められる調査・修正を止めずに確認してください。

統括は最低限、**修正担当と独立確認担当を別にする**こと。全7機種を機構や測定種類で分担し、共通関数の編集担当を明示して同時編集を避ける。独立確認担当は、支持入力と部材構造・取付条件から位置/姿勢/交点/伸びを別に求める。製品の符号表、測定関数の出力、旧テスト期待値を独立期待値と呼ばないこと。

既存の独立計算補助を使う場合は、その仮定を再読して適用範囲を明記すること。実ブラウザーの取得座標から交点だけ解いた確認と、支持入力から全幾何を構成した確認は区別してください。発見した食い違いを再現条件とともに修正担当へ返し、再修正後に同じ条件で独立再確認してください。

## 必ず維持する仕様

- 旋盤タレットは奥側。Xスライド・工具・往復台の関係も維持。
- 心押し台は3D模型だけ。測定・精度計算に参加させず、テスト加工・心押し検査を復活させない。センタは測定バーから離し、模型でもバー支持を追加しない。
- 旋盤は主軸固定テストバーをタレット側ダイヤルで測る構成。直径差の2倍処理へ変えない。
- 横形の直角マスタ/ダイヤルと、バー/ダイヤルの所有関係は前述のユーザー決定を維持。
- 整数µm表示、粗0.010 mm/微0.001 mm、支持選択、軸操作、デモ、理想輪郭、初期比較、保存・読込を維持。
- 既存の測定欄・左右スライド・設定・固定水準器・色調と操作を維持。関連する図・符号・誤解を生む表示は修正対象だが、無関係な画面改変や大きな別枠追加で置き換えない。
- 個体seedと固有誤差の関係を維持。未実装の横形B/パレット旋回、旋盤Y/タレット割出し等を追加しない。
