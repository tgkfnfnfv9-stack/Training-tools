# 同じ整数に見える値の追加独立確認

製品変更なし。検証したHTML `81af91d648ef304d5a7d411dd1d479e75f83fd851efcadc3676dcd7689e867a2`、測定ソース `0b2ebbd5…` に対して288比較、不一致0。[診断コード](../../tests/diagnose-horizontal-fixed-values-20261010.cjs)／[数値記録](fixed-values.json)。B/E操作は[実ブラウザー記録](browser/after/results.json)の実ボタン操作を使った。共通平面傾斜の追加ケースはDOM検証環境で実行した。その後の最終版はR中央線合わせの説明だけを追加し、[最終変更範囲の独立確認](compatibility.md)で数式不変を確認した。

## XYの0：今回のB操作では幾何上不変

理想・中央・B（手前右）±0.010 mmでXY生値は0のまま。ただし支持8点から独立に補間面・平均平面・部材基底を計算すると、頭のX走査0→300 mmとY走査が参照する**奥セル4点は全て0**で、局所左右／前後勾配も0だった。RをX送りに合わせた後のS法線 `nS` と、同じ頭のY移動方向 `uY` を別計算し、指示差 `−0.300 nS·uY ×10⁶` を求めた。

B＋0.010では `nS≈(1,0,−1.124×10⁻¹²)`、`uY≈(0,1,0)`、期待値 `+1.47×10⁻¹⁷ µm`。B−0.010は `−1.47×10⁻¹⁷ µm`。製品のR/S法線・頭の300 mm実移動とも一致した。これは「小さい生値を0へ丸めた」という説明ではなく、この配置で法線方向への相対移動がない結果である。支持変更後はRの方向合わせ・Sの始点10 mmゼロを取り直している。

used seed123456では同じ範囲で固定XY角から期待 `300000 sin(16.959/300000)=16.958999990968 µm`、製品 `16.9589999913～16.9589999917 µm`、表示+17。**XY全体が固有値として固定されているわけではない。** E（奥側の中間左）＋0.010では下表のとおり変わる。変わらない範囲を中央・B操作に限定する。

## 生値・表示・DOM更新の分類

各XY/XZセルのDOM `data-reading-microns` を保存し、画面整数と別に比較した。平面と測定子の交点は製品接触ヘルパーを使わず二分探索で再計算し、下表の生値と2×10⁻⁸ µm以内で一致した。

|実操作（中央）|XY生値 → 整数|XZ生値 → 整数|判断|
|---|---|---|---|
|理想・平坦|0 → 0|0 → 0|基準|
|理想・B＋0.010|0 → 0|+0.468151644 → 0|XYは幾何不変。XZは計算・DOM更新あり、整数だけ同じ|
|理想・B−0.010|0 → 0|−0.468149507 → 0|XZは符号も変わり、絶対値0.5未満なので整数0|

|used・平坦|+16.958999992 → +17|+8.128999999 → +8|固定個体、再方向合わせ／再ゼロ|
|used・B＋0.010|+16.958999991 → +17|+8.597141627 → +9|XYは同じ頭の角関係。XZは生値・整数とも変化|

## a/bと固有TIRを分ける

理想B＋0.010でaは `0→+1.340483855 µm（+1）`、bは `0→−2.554398789 µm（−3）`。B−0.010ではa `−1.340742165（−1）`、b `+2.554296863（+3）`。円筒半径25 mmと各実測定子の交点を独立に解き、一致した。始点の10 mmゼロ以後、途中でゼロを取り直していない。

全支持を `h=0.08x−0.05z+0.03 mm` の一枚の傾斜平面へ変えた場合、理想a/bはともに0、usedではa `8.125810727275→8.125810727268`、b `14.118678122278→14.118678122323 µm`。全サンプルの計器本体・測定子とバーを共通の剛体回転・平行移動で変換した独立座標と一致し、円筒接触も一致した。単に不変と仮定せず、**相対配置が同じであること**を確認した。

一方、共通の固有検査モデルの回転TIRはseed123456で根元 `11.985050763935`、先端 `14.390284296974 µm`。平坦／共通傾斜／B単独で完全一致し、偏心・傾きベクトルから回転一周の最大−最小を独立計算して一致した。TIRは符号付きa/b平行度とは別量で、横形のa/bを固有TIRとして固定する根拠にはならない。

この検証の独立性の範囲：中央BのXYは支持入力から指示までを独立計算。XZと一般支持のa/bは製品の実座標を観測として独立接触を計算した。一般の支持→姿勢の全範囲は[物理確認](physical-after-oracle.json)・[所有確認](ownership.md)と合わせて判断する。
