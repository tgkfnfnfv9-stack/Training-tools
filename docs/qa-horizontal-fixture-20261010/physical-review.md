# 横形YZ変更の独立物理確認

2026-10-10。修正担当とは別の担当が、テーブル上のマスタと主軸側のダイヤルという所有先から期待を組み立て直した。旧配置の内部一致や、未実装案の合格を今回の期待値には流用していない。

**修正後は主軸側の縦面Sを頭Y＋で測り、面へ近づけば＋、離れれば−となる。支持からの独立計算、実ブラウザーの生値、整数表示が一致した。** Rは上面を頭固定計器で測りながらパレットZを送り、両端等指示に合わせる。その後に選択Zへ戻し、別のS腕を取り付けてY区間始点でゼロにする。

## 変更前に保持した物理期待

上をY＋、主軸側をZ＋とする。Sの主軸側に計器本体があり、測定子は−Z向き。頭Yが奥へ倒れるなら、Y＋送りで本体が面から離れるので指示は負になる。

|単純配置|独立期待 µm|結果|
|---|---:|---|
|水平Z、頭Yが奥へ＋1 mrad|−299.999950|一致|
|水平Z、頭Yが手前へ−1 mrad|＋299.999950|一致|
|同じ器具で始終を交換し、始点ゼロを取り直す|元の値の符号逆|一致|
|手前側の面に計器を移し、＋Z向きに接触|元の値の符号逆|一致|
|全体へ共通の3D剛体回転・平行移動|元の値と同じ|一致|

計18状態、最大差5.85×10⁻¹⁰ µm。[符号の記録](physical-sign.json)。測定後の数値へ符号を掛ける期待ではなく、固定S面からの離間量を正負の根拠にした。

## 支持操作で確認した逆転

理想個体、標準寸法2.72×3.68 m、**X=Y=0、Z=−100**。支持G/Hだけを同時に操作する。左右ねじれを生じさせず、後側支持勾配から頭の前後倒れを独立に求められる条件。

|操作|旧生値 µm|旧表示|新ブラウザー生値 µm|新表示|支持からの独立期待 µm|
|---|---:|---:|---:|---:|---:|
|G/H＋0.010 mm|−2.445652173675|−2|＋2.445652173777|＋2|＋2.445652173866|
|G/H−0.010 mm|＋2.445652173673|＋2|−2.445652173555|−2|−2.445652173866|

ブラウザーは実際の支持選択・上下ボタンを操作した記録。G/H＋では頭Yが手前へ倒れ、主軸側の計器がS面へ近づくので正になる。旧上面／Z送り法は別の接触配置だったため符号が逆だった。[前後の入力と独立期待](physical-browser.json)。

## 支持から組み立てた2D独立計算

左右同高の前後4段について、支持高さから共通平面と各補間区間の勾配を求め、座面の剛体回転を2次元で構成した。Rは候補の正規化した端点弦を使わず、固定された世界先端がR終端の面にも載る角度を二分探索で求めた。Sは静止マスタ法線に対する頭Yの移動の投影から期待値を算出した。

3深さ（3.68／2.70／1.23 m）×9支持状態×YZ固有角差0／±30 µm×4軸状態の324状態。支持状態には前後個別の±0.010 mm、中間支持、±0.050 mmと最大±0.500 mmの交互配置、共通平面を含む。R区間内の支持境界とその両側も検査した。

|確認|結果|
|---|---:|
|比較数|55,728、不一致0|
|生値の最大差|6.51×10⁻¹⁰ µm|
|接触点の世界座標の最大差|1.78×10⁻¹⁵ m|
|R始終の指示差|最大2.69×10⁻¹⁰ µm|
|R途中の始点からの指示差|最大292.837605 µm|
|表示誇張ON/OFFによる生値差|0|

R途中の値は最大支持条件では明確に変わる。方向合わせが保証するのは両端の等指示であり、途中まで0とする処理はない。途中の接触は0〜20 mmの伸びと有限面の範囲内だった。

R中はX/Yと計器本体が固定、S中は選択Zとマスタが固定、S初期伸びが10 mmであることも確認した。R後に選択Zへ戻しても同じマスタ姿勢をパレットに従って運び、そこでRを再調整していない。S途中には再ゼロしない。[全状態](physical-after-oracle.json)、[旧配置の観測](physical-before-oracle.json)。

## 非対称支持・個体誤差を含む3D独立計算

2D検査だけでは左右非対称B/E操作やused個体を認定できないため、別の3D計算を追加した。入力はブラウザーに記録された8支持の高さ、寸法、軸位置、保存個体の角度差のみ。製品の姿勢・測定関数や出力姿勢を期待値には使用していない。

1. 8支持から最小二乗平面と双線形セルの接線を求め、接線の外積から座面の基底を作る。
2. 個体のXY／XZ／YZ角度差を3組の内積条件として解き、Y/Z方向を構成する。
3. 固定計器先端がR終端でもR面と厚み中央面に残る2条件を、マスタのyaw／pitch角の二分探索で解く。候補の端点弦の正規化式を呼ばない。
4. 選択Zへ戻した静止S面の法線と、頭Yの移動から露出長の増減を求める。

この独立導出により、説明に不足していた設置条件も発見した。**上面Rの両端等指示だけではマスタの横向き（yaw）は一意に決まらない。R走査の始終で計器先端が厚み中央線を通るよう横方向も合わせる必要がある。** 現数値モデルはこの追加条件を自動的に適用していたため、製品の取付け説明にも明記する再修正を指示した。導入説明・測定注記・YZ詳細手順の3箇所にこの条件が追加されたことをソースで再確認した。数値式の変更ではない。

反例はused123456・平坦支持・軸中央。yawを±0.05 radにしても、Rの傾きを調整すれば上面の始終点を等指示にでき、横ずれは約15 mmで厚み中央±25 mmの有限面内に収まる。Sも有限面内だが、結果は以下のように異なる。

|上面Rは全て両端等指示|Sの指示 µm|整数|
|---|---:|---:|
|厚み中央線も方向合わせ|−14.119999995|−14|
|yaw=−0.05 rad|−14.985744413|−15|
|yaw=＋0.05 rad|−13.290512610|−13|

したがって中央線合わせは、未検証の微小差を無視するための注記ではなく、今回の測定値を一意に決める設置条件。以下の独立期待はその条件を適用した値である。[再現式・入力・3結果](physical-yaw-alignment.json)、[独立反例スクリプト](../../tests/check-horizontal-fixture-independent-yaw-20261010.cjs)。

ブラウザー61行すべてで生値と整数表示が一致した。最大差3.11×10⁻¹⁰ µm。used123456・標準寸法・X=Y=Z=0の代表値は以下。

|平坦|−14.119999994584|−14.119999994695|−14|

## 回り込み腕と有限マスタ

旧提案の「鼻端と計器を一直線でつなぐ腕」には、マスタを貫通する反例があった。修正後は鼻端から上へ逃げ、厚みの外側を回って計器へ届く6点の剛体経路を持つ。腕は半径4 mm、測定子は別で、面から10 mm離れた計器本体から伸びて接触する。

まず2D独立マスタの324状態で59,130線分を検査し、腕半径控除後の最小余白は5.587225 mmだった。

さらに、2寸法×19支持状態×理想／used×12軸状態の912状態で3D経路を検査した。各8支持の±0.500 mm、正負ねじれ、全軸端8組、中央、選択Zが支持境界の直前／一致／直後を含む。

|3D腕の検査|結果|
|---|---:|
|Rの全記録位置における線分|88,920|
|Sの全記録位置における線分|77,520|
|半径4 mm控除後の最小余白|5.608296 mm|
|マスタとの交差|0|
|腕の各線分長の最大変化|5.56×10⁻¹⁷ m|

鼻端から最初に上がる線分も含む。独立の線分対直方体の最短距離計算で、端点だけではなく各線分全体を検査した。R/Sの時刻は16分割とR支持境界の両側であり、未サンプル時刻まで含む連続衝突判定とは区別する。この3D腕検査では機械／マスタ姿勢を観測に使っており、上の支持からの独立計算とは検査範囲が異なる。[3D腕の結果](physical-arms.json)。

## 設置と未確認範囲

マスタのパレットからの最小高さは49.884862 mm、パレット端までの最小余白は82.172283 mm。下面の4隅高は最大0.118875 mm異なるため、固定50 mm脚4本ではなく、調整台でRを合わせてから固定する仮定が必要。製品説明にもその条件が入った。

サンプルワークとマスタは同じ空間を占めるため、測定時はワークを外す。これも製品説明で明示された。腕とマスタの有限形状は確認したが、全機械部材との干渉、実物の腕の剛性／たわみ、実機の据付感度は認定していない。
