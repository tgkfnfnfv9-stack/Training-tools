# 6点支持の立形追加・旋盤テストバー300 mm（2026-10-13）

対象：main 93f88b8（PR #37 マージ後）から作業。ブランチ `feat/six-point-vertical-20261013`。

## 1. 立形・6点支持（新規、機種一覧で小型の下・全7機種）
- 構成：小型立形と同じ固定コラム・テーブルXY・主軸頭Z。一回り大きい（機械幅3.9 m・奥行3.5 m、支持スパン3.12×2.8 m）。
- 支持：左右に手前・中間・奥の3点ずつ。A 左手前、B 右手前、C 左中間、D 右中間、E 左奥、F 右奥。
- 計算モデル `compact-six-sag-v1`：
  - 四隅のボルトは小型と同じねじれ板（非対称剛性の2モードRitz）。
  - 中間ボルトが四隅の面から r だけずれると、ベッドが前後に反る（形 1−Z²、左右は直線で配分）。
  - **仮定値**：反りの大きさは r の50 %（ベッド剛性とボルト剛性の比、`compactSixSagShare=0.5`）。中間ボルト1本 +0.1 mm で YZ 約10 µm/300 mm。
  - 6点が同じ平面上なら r=0 で、機械は一体で傾くだけ（直角・触れは不変）。
- 応答（独立検証と小数3桁まで一致）：

| 支持の変更 | テーブルに対するコラム前後倒れ | YZ |
|---|---|---|
| C（左中間）+0.1 mm | −34.8 µrad（後ろ） | +10.4 µm |
| 中間2点 +0.1 mm | −69.6 µrad | +20.9 µm |
| 奥2点（E,F）+0.1 mm | +34.8 µrad（前） | −10.4 µm |
| 全6点が同一平面 | 0 | 0 |

  奥2点を上げると、コラムはテーブルより大きく前に倒れ（コラム62 µrad、テーブル約27 µrad）、YZは上でゼロ→下げるほどマイナス。
- 抽選・微調整ヒント：他機種と同じ（粗調整後に0.02 mm超え、最良で全項目15 µm以内）。16回の試行すべて、ヒントどおりで目安内。
- 内部の機種一覧の順番は変えず末尾に追加し、機種選択の表示だけ小型の下に並べる（保存データ・既存の番号は不変）。

## 2. 旋盤テストバー 300 mm（`lathe-carriage-v4` / `lathe-testbar-v3`）
- バー：長さ300 mm・φ50、主軸端に固定（以前の模型は2.2 m）。
- 計器：タレットの工具位置に固定。主軸端から10 mm（a、ゼロ）→ 290 mm（b）まで Z＋へ280 mm 送る。両端10 mmは余白。側面（奥から）・上面（上から）、押込み＋。
- 工具位置がバーの根元へ届くよう、旋盤の Z 移動範囲を ±0.7 m → ±0.9 m に変更（スライダーの操作・画面配置は同じ。往復台と主軸台は干渉しない）。
- 独立検証：接触位置は軸方向 0.0100→0.2900 m、走査の Z は −99.7 → −68.6 %（範囲内）。各支持 +0.1 mm の側面読みは自前の一次幾何と一致（±7.000 µm）。剛体傾斜で不変（≤4e-10 µm）。
- 条件：支持幅（設定）を約0.64 m未満または約5.33 m超にすると、バー位置へ届かずバー測定は「—」（無効）になる。
