# 横形測定表示変更の独立互換確認

確認担当は製品変更担当と別。`ea7498e` の生成HTMLを不変の比較元とし、実Linux Chromiumで全7機種を各2状態ずつ、変更前14状態・変更後14状態で比較した。**140比較すべて一致、ブラウザー例外0件。**

これは今回の表示変更が既存数値・保存・他機種へ波及していないことの確認であり、測定式の物理的な正しさや実治具の成立性の根拠には使わない。

## 対象と方法

- 比較元：`ea7498eb4e013833ccbc111472cc804f014a7b2f`、HTML SHA256 `a33e7a9efc3094f41d51bbf48ca541176d8e9984aa3774a5d5ff3ec54edfbf7c`
- 比較先：今回の作業ツリー、HTML SHA256 `9d5cd394c191c51f346f272a098841b46fbde64fdc5fe69ae4753f292b05d819`
- 機種：vertical / travel / gate / gantry / five / lathe / horizontal。
- 状態1：new、seed 123456、平坦支持、全軸中央。
- 状態2：used、seed 123456、支持の2点目 +0.013 mm・3点目 −0.017 mm、軸入力 X 37 / Y −62 / Z 81 / A 45 / C −33。機種に存在しない軸は保存されない。
- 両状態とも表示誇張なし、支持操作単位0.001 mm。1280×1000のChromiumで実行。実iPhone Safariでの結果ではない。

## 確認結果

| 比較 | 結果 |
|---|---|
| 全7機種の測定生値と整数表示 | 14状態すべて変更前後で完全一致 |
| 横形XY / XZ / YZ / Z平行a・bの生値 | 2状態とも完全一致 |
| 横形以外6機種の測定欄・基準説明・精度詳細のDOMと文字 | 12状態すべて完全一致 |
| 全7機種の保存record全体 | 14状態すべて完全一致 |
| ブラウザーの実ダウンロード | 前後各14件、取得JSONはその時点のrecordと完全一致 |
| 変更前JSONの実ファイル入力からの読込 | 14件すべて受理。支持を実ボタンで変更してから読み込み、全record・生値・整数表示が復元 |
| 実行中の候補HTML変更、ブラウザー例外 | ともになし |

保存比較では実際に保存可能なnew/used個体を使う。デバッグで `machineProfile=null` を注入した理想状態は通常の個体保存契約ではないため、保存互換試験には使っていない。旋盤の読込比較では、存在しないY/A/C軸の診断メタデータだけを除外する。数値・支持・個体・正式なX/Z軸状態は除外していない。
