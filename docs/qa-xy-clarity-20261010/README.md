# 横形XY：ゼロ・送り・模型位置の食い違いへの修正

2026-10-10。ユーザーの「コラム右倒れなのに、下へ行くと−」という公開版画像を受けた継続作業。最新mainを再fetchし `cbdcf81a4b3b252d4113621b8361b20640955688` を確認した。修正前PRは `ea7498e`。公開版とPRの測定計算を取り違えず、修正担当・独立幾何担当・実ブラウザー担当・互換確認担当を分けた。

## 今回修正したもの

- 横形の常設欄を「測定の終点値」と明示。小図ではゼロ位置と一定の測定方向を示す。
- 詳細の先頭に、模型の現在位置・ゼロ位置・終点を同じ部材座標のmmで表示。300 mmを確保するため計算上の始点を戻す場合、その移動量も表示する。
- XYの「上で再ゼロして下降」と「下のゼロを保持して戻る」を区別する。
- 横形のダイヤル説明から別定義の局所角度換算値を外す。修正前は同じXZ詳細に接触指示＋8と局所角度−8が並んでいた。設定内の局所角度図は維持する。

今回の変更は横形測定UI。測定式・測定配置・再ゼロ条件・保存形式は変更していない。前段PRには姿勢と有限R合わせ等の計算修正があるが、今回新たに全数値の符号を反転したり、支持操作で必ず数値が変わる処理を追加したりしていない。

最初のUI案は小図内の文字が携帯幅で密集したため、独立ブラウザー確認で差し戻した。上段は短いゼロ位置・方向表示へ整理し、取付先等の詳しい説明は既存の詳細図へ残して再確認する手順を取った。

## XYの数値確認

理想個体・標準寸法・軸中央。主軸側計器で、テーブル上のR合わせ済み直角マスタを右から測る。下でゼロ、Y上へ300 mm。G以外の支持は0。

|支持状態|独立期待値 µm|PR生値 µm|画面の整数 µm|
|---|---:|---:|---:|
|全支持0|0|0|0|
|Gを0.010 mm下げる|＋1.963718|＋1.963718|＋2|
|Gを0.010 mm上げる|−1.963712|−1.963712|−2|

Gを上げた例では、300 mm上送りで計器が右へ0.647978 µm、マスタ面が左へ1.315734 µmとなる。計器がマスタから離れ、測定子の伸びが10.000000→10.001963712 mmへ増えるため指示は負になる。支持高さから独立に接線・剛体姿勢・R走査の弦・接触面距離を算出し、18状態で生値誤差は最大9.4×10⁻¹⁰ µm。実描画用コラム方向も照合した。

コラムとマスタが共に右へ30 µm傾けばXYは0。同じ右倒れでもマスタがさらに右へ傾けば正となる例も確認した。床に対するコラム倒れだけで正負は決められない。

公開版のG操作値は約±0.041360 µmで、上表とは異なる。公開版の代表案内方向によるR合わせと、PRの有限X走査で腕を含めたR合わせとの差である。[公開版の確認](../qa-public-xy-20261010/README.md)と混ぜない。ユーザー画像の−19そのものはseed・支持入力が不明で、同一状態の再現とは扱わない。
