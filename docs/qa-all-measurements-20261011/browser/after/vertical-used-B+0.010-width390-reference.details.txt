③ サドル＋テーブルを部材−Y・手前へ300 mm（NC指令の符号ではありません）。基準器に対する計器は奥へ。測定子が本体へ右に引っ込むと＋、伸びると−。固定したS面へ本体が近づく向きとは区別します。

図の右＝右、図の上＝奥。S面に沿う展開図で、模型のカメラとは独立です。Rは方向合わせ面、Sは読みを比較する面（旋盤はSのみ）。「直角図のずれを強調」で本体の法線変位と測定子の傾きの強調を切り替えます。小型の接触計算は、模型と同じ物理姿勢を使います。器具の寸法は強調を外しても模式図です。図の変位・傾きは枠内に制限します。数値には誇張を掛けません。破線は本体の始終位置を結ぶ目安で、連続軌跡ではありません。

+300.0 → 0.0 mm（Y部材位置・中央0）。スライダーの現在位置と接触ゼロ位置は同じとは限りません。

Y走査は模型の測定Pの移動を使います。

初期支持状態：+1 µm／現在：+17 µm（同じ区間で各々ゼロ）。

設定内の局所軸角度は現在位置の角度換算です。この接触・有限走査の指示差とは定義が異なります。

支持・軸位置・寸法・個体の変更ごとに取付け・方向合わせ・始点ゼロを取り直します。器具とゼロを保持したまま支持を変える測定ではありません。5軸はA=C=0。基準面は走査300 mm＋両端10 mm、幅50 mmの仮想校正面、計器の初期伸び10 mm・計算範囲0〜20 mmです。小型Yは模型のテーブル上面中心P（支持基準から0.50 m）の移動を使います。他の非横形の走査は姿勢一定の代表点です。非横形の直角検査は実際の主軸から計器本体までの腕、器具の取付高さ・支持台寸法を定義していません。取付姿勢を始点から輸送し、変姿勢の区間は16分割の内部点で接触を確認しますが、全治具干渉・測定力・弾性を再現しません。保存した機械入力から毎回再計算し、器具取付けとゼロ自体は保存しません。同じ固定配置で指示だけ再ゼロする逆走と、方向合わせから取り直す本測定は別です。
