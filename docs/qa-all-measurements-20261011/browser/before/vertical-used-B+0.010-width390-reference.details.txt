基準器（旋盤は精密フランジ、ほかは直角マスタ）とスピンドル式計器の教材配置。●0から300 mmの仮想測定。＋＝押込み増加／−＝減少（ID-F通常カウント）。黒い基準面、オレンジの相対移動、押込＋を区別します。小型のZ送りと触れは共通の仮想主軸姿勢で接触計算します。前後の支持応答は中央で約5倍、固有誤差はそのままです。模型・局所角度とは姿勢を区別します。

直角マスタ：テーブル上／計器：主軸頭に固定。右側からS面に接触。

① R面を開始位置の測定PのX局所送り接線に平行に方向合わせ。RとSの直角が保証されたマスタを使用。平定盤の側面を代用しない。
② 手前・右側の●0でゼロ合わせ。
③ サドル＋テーブルを部材−Y・手前へ300 mm（NC指令の符号ではありません）。基準器に対する計器は奥へ。測定子が本体へ右に引っ込むと＋、伸びると−。固定したS面へ本体が近づく向きとは区別します。

図の右＝右、図の上＝奥。S面に沿う展開図で、模型のカメラとは独立です。Rは方向合わせ面、Sは読みを比較する面（旋盤はSのみ）。「直角図のずれを強調」で本体の法線変位と測定子の傾きの強調を切り替えます。小型の接触計算は、直角測定と触れに共通の仮想主軸姿勢を使います。模型と局所角度は元の姿勢です。器具の寸法は強調を外しても模式図です。図の変位・傾きは枠内に制限します。図と数値は同じ仮想測定姿勢から求めます。数値に後から倍率を掛けません。破線は本体の始終位置を結ぶ目安で、連続軌跡ではありません。

+300.0 → 0.0 mm（Y部材位置・中央0）。スライダーの現在位置と接触ゼロ位置は同じとは限りません。

Y走査は模型の測定Pの移動を使います。

小型は前後の支持応答を中央位置で約5倍とする共通の仮想主軸姿勢です。支持のみの中央YZ角差δに対して、主軸とZ送りを基準X軸まわりに追加で4δ回し、300 mmの走査と直径300 mmの触れをそれぞれ接触から計算します。固有誤差は増幅しません。補正姿勢は支持・寸法ごとに固定し、テーブル送りで変えません。全位置の数値が厳密に5倍になる仕様ではありません。中央以外ではXZにも微小な交差影響があります。元の有限測定値：+17 µm。実機感度の再現ではありません。共通の剛体傾斜では補正せず、模型・局所角度・調整評価・参考最良は元の計算です。

初期支持状態：+1 µm／現在：+17 µm（同じ区間で各々ゼロ・ともに共通の仮想主軸姿勢）。

従来の局所角度差：+17 µm／300 mm換算。上の表示値とは別です。

支持・軸位置の変更ごとに方向合わせとゼロを自動で取り直します。5軸はA=C=0。旋盤は主軸基準の精密フランジでX走査。基準面は走査300 mm＋両端10 mm、幅50 mmの仮想校正面、計器の初期伸び10 mm・計算範囲0〜20 mmです。取付けや干渉、測定力、基準器の実寸は再現しません。姿勢変化を含む教材モデル reference-scan-v3。小型Yは模型の測定P、横形Zはパレット上面中心（支持基準から0.61 m）の移動を使います。他の走査は姿勢一定の代表点です。取付姿勢を始点から輸送し、変姿勢の区間は16分割の内部点、横形では支持境界の両側でも接触を確認します。連続経路の衝突判定ではありません。未知のガイド曲線は追加していません。保存した機械状態から毎回再計算します。旧データの局所角度・参考調整・軸位置は維持し、横形の有限測定値は今回の取付位置で再計算されます。同じ固定配置で指示だけ再ゼロする逆走と、方向合わせから取り直す本測定は別です。
