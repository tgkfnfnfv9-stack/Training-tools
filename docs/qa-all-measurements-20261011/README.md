## 確認した問題と修正

1. **小型立形だけの追加主軸回転を撤去。** 模型と同じ支持姿勢を使う。旧式は中央支持YZ差δに追加4δを与え、測定だけ約5倍の応答を作っていた。支持入力から別に構成した幾何と一致しなかった。測定面・300 mm区間・所有関係・再ゼロ工程は維持した。
2. **旋盤の面X/Zに有限接触判定を追加。** タレットの12角前面／外側フラットを外れた走査を無効表示にする。始点だけでなく途中・支持境界両側・終点と測定子伸びを判定し、不成立を0で埋めない。
3. **個別改善を表示中の有限測定と揃えた。** 局所角度で改善していても有限測定で悪化する場合を区別する。設定の局所角度・参考総合評価は別定義と明示する。
4. **再測定と旧ゼロ保持、固有成分と総指示を区別。** 全直角詳細の現在位置・始点・終点を示し、再取付け・始点再ゼロの説明を揃えた。TIRと上面残差は支持非依存の固有成分を維持する。

計算に着手する前に、反例、変更式と配置、再ゼロ条件、旧保存への影響をユーザーへ説明した。[変更前説明の記録](change-rationale.md)。倍率、揺らぎ、全数値の一律符号反転、支持操作での個体再抽選は追加していない。

## 付けたままと再ゼロ後は同じ値ではない

横形と旋盤の既存絶対配置は、初回の器具を取付先部材座標へ固定し、支持変更後の部材姿勢で輸送した。世界座標へ固定した診断ではない。旧ゼロ保持、同一配置で始点だけ再ゼロ、R合わせ・付替えもやり直す再測定、逆走査を別に記録した。

used seed123456、全支持0からBのみ+0.010 mm、軸中央の例：

|測定|操作前|完全再取付け・再ゼロ後|初回取付け・旧ゼロ保持の終点|
|---|---:|---:|---:|
|横形XY|16.959000|16.959000|16.270963|
|横形YZ|−14.120000|−12.544072|−10.166201|
|旋盤面X|−3.757939|−3.757939|−7.583003|

このUIは完全再取付け・始点再ゼロ後の値を表示する。不変な再測定値を、付けたままの指示も不変だという証拠にはしない。[固定保持の全支持比較・座標・伸び・逆走査](independent-horizontal-lathe.md)。

非横形の直角測定は実取付高さ・腕長・材料点が、4方向触れは軸方向腕長・初期伸び・ストロークが未定義。そのため**これらの旧ゼロ保持の絶対指示は一意に求められない**。再ゼロ値で代用していない。追加の教材診断配置を採用するかをユーザーへ確認し、回答待ちの間も独立して確定できる修正を完了した。[不足する条件](independent-milling.md)。

## 保存と確認できない実物条件

保存schema、支持入力、個体seedと固有成分は維持した。旧JSONを実ファイル入力で読み込み、再ダウンロードを確認する。保存には器具配置・初回ゼロ・測定結果がないため、読込後は新しい計算で再測定する。小型の値と旋盤の面外判定は変わり得る。

横形の現方式は長い剛体腕を仮定し、鼻端と計器の上下差は始点で最低約920 mm、中央指定で約1220 mm。方式や高さを勝手に変更していない。非横形の実取付け、触れのストローク、横形長腕の剛性と干渉、旋盤穴の傾斜した有限円筒との接触は未モデル化／未認定。支持補間と剛体部材は教材の幾何仮定であり、荷重・弾性・測定力の実機検証ではない。

全測定を棚卸しして、定義済みの計算と表示の矛盾を修正した。未定義な実取付けまで解決済みとは扱わない。
