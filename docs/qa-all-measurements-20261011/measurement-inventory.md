# 全7機種・現存測定の棚卸し（2026-10-11）

基準は `main baede5bfafed034f5f7d21ec9957e344dc7c8c98`。製品の現在UIにある機種と測定だけを数える。`kind=vertical`、`portal`、旧精密フランジ、加工試験、心押し検査は追加しない。

- **非横形の器具位置**：Sの原点を仮想原点 `[0,0,0]` に置く代表配置。支持からの現実の取付高さ、主軸鼻端から計器本体までの腕寸法、設置台は未定義。S面は走査300 mm＋端余白10 mmずつ、幅50 mm、初期伸び10 mm、計算範囲0〜20 mm。マスタの実寸・全機械干渉・Rの有限実走査を再現していない。小型Yだけテーブル上面中心P（支持基準から0.50 m）の材料点移動を使用し、他は姿勢一定の代表点（この仮定の適用限界を保持）。
- **横形の器具位置**：320×320×50 mmの教材マスタをXY/YZは立て、XZは寝かせる。パレット上面原点は模型内部 `[0,1.27,-.85]`、支持から0.61 m。Sの理想接触はXY/YZで上面から60→360 mm、XZで50 mm。鼻端模型位置 `[0,2.55,-.93]` から剛体腕を仮定する。RとSは付替え。各面の有限範囲・測定子伸びをサンプル確認するが、鼻端高さとマスタ上端の大きな差、腕経路、全機械干渉、調整台実寸の現実性は未確定。横形担当の配置監査を参照。
- **再測定工程**：支持・軸位置・寸法・個体を変えるたび、現在の入力からR合わせ、S用取付け、区間始点戻し、初期伸び10 mm、始点再ゼロを行う。途中再ゼロなし。軸端では300 mmを確保できるよう計算上の始点を戻す。表示はその区間の終点値で、スライダー位置の瞬間指示ではない。
- **取付保持**：上記再測定APIには取付時の機械座標とゼロを保存する状態がない。支持変更後に再びAPIを呼ぶだけでは固定取付けの検証にならない。独立診断は初期器具を所有部材の座標で保持して輸送する。実寸未定義の代表配置での診断一致と実器具の到達確認は別。
- **5軸**：A/C非0の直角測定は無効。意図した旋回角を固有直角誤差として除かない。

各点は主軸軸線に平行な直線とテーブル平面の交点。手前接触が面外なら共通ゼロがないため全4値無効。各他点も面外は無効。支持変更のたびに面への軸線交点へ中心を合わせ直し、手前を再ゼロする。軸線方向の共通移動は差から消える。この自動合わせをした4点差は、取付腕と初期ゼロを保持した絶対指示とは違う。

半径150 mmは定義されるが、主軸鼻端から旋回面までの実際の軸方向腕長・計器初期伸び・可動量・測定力・全治具干渉は製品では未定義。有限テーブル面だけを判定する。回転TIRとも9点上面固有値とも異なる。修正前の小型には支持由来の追加4δ姿勢があり、模型と別の姿勢で測っていた（担当修正記録参照）。

## 横形バー：a/b＝2終点指示

主軸に理想円筒φ50 mm・全長320 mmを固定し、主軸は回さない。ダイヤルはパレット上面中心に剛体腕で固定。aはバー左側から右向き、bは下から上向き。別の接触配置。鼻端の前310 mmでゼロ→前10 mmまで、パレットZ＋を300 mm送る。バーは静止、計器と腕と測定子方向をパレット姿勢で一体輸送する。初期伸び10 mm、範囲0〜20 mm、バー端余白各10 mm、16分割＋支持境界両側で接触を確認。取付支持高0.61 mは計器本体の高さではなく腕基準。

支持・XYZ・寸法・個体の変更ごとにバー位置と計器取付けを現在入力から作り、始点再ゼロ。支持変更前のゼロは保持しない。主軸鼻端まで到達する腕の長さと経路は教材仮定であり、実物としての到達・剛性・干渉確認は未実施。径の2倍変換はしない。

|旋盤|同一理想バーの2断面（1ページ目）|なし|面、穴芯、バー平行とは別|

- TIRは固有偏心ベクトル `e (µm)` と傾き `t (µrad)` の理想円断面中心 `e+tL/1000` を回し、固定径方向の円周交点の最大−最小を取った `2|e+tL/1000|`。一様な位置オフセットとゼロ設定はTIRから消える。同じバーなので根元より300 mm先が小さいこともある。静止状態の取付保持指示の差はこの値から求められない。
- 9点は奥→中央→手前の各行に左／中／右。個体seedからの生高さの最小二乗平面を除き、その残差を左中央で0にする。`range=max-min` は残差9点の最大差。厳密な最小領域平面度でも、主軸側計器の総指示でもない。平面状の高さ・傾き追加を除去する定義なので支持非依存が妥当。荷重・支持による弾性変形は含まない。
- 両方とも支持・軸・部材姿勢・器具取付点・腕・測定子の初期伸びを入力しない。TIRの計器本体をどこへ固定するか、9点の実走査器具と高さは定義されていない。未定義器具を追加せず、固有値として検証する。これらを「付けたままダイヤルが不変」の証拠にしない。
- 独立円交点と一般連立方程式による最小二乗解、全50支持の粗微上下、実DOM整数表示、旧保存復元の証拠は [固有・保存監査](intrinsic-save-audit.md) と対応CSV/JSON。

## 詳細・評価・保存との対応

|UI/データ|何を表すか|測定値との関係|
|---|---|---|
|上段の直角・バー・面|再取付け・始点再ゼロ後の有限300 mm終点指示|現在位置でゼロを保持する針の指示ではない|
|4方向触れ|現在支持姿勢で手前再ゼロした直径300 mmの4点差|固有TIR・上面残差とは別|
|設定の局所軸角度|現在位置の軸方向の角差を300 mmへ換算|接触・腕・有限走査ではない。同じ測定カードで別符号の値を併記しない|
|初期比較|同一個体・現在寸法/選択区間で、初期支持と現在支持を各々再測定|過去に器具を付けた状態のゼロは保持しない|
|参考最良・微調整総合評価|代表端/中央の局所直角差、相対姿勢差、平均傾き等の補助目的|有限測定、TIR、上面9点、穴芯など全数値を一括最小化する値ではない|
|保存JSON|支持高さ・寸法・軸位置・個体seed/固有入力・初期支持・参考最良支持|器具の部材座標、初回接触、ゼロ、測定結果を保存しない。読込後は現在の測定仕様で再計算|

付随する水準器は全7機種とも別定義。右枠の固定表示は全支持の平均傾き `levelSolution.lr/fb (mm/m)` で、模型の特定位置に置いた器具やダイヤルではない。設定内の局所水準器は横方向中央x=0、選択した前/中/奥 `z=measurePos*depth/2` の支持面勾配を表示する。気泡は高い側へ移動し、支持変更で平均/局所が別々に変わる。感度設定は目盛表示、誇張は描画だけ。これらに接触ゼロ、マスタ、回転TIRの定義を適用しない。主測定の124数値とは分けて追跡する。

機種の保存 `calculationModel` は支持/部材モデルを識別する。有限検査モデルの表示名とは別。入力schema・個体seedを変えない測定修正でも再計算結果は変わり得るので、その説明と旧JSONの実読込を残す。
