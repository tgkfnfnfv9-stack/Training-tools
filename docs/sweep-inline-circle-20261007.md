# 触れの小円と手前ゼロ

開始mainは 7c9fcb344b73dd2922aee9b2ef753fe31200a8c3。remote mainも同一、開始時の未コミット変更なし。

依頼は既存「触れ」枠に小さい円を追加し、手前を0と分かるようにすること。他のUIは変更しない。

既存5機種の触れ枠内に4方向の測定位置を示す小円を追加。下側の手前接触点を橙色で示し、手前0を表示する。右・奥・左・手前の4つの数値は既存の計算・ゼロ基準を維持。手前が面外などで無効なら小円の0も抑止する。

小円は測定位置の模式図で、カメラ投影や旋回中の5軸テーブルを描き直す図ではない。計算式、符号、保存形式を変更せず、円の描画から数値を生成しない。

触れ枠64×79を維持（横形のZ平行枠は従来の64×77のまま）するため、枠内だけの見出しと行間を調整した。横形のZ平行図、旋盤、枠外の模型・固定水準器・軸操作・設定には変更しない。

修正担当と独立確認担当を分け、固定した修正前HTMLと修正後HTMLを実ブラウザーで比較。詳細・証跡は qa-sweep-inline-circle-20261007/README.md を参照。実iPhone Safariは未確認。今回の表示確認は実機の測定精度の検証ではない。

初回の独立比較で、触れ枠は元が79px高なのに77pxと誤認したことで、枠外を2px動かす不具合を検出。触れ枠内の見出し高さを修正し、元の79pxへ戻して再確認した。

既存の独立数値検証 check-spindle-sweep.cjs は323件成功。「SVGが存在しない」という旧UI条件のみ、今回明示依頼された小図が1つ存在する条件へ更新した。旧ダイヤル盤、1周操作、アニメーションが存在しない条件は維持している。
