# 1番・小型立形YZのブラウザー重点確認

対象固定HTML SHA-256: `2559e5d7873677c532143883fcc50d44763b459f5d2982eac95e69e366d4b141`。実行: `node tests/browser-compact-yz.cjs`。Chromium、1280×1000／320×568。57項目成功、ブラウザー例外なし。

## 症状の再現と判定

「柱が前倒れから後倒れになっても、YZの値が良くならない」は実ブラウザーで再現した。YZ固有差を+30 µm/300 mmに固定し、4支持を前後で同量ずつ調整して共通の前後傾斜だけを変えると、以下となった。柱・テーブルの倒れは床基準、正は前倒れ。支持基準面の傾斜は mm/m。

|支持面前後傾斜|柱前後倒れ µrad|テーブル法線前後倒れ µrad|有限YZ µm|
|---:|---:|---:|---:|
|+0.15|+250|+150|−30|
|−0.10|ほぼ0|−100|−30|
|−0.35|−250|−350|−30|

主軸頭のZ送りだけでなく、測定PのY送りも共通に回転する。そのため床に対する柱倒れのゼロと、Y/Zの直角のゼロは一致しない。柱を鉛直にしても相対差100 µrad（300 mmで30 µm）が残る。これは図の符号間違いではなく、現行モデルの共通回転と固有直角差の結果。

- [ほぼ鉛直の側面](compact-common-tilt-upright-side.png)
- [後倒れの側面](compact-common-tilt-back-side.png)

模型と図を目視確認した。側面の模型は画面右＝奥、上＝上。有限YZ図も右＝奥、上＝上、上・奥側の接触ゼロから下へ走査しており指定に一致する。XZは右＝機械右で、YZとは異なる断面。

## 追加照合

理想、YZ固有角度差±30 µm/300 mm、対角捻れ±0.12 mmの5状態について、PC／携帯の図の方向・ゼロ接触位置・読みを確認した。純粋なYZ角度差δに対する独立期待値は `−0.3 sin(δ) × 10^6 µm`。下向き走査で本体が後方へ遠ざかる正の角度差では測定子が伸び、指示は負となる。角度差以外のXY・XZはゼロに保たれた。

カメラ回転、ズーム、表示誇張の変更で測定値が変わらないことも確認した。正負捻れについてはブラウザーと表示の確認であり、数値の独立検証は別担当の `tests/check-compact-yz-independent.cjs` と `tests/check-compact-yz-sensitivity.cjs` を参照。

## 修正

`src/reference-measurement-ui.js` の小型立形YZの説明に、床基準の倒れとY/Z相対差の違い、共通傾斜では指示が変わらないこと、中央付近では現行曲げ仮定のYZ調整効果が小さく固有差が残ることを追加した。式・測定配置・ゼロ位置・XY/XZ図・保存仕様の変更なし。

- [修正説明の実ブラウザー画像](compact-yz-explanation.png)
- [説明部分の拡大画像](compact-yz-explanation-text.png)
- [57項目の検証記録](browser-compact-yz.json)

確認範囲で未修正の確定した図／測定配置／符号の不整合はない。ただし現行曲げ仮定のYZ感度が実機に妥当であることは未確認。柱が見かけ上鉛直になれば直角も良くなる、と一般化してはいけない。今回の説明追加は実機の変形や調整能力の検証を代替しない。
