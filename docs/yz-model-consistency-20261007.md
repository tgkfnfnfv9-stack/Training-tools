# 小型立形YZ：接触符号・誇張模型・支持調整感度の再修正

## 結果

小型立形の誇張3D模型で、実際のYZと符号・改善方向が逆に見える不一致を発見した。前回の独立確認では見落としていた。最終修正は**小型の3D姿勢を実寸とし、微小差の強調を既存の直角図へ集約する表示変更**。実寸µmの測定式・曲げ面・支持調整感度は変更していない。ユーザーが求めた「数値を大きく変える」変更ではないことを明記する。

## 符号は現配置と一致

YZは奥側から測定子を手前へ出し、上でゼロ、主軸頭を下へ300 mm動かす。基準器に対する柱の前倒れをθ>0とすると、本体は下降に伴って奥へ離れ、測定子が伸びる。押込み＋の読みは `−300000 sinθ µm`。前倒れ−／後倒れ＋。反対の手前側から当てた場合は逆になる。

応答冒頭で「前倒れ＋が現配置に合う」と述べたのは誤りで、手計算後に訂正した。[接触側の独立導出](yz-contact-sign-20261007.md)と18件の正負・反対側・再ゼロ・剛体移動の検証を参照。符号は変更していない。

## 新たに確認した誇張表示の不一致

既定寸法・中央位置、固有XY=33、XZ=75、YZ=0 µm/300 mm、B=C=D=0：

|A支持|実寸有限YZ|実寸の模型Y・Z内積|約300倍誇張した模型Y・Z内積|
|---|---:|---:|---:|
|−0.5 mm|+1.191261 µm|+0.00000397084|−0.00063581041|
|+0.5 mm|−1.187348 µm|−0.00000395780|+0.00177771635|

模型柱の上下頂点と、描かれる材料点PのY移動から得た3D方向を照合した。カメラ投影や図の符号表による錯覚ではない。固有YZ=−15の例では、A −0.5→+0.5で読みが+16.191→+13.813 µmへ改善するのに、誇張模型は悪化方向へ動いた。

原因は、支持勾配・固有角を約300倍してから非線形の姿勢合成と材料点微分を行うこと。倍率の二乗に依存する交差項が弱いYZ変化を上回った。原因関数は `compactSupportFrame`、`compactWorkVisualPoint`、`compactPathFrames`（src/accuracy-ui.js）、`displayPoseFrame`、`displayBodyFrame`（src/leveling-ui.js）。[独立詳細](qa-yz-sign-20261007/model-review.md)。

## 試作→独立確認→撤回→再修正

最初は実数XZ/YZ角を拡大した条件へ柱の表示方向を合わせる補正を作った。符号15ケース等は通ったが、独立確認でY送り時に固定柱上端が約5.7 mm動く新しい矛盾を発見し、全て撤去した。テストが通った項目だけで採用していない。

固定倍率を2／5／10へ抑える案も各9,720条件で比較した。小型の全許容寸法と支持端点等では、実寸角度へ戻したYZ誤差が最大3.994／16.036／36.291 µm。2倍でも意味のある誤差の符号逆転が残り、固定倍率制限では解消できなかった。[実験結果](qa-yz-sign-20261007/factor-limit-results.json)。

そのため最終的に、小型の3D模型は実寸姿勢へ統一した。固定柱・部材移動・材料点・矢印の実寸関係を維持し、別の測定図で微小差を示す。誇張図に合わせて架空の柱移動や読みに置き換える方式は採用していない。

## なぜ数値そのものを大きくしなかったか

初期寸法・柱配置の中央でA+0.01 mmとすると、XY +0.333868、XZ −0.703125、YZ −0.023946 µm。1 µm丸め表示では数回の操作で変わらない場合がある。これは小数点表示のバグではなく、現行2モード曲げ面の感度。

中央の前後勾配差では共通傾斜とq1が消え、小さいq3項が残る。同じ剛性分布でRitz基底を4／6／13／26モードへ増やしても、A+0.01のYZは約−0.02336／−0.02498／−0.02279／−0.02184 µmで大きくならなかった。左右剛性比や柱配置の変更は新しい未同定の仮定になる。希望の数値を得るための係数調整は行わなかった。

したがって今回の最適化は表示と数値の整合。**実寸の調整感度を高めた変更ではない。** 実寸の微小角は3D模型では目視しづらく、既存の直角図で確認する制約が残る。
