# 小型立形：左右の剛性差と前後曲げの教材モデル

2026-10-06。開始時mainは `39900cac24842b797c8b24b04ef4d75f52667444`。対象は小型立形・4点支持のみ。計算仕様を `compact-asymmetric-bending-v4` とする。テーブル上面Pの送り接線・300 mm換算という測定量の定義は [compact-table-path-20261006.md](compact-table-path-20261006.md) を引き継ぐ。

## 何を変えたか

従来の4点双線形面では、共通平面を除いた変形はねじれ1成分だった。左右中央のサドルとコラムの前後傾きは同じになり、C左奥を調整しても中央YZの一次変化は生じなかった。これは従来仮定では正当な不変であり、左右対称の線形構造の対称性にも合う。有限幅の対称な柱座で勾配を平均するだけでは解消しない。

今回はユーザーの希望を受け、**右側ほど曲がりにくいベース**という非対称な教材仮定を追加した。ねじれと前後曲げを組み合わせた面の形を、選択した2つの変形形状の範囲で曲げエネルギーが小さくなるよう決める。直角差へ支点別の係数を足す処理ではない。支持は従来どおり4点で、支持位置と支持高さを保持する。

この模型は、工作機械の鋳物を実測して同定したものではない。実機の板解析、実機の有限要素解析、実機の調整量予測を実施したという意味ではない。

## 2自由度のエネルギー近似

支持幅を `2a`、前後長を `2b` とし、支持中心を原点として `X=x/a`、`Z=z/b` を使う。このX/Zは面の正規化座標であり、NC軸名とは異なる。

4隅の高さから平均平面とねじれ振幅 `t` を分離する。残差面を次で表す。

`w = t X Z + q1 (1−X²) Z + q3 (1−X²) Z³`

追加する両形状は四隅で0なので、支持高さを変えない。`q1` は中央線の前後勾配にも作用するが、それだけなら中央線の勾配は前後で一定。`q3` は中央線の勾配へZ²の変化を与え、サドル位置と後方コラム位置で前後傾きが異なり得る。

相対曲げ剛性は `D(X)=1+αX`、`α=0.5` とする。支持範囲内の左右端は0.5と1.5で、相対比は1:3。ポアソン比に対応する教材定数は `ν=0.3`。いずれも実機材料値・実測値ではなく、応答を特定の表示量へ合わせて調整した係数でもない。模型の右側には「高剛性側（仮定）」を表示する。これは仮定の位置を示す表示で、新しい支持点や寸法を決めた実物の補強リブではない。

次の曲率エネルギーを、`q1,q3` について最小化する。

`E = 1/2 ∫ D(X) [wxx² + wzz² + 2ν wxx wzz + 2(1−ν) wxz²] dx dz`

ここで微分は物理座標x,zによる。共通倍率は最小形状を変えないため、実ヤング率や板厚を与えた絶対剛性とはしていない。支持高さはmmで扱うが、エネルギー最小化の全項に共通する単位換算倍率も最小形状を変えない。

エネルギーは `1/2 qᵀKq + fᵀq + 定数` となり、`Kq=−f` の2元連立方程式で解く。正のDと今回のνに対してKは正定値で、選んだ2形状の範囲では最小解が一意に定まる。数値積分は各方向4点のGauss–Legendre積分。曲率積とDの積の次数はX方向最大5、Z方向最大6なので、7次まで積分できるこの設定で多項式積分は丸めを除き一致する。

対称剛性 `α=0` ならねじれと追加形状の連成積分が消え、`q1=q3=0` に戻る。αまたはねじれの符号を反転すると追加変形も反転する。左右剛性差を無言で仮定せず、この条件を明示することが重要である。

これは2個の選択多項式へ限定したRayleigh–Ritz型の近似であり、自由端の自然境界条件を全て満たす薄板の厳密解ではない。変形形状を増やした場合の収束性も実機対応も確認していない。

## 部位・模型・精度への伝達

平均平面は既存の適正な剛体回転として外側へ適用する。曲げの入力にはねじれ残差だけを使い、一様高さ変更や共通平面の追加が内部角を変えないようにする。

補正後の同じ高さ面・勾配・曲率を、ベッド、案内、コラム根元、サドル、Pの送り接線へ使う。曲面を見せるためベッドと案内の描画面に中間頂点を設ける。コラムとサドルの代表姿勢は各参照位置の勾配に従う。

Pは引き続きテーブル上面中心、支持姿勢の基準から0.50 mの仮想測定点。X/YはPの局所送り接線、Zは柱側の送り方向である。XY/XZ/YZはそれらの内積で決まり、固有誤差は一度だけ合成する。表示誇張・回転・ズームは実計算へ入れない。

前後曲率が加わるため、左右中央でもサドルとコラムの前後傾きが異なり、YZが変わり得る。方向・位置・初期固有誤差次第で改善も悪化もある。全操作で全精度が必ず変化するとはしない。

## 変化量と丸め

標準教材寸法 `a=1.04 m,b=1.08 m` では、独立した閉形式の積分から `q1/t≈0.1267289033`、`q3/t≈0.0248194597` となる。

C左奥のみを `+0.01 mm` 上げた場合、残差振幅 `t=−0.0025 mm`、`q1≈−0.0003168223 mm`、`q3≈−0.00006204865 mm`。中央のサドル位置 `z=−0.27 m` とコラム位置 `z=0.783 m` の前後勾配差から、追加YZの一次近似は **約−0.024 µm／300 mm** となる。これは標準配置・微小角の説明例で、個体の合成精度や任意位置の厳密値ではない。

したがって粗調整1回でも内部計算は変わり得るが、整数µm表示では同じ数字が続く場合がある。1回で数字を動かすために剛性差を増幅したり、直角差へ最小変化量を加えたりしない。

## 残る制限と保存

荷重・反力・浮き・接触・締付け、実機の3次元鋳物剛性、柱とベッドの全面接合、有限幅の案内ブロックの同時適合、熱変位・切削荷重は未再現。支持範囲外の形状は同じ式を延長する教材表示で、外側まで同じ剛性分布の実物が存在すると保証しない。

比較値はAbbeの影響を含むPの局所送り角の300 mm換算であり、実際の300 mm走査や、補正済みの機械固有直角度ではない。新しい固有乱数は追加せず、旧個体の固有誤差を書き換える操作も行わない。

計算仕様が変わるため旧 `compact-table-path-v3` などの保存は保持したまま新仕様へ自動適用しない。他6機種の計算仕様は変更しない。

## 構造担当の実装後再点検

修正担当とは別に、曲率エネルギーの閉形式積分を使って4点Gauss積分を照合した。標準・縦長・横長の寸法、左右剛性差の正負と0を含む108確認で、エネルギー行列・四隅の高さ・最小条件が一致した。積分行列の相対差は `6.47×10^-16` 未満だった。

さらに、固有誤差の有無、平坦・C上げ・ねじれ、軸位置の端寄り・中央について、模型Pの実変換の中央差分、共通平面追加の角度不変、柱脚の代表中心と面の接続を90確認した。全て成功し、PのXY送り角と計算の差は `1.55×10^-6 µrad` 未満だった。柱座全面や全案内ブロックの同時接触まで確認したという意味ではない。

別担当が作成した `tests/check-compact-bending.cjs` の670確認と、`tests/check-compact-table-path.cjs` の168確認も再実行して成功した。
