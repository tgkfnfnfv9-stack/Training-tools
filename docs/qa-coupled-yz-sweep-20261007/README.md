## 実ボタンで確認した変化

同じ固定した教材個体（XY 33 / XZ 75 / YZ −15 µm 相当、支持初期 0）で A を粗調整 10 回上げる（合計 0.10 mm）。この固定値は再現用の試験条件であり、抽選プロフィールの保存検査には使用していない。

|対象|変更前の開始→操作後|変更後の開始→操作後|
|---|---|---|
|YZ 表示|+15 → +3 µm|+15 → +14 µm|
|奥の触れ表示|+15 → +15 µm|+15 → +14 µm|
|手前の触れ|0 → 0|0 → 0|

変更後の内部値は YZ 14.99999999 → 13.80434135 µm、奥の触れ 14.99175057 → 13.79440554 µm。約 5 倍は中央支持応答の目安で、YZ と触れの全位置の数値を同一にする意味ではない。整数表示なので粗調整 1 回・微調整 1 回ごとに必ず文字が変わる仕様でもない。

## 確認済み

- A/B/C/D を実際に選択し、粗 0.01 mm・微 0.001 mm の上下操作と往復再現。
- 3 画面サイズで連続 10 回の操作により YZ と触れの丸めた数値が一緒に変化。
- 黄色の追加コラム表示が存在しない。
- カメラ、ズーム、図の強調切替で測定値不変。
- 手前が面外なら触れ 4 点すべて数値を抑止。
- 実際に生成した正規プロフィールでブラウザー保存レコードの検証・読込後に同じ測定値を再現。
- 他 6 機種の表示測定値は修正前後一致。横形・旋盤の触れパネルは引き続き非表示。
- 320 px でも支持ボタンは最小 24 px 以上、横スクロールなし。画像による目視確認も実施。
- ブラウザー例外なし。

## 発見して再修正した表示問題

初回案では「触れ（共通）」が 390 px / 320 px で二行に折れた。`after-heading-wrap/` に画像を保存。修正担当が見出しを「触れ」へ戻し、共通姿勢の説明は既存説明・アクセシブル名へ移した。修正後 `after/compact-320-after-10-coarse.png` を目視し、折返し改善を確認した。

初回の機種比較テストは横形の非表示パネルに残る前機種の DOM 値も比較して失敗した。横形の表示や測定値が変わったわけではなく、最終テストは可視の測定結果を比較し、別途非表示を確認する。

## 未確認・限界

実端末 Safari での操作、実機の弾性挙動・測定力・取付干渉は未確認。正負や接触幾何の独立数値検証は別担当の `tests/check-coupled-yz-sweep-independent.cjs` の範囲を参照。主模型と局所角度・調整評価は元の物理計算、上段の直角測定と触れは共通の教材用仮想姿勢という区別を維持する。
