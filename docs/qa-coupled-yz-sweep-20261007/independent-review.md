# 小型 YZ と触れ：独立再確認

## 対象と修正の再確認

数値に別々の倍率を掛ける旧表示を廃止し、中央・固有誤差なしで得た支持由来の前後角差から、支持ごとに固定する仮想主軸姿勢を用いる変更を確認した。YZ 有限走査と触れの面接触が同じ仮想軸を使う。物理模型・局所診断とは区別された教材値である。

設計段階で、現在の X/Y 位置から毎回補正回転を作る案では、テーブル移動だけで固定主軸の姿勢が動くと指摘した。採用版は中央基準の固定回転となり、移動域で姿勢不変を確認した。

最初の結合実装では触れの軸だけを回し、主軸鼻先の材料点位置を元のまま残していた。これでは Z 送り時の鼻先接線が仮想測定軸と違うため再修正を依頼した。鼻先も同じ支持基点まわりの回転を使う修正版を再確認し、全 120 ケースで両者が一致した。

## 独立計算

`tests/check-coupled-yz-sweep-independent.cjs` は、製品の表示符号表や数値倍率を期待値に使わない。方向・取付点を受け、基準面と測定子の直線の交点を独立計算して指示を求める。平面形状そのものの独立 Ritz 解は既存の別試験が担当し、今回の試験は共通仮想姿勢から接触と数値への整合を対象とする。

120 ケース、2755 比較が成功した。寸法は 2.08×2.16 m、0.5×0.5 m、20×0.5 m、0.5×20 m、支持は理想・単点正負・正負鞍、固有誤差あり/なし、中央/移動両端を含む。

確認事項：

- YZ の 300 mm 有限走査と独立の面接触計算。
- 触れ 4 方向の独立交点計算。最大差 5.69×10^-14 µm。
- YZ の Z 方向、触れの回転軸、鼻先の Z 送り接線が同じ。
- X/Y/Z 移動で仮想固定主軸の姿勢が動かない。
- 手前が 0、右＋左＝奥、手前面外で全数値抑止。
- 反対接触側、始終点交換後の再ゼロ、共通剛体移動・回転。
- 純粋な共通剛体傾斜では理想 YZ/触れを 0 とする。
- 支持の粗操作と往復、カメラ・ズーム・図強調の数値不変。
- XY の読みに変更なし。固定中央 X 回転による XZ 交差変化は試験域最大 0.0000301 µm。

中央、固有 XY=33、XZ=75、YZ=-15 µm の平面支持から A を 0.01 mm 上げた変化は、YZ -0.119572907 µm、触れは右 -0.411429774、奥 -0.119734503、左 +0.291695271、手前 0 µm。YZ と奥は局所送り接線とテーブル面法線が異なるため厳密同値ではない。右/左には元の左右傾斜成分も含み、奥の変化の半分だけになるとは限らない。

## 限界

今回の通過は共通の仮想測定姿勢・接触幾何の整合を示す。実機の弾性、荷重、接触、実測感度を同定した証明ではない。約 5 倍は中央支持角の設定であり、全移動域の各数値を厳密に 5 倍にする仕様ではない。ブラウザー・保存読込・公開サイト確認は親担当の別記録を参照する。
