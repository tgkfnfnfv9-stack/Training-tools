## 部材移動の実操作

各軸を −100 → ＋100 と操作し、描画された材料点を観測した。期待する可動部は機械構造から先に定めた。模型の関数が返す移動量を期待値の式へ転記していない。

|実スライダー|観測した可動部|模型内部での変位 m|その軸で動かない部材|
|---|---|---|---|
|X −100 → ＋100|コラム、頭、鼻端|(+1.1, 0, 0)|パレット、ワーク、ベース|
|Y −100 → ＋100|頭、鼻端|(0, +0.6, 0)|コラム、パレット、ワーク、ベース|
|Z −100 → ＋100|パレット、ワーク|(0, 0, +0.9)|コラム、頭、鼻端、ベース|

部品名の付随も個別に確認した。数値は内部 xyz であり、実機 NC 指令の符号を確認した表ではない。実操作画像は `before/physical-X-negative.png` 〜 `physical-Z-positive.png`。生の材料点、実描画メッシュ、矢印の観測は `mechanics.json` に残す。

実動作デモは軸ボタンで対象を選び、設定内の開始／停止をクリックした。停止位置に最も近い整数位置をスライダーで再現し、全メッシュ頂点を比較する。デモ位置は連続値、スライダーは整数なので、最大0.5刻み分の既知の移動量だけ許容する。結果は `demos.json` と `demo-X-stopped.png` 等。

## 実画面で確認した問題

- Y下端付近で工具とワーク上端が近接・重複する。`before/physical-Y-negative.png`、`before/combined-twist1-X100-Y-100-Z100.png`。模式模型の干渉を実ブラウザーでも再現できる。ミクロン単位の測定式の正否とは別の問題として、構造修正担当へ報告した。
- 軸中央だけでは分からない部材の追従を確認するため、正負捻れ `h=±0.05xz mm` の全8組の複合端を操作し撮影した。`combined-twist…`。
- Zパレット座の支持補間境界前後を Z=51,52,53,54 で採取した。`boundary.json` と `boundary-Z…png`。補間の区分境界では勾配が滑らかに連続すること自体は仮定せず、姿勢と測定の同じ状態を記録する。
- 小図の円で a は左9時、b は下6時、長手図は0が左の先端寄り、主軸が右。`before/parallel-detail-contact.png`。小図は模型カメラに連動しない固定の説明投影。

## 実操作で再取得した数値

値は画面の整数 µm、順に XY / XZ / YZ / a / b。前記録を期待値にせず、今回の実ページから取得した値。

|同じBを下げて復帰|+17 / +8 / +14 / +8 / +14|
|h=+0.05xz、X −100|+18 / −1 / +22 / −20 / +14|
|同、X ＋100|+18 / −1 / +6 / −20 / +14|
|同、Y −100|+18 / −1 / +14 / −16 / +14|
|同、Y ＋100|+18 / −1 / +14 / −25 / +14|

X両端のbは生値では14.1111480875 → 14.1111496541 µm。整数の14が同じでも生値まで固定という意味ではない。Y両端のaは −15.7226469862 → −24.7226470128 µm。支持Bの往復は生値まで復帰した。相殺・取付高さ・方向合わせの妥当性は、この画面取得だけで正しいとは判定せず、独立測定監査と照合する。
