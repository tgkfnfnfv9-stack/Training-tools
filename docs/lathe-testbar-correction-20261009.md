# 奥側タレット・テストバーによるダイヤル測定への訂正

ユーザーの訂正に従い、旋盤のテスト加工・心押しを削除し、テストバー測定へ置き換えた。タレットも手前から奥へ移した。開始mainは `97fbbc263dc65758cd49b683b53cd4c54f2a7bf2`。元workspaceと旋盤worktreeは同HEADで未コミット変更なし、fetchでも一致を確認した。

## 変更

- 第2ページ右側を「テストバー測定・µm」へ置換。主軸固定バー、タレット側ダイヤル、a=0→bへのZ 300 mm送りを図示。側面（奥）と上面の指示を整数µmで表示する。
- テスト加工の径差・心押あり・片持ちの項目と計算を削除。模型の心押台・クイルも削除し、従来の工作物をテストバーへ変更。
- タレット、Xスライド、工具ホルダ、工具、往復台の位置を奥側（内部+z）へ鏡映。往復台の支持基準もz=−.15から+.15へ移し、測定計算と揃えた。
- Xの＋は従来どおり内部+zなので、奥側タレットでは主軸から離れる径外向き。Zの＋は内部+x、主軸側から先端側。NC直径指令の倍率や機種固有の符号検証とは分ける。
- 刃物台の前面・外側フラット、仮想穴ホルダの位置・法線も鏡映。X面の固有誤差の表示符号は、この配置変更に伴い反転する。
- 模型バーは支持寸法を変えてもφ50 mmの円断面を維持。主軸と一緒に姿勢が変わり、X/Z送りでは動かない。理想輪郭も同じ径を維持する。

## 新しい検査配置

|項目|側面|上面|
|---|---|---|
|固定する基準器|主軸に付けた理想円筒バーφ50 mm|同左|
|計器の搭載先|タレット側の固定ブラケット|同左、別の取付け|
|接触する側|奥側（内部+z）|上側（内部+y）|
|測定子の向き|奥から手前|上から下|
|走査|主軸側aから先端側bへ、部材Z＋300 mm|同左|
|指示の＋|測定子の押込み増加|同左|

主軸は回さない。第1ページの回転TIR（根元／300 mm先）とは別の検査である。バーに対するZ送りの平行度を、計器の接触から求める。

始点は現在Zのタレット材料点 `[.08,1.5,.20]` を主軸中心線へ射影した位置。端ではZだけを内側へ戻して300 mmを確保する。ここに側面または上面の計器を付け、測定子の伸び10 mmでゼロを取る。本体と測定子の向きを同じ取付けとして往復台の剛体姿勢で輸送し、途中では再ゼロしない。

支持・軸位置が変わったら始点の取付けとゼロを取り直す。穴芯検査は独立した固定の公称X位置で実施し、今回の奥側配置では `X=−.20/.35×100`。支持に合わせた芯合わせは行わない。

バー中心は標準・平坦状態で内部y=1.5 m、支持基準y=.66 mから+.84 m。上面接触はさらに半径25 mm上、側面接触は奥側へ25 mm。計器本体は接触点よりさらに10 mm外側であり、取付基準・本体・接触点を同じ座標として扱っていない。

## 計算と成立条件

`src/lathe-inspection.js` の `cylinderContact` は、本体から測定子方向へ延ばした半直線と固定円筒の近い交点を解く。指示は `(始点の伸び − 終点の伸び) × 10⁶ µm`。加工径差の計算は削除しており、2倍しない。

16分割に加え、支持補間境界とその両側を確認する。測定子の範囲0〜20 mm、円筒との交点、有限バー長から外れる場合は数値を出さない。全軸行程が300 mmに満たない場合も「走査範囲不足」とする。連続する治具同士の干渉判定ではない。

機械姿勢は共通剛体傾斜と局所姿勢に分け、同じ配置全体への剛体移動・傾斜で指示を変えない。支持の変化による計器取付け高さと腕の回転は含む。カメラ・表示誇張・ズームは計算へ入れない。

バー自重たわみ、取付けの弾性、測定力、基準器固有の曲がりは未実装。仮想ブラケットの実寸・実機干渉を保証するものではない。前面・BOT面の無限平面近似、穴の円断面近似は従来のモデル限界として残る。
