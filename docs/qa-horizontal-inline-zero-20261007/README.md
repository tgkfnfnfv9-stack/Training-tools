# 横形「Z平行」同一枠の小図：独立確認

対象は既存の右上「Z平行」64 px 幅の枠の下2行だけ。計算や他箇所の UI を変えず、バー先端寄りのゼロ位置と主軸側への走査を小図で示す変更を確認した。

- 変更前：ac6f121 の公開用 HTML。SHA256 `5f602fd71182c73ce8825d0e58d7251a5b41535c9c6f0877cda6a54c890b6bd0`。
- 最終変更後：SHA256 `a56c8522dd18b0d073cd3b9f3d8396f7460e1cbe342f430fe48aa2da4cbe06a7`。
- 独立担当の Playwright 検査：**118 / 118 成功**。
- 1280×1000、390×844、320×568、全7機種を同じ固定状態で比較。

## 見つけた問題と再修正

初版の小図領域30 pxでは旧2行の合計31 pxに対して1 px不足し、携帯画面の模型・水準器を含む外側レイアウトが動いた。担当へ指摘し、小図領域とviewBoxを31 pxに修正。最終版では外側配置・ピクセル差はゼロとなった。

また、最初の300 mm矢印の両端が図の始終点とずれていた。指摘後、ゼロ点x=9から終点x=35に対応する矢印へ修正された。

## 最終確認

- 横形の右上枠外は3画面とも完全に同じピクセル。
- 他6機種は3画面とも全画面が完全に同じピクセル。
- 全機種の測定値、右上枠外の可視ID要素座標、既存の見出し・a/b数値行の位置は不変。
- 従来の詳細図と説明のHTMLは不変。クリックで開く操作も維持。
- 小図の全テキストはviewBox内に収まる。
- オレンジの点と「0」はバー先端寄りの同一軸方向位置を示す。矢印はその位置から右の主軸側へ向く。a左右とb上下の接触方向自体は異なることをaria説明にも明記している。小図は長手方向の略図で、両測定の接触面を同一面とする変更ではない。
- 計算変更なし。親担当の既存主軸回帰323件成功も報告を受けた。

画像比較はブラウザーの `reducedMotion: 'reduce'` を両版に指定し、既存水準器の遷移途中の微小差を除去した。固定状態は試験用に設定しており、実機の幾何精度を証明するものではない。
