# 横形の既存Z平行枠にゼロ位置の小図

開始main ac6f12124459790183a09ad52e2eb716735b0eac、作業ツリーはクリーン。ユーザー指示は「同じところで小さい絵」「ゼロ位置を明確に」「他のUI変更禁止」。

変更範囲は横形の右上64pxのZ平行枠内のみ。既存の見出し・a左右/b上下の数値行を保ち、下の始点/走査の2行分へ31pxの長手方向略図を入れた。左のオレンジ点と0は先端寄りの開始位置、白抜き点は終点、矢印は右の主軸側への300 mm走査。a/bは接触側が異なるが、長手方向のゼロ位置は同じであることを図の代替説明に明記。

独立レビューで初版が枠を1px縮め周囲を動かすことと、SVG文字領域の1px超過を検出。小図領域とviewBoxを31pxへ直して再確認した。
