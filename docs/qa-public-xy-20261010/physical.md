# 公開版XYの接触符号：独立確認

対象は公開HTML SHA256 `7c63eaa1c49ab749e7e898f228a6c88151185c0a5ca68566fda46e8c731c03d9`。製品コードは変更していない。ユーザー画像の支持高さ・個体seed・軸位置は不明であり、**画像の−19 µmという状態は再現したと主張しない**。

公開版のXY小図と計算は、ともに「テーブル上のマスタの右側へ、主軸側の計器を左向きに当て、下端でゼロ、上へ300 mm送る」。小図のゼロはSVG y=31、終点はy=14。上送りに伴う測定子の伸びが正なら指示は負になる。

## 単純な10 µmの例

マスタS面をx=0、計器本体の下端位置をx=10.000 mm、上端位置をx=10.010 mmとする。右から左へ向けた測定子の伸びは、下で10.000 mm、上で10.010 mm。

|操作とゼロ|独立期待値|公開計算との照合|
|---|---:|---:|
|下でゼロ→上へ300 mm|−10 µm|−9.999999999999593 µm|
|同じ取付けのまま上でゼロ→下へ300 mm|＋10 µm|＋9.999999999999593 µm|
|下のゼロを保ち、上から下へ戻る|−10→0 µm|下へ動いている途中でも負は残る|

したがって「下へ行くのに−」だけでは符号誤りとは確定しない。**上でゼロを取り直して下へ測ること**と、**下のゼロを保って下へ戻ること**を分ける必要がある。さらに公開アプリの上段値は、その瞬間のダイヤル指示ではなく、毎状態で設定し直した300 mm区間の始終差である。

## G支持を下げる操作との違い

Gの上下は機械支持高さの変更であり、計器をY下送りする操作ではない。理想個体・他の支持0・軸中央からGだけ±0.010 mmにし、支持点の双一次補間を別途微分して姿勢を求めた。公開版はX代表案内へ仮想的にR合わせするため、コラムだけでなくマスタS面も傾く。

|G高さ|上へ300 mmでの計器の左右変位|同じ高さでのS面の左右変位|独立期待値|公開生値|整数|
|---|---:|---:|---:|---:|---:|
|−0.010 mm|−0.647978 µm（左）|−0.606618 µm（左）|＋0.041360294117 µm|＋0.041360294113 µm|0|
|0|0|0|0|0|0|
|＋0.010 mm|＋0.647978 µm（右）|＋0.606618 µm（右）|−0.041360294117 µm|−0.041360294120 µm|0|

これらは正面から見た物理座標の左右変位であり、ユーザー画像のカメラ投影を復元した値ではない。表示誇張も掛けていない。さらに共通の右倒れ `h=-0.01x mm` を与えると、コラムもS面も同じだけ右に傾き、公開XYは0になる。**世界座標に対するコラムの右倒れだけでは、マスタとの相対変位やXYの正負は決まらない。**

この確認は、公開版の「代表X案内へ仮想R合わせ」という現モデルに対する接触符号の確認である。そのR合わせが実物の計器による有限送りを表せていない既知問題を解決した、という認定ではない。
