## 画像の−は「下へ測った値」ではない

公開版XYは、マスタに右側から接触し、下でゼロ、主軸頭を上へ300 mm送った指示差を表示する。Yスライダーを下げても、計算の走査方向は上のまま。実ブラウザーでも小図のゼロと上向き矢印、内部の始終姿勢、DOM生値がこの意味で一致した。

同じ器具を保持し、上へ行くほど計器本体がマスタから右へ10 µm離れる単純例：

|ゼロと送り|正しい指示|
|---|---:|
|下でゼロ→上へ測る|−10 µm|
|上でゼロを取り直す→下へ測る|＋10 µm|
|下のゼロを保持→上端から下へ戻す|−10から0へ戻る。途中は負のまま|

したがって「下へ行くのに−」だけでは逆符号と判定できない。ゼロ位置と、表示が往路の測定結果か現在の指示かを固定する必要がある。**現在のUIは下降中のダイヤル指示を表示していないため、模型の動きと数値を連続測定として読むと矛盾する。**

## 支持Gを下げる場合

写真下部の「↓下げる」は支持点Gを下げる操作で、Y送りではない。理想・平坦・中央からG−0.010 mmの別計算では、300 mm当たり計器は左0.647978 µm、仮想R合わせ後のマスタ面も左0.606618 µmへ傾く。相対的な接近量は＋0.041360294 µmで、公開計算と一致した。G＋0.010 mmは逆。

コラムもマスタも一緒に右へ傾く条件ではXY0の例もある。画像上のコラムの床に対する右倒れだけでは、マスタに対する読みの符号を決められない。
