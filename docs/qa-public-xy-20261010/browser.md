# 公開版 XY：支持の「下げる」と Y 下降を分けた実操作

対象は公開 HTML SHA256 `7c63eaa1c49ab749e7e898f228a6c88151185c0a5ca68566fda46e8c731c03d9`。Linux Chromium・390×844 で実操作した。実 iPhone Safari は未確認。ユーザー画像の個体 seed、支持高さ、軸位置は取得できていないため、画像の −19 µm と同一状態を再現したという記録ではない。

## 操作と実測

初期状態だけを理想個体または used / seed 123456、平坦支持、X/Y/Z 中央へ固定。その後は G の支持選択、粗調整、上下ボタン、Y スライダーを実際に操作した。

|個体・操作|XY 生値 µm|整数表示|内部の Y 測定区間 mm|
|---|---:|---:|---:|
|理想・平坦|0|0|0 → +300|
|理想・G を 0.010 mm 上げる|−0.041360294|0|0 → +300|
|同じ支持のまま Y を −100 へ|−0.041360294|0|−300 → 0|
|同じ支持のまま Y を +100 へ|−0.041360294|0|0 → +300|
|used 123456・平坦|+16.958999991|+17|0 → +300|
|同個体・G を 0.010 mm 下げる|+17.000360285|+17|0 → +300|
|同じ支持のまま Y を −100 へ|+17.000360285|+17|−300 → 0|
|同じ支持のまま Y を +100 へ|+17.000360285|+17|0 → +300|
|同個体・平坦から G を 0.010 mm 上げる|+16.917639697|+17|0 → +300|

支持を上下逆操作すると生値が元へ戻ることも記録した。支持操作の小さな変化は生値には存在する。上表の整数が同じことと、Y 操作に対して生値まで同じことは別現象である。

**現在の XY 数字は、現在位置からの連続したダイヤル指示ではない。** Y スライダーを下降させても、プログラムはその都度「下側でゼロ、上へ 300 mm」の値を出す。マイナス側では選択された測定区間が移り、Y が 0 以上では全て 0 → +300 mm に制限される。小図のゼロと矢印も下ゼロ・上向きのままである。したがって、この欄を「いま下げたときの針の増減」と読むと操作と意味が食い違う。

例えば used 123456 / G −0.010 mm では、Y −100 → +100 の実操作で主軸頭の表示位置は上下に約 600 mm 動き、パレットは不動だった。しかし表示生値は +17.000360285 のままである。模型の移動が停止したり DOM が更新されていないという再現ではない。

## 右倒れと符号

理想個体 / G +0.010 mm では、正面模型のコラム上端は下端より画面右に傾く。表示座標での上下端の X 差は +1.207628 mm（表示倍率 223.642618 を含む）。この状態の仮想マスタ S 面も、下端から上端 300 mm で X +0.606618 µm 傾いている。一方、計器本体の上送り X 変位は約 +0.647978 µm であり、マスタから離れる差が約 +0.041360 µm 残る。

独立に平面と測定子直線の交点を解くと、測定子の伸びは始点 10.000000000 mm → 上端 10.000041360 mm。下ゼロから上送りした指示は −0.041360294 µm となり、画面の生値と一致する。これは取り出した測定配置内の接触計算の照合であり、支持から姿勢を作る式そのものを独立に正しいと認定するものではない。

上端でゼロを取り直して下降する場合は +0.041360294 µm。**下側のゼロを保持して上端から戻る場合は、上端の負値から 0 へ戻る途中も負値を取り得る。** 「下降中だから常に正の数」という結論にはならず、ゼロ位置を指定する必要がある。現在の UI はこの連続した戻り指示を表示していない。

コラムとマスタ双方の傾き、取付側、ゼロ位置、走査方向が必要であり、床に対するコラムの右倒れだけでは正負を確定できない。
