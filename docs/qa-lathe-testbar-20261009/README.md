## X/Zの実操作と追従

|スライダー|実際に動く部材|両端−100→＋100の内部座標変位|動かない部材|
|---|---|---|---|
|X|タレット、Xスライド、工具ホルダ、工具|(0, 0, +0.7) m|往復台、主軸台、テストバー、ベッド|
|Z|上記4部材と往復台|(+1.4, 0, 0) m|主軸台、テストバー、ベッド|

全ラベルの材料点を個別に観測した。タレット中心は軸の両端・全4組の複合端を含めて内部z>0の奥側にある。X＋は内部＋zを保ち、奥側タレットでは主軸から離れる向きとなる。これは部材スライダーの確認で、NC指令の符号を認証したものではない。

実軸ボタンからデモを開始／停止し、停止位置に最も近い整数位置へ実スライダーを動かした。最大0.5刻みの既知の丸め差だけを許容して、全ラベルの位置が一致した。中央戻しも確認。12角キャップは実描画メッシュ上で前後各12頂点。

## 同じ個体での操作値

`used / seed 123456`、支持高さ0、軸中央から開始。下表は整数µm。旧加工径差と新しいダイヤル指示差は別の検査として扱う。

|支持操作|主軸TIR a/b|刃物台X/Z|バー側面（奥）/上面|
|---|---|---|---|
|平坦|12 / 14|−4 / +8|−17 / 0|
|Bを+0.010 mm|12 / 14|−4 / +7|−16 / +1|
|Bを−0.010 mm|12 / 14|−4 / +9|−18 / −2|
|Bを元へ戻す|12 / 14|−4 / +8|−17 / 0|

生値の側面／上面は、平坦で −16.958999991 / −0.005752154 µm、B上げで −16.209041002 / +1.494852541 µm、B下げで −17.709041000 / −1.506380014 µmだった。[B上げの画面](after/lathe-testbar-B-positive.png)／[B下げの画面](after/lathe-testbar-B-negative.png)。往復は全測定の生値まで復帰した。

平坦支持ではX/Zの位置だけを変えても、今回のバー側面・上面値は変わらなかった。「軸を動かしたから値が必ず変わる」とは判定していない。支持調整でバー値は応答し、主軸回転TIRとX前面の固有成分は不変だった。今回の前面Xはタレット反転後の接触配置で−4となり、旧版の+4との同値を要求していない。式の独立検算は別担当の測定監査を参照する。
