## 修正前の寸法による反証

[`coverage-before-fixture-reach.json`](coverage-before-fixture-reach.json) は理想個体、支持全点 0、標準寸法から独立の支持・部材座標再構成で得た値。X / Y / Z を同時に -100、0、+100 とした例を記録した。旧製品の値を期待値として入力していない。

| 配置 | 中央での取付基準点→計器本体の直線距離 | 全軸 +100 の例 | 問題 |
|---|---:|---:|---|
| 横形 XY | 1234.382 mm | 1383.365 mm | マスタ低位置と主軸側取付けの高さ差を長腕で吸収 |
| 横形 XZ | 1262.814 mm | 1621.635 mm | 同上。XZ は Y 走査でないため高い Y をそのまま使う |
| 横形 YZ | 1245.351 mm | 1510.265 mm | 有限 R / S 面を作っても腕は有限化されていない |
| 横形 Z 平行度 a | 1338.553 mm | 1747.348 mm | パレット側から高いバーへ伸びる |
| 横形 Z 平行度 b | 1304.655 mm | 1726.593 mm | 同上 |

| 旋盤 面 Z | 1943.354 mm | 2472.069 mm | 同上 |

これらは「距離が長いから必ず実機では不可能」という認定ではない。教材が有限治具の寸法を定めず、任意の位置を測れるとしたまま数値だけ返していた証拠である。実機の剛性・安全を認定することと、教材の寸法・到達条件を定義することを混同しない。

## 実装後の独立レビュー項目

1. 主軸／パレット／タレット／主軸台の所有関係が、数式、保持した器具、3D、説明で一致する。
2. 箱台・ホルダ・腕が取付先の有限材料と連結する。装着前後に器具が空間へ飛ばない。
3. 取付時に選んだ材料点・方向は、支持変更後の「保持」では同じ所有部材の局所座標に残る。支持後に接触へ自動追従させない。
4. 「再取付け・再ゼロ」は明示操作とし、支持変更だけで保持ゼロを上書きしない。再取付けできない場合は旧取付けを正常と偽らない。
5. 各走査・回転の端点だけでなく、面端／穴入口出口／支持補間境界を点検する。有限面・有限円筒・20 mm 測定子行程・腕上限を別々に確認する。
6. 中央だけでなく全軸端、最小寸法、最大寸法、新品／中古、各支持 ±操作、往路／復路、保持／再ゼロを確認する。
7. 旧保存データの入力・個体シードを保存したまま読める。新しい一時的取付状態を保存するならスキーマ・復元条件を明示し、保存しないなら復元時に未取付けへ戻ることを説明する。
8. 古い自動再取付け・長腕・円断面近似の説明が生きた UI に残らない。未接触を 0 と表示しない。
9. 固有 TIR と上面形状は固有値として維持する。全数値を支持操作で変える細工は入れない。

### 保持・保存・表示の追確認

- 横形は接触面、法線、器具、足、計器基部・方向、腕をそれぞれの所有部材の局所座標へ保存する。旋盤の面は主軸台、バーは工具ホルダへ保存し、穴は主軸アーバの到達長と旧 a のゼロを保存する。支持変更後に接触位置へ自動で再配置する処理が保持側に入っていないことを読んだ。
- 表示する比較は同じ区間の終点、穴は各回転方向である。現在機械位置の連続した針と取り違えない説明がある。旧ゼロ保持と再取付け・再ゼロは別列で生値と整数を示す。初回無効の器具は保持側で後から勝手に成立しない。
- 位置・寸法・個体の変更と JSON 読込で保持を解除する。保存 JSON は機械入力のみ。旧保存の `bestState` も支持高さであり、旧計算の測定値を復元しない。
- [`coverage-save-review.json`](coverage-save-review.json) は前バージョンの実ブラウザー保存 JSON を現在コードの DOM ハーネスへ読み込み、同一 JSON を再読込した独立確認である。横形・旋盤とも受理、機械入力 17 項目の差分なし、一時取付け非保存、同一設定の再読込でも保持解除を確認した。実ブラウザーでの import / export はブラウザー担当の記録に分ける。
- 構造模型と、計算と同じ有限治具を使う専用配置図の区別を主画面に表示する。配置図は物理寸法で、変位の誇張を使わない。配置図自体は現在支持で再取付けした状態であり、旧ゼロ保持の図と誤認させない説明を追加した。
- 支持へ依存する量に定数倍・ノイズ・丸め結果の強制変更を加える処理は見つからなかった。再ゼロで消える変化、同じ整数に丸められる変化、固有成分の不変をそのまま残す。

### 独立レビューから修正へ戻した指摘

1. 同一個体・同一寸法・同一軸位置の JSON を再読込すると比較キーが変わらず、取付けが残る問題。`applyLevelRecord` の明示リセットで修正し、上記保存確認で再確認した。
2. 旋盤・横形の配置図が、無限面の交点や治具干渉中の点まで橙色の接触点として描く問題。有効な検査・サンプルだけを接触点として描くよう修正した。無効な取付位置の線には未成立の説明を付け、数値は変更していない。
3. 旋盤の梁を「40 mm 角」と説明しながら、計算と図が半径 20 mm の円形断面だった問題。仕様を実装と同じ円筒 φ40 mm へ統一した。角柱の外接半径を誤って 20 mm と扱う説明は残さない。
4. 保持中にも配置図は再取付け側を表示するが、その区別が弱かった問題。配置図に「現在の支持で再取付け・再ゼロした配置」と明記した。
5. 校正円筒の平行度と seed の固有回転成分を「同じバー」とだけ説明すると、同一偏心バーの総指示と誤解できる問題。別の成分参照として明記する修正を依頼し、境界を確認した。

レビュー担当が再実行した横形有限配置確認は 341 チェックで失敗 0。50 / 350 mm の固有 TIR 独立計算は 16 ケース、最大誤差 3.43 × 10⁻¹² µm、失敗 0。独立数値担当による全面的な支持応答・保持・有限境界の数値確認は、それぞれの報告に分ける。
