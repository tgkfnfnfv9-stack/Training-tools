# 水準器のスライド切替（平均2本／四辺4本）（2026-10-13）

PR #40 の「ねじれ」水準器1本を、スライドで切り替える2ページに置き換え。

## 表示
- 1ページ目「平均」：平均・左右、平均・前後（従来どおり）。
- 2ページ目「四辺」：同じ水準器を四辺に置いた4本。
  - 奥辺 · 左右 ／ 手前辺 · 左右：奥と手前の辺の左右傾き
  - 左辺 · 前後 ／ 右辺 · 前後：左と右の辺の前後傾き
  - 奥辺と手前辺の差（左辺と右辺の差）がねじれ。4本とも中央なら水平かつねじれなし。
- 右枠を左右にスライド、または下の ‹ › で切り替え。表示だけの切替で、保存や計算には影響しない。
- 値は外側の支持線の上の支持面の高さから求める（四隅の高さの差 ÷ 辺の長さ、mm/m）。計算・測定値は変更なし。

## 確認
- ブラウザ（PC・スマホ、スワイプ操作）：ページエラー0。例の個体で 奥辺 −0.082・手前辺 +0.144 mm/m（差 −0.226 ＝ ねじれ）、左辺 +0.116・右辺 −0.102 mm/m。
