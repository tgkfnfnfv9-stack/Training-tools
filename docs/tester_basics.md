# テスターの使い方：断線探しの範囲と資料

「テスターの使い方」は、シーケンス回路の断線をテスターで探す練習です。5種類の回路と電源をランダムに選び、配線を1本または2本（初期値）ランダムに断線させます。

| 回路 | 電源 | 主な機器 |
|---|---|---|
| 自己保持 | AC100 / 200 / 24 V | PB0・PB1・MC・RL・GL |
| インターロック（正逆） | AC100 / 200 / 24 V | PB0・PBF・PBR・MCF・MCR・RL・YL |
| 信号機回路 | AC100 / 200 / 24 V | BPBS・YPBS・CR1・T1（4秒）・T2（2秒）・WL・YL・GL |
| スターデルタ | AC100 / 200 / 24 V | THR・PB0・PB1・MC・T（5秒）・MCS・MCD・YL・RL |
| 電動機主回路 | 3相200 V | MCCB・MC・THR・電動機、操作回路はR–S間 |

- 電源ONでは交流電圧を測ります。測定値は、回路図どおりの結線と負荷の抵抗から複素フェーザの節点解析で計算しています。どこにもつながっていない端子は「≈0 V」と表示します。
- 電源OFFでは抵抗を測ります。正常な線は0 Ω、断線した線はOL、または負荷を通った抵抗値になります。
- 電源ONのままΩレンジで当てると、危険の警告を出して測定しません。
- 主回路で1相が欠けると電動機はうなり、電動機端子の線間に線間電圧の半分（100 V）が出ます。
- リレーは定格電圧の70 %で動作します。タイマはオンディレーで、画面上の時間で進みます。

数値は学習用の理想計算です。テスターの内部抵抗・誤差・誘導電圧・実機の合否は再現しません。制御盤での作業は職場の手順と資格に従い、実機では機種の取扱説明書を優先します。
