数値は従来の1 µm刻み。現在値が丸め後0になる `|値| < 0.5 µm` の常時図だけ、現在線を理想線に合わせている。`±0.49 µm` は0と重なり、`±0.5 µm` は±1と符号方向の線を表示する。計算値・生の模式図座標・詳細図の倍率5000・300mm換算・保存値は変更しない。実際の300mm走査とは説明していない。

XYはO・0が左下、基準Xは下辺を右、比較Yは上。XZ/YZはO・0が左上、基準X/Yは上辺を右、比較Zは下。端の「左」「前」は承認された表示配置の記号で、機種ごとの物理基準・測定方向は docs/measurement-reference-20261006.md のまま。旋盤は上辺の主軸Z基準と比較Xを維持する。

ダイヤルは手前0をその状態ごとに維持し、他3点は手前との差。押込みが手前より強いと＋、離れると−。手前が面外なら4点とも数値を出さない。支持変更時には手前も変化するため、絶対押込みと手前との差は同じではない。計算を反転する変更は加えていない。
