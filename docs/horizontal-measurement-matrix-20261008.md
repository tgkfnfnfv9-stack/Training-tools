## 接触式と独立手計算

平面S上の点をp、単位法線をn、計器本体をb、本体から先端への単位方向をuとする。接触は `n·(b+e u-p)=0`、従って `e=n·(p-b)/(n·u)`。ゼロ後の指示は `(e0-e1)×10^6 µm`。伸びeが減ると＋。部材＋X/Zや局所角度の＋とは別の定義である。

1. 理想直交・支持高さ0なら、頭のY送り/マスタのZ送りともeは10mmのまま、XY/XZ/YZ・Z平行a/bは0。
2. 右側の計器に対しSを10µm右へ動かすと、e=10mm−10µmで＋10µm。同じ固定Sに対し右側計器を10µm右へ動かすとe増加で−10µm。左側からの計器なら関係は逆。
3. 平面支持 `h=.03x+.04z(mm)`、固有誤差なしの場合、全体が同じ剛体姿勢となり、全5項目は0（実行結果最大残差約1e−10µm）。床に対する傾斜を直角誤差と取り違えない。
4. `h=kxz(mm)`、k=+0.001、中央X/Z、固有誤差なし。パレットZを0.3m送ると左右傾斜は `Δa=k×.3(mm/m)`、高さHの点は一次近似で `Δx=−H k .3/1000(m)`。直角XZのH=.61より−0.183µm、Z平行aのH=1.89より−0.567µm。実装を実行した結果もそれぞれ−0.183、−0.567µm。k負で両方の符号反転。二つのZ測定が同数になる要件はない。
5. 基準X=eX、Y=(-sinα,cosα,0)、Z=(-sinβ,0,cosβ)という既知配置なら、上昇する頭のXYは `+.3 sinα×10^6`、奥へ移動するマスタのXZは `−.3 sinβ×10^6`。XZの基準器搭載先が違うためXYと符号の関係が異なる。
6. 円筒断面半径r、左からの計器本体が横にdx、上にdy移動したときaの読みは `[dx+sqrt(r²−dy²)−r]×10^6`。下からのbは `[dy+sqrt(r²−dx²)−r]×10^6`。他方向の移動による二次の円弧成分もあるため、a=横移動だけ、b=縦移動だけとは厳密には一致しない。

## 一致、誤読原因、疑い、未確認

**一致を確認した事項**

- XZ/YZは実在するパレットZ送りを用い、存在しない頭Z移動を数値計算していない。
- Z平行a左/b下の接触と図は一致。バー固定、計器パレット移動、先端→主軸方向である。
- 上記の理想、剛体傾斜、正負鞍面の接触符号と取付高さ応答。
- 円筒バーの中心線はパレットZの方向を流用していない。

**確実な誤読原因（表示修正対象）**

- 小図の『頭固定』は計器の頭取付を表すが、XYで頭自身がY移動することと同時表示され、頭が空間に固定されたように読める。
- 小図の矢印は基準器に対する計器の相対移動。模型部材の移動矢印との区別が小図単独では足りない。
- 部材＋ZとNC＋Zの区別は詳細を開くまで分からない。Z平行の小さい長手図は主軸側を黒いブロックだけで示し、カメラ模型との対応が不明瞭。
- YZ展開図の右が上、図上が奥になることは正しいが、向きを明示しないと『図右=機械右』と誤認される。

**モデル上の制約（数式を勝手に変更しない）**

- 現有限直角のR面合わせは代表案内方向である。主軸鼻など任意材料点のX送り接線を使用していない。
- 具体例：`h=.01xz(mm)`、原点、固有誤差0。代表X案内は概ね `[1,+12.88,0]`（角度成分µrad）、実際の鼻材料点のX移動接線は `[1,−9.30,−18.90]`。柱姿勢がXで変わり、鼻の取付高さ/奥行による差が生じる。前者でRを合わせた教材配置を、鼻をX送りして現物のRを合わせる実測と同一視できない。
- 現XZ/YZは支持基準＋0.61mの仮想接触原点。実物の主軸頭へ長い計器取付具が必要になりうるが、取付具の到達・衝突を解いていない。
- Z平行のパレット上ブラケットはバーへ届く高さ・前後オフセットを持ち、姿勢変化時にオフセットを全て輸送する。支持調整/軸位置変更ごとにブラケットとゼロを置き直すため、固定された現物器具の連続変化と異なる。
- 基準器方向合わせから取り直す逆走と、同じ固定配置で指示だけ再ゼロする逆走は別。後者だけなら読み差の符号は反転するが、前者は姿勢が変わる経路で単純な符号反転ではない。

**未確認/対象外**

- 実機Haas EC-630の全軸構造・メーカーNC正方向と、この模型の全寸法/全物理挙動の同一性。
- 剛性、荷重、接触、測定力、実際の基準器寸法や干渉。教材の支持傾斜近似は実機捻れ再現の証明ではない。
- 本担当は横形の表示/説明だけを `src/reference-measurement-ui.js` で修正した。最終ソースの実ブラウザー検証は親担当/独立担当の結果を参照する。
