# 軸の分担と固定部分

これは構造を比較するために軸分担を固定した学習モデルです。リンク先のメーカー機種を正確に複製するものではありません。機種を指定する段階では据付図・軸構成図を確認して別データにします。

## UIに採用した移動構成

|カテゴリ／方式|X|Y|Z|主な固定部分|
|---|---|---|---|---|
|立形・片側コラム（標準／小型）|テーブルが左右|サドル＋テーブルが前後|主軸頭が上下|ベース・コラム|
|横形|コラム＋主軸頭が左右|主軸頭が上下|パレット台＋ワークが前後（主軸方向）|ベース・案内レール|
|立形・移動コラム|コラム＋主軸頭が長手（左右）|主軸側スライドが前後|主軸頭が上下|ベース・テーブル・ワーク|
|固定門形・テーブルXY方式|テーブルが左右|サドル＋テーブルが前後|主軸頭が上下|門・梁・ベース|
|固定門形・長手テーブル方式|テーブルが長手（前後）|主軸サドルが門幅（左右）|ラムが上下|門・梁・ベース|
|移動門形|門全体が長手（前後）|主軸サドルが門幅（左右）|ラムが上下|テーブル・ワーク・基礎側ベース・走行レール|
|5軸・テーブル旋回形|トラニオン一式が左右|サドル＋トラニオン一式が前後|主軸頭が上下|ベース・コラム|
|NC旋盤・2軸|刃物台が径方向|なし|往復台＋刃物台が主軸方向|ベッド・主軸台・心押台（加工中）|

5軸の模型では、AはX軸回りの傾斜、Cは傾斜するテーブル軸回りの回転。A旋回にCテーブルが追従します。回転軸の分担・名称は実機ごとに異なります。横形のB軸や旋盤の主軸回転は今回の軸デモに含めません。

## 操作・表示

- 軸の両矢印は、個体の固有直角度と支持点の調整を含めた計算上の軸方向です。微小な角度差は「変形を強調」の設定に従って表示します。部品の移動は構造を理解するための模式移動です。局所支持姿勢と固有方向を使いますが、荷重による実軌跡は再現していません。旋盤の送りZは往復台の方向を示し、主軸基準XZ図の主軸軸線とは別です。
- 端1／端2は学習モデルの位置。NCの＋／−指令や実機ストロークを表しません。
- NC軸の符号は工具とワークの相対座標で扱うため、テーブル側の移動符号を単純に工具側と同一視しません。
- 固定部は灰色。選択軸によって移動する部品は、その軸の色で強調します。
- 主軸頭・工具・ワークなど子部品は、親スライドの動きにも追従します。
- ページ移動、機械・方式・確認軸の変更、位置スライダーの操作で動作デモを停止。
- 3D視点は左右回転のみ。XYZスライダーはカメラを動かしません。
- 支持高さから工具側・案内側の参照姿勢を作り、相対直角度を比較します。構造別の仮定は `leveling-model.md` を参照。剛性・荷重・実機加工誤差は計算しません。

## 計算上の軸方向の区別（2026-10-06）

- 移動コラム・移動門形のX送りは固定テーブルではなく、現在のコラム／門走行位置の案内姿勢を使う。
- 門形のY/Zは左右柱天端から作る共通の梁姿勢。固定門形Xはベッド・テーブル、移動門形Xは走行案内を参照する。
- 旋盤の直角図は「主軸基準XZ」。X送りと主軸軸線の比較であり、NC送りX/Zの直角度全体を示すものではない。
- 門形骨格の支持姿勢と、固有軸差を含む矢印・直角図を区別する。詳細は [leveling-model.md](leveling-model.md) を参照。
