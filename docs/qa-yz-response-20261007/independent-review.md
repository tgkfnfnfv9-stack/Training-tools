# 独立確認：小型 YZ の教材表示応答

製品変更担当とは別の担当が、製品コードを編集せず確認した。

- `tests/check-compact-yz-response.cjs`：112 比較成功。
- `tests/check-page-redraw.cjs`：98 比較成功。全 7 機種の再入場時抽選と明示 JSON 保存・読込が再現する。
- 固定した生成 HTML の SHA-256 と結果は `independent-numeric-results.json`。

## 期待値の作り方

表示ヘルパーや実装の gain 定数を期待値に使用していない。変更前に採取した生の 300 mm 有限測定値を 5 点保存し、独立に `I0 + 50 × (I − I0)` を計算して表示値を比較した。生値が変更されていないことも同時に比較した。

標準寸法・中央軸位置、固有 XY = +33、XZ = +75、YZ = −15 の例：

| A 支持高さ mm | 元の有限測定 µm | 教材表示 µm |
|---:|---:|---:|
| −0.01 | +15.023786867 | +16.189343675 |
| 0 | +14.999999994 | +14.999999994 |
| +0.01 | +14.976214685 | +13.810734557 |

実際の上下ボタンを呼ぶテストでも、粗調整 0.01 mm で約 1.189 µm、微調整 0.001 mm で約 0.119 µm の変化。粗操作の往復、微操作の往復で元へ戻る。粗一押しの表示例は +15 → +14。これは標準配置の例であり、全配置で同じ感度を保証する値ではない。

## 確認した範囲

- 正負の支持変化、固有 YZ −15 / 0 / +15、Y 位置 −100 / 0 / +100、寸法変更に対して同じ条件の全支持 0 基準を取り直す。
- 全支持同高さでは固有誤差を増幅しない。理想軸の正負剛体平面傾斜は YZ = 0 を維持する。
- 初期支持比較と現在欄は同じ変換を使う。元の物理値と教材値の DOM 属性は別に保持される。
- ズーム・図の強調切替で数値や物理姿勢は変化しない。保存記録は強調切替の既存フラグ以外変化しない。
- 無効な接触結果を数値へ変換しない。
- XY / XZ と他 6 機種の値は元の有限測定値のまま。
- 追加された柱拡大欄は削除。既存の測定注記で YZ 支持変化 ×50 を示し、詳細説明は式と実測値との区別を記す。

## 限界

これは教材の数値応答を調整したもの。実機の弾性や実測感度を検証した結果ではない。元の接触図・局所角度・調整評価・参考最良は元の幾何計算を維持するため、増幅した YZ 数値と同じ評価量にはならない。Y と Z が同じだけ傾く剛体傾斜を直角不良へ置き換えない。整数表示では微調整一押しが見かけ上同じ整数になる場合も残る。
