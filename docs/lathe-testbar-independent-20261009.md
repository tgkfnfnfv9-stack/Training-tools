# タレット旋盤・独立確認（2026-10-09、テストバー版）

実装担当と別の担当が、`src/lathe-inspection.js`、`src/lathe-inspection-ui.js`、旋盤模型を確認した。製品ソースは編集せず、独立検算を `tests/check-lathe-independent-20261009.cjs` に実装した。この記録は、加工径差・心押しを撤去し、奥側タレットと主軸固定テストバーへ変更した最終仕様の確認である。以前の加工径差の検証値は現仕様の期待値に使用していない。

## 結果と独立性

**390,591比較成功。通常の測定1,020状態、走査不足・最小行程20状態、純円筒接触16条件、模型48状態。** 測定の独立期待値との最大差は `6.21031e-10 µm`。

```sh
node tests/check-lathe-independent-20261009.cjs
```

入力した6支持高さから双一次補間と最小二乗平面を独立に求め、共通回転・残差の局所回転・取付ベクトルを組み立てた。面接触は符号付き距離の二分探索、穴4点は円への距離の二分探索、バーは主軸中心線への外積距離が25 mmとなる位置の二分探索で求めた。製品の円筒接触は二次方程式なので、別の解法で比較している。

描画関数、`geometryModel`、製品の姿勢関数、製品の符号表を期待値にしていない。固有誤差振幅は同じ個体の固定入力として受け取る。この検算は乱数分布や実機の弾性変形を保証しない。模型の再確認では描画関数の出力を検査対象とし、期待値は上記の独立主軸姿勢と宣言された半径25 mmから作った。

## 独立レビューで見つけた今回の不一致と再修正

バーを通常の模型点として変換すると、支持奥行を変える処理がバーの横半径だけに掛かっていた。例えば奥行1.2 mでは上下半径25 mm・横半径17.857 mmの楕円表示となる一方、検査は半径25 mmの円筒だった。

実装担当がバー専用 `latheTestBar` 姿勢を導入し、主軸と同一の剛体取付を保ったまま、バー断面のz寸法を支持奥行から独立させた。長さと主軸位置は支持幅に従う。理想輪郭も同じ断面補正を適用した。修正後48配置で全周頂点・両端・理想輪郭を別担当が再確認し一致した。検査計算の変更は不要だった。

前段の旋盤監査で見つかった穴芯図左右、X/Z始点の共通clamp、BOTフラット頂点接触、走査不足、穴断面近似の明記も現仕様で再確認した。現在の奥側BOT点は `[.23,1.5,+1.43]`、公称穴Xは `−.20/.35×100`。孔軸傾きによる楕円断面を解いているとは説明していない。

## 軸・接触・公式資料との関係

内部座標はxが機械長手、yが上、zが奥。タレットは奥側。スライダーX＋は部材の内部＋z移動、Z＋は内部＋x移動。主軸台・バーは両軸で静止し、往復台はZ、タレット・ホルダ・工具はX/Zへ動く。これは教材の部材移動方向であり、機種固有のNC径指令符号を認証したものではない。

[Haas ST Lathe Alignment – Indicating Zones](https://www.haascnc.com/service/troubleshooting-and-how-to/how-to/st-lathe-alignment-indicating-zones-.html) は、主軸にバーを取り付け、タレット側計器をZへ送ってバーの上面・側面を検査する配置を示す。また、タレット面XとBOTフラットZは主軸保持リング側の計器で動くタレット面を測り、穴芯は所定X位置で主軸側計器を旋回する。教材の搭載先・可動部材はこの関係と一致する。一律300 mm、6点支持、取付座とブラケットは教材側の設定である。

| 項目 | 固定・移動と接触 | 数値の意味 |
|---|---|---|
| 主軸a/b TIR | バーを主軸で回転。根元と300 mm先 | 同一個体の固有回転振れ。支持調整で不変 |
| タレットX面 | 主軸台側に計器固定。始点面法線へ方向合わせし、タレットをX＋へ300 mm | 奥側配置の固有面角をθとすると `−0.3 sinθ×10⁶ µm`。同じ剛体内のX方向と面の差なので支持姿勢を変更しても不変 |
| BOT Zフラット | 主軸台側に計器固定。奥側フラットをZ＋へ300 mm | 面材料点・面法線の運動、支持から0.84 mの取付高さを反映 |
| 穴芯 | 固定公称Xに戻した仮想ホルダを現在Zで測る | 部材径方向と上下の芯差。支持変更時に芯合わせを取り直さない |
| バー側面（奥） | 主軸固定バーに奥側から手前へ測定子。タレット固定本体をZ＋へ300 mm | 始点aの伸び−終点bの伸び。押込み増加＋、直径差ではない |
| バー上面 | 同じ固定バーに上から下へ測定子。側面とは付け替えた別検査 | 同じ伸び差。主軸と取付高さ・腕・途中の姿勢変化を含む |

バー検査の始点aは、タレット材料点 `[.08,1.5,.20]` を主軸軸線へ射影した長手位置。そこでバー半径25 mm＋測定子の伸び10 mmの位置に計器本体を置く。始点から終点まで取付腕と測定子方向をタレットの同じ剛体座標で運び、途中の方向合わせ・再ゼロはしない。支持・軸位置を変えて新しい検査を表示する際はaの取付と接触ゼロを設定し直す。

正捻れの一次の径方向変位は `−0.84×0.05×0.3/1000 m = −12.6 µm`。奥側にある固定計器からBOT面は離れるため約−12.6 µm。一方、バー側面検査では動く計器本体が固定バーへ近づくため約＋12.6 µm。この逆符号は搭載先と接触幾何から導いた。

バー上面が整数表示で0のままでも、値を固定しているわけではない。aの再取付・高さと腕の運動による一次成分の相殺と、円筒接触・3次元回転の二次成分があり、この例では整数µm未満になる。正負捻れが全小数桁で反対にならないのも二次成分を保持しているため。

## 残るモデルの限界

- 支持補間と剛体姿勢の教材。荷重、弾性、熱、測定力、バー自重のたわみを解いていない。長い理想バーは実用治具設計の推奨ではない。
- バー接触は16分割＋支持補間境界と両側を確認する。全連続経路での治具干渉、ブラケット実寸、タレットやチャックとの衝突を保証しない。
- 面測定は無限平面近似。寸法縮小などで有限タレット面から測定子が外れる条件は判定しない。
- 穴芯は円断面の偏心近似。孔軸傾き・楕円断面・穴深さ方向の芯差を対象にしない。
- タレット割出しとY軸は未実装。実機のNC径指令方向は教材のXスライダー方向と区別する。
- ブラウザー操作・保存読込・他6機種の比較・公開後確認はブラウザー担当と親担当の記録を参照。実iPhone Safariはこの独立数値検算では未確認。

断面修正を含むビルドで最終検算成功。確認時の生成HTML SHA256は `42a265f8fce434a7b589cb745184b7d918c43e26dacb299b9d1bc27d610b818b`。合格は宣言された教材内の幾何整合を示し、特定Haas型式の精度・支持感度・実機再現の認証ではない。
