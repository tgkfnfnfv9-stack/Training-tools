## 何が動き、どこが基準か

以下の「固定」は軸操作に対する固定であり、床に対して姿勢が絶対に変わらない意味ではない。支持高さを変えると各取付座の姿勢が変わる。

|機種・軸|動く部材|その軸で固定される主な部材|
|---|---|---|
|横形X＋（内部右）|コラム・Y案内・主軸頭・主軸|ベッド、パレット|
|横形Y＋（上）|主軸頭・主軸|コラム、パレット|
|横形Z＋（奥）|パレット台・回転座・パレット・ワーク|ベッド、コラム・主軸頭|
|旋盤X＋（奥・径外側）|Xスライド・奥側タレット・工具ホルダ・工具|往復台、主軸台・バー、心押し模型|
|旋盤Z＋（主軸から先端側）|往復台と、その上のX機構・タレット・工具一式|主軸台・バー、心押し模型|

|検査|基準器／計器の搭載先|測定で動く側とゼロ|
|---|---|---|
|横形XY|パレット上のマスタ／主軸頭固定計器|Rを頭X送りで合わせ、Sは頭Y＋送り。始点ゼロ|
|横形XZ・YZ|パレット上のマスタ／主軸頭固定計器|Rはそれぞれ頭X・Y送りで合わせる。SはパレットZ＋送り。マスタから見る計器は手前へ。始点ゼロ|
|横形a・b|主軸固定バー／パレット側計器|計器をZ送り。先端側から主軸側へ300 mm。別取付け、始点ゼロ|
|旋盤タレット面X・Z|移動するタレット面／主軸台側計器|面をX・Z送り。計器を始点の法線へ合わせてゼロ|
|旋盤穴芯|仮想ホルダの穴／主軸側計器|公称X芯位置へ戻す別配置、現在Zで4方向測定。支持変更で芯合わせし直さず、aで指示ゼロ|
|旋盤バー側面・上面|主軸固定バー／タレット側計器|主軸側から先端側へZ＋300 mm。別取付け、始点ゼロ|

各状態を測り直すときの再取付け・R方向合わせ・始点ゼロと、同じ取付けのまま送り中の姿勢輸送を分けた。走査途中に再ゼロしない。実物の計器を据え付けたままゼロを保持して支持を調整する操作とは別の教材仕様である。内部座標の方向と、型式固有のNC指令符号も区別する。
