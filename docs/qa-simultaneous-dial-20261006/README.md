# 直角図とダイヤル測定の同時表示：検証記録

2026-10-06。ユーザー承認の配置案②に基づく小型立形の表示変更。

## 変更内容

- XY・XZ・YZ直角図と数値を残し、その右に主軸ダイヤルの4点測定を常時表示。
- 0°右・90°奥・180°左・270°手前。既存の0°基準、直径300 mm、符号付き整数µmを維持。
- 模型の下にX・Y・Z選択と「1周回す」を同時表示。動作軸の色と矢印も保持。
- 携帯縦は左の直角3図を縦に並べ、右を4点2×2にする。短い横画面では上段を全幅にし、その下に模型と調整を左右配置。
- 小画面では粗調整／微調整・支持点選択だけ内部スクロールし、下げる／上げるは固定。
- 短い模型欄の余白を減らして模型を拡大。部品名は高さが足りない場合に省略し、支持点・軸・ダイヤルを優先する。

## 計算・データ

計算式と保存形式の変更なし。主軸とテーブル面の相対姿勢を使う既存の計算を維持し、表示用誇張・カメラ回転・ズームを測定値へ混入させない。全7機種と支持点数は不変。固定門形は長手ベッド9点＋左右柱各3点の計15点。ダイヤルは小型立形のみ。

理想平面と主軸軸線の相対傾きを扱う教材モデルであり、実際の面の凹凸、回転振れ、接触力・取付たわみ等は再現しない。固有誤差は従来通り残る。

## 初回に見つかった問題と修正

320×480では模型が過小、水準器が操作欄に重なり、選択スクロール欄に44pxのボタン全体が収まらなかった。測定見出しと余白を圧縮し、選択欄を47px確保。短い模型の描画余白を減らし、水準器を親の範囲内に収めた。再検証で解消を確認。

既存の「粗調整では数値を出さない」テストは新たに常時表示するダイヤル測定と矛盾したため、承認された測定要素だけを厳密に検証して例外化した。誤った測定値や無関係な数値の混入を検知する試験を追加し、計算オラクルは変更していない。
