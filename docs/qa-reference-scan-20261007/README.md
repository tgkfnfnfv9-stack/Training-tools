## 発見して修正を確認した問題

1. 初期図の「直角／マスタ」等が全42画面で重なった。図内の語数削減・展開図寸法調整後に解消。続いて上端ラベルの0.84〜2.18pxのはみ出しも修正した。
2. 横形の通常支持fixtureで、全区間Simpson積分が支持勾配の折れ目を跨ぎXZ/YZとも「収束範囲外」になった。支持格子位置で分割し内部Gauss点で積分する修正後、有効な数値へ復帰。境界を始点／終点にする場合も独立式と一致した。
3. 詳細欄を閉じた際の内部スクロール残留で粗／微調整タブが部分的に隠れた。開く前の位置へ戻す修正を全42画面で確認した。
4. 旧図にだけ存在する薄線／薄面の説明を整理。旋盤図は直角マスタの下辺を描かず、フランジのS面断面へ区別した。

## 計算時間の参考測定

[performance.json](performance.json) はNodeのDOM模擬環境で1機種の全測定面を30回計算した時間。最終中央値は約0.11〜7.13ms（横形が最大）。通常fixtureの横形は修正前の中央値約30.7msから改善した。JIT・GC・他処理の影響を含み、ブラウザーの画面更新時間やスマートフォン性能の保証ではない。
