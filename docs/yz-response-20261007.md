# 小型YZ数値の支持調整応答を変更

## 指示と変更範囲

ユーザーは追加されたコラム前後倒れ欄（黄色で指定）を不要とし、既存YZの数字（赤丸）だけ、支持調整でもっと変わるよう指定した。作業開始時mainはd4167ba42392ae6c7e5213d288264a0943c7b78a、作業ツリーはクリーン。

追加欄・更新処理・専用CSS・説明を撤去。既存の小型YZ数値にだけ、支持寄与を50倍にする教材表示を導入した。新しいパネルは追加していない。短い縦画面の支持操作領域168px確保は、削除した欄への依存を除いて維持した。

## 式・意味・例

Iは従来reference-scan-v3の300 mm有限仮想測定、I0は同じ個体・寸法・軸位置で支持高さを全て0にした同じ測定。

**表示値 = I0 + 50 × (I − I0)**

I0に含まれる固有誤差は増幅しない。支持変更に伴う差だけ増幅する。現配置の接触符号は変えない。ただし、支持寄与を増幅した合計値なので、物理値と教材値の符号が常に一致するとは限らない。教材値0も元の物理値0を意味しない。

標準配置・中央でA+0.01 mmを与えた例は、元のYZ変化約−0.024 µmから教材表示約−1.2 µmへ。整数表示では+15→+14となる。微調整0.001 mmは約0.12 µm変化なので、毎回整数が変わるとは限らない。実機感度を再現した値ではない。

既存の測定欄に「YZ支持変化×50」を常時表示し、▽の既存説明へ教材値であることと式、元の有限値を記載した。図は元の接触配置を保持する。図の拡大と数値の支持変化倍率は別。

## 計算と保存互換性

数値表示の計算変更であり、単なる装飾変更ではない。新しい剛性・弾性モデルは導入していない。referenceScanの物理計算と接触判定は不変で、別関数referenceReadingが表示専用オブジェクトを返す。元の測定・基準のどちらかが無効なら表示を抑止する。

小型のXY/XZ、他6機種、模型姿勢、水準器、支持粗0.01/微0.001、4方向ダイヤル、従来局所角度・参考探索・調整評価は元の計算。支持の共通剛体傾斜でYZが改善するようにはしていない。

保存JSON形式・支持値・固有誤差・軸位置は変更しない。旧保存も読める。同じ旧保存状態の小型YZ表示は、新しい倍率で再計算されるため以前と異なる。表示モデルはcompact-yz-response-v1、物理モデルはreference-scan-v3のまま。初期比較も同じ倍率で表示する。ページ再入場のリセット・再抽選を維持。
