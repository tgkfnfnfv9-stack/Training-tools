- 全7機種 × 1280×1000、390×844、320×568。個体は保存仕様に沿って seed=234567、中古、支持高さを固定した。

- 第1ページ：測定欄の外側の全ピクセルと既存要素の位置・寸法が比較元と同一。旋盤はページ全体の全ピクセルが同一。
- 第2ページ：第1ページと比較して測定欄の外側の全ピクセル・要素位置が同一。模型・水準器・軸選択・支持操作が移動しない。
- 旋盤以外の6機種で第2ページを表示し、数値・注記・SVG 文字が表示範囲に収まる。旋盤に第2ページ・ページ操作は出ない。
- 主軸振れの根元と300 mm先、上面の左中央0、傾き除去、固有成分・レベル調整では不変の注記。5軸の A=C=0 注記を含め、PC と最小320px画像を目視確認。
- Chromium の実ポインターによるマウスドラッグと CDP のネイティブタッチ入力による左右スワイプ。ページ設定関数への直接呼び出しではなく、実際の横スクロール・イベントを確認。触れ枠からドラッグしても元の詳細欄が誤開閉しない。
- 矢印キーで往復（戻る前にフォーカスを取り直さない）、非表示ページの inert、ページ2のまま390→320リサイズ時の位置維持。
- ページ送り、支持調整往復、軸移動、カメラ・ズーム・誇張変更で個体と新しい2図の数値が変わらない。6機種で支持・軸位置を変更、5軸旋回姿勢でも固有基準検査値を保持。
- 新しい個体の抽選・機種変更で第1ページへ戻る。
- 比較元887ba72が生成したJSONを新ソースへ実際のファイル入力で読み込み、同じ個体から同じ2図を再生成。

## 修正と再確認

初回結果は `initial-review.json`。表示範囲検査で上面図の下端注記が SVG viewBox を約1px超える箇所と、横形の根元ラベルの上端超過を発見。表示担当へ伝え、注記を y=55、横形根元を y=13 へ変更して再確認した。矢印キー操作時もフォーカスを残す処理を追加して最終試験した。

初回の「外側要素位置」18件はテストが新設ページ自体を外側と誤分類していたもの。比較範囲を carousel 全体に合わせて修正した。初回から画像差分による外側ピクセル検査は成功している。修正後の最終結果は `after/results.json`。
