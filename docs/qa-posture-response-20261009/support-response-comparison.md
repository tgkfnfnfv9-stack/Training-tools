# 実操作・独立計算の数値対応

旧式値は旧配置の観測、新式期待値は独立した支持・剛体・接触幾何から求めた値。期待値に旧実装値を使用していない。単位 µm。全入力・全項目は [CSV](support-response-comparison.csv)。支持操作はmap選択＋粗微＋上下ボタン、既知ねじれ入力だけevaluate。
