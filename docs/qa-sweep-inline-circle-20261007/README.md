# 触れの小円・手前0の独立確認

対象: 既存5機種（小型立形・移動コラム・固定門形・移動門形・5軸）の触れ枠内だけに測定位置の円と手前0を追加。横形と旋盤のUIは変更しない。

比較基準は main `7c9fcb344b73dd2922aee9b2ef753fe31200a8c3` の公開用HTMLを `git show` で固定した `before/index.html`。変更実装担当とは別の確認担当が Playwright / Chromium 実ブラウザーを操作した。ローカルHTMLはrouteで応答し、外部サイトとは区別した。

## 発見・再修正

初回検査では、対象5機種の元の枠は64×79pxだったのに64×77pxへ縮めていた。横形の枠64×77pxと混同したため。携帯画面では模型・水準器等が2px動き、「他のUIを変更しない」に反した。`first-review/results.json` と `first-review/0-390.png` に失敗を保存した。

修正担当が見出し行を25→27pxへ調整して元の外寸64×79pxを復元。小円自身は24×25pxのまま。再ビルドしたHTMLで全対象を再検査した。上端の文字と接触点が重なる案は、最終版では上端の文字を省略して解消した。

## 検査範囲

- 全7機種 × 1280×1000 / 390×844 / 320×568 の21画面を固定状態で比較。
- 対象5機種: 枠外の表示要素の座標とサイズ、枠外の全ピクセルが変更前と一致。
- 横形・旋盤: 全画面のピクセルが変更前と一致。
- 全数値の表示文字・内部reading値、既存詳細選択UIのHTMLが一致。
- 枠内の小円は手前点が下側、前点と0ラベルの対応、SVG文字と図が枠内に収まること。
- 手前接触が面外なら4数値すべてを抑止、小円も「手前—」となり無効な0を表示しない。
- 正負3桁・4桁の文字を表示してラベルと数値の重なり、枠はみ出しがないこと（表示専用の幅負荷検査でありエンジン改変なし）。
- 5軸A/C旋回状態の小円が測定位置の模式図と説明されること。カメラ投影やテーブルの上面輪郭の忠実な図という主張ではない。
- 横形→小型立形→旋盤→5軸の切替で適切な小図だけが現れること。
- 既存方向選択が小円追加後も開けること。ブラウザー例外なし。

最終 **196/196成功**。固定した最終HTMLのSHA256は `9dd7f647fb6d741ccc1321ba308baaa98b22634691abc54a135d4edb84ee9f43`。詳細は `after/results.json`。各画像は before / after 配下に保存。検査コマンド:

```
node tests/browser-sweep-inline-circle.cjs before
node tests/browser-sweep-inline-circle.cjs after
```

再現時はfont読込み後に静止し reducedMotion=reduce を使い、動画・遷移に伴う無関係なピクセル揺れを除いた。ピクセル除外は対象枠の境界から1pxのアンチエイリアス領域まで。全数値の比較には除外はない。

## 限界

確認は教材の表示・既存読みの保存と参照無効時の振る舞いに限定。計算式、実機剛性、測定器荷重、実機精度を今回再検証したものではない。実iPhone Safariは未確認。
