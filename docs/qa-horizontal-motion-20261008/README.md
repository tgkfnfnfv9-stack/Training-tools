対象は b56dbbd の公開用 HTML と今回の修正版。`before/index.html` は `git show b56dbbd:index.html` で固定したもの。テストは Chromium の実ページ上で実行し、画像と状態を同時に保存する。

利用者の画像の乱数種は不明である。以下は画像の個体を再現したものではなく、`used / seed 123456` の固定した別の教材個体を使う。支持高さをすべて 0 にし、軸位置は中央から開始した。値は画面の整数 µm、並びは XY / XZ / YZ / Z平行a / Z平行b。

|実際の操作|模型で動いた部材|表示値（µm）|
|---|---|---|
|中央、支持 0|停止|+17 / +8 / +14 / +8 / +14|
|X スライダー −100 → +100|コラムと主軸頭が一緒に左 → 右。台とベースは固定|同じ値|
|Y スライダー −100 → +100|主軸頭が下 → 上。コラムと台は固定|同じ値|

平面上の固定姿勢の個体では、取付位置を変え毎回方向合わせ・ゼロを取り直しても、このモデルの平行度と直角度は同じになる。軸を動かせば必ず数値が変わる仕様とはしていない。上表の左右・前後は模型の部材方向であり、NC 指令符号を検証した表ではない。

同じ seed 123456 の個体に `h=0.05xz` を与え、実際のスライダー操作で再確認した。画面の整数 µm（XY / XZ / YZ / Z平行a / Z平行b）は次の通り。

|X：コラム＋主軸頭|+18 / −1 / +22 / −20 / +14|+18 / −1 / +6 / −20 / +14|

Z 操作でも丸め前の値は僅かに変化する（XZ の差は約 0.00085 µm）。整数表示にしたため変化が見えない場合と、計算が操作に追従していない場合を区別する。また X 操作による YZ と Z 平行 b の変化量は異なる。計器台の横方向の持出しとパレット姿勢変化を含む Z 平行度は、上面中心を追う直角測定と同じ検査ではない。

## 修正前に実画面で確認できたこと

- `motion-X--100.png` / `motion-X-100.png`: 実スライダーによりコラムと主軸頭が一緒に左右移動。パレットとベースは残る。
- `motion-Y--100.png` / `motion-Y-100.png`: 主軸頭だけがコラムに沿って上下移動。したがって XY の小図の「頭固定」は、この走査時の機械部材の動きとしては誤り。
- `motion-Z--100.png` / `motion-Z-100.png`: パレット台とワークが前後移動。主軸側は残る。XZ/YZ の基準器に対する計器の相対移動と部材の移動は反対。
- `view-side.png` と `parallel-detail-contact.png`: 主軸は奥側、テストバーは手前へ突出。Z 平行度の長手図は左が先端、右が主軸、計器台は右（主軸側）へ。前面円の a は左側接触、b は下側接触。小図は固定した説明図で、模型を回しても向きは変わらない。
- 正面・側面・斜めのカメラ変更で数値は不変。
- 理想平面・全体の剛体傾斜を与えた場合は 3 直角、Z 平行度 a/b ともほぼ 0（誤差 < 0.000001 µm）。
- 正負の鞍面 `h = ±0.05 x z`、固有誤差なし、Z 位置 −100/0/+100: XZ は約 ∓9.15 µm、Z 平行度 a は約 ∓28.35 µm。両者は異なる取付高さと接触配置の検査で、同じ数値であることは期待していない。b は両符号で約 −0.0159 µm。整数表示では 0。
- `twist-1-front.png` / `twist--1-front.png`: 正の鞍面では後方のコラム座の右が高く、コラム上端は左へ倒れる。負では逆。手前のパレットの左右傾きも反転し、コラム座とは反対になる。`twist-1-side.png` の中央 X では前後倒れはほぼない（独立期待値 `∂h/∂z = kx = 0`）。
- 上記側面画像では、旧模型の主軸頭・案内とコラムとの間に離れた隙間も確認した。測定数値の誤りの証明ではなく、構造の模式表示の問題として扱う。

正面の厳密な正投影では前後の支持点が同じ画面座標へ重なる。G/H の文字が A/B に重なって見えるケースがある。これだけで支持点の左右や高さ計算が誤っているとは判断しない。

## 比較の方法と限界

390/1280 px で 7 機種の同じ乱数・支持状態を使用。横形以外の 6 機種は、通常測定ページと固有精度ページの画面全ピクセル・数値・文字を前後比較する。横形は実スライダー、正負捻れ、移動端、表示方向、保存読込、支持調整往復、固有精度不変を確認する。

スクリーンショットは実際の画面表示の証拠であり、実機に取り付けた計器による測定ではない。画像の見た目だけからミクロン単位の接触計算の正当性は判定しない。計算の独立幾何検証は別担当の結果と合わせて判断する。
