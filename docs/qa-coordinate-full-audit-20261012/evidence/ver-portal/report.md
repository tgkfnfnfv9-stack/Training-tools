## 1. 座標系・単位・符号
- 共通(世界)座標 = 描画内部 xyz：x=右, y=上, z=奥。長さ m、支持高さ mm、勾配 mm/m（回転では /1000 して無次元）、表示 µm。
- 機械軸の対応（app.js axisConfig）: travel X=+x(コラム＋主軸頭), Y=+z(主軸頭前後), Z=+y。gate/gantry X=+z(gate:テーブル, gantry:門全体), Y=+x(サドル), Z=+y(ラム)。
- 支持面: h(x,z)[mm]。勾配 lr=∂h/∂x, fb=∂h/∂z [mm/m]。
- 部材の座り（剛体回転）: a=lr/1000, b=fb/1000、up=unit(−a,1,−b)、right=unit(1,a,0)、back=right×up、R=[right up back]（鉛直軸まわりの回転なし＝据付での水平面内回転は生じないという仮定）。部材の材料点 p（公称位置）→ 世界 = ref + R(p − ref0)（回転→並進の順）。
- 固有直角差: 保存値 µm/300mm を角度 θ=µm/0.3e6 rad。Y=Ycos−X sinθXY、Z は X·Z=−sinθXZ, Y·Z=−sinθYZ を満たす単位ベクトル（＋は 90°より開く）。方向は部材の公称局所座標に置き、取付部材の R で回す。
- ダイヤル: 測定子伸び e = n·(face−body)/(n·p)（n=S面の外向き法線＝計器側、p=測定子方向、初期 p=−n、初期伸び 10 mm）。読み = (e_zero − e)×1e6 µm、**＋＝押込み増加**。整数表示は |値| を四捨五入し符号付き（製品 squarenessMicronText と同規則で別実装）。
- 直角測定の配置（ユーザー指定＋製品カードの記述した接触側・送り向き）: マスタはテーブル上（gate はテーブルとともにX移動、travel/gantry は固定）。計器は主軸側（travel: コラム＋主軸頭、gate: ラム、gantry: 門→サドル→ラム）。
  XY: マスタ寝かせ、S面法線=+X（計器は+X側から接触）、主軸頭／サドルを **+Y へ300 mm**（σ=+1）。XZ: マスタ立て(X–Z面)、S法線=+X、**Zを−へ300 mm**（σ=−1、上→下）。YZ: マスタ立て(Y–Z面)、S法線=+Y、Z−へ300 mm。S走査中は取付部材の姿勢不変（Y/Zはコラム・門の座りを動かさない）なので、読み = −σ·0.3·(n·s)/(−n·p)×1e6。
- 区別: 製品の「従来の局所角度差×300 mm」(pair.deviation×0.3) は、XZ/YZ では下向き走査のため有限走査値と符号が逆（travel 前: 局所 +12.08 / 走査 −12.08）。本報告の値は有限区間走査の終点値。

## 3. 条件と式
- **B1（製品定義の方向合わせ）**: R面を現在位置の基準軸の局所方向 d_base に平行、始点ゼロ。読み = −σ·0.3·(d_base·d_scan)×1e6。
- **B2（実走査の方向合わせ）**: 計器を主軸側に付けたまま基準軸を300 mm走らせ（X: 区間 [clamp(現在,−half,half−0.3), +0.3]、travel half=1.0 m, gate/gantry 0.7 m。Y: 頭/サドルのみ移動）、両端等指示になるようマスタを自分の面内で回す。テーブル局所座標での計器先端の弦 Δ = T(x1)⁻¹tip(x1) − T(x0)⁻¹tip(x0)（tip は工具側部材に固定、移動するコラム／門／テーブルの各位置の座りを使う）をマスタ面へ射影→S法線。現在位置で S を走査、始点ゼロ。
- **C**: 支持操作前に B2 で取付け（マスタはテーブル、計器は工具側に固定）、そのまま支持を変え、始点でゼロだけ更新。n' = R_T'·n_local、p' = R_C'R_C⁻¹p。読み=(e'_start−e'_end)×1e6。回転のみで決まる。
- **A**: C と同じ取付けで最初のゼロ(操作前の始点、e0=10 mm)を保持。読み=(e0−e'_end)×1e6 = C + 始点の跳び(e0−e'_start)。跳びは「計器本体／接触点の位置×部材回転」の腕で決まる。
- 触れ: 主軸軸線 a = 工具側部材の固有Z方向（製品と同じく主軸軸線＝Z送り方向と同一視。模型に別パラメータが無い）、テーブル法線 u=R_T·up、半径 r=0.15 m（製品値）、主軸旋回（軸送り走査ではない）。リング点 ρ(θ)=r(cosθ e0+sinθ e90)、e0=工具側右方向の軸直交成分、e90=e0×a（0°右, 90°奥, 180°左, 270°手前）。λ(θ)=−u·ρ/(u·a)、読み(θ)=(λ(θ)−λ(270°))×1e6（手前ゼロ, ＋=押込み増）。A は初期の手前ゼロ保持で、リング点を工具側部材、表面点をテーブルに固定して運ぶ。

## 5. 一致／不一致と原因推定
### 5.1 一致したもの
- **B1 と製品DOM**: travel・gantry の XY/XZ/YZ は前後とも差 ≤1e-4 µm、gate の XY/XZ は ≤0.021 µm（製品は common 回転と相対回転を合成、本実装は局所勾配で1回の座り回転。二次の微小量で、整数表示は同じ）。製品の表示値は「現在位置の基準軸の局所方向へR面を合わせ、始点でゼロ、300 mm走査」の値（B1）であり、接触計算そのもの（伸び差＝−σ·0.3·n·s）は正しい。
- **触れ（B=C、手前ゼロ）**: travel・gantry は製品DOMと 4方向とも一致（差 <1e-4 µm）。gate は「せん断仮定」で一致（下記5.2③）。
- Y/Z が同じ剛体（コラム、または門剛体）に載る対（travel YZ、gantry YZ、本実装の gate YZ）は支持操作で変わらない（固有 −18.206 µm → 表示 +18、下向き走査のため符号反転）。共通剛体運動の相殺で正常。
- 製品が A/C を表示しないこと: 製品は支持・軸位置の変更ごとに方向合わせとゼロを自動で取り直すと明記しており、表示は B 型のみ。A・C は「製品に該当表示なし」。

### 5.2 不一致
① **travel XY/XZ：移動コラムの姿勢変化を R 方向合わせに入れていない**（製品 − B2：XY 前 +4.75 / 後 +10.96、XZ 前 −8.91 / 後 −20.55 µm、整数 XY −1 vs −6 / −1 vs −12、XZ −12 vs −3 / −10 vs +11）。
原因: 双一次支持面ではコラム座り点の前後勾配 fb が X 位置で線形に変わる（ねじれ成分）。X 300 mm（コラム x=−1.0→−0.7 m）で Δfb＝前 −0.0102 / 後 −0.0236 mm/m。計器はコラムと一緒に傾くので、先端（レール基準から高さ 0.465 m、前後 −0.872 m）が XY では前後へ Δfb×0.465 m、XZ では上下へ動き、両端等指示に合わせた R 面がその分回る。製品 referenceScan は travel/gate/gantry で `varies=false`・"representative-fixed-posture"（開始位置の姿勢を固定）で、R を局所方向に合わせるためこの項が無い。取付位置感度は 0.1 m あたり 1.0〜2.4 µm で、差 4.7〜20.6 µm はこの仮定の範囲を超えて残る（XZ は基準点の取り方に依存しない：双一次面が z に線形なため）。
② **gate XY/XZ、gantry XY/XZ：移動するテーブル／門の姿勢変化**（製品 − B2：gate XY +4.36/−7.59, XZ +1.35/−2.34；gantry XY −0.32/−6.20, XZ −0.10/−1.92 µm。整数 gate XY −1 vs −5、−94 vs −87、XZ −35 vs −36、−76 vs −73；gantry XY 0 vs +1、+31 vs +37、XZ −14 vs −12（後））。gate はテーブル（ベッド双一次）の左右勾配 lr が X で変わり、マスタ（上面+25 mm、テーブル基準から 0.485 m）が傾きながら動く。gantry は左右柱足の lr が X で変わり門がロールする。原因は①と同じ（開始位置の固定姿勢＋局所方向合わせ）。
③ **gate YZ と gate 触れ左右：ラム方向のモデル仮定**。製品 YZ 前 +47 / 後 +86 µm、本実装（剛体：サドルは梁の案内に乗りラムは梁と一緒に回る）+18 / +18。製品値は「ラムZ＝左右柱 up の平均で、梁方向へ直交化しない」せん断仮定を自前で組んだ値と完全一致（46.5322 / 85.7582）。L3 は左右柱側が別の3点平面で、左右柱足の高さ差（梁の傾き）と柱の左右倒れが一致しないため差が出る（gantry は両柱が同じ双一次面の縁に乗り両者が一致、せん断＝剛体で差なし）。触れも同じ理由で 右/左 が ±14.16（前）/±33.78（後）µm 異なり、製品はせん断仮定側。物理的にはサドルが梁の直動案内に乗る限り梁ロールは Y と Z を一緒に回すので YZ は変わらないはずで、製品の YZ 変化 +28〜+68 µm は仮定に由来する（計算誤りではない）。どちらを採るかは部材接続の仕様確認が必要。
④ A は製品に表示がないため比較対象なし（不一致ではない）。

## 6. 触れ（主軸旋回、r=0.15 m）で分かること・分からないこと
- 分かる: その軸位置での「主軸回転軸」と「テーブル上面法線」の相対傾き 2成分。手前ゼロで 奥 = 2×前後成分、右−左 = 2×左右成分、整合条件 右+左=奥（全ケースで成立）。
- 分からない: (a) コラム倒れとテーブル傾きの分離（相対量のみ。全体の共通傾きは消える）。(b) 主軸軸線と Z 案内の分離（模型は同一視、実機では旋回は主軸軸線だけを測り、Z 案内は Z 送り走査が別に必要）。(c) 固有直角差（Z の XZ/YZ）と支持起因の傾きの分離（例 gantry 前: 柱とテーブルの勾配が同じため 奥 = −13.943 = 固有 XZ がそのまま出る）。(d) 門形の左右成分は梁・ラム接続の仮定（5.2③）で変わる。(e) travel では X 位置で値が変わる（コラム座り点とテーブルの勾配差）。
- A（初期の手前ゼロ保持）では 4方向が同じ量だけずれる（主軸リングとテーブル面の上下相対変位）: travel +24.09, gate +82.52, gantry −1.69 µm。差分の形は B と同一。上下の腕長さは一次では効かず、模型の座り高さだけで決まる（travel はレール基準・座り点基準で同値）。

## 7. 条件不足
- **直角の A は条件不足**: 計器本体・接触点の位置（マスタ寸法と置き場所、計器の腕）が未指定。表の A 値は「鼻先直下・上面+25/+310 mm」と置いた暫定値で、接触高さ 0.1 m あたり 跳びが（XY・XZ / YZ）travel −3.0/+4.5、gate +13.6/+1.4、gantry 0.0/+1.1 µm 変わる。gate YZ の跳び −389 µm は 2.51 m 柱の倒れで梁中心が横へ動くことによる（柱の回転中心＝座り点という模型定義に依存）。B 値で代用していない。
- C は回転だけで決まるが、初期取付け（B2）が接触位置仮定に 0.1 m あたり ≤2.4 µm 依存。
- テストバー測定は本担当範囲外のため扱っていない。
- 製品の 15 点薄板スプラインは測定姿勢に使われていない（parts が優先）ため、その妥当性は未検証。
