## 2. 座標系・単位・符号

- 世界座標 W（＝内部の描画座標 xyz）: x=右、y=上、z=奥（コラム側）。長さは m、支持高さは mm、勾配は mm/m（÷1000 で無次元）、指示値は µm。
- 機械軸: +X=コラムが右へ、+Y=主軸頭が上へ、+Z=パレットが奥（主軸側）へ。主軸は −z（手前）を向く。
- 部材の局所座標: パレット枠 F_p と主軸頭枠 F_h（コラム座の傾き R_c に、固有のXY直角差による回転 R_b を合成）。マスタはパレット枠に、ダイヤルは主軸頭枠に固定した材料点と方向として持つ。
- 固有直角差（入力データの意味）: ε_ij = microns / 300 mm [rad]。角(i,j) = 90° + ε_ij。X̂=e_x、Ŷ=[−sin ε_XY, cos ε_XY, 0]、Ẑ は X̂·Ẑ=−sin ε_XZ、Ŷ·Ẑ=−sin ε_YZ を満たす単位ベクトル。
- ダイヤル: 計器本体 B から測定子方向 p へ伸びる半直線と面（点 Q、法線 n）の交点。伸び e = n·(Q−B)/(n·p)。初期の伸び 10 mm、有効範囲 0〜20 mm。
- **指示（µm）= (e_ゼロ時 − e_読取時)·10⁶。＋は押込みの増加（伸びが減る）**。整数表示は製品と同じ規則（|値| を四捨五入し、0 以外には符号を付ける）。
- 確認: 支持を全て0にすると、独立計算の値は XY=ε_XY·300、XZ=ε_XZ·300、YZ=ε_YZ·300（µm）にそれぞれ一致した（−1.338 / −13.943 / −18.206）。Z平行度は a=−13.950、b=+18.202 で、手計算の円断面の交点（−13.9496 / +18.2021）と一致した。

## 3. 独立模型の式

1. 支持面 h(x,z): 2×4 格子のセルごとの双線形補間。セルの境界では奥側のセルを使う。h_x、h_z はセル内の偏微分（mm/m）。平均平面は最小二乗で求めたが、表示のためだけに使い、姿勢には全体の勾配を使った。
2. 座（seat）: 点 P=[x, 0.66+h/1000, z]、法線 n=unit(−h_x/1000, 1, −h_z/1000)、R = 最小回転(e_y→n)（Rodrigues）。部材は1点の座の接平面に剛体として乗る（製品の模型の定義）。
3. パレット（Z送り s=0.45·Z/100）: 座は (0, −0.85+s)。原点 = P + R·(s·(Ẑ−e_z))。材料点 = 原点 + R·r_local。上面の基準点は r=[0,0.61,0]。
4. 主軸頭（X送り x_c=0.55·X/100、Y送り d_Y=0.3·Y/100）: 座は (x_c, 1.334)。鼻 = P + R_c·(R_b·[0,1.89,−2.264] + Ŷ·d_Y)。R_b=最小回転(e_y→Ŷ)。F_h=R_c·R_b。**X送りの経路は座の点そのもの**であり、2本のXレール（z=1.158/1.418）の傾きは使わない（製品の horizontalToolPoint では X 補正が恒等的に0なので、レールは走査値に入らない。これは模型の定義として扱った。レール平均の傾きと座の傾きが異なるケースでも製品と 3e-3 µm 以内で一致したので、数値でも裏付けられる）。
5. 走査の始点: start = clamp(位置·half/100, −half, half−0.3)、終点 = start+0.3 m（300 mm を確保できない場合は始点を戻す。製品の定義）。

- 方向合わせは、マスタの面内1自由度だけを回して等指示にする（物理的な手順）。製品は面法線を端点の弦に 3 次元で一致させているが、この差は2次の微小量（後述の 1e-3 µm 程度の差の主因と推定）。
- Z平行度（**テストバーの寸法・取付は製品の仮定**。ユーザーは指定していない）: バーは主軸に固定する。軸 â = F_h·e_z（**主軸の軸線は主軸頭枠の z で、Ẑ ではない**という製品の仮定）。原点 O = 鼻 − 0.31·â、半径 25 mm、校正区間は O から軸方向に −10〜310 mm。計器はパレットに固定し、本体 = O − 35 mm·dir、測定子 = dir。a は dir=F_h·e_x（左から右向き）、b は dir=F_h·e_y（下から上向き）。パレットを Z+ へ 300 mm 送る（バー先端側から主軸側へ）。**主軸は回さない**ので、回転振れ（TIR）とは別の測定で、バーの偏心・振れは含まない。接触は半直線と円柱の近い側の交点。

### 条件
- **A**: 支持を変える前に取付け、方向合わせ、始点でゼロ。そのまま支持を変える。マスタはパレットと、計器（またはバー）は主軸頭と一緒に動く。方向合わせもゼロも更新しない。表には「A始点指示」= e_前(始点) − e_後(始点) と、「A終点」= e_前(始点) − e_後(終点) を載せた。
- **B**: 支持を変えた後に、マスタの方向合わせ（R）をやり直し、計器を名目位置（伸び 10 mm）に取り付け直し、S の始点で再ゼロ（Z平行度はバーと計器を名目位置に再取付けして始点で再ゼロ）。
- **C**: 支持を変える前の取付けと方向のまま、支持変更後の始点でゼロだけ取り直す。C = e_後(始点) − e_後(終点)。
- 条件Aに必要な取付点と腕は、製品の模型で定義されている（マスタの角はパレット上の材料点、計器本体は鼻からの剛体ブラケット、テストバーは鼻に固定、Z平行度の計器はパレット上の材料点）。このため **Aは計算できた（条件不足ではない）**。ただし、これらの寸法はユーザー指定ではなく製品の仮定である。

## 5. 一致・不一致と原因の推定

1. **B と製品は一致**（≤0.003 µm）。残る差は2次の微小量で、次の3点が原因と推定する。(i) 方向合わせの方法: 製品は端点の弦に面法線を3次元で一致させ、本計算は面内1自由度で等指示にした。(ii) 部材の向きの取り方: 製品は平均平面の回転と残差勾配の回転を合成（yaw の規約は right=[1,a,0]）、本計算は全体の勾配からの最小回転。(iii) R計器の初期取付位置の取り方。いずれも整数表示には影響しない。
2. **A は B と大きく異なる**（A終点−B は上表で最大 約125 µm）。原因は (a) 支持の変更で座が上下・傾斜して、パレットと主軸頭が相対的に並進・回転すること（始点の指示が0からずれる。鼻はコラム座から 1.89 m 上、2.264 m 手前にあり、腕が長い）。(b) 方向合わせを更新しないので、マスタの姿勢の変化がそのまま S の読みに入ること。(c) Z平行度では、パレット座の傾きの変化で計器が動き、主軸頭の傾きの変化でバーの軸が動くこと。製品は A を表示しないので、画面の値を「器具を付けたまま支持を回した時の針」と読むことはできない（製品の文言もそう明示している）。
3. **C と B の差は「方向合わせの更新」によるもの**。XZ や Z平行度 b のように、R がパレット側の姿勢変化の影響を受けない（あるいは同じ1セル内）ケースでは C≒B。XY・YZ では、コラム座や Z 区間のセルが変わるため C≠B になる。
4. 動かない理由の確認（正常）: 中央4本を一様に +0.05 mm にすると、XY と XZ は B・A・C ともほぼ不変（≤0.007 µm）。後ろのセルの h_z が x によらず一様に変わり、コラムのピッチだけが変わるので、x 方向の読みに入らないためである。A(左手前)+0.05 の XZ では A終点＝変更前の値になる（終点のパレット座は中間セルにあり、影響を受けない）。
5. 模型の定義に関する注記（不一致ではない）: (a) XY が固有値 −1.3 µm ではなく +26 µm になるのは、後ろセルのねじれのためである。X送りに伴ってコラムのピッチが変わり、鼻（2.264 m 前）が上下する（約 23 µm/300 mm）。支持1点の座による剛体の模型だから生じる効果である。(b) 画面の geometryAssumption は「Xは二本の走行レール」と述べているが、有限走査の値にはレールが入っていない（4項の X 経路を参照）。(c) Z平行度の主軸軸線は「主軸頭枠の z」と仮定されており、主軸単独の傾き誤差は入力に存在しない。このため a≒−(XZ)、b≒−(YZ) となり（支持が平らなとき）、実質的には Z 送りと主軸頭の姿勢の関係を見ている。主軸回転の TIR とは別物である。(d) YZ の S 面の平面は角から 10 mm 法線方向にずれた位置を通る（製品の配置）。差には影響しないが、A の絶対位置の解釈では注意が必要である。
