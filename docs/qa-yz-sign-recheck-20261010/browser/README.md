## 実操作と生値

理想状態と used seed 123456、全 8 支持点、微調整 ±0.001 mm と粗調整 ±0.010 mm。支持点選択、微粗切替、上げる・下げるは Chromium の実クリック。初期の機種・プロファイル・平坦状態だけを既知入力として evaluate で設定した。

各候補 66 状態、合計 132 状態。各状態で XY/XZ/YZ の計器伸び、読みの生値、整数、SVG の実際の測定子両端と全長を採取した。製品の contact/compare を呼ばず、捕捉した始終姿勢から別の平面と直線の交点計算で伸びを求めた。これは姿勢モデル全体の独立検証とは区別する。

## 図の方向と配置

YZ 小図は「図上＝奥（＋Z）」「図右＝上（＋Y）」であり、実物の上下を 90 度回した展開図。頭側計器が右、測定子が左（物理 Y−、下向き）でマスタ上面 S に当たる。Z＋はパレットとマスタの奥移動で、計器の相対移動は手前。図では上のゼロから下へ移る。公開版の R 表示は下辺、PR は上辺。

この方向・配置に対する接触の符号は一致したが、通常の Y 上／Z 横の見方とは異なるため、実物の見取り図として読み違える可能性は残る。想定した物理配置自体の妥当性は別担当の監査対象。

## 公開版に残る図の反例

支持 ±0.400 mm、軸 ±100 の範囲で各候補 700 姿勢を決定的乱数で設定し、図の長さを探索した。これは evaluate による入力試験で、支持ボタンの実操作とは区別する。公開版に 1 件、PR に 0 件の反例を得た。

公開版：used seed 123456、X−21 / Y11 / Z97、支持 A〜H `[0.004,0.373,0.055,0.342,0.342,-0.108,0.381,0.051]` mm。YZ 生値は **＋0.071434 µm、整数 0** だが、SVG の測定子長は **11→11.018681** と伸びて見える。本体の法線移動と測定子角度を別々の倍率で強調しており、図の全長は計器の実際の伸びと同じ符号になる保証がない。これは「表示が＋の整数なのに伸びる」例ではないが、生値と図の逆転として残す。

**追試で現 PR にも同じ種類の反例を確認した。** 理想・全軸 0、A ＋0.050 mm、E ＋0.091 mm の単純な二支持操作で、生値＋0.033566 µm に対して図の全長は 11→11.012564 と伸びる。図制限なし。実ボタンでも再現。[現 PR の反例と前後画像](pr-counterexample.md)。先の 700 姿勢で 0 件だった結果だけで正常とは判断しない。
