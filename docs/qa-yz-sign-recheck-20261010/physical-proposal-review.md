# YZ配置変更案の独立レビュー

2026-10-10。対象は未実装の [proposal.md](proposal.md) と [proposed-fixture.cjs](proposed-fixture.cjs)。製品および提案の計算コードは変更していない。接触側の採用判断とも別の検査である。

計算検査時の測定ソースは `874d659`（SHA256 `4f61d895955d73d8fc084780d28dd9fe49c6426398d890fe8b842e5f8e73db39`）。記録作成中に別担当が現配置の小図と説明を修正したが、差分を確認し、候補で使用する機械姿勢・測定計算は変更されていないことを確認した。

**提案のR合わせ、選択Zへ戻した後のS取付けとゼロ、頭のY送りによる押込み差には、確認範囲で数値上の破綻を認めなかった。有限器具の設置を実物として成立させるには、調整台／脚、サンプルワーク撤去、回り込む計器腕を明示する必要がある。**

## R合わせと戻しの検算

提案は、固定した頭の計器先端が始終点で同じ世界点Cにあるよう、移動するパレットの始終姿勢からR面を決めている。これは単なる `base=Z`、`scan=Y` の名前交換ではなく、実際の移動物に対応する。

独立に各サンプルの測定子上の点を動かし、面までの符号付き距離が0となる伸びを二分法で求めた。提案の解析交点式は期待値に使わなかった。R始終点で世界接触点が同じことも直接比較した。

R完了後は選択Z位置へパレットを戻し、同じマスタ座標と法線をパレットに従って運ぶ。ここでマスタの方向合わせを取り直してはいない。Sは別の頭固定腕を取り付けるので、そのS始点で新たに10 mm伸びを設定しゼロにする。この再取付け／ゼロは提案に明記され、計算もその通り。RのゼロをSへ引き継ぐ処理ではない。

「頭固定」は、R走査の間に頭のYとXを固定する意味。S走査では腕は頭に固定したまま、頭そのものがYへ動く。現在スライダーのYが軸端なら300 mm区間の開始Yへ移動してから取り付けるため、選択YとゼロのYは同じとは限らない。

## 固定期待値と数値範囲

先に [physical.md](physical.md) で導出した実支持の固定期待値と比較した。理想個体、標準寸法2.72×3.68 m、X=Y=0、Z=−100、G/Hだけ同時に操作する。

|---|---:|---:|---:|
|＋0.010 mm|＋2.445652173866|＋2.445652173777|＋2|
|−0.010 mm|−2.445652173866|−2.445652173555|−2|

さらに、寸法2組（2.72×3.68 m、0.50×1.23 m）、支持19組（平坦、G/H±0.010 mm、8支持各±0.500 mm）、理想／used123456、軸位置5組を組み合わせた380状態を確認した。0.50×1.23 mは保存が受け付ける寸法で、Zの総移動が約300.8 mmになる短いケース。

|確認|結果|

## 設置条件として足りない点

### 固定長50 mmの脚4本ではない

Rを合わせるとマスタはパレット上面に対して傾く。検査した状態では、マスタ下面4隅の高さに最大0.118875 mmの差があった。全ての下面頂点はパレットより上にあるので食い込みではないが、50 mm固定脚4本がそのまま4点で接するとはいえない。

「理想時50 mmのすき間」は寸法の説明として成立する。実物の設置説明には、調整脚または角度調整台を使い、R合わせ後に固定して、Z送り／戻しの間に同じ剛体姿勢を保持する仮定が必要。

### 描画中のサンプルワークとの同位置占有

標準・理想時、3Dのサンプルワークはパレット中心に720×720 mm、高さ550 mmで描かれる。提案マスタは中心に幅50×奥行320 mm、高さ50〜370 mmであり、ワークの内部に重なる。

これは接触計算の破綻ではないが、「3Dのワークを置いたまま、同じ場所にマスタも置ける」と説明してはならない。検査時はサンプルワークを外してマスタへ置換する教材仮定が必要。現在の候補は器具を3Dへ描いておらず、画面上の全器具干渉を検査したものではない。

### 一直線の計器腕ではマスタを貫通する場合がある

選択X=0、Y=100、Z=100、平坦支持、理想個体、標準寸法では、S区間開始はY=0 mm、終了はY=300 mm。開始時のパレット座標で鼻端は `(0,1.28,−0.53) m`、S計器本体は `(0,0.06,+0.17) m`。

この2点を一本の直線棒で結ぶと、マスタ上面付近 `(0,0.36988,−0.00780) m` から主軸側面付近 `(0,0.07830,+0.15950) m` までマスタ内部を通る。候補コードはこの直線棒を作っているのではなく、頭から一定位置にある計器本体の材料点を計算している。その剛体点としての輸送は成立している。

実器具としては回り込む腕が必要。検査状態で頭の鼻端から計器本体までの距離はR用最大約1.12 m、S用最大約1.51 mだった。これは小型の直結計器と同じとはいえず、具体的な腕の形状、他部材との干渉、剛性・たわみは未検証。教材の有限接触モデルとして採用する場合にも、その限界を隠さないこと。

## 現配置の小図修正に対する追加確認

別担当による横形小図の変更は、数値計算を変えず、計器の線分長を「始点ゼロからの露出長変化」に対応させるものだった。押込み＋1 µm、0、伸び−1 µmの3状態と、測定子角度−0.1／0／＋0.1 mradの3状態を独立に合成し、線分長をSVG座標から計算した。

9件すべてで、＋1 µmなら基準11単位より1/6単位短く、−1 µmなら1/6単位長くなった。角度の変更でこの長さの正負は逆転しない。最大差は1.27×10⁻¹³図座標単位。[数値記録](physical-diagram-review.json)。

この図は「ゼロからの測定子露出長差を強調した模式図」であり、計器本体の世界変位と同じ縮尺の投影図ではない。修正後の説明はその区別を明記している。これも主軸側縦面／Y送り法への変更を承認するものではなく、現配置における図と押込みの正負を確認したもの。
