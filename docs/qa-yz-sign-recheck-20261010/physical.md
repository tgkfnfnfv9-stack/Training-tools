# 横形YZ：配置を独立に組み立て直した符号監査

2026-10-10。前回の測定式と同じ配置を再計算して一致したことは、ユーザーが意図する測り方の確認になっていなかった。今回の診断はその前提差を調べる。実装担当とは別の担当が、2次元の接近・離脱から期待値を作った。

現コードの「YでRを合わせ、上面Sに上から当て、パレットをZ＋」と、「ZでRを合わせ、主軸側の立ち面Sに当て、頭をY＋」では、同じ非直角に対して符号が逆になる。どちらも物理的に構成できる測定だが、取り替え可能な説明ではない。後者がユーザーの意図なら、前者を再検算して正しいと結論したことが問題であり、数値に−1を掛ける修正では解決しない。

## 物理座標と接触

ここでは模型内部のYは上、Zは主軸側（奥）。NC指令の符号とは区別する。計器は押込みで＋、伸びで−。

```text
                    Y＋ 上
                    ↑
                    │              主軸頭
                    │                 □
              マスタ│                 │
                 ┌──┐                 │
                 │  │                 │
                 └──┘                 │
              パレット                │
       手前  ←────────────────────────→ Z＋ 主軸側
```

|構成|Rの方向合わせ|Sの接触|本測定で動くもの|Yが奥へ倒れる場合|
|---|---|---|---|---|
|監査開始時の実装|頭のY送りに沿う立ち面R|上面Sへ上から下向き|パレットZ＋|斜めの上面が計器へ上がるため＋|
|主軸側立ち面を測る構成|テーブルZ送りに沿うR|主軸側Sへ奥から手前向き|頭Y＋|頭がS面から奥へ離れるため−|
|手前側立ち面を測る別構成|テーブルZ送りに沿うR|手前側Sへ手前から奥向き|頭Y＋|頭がS面へ近づくため＋|

接触側まで指定しなければ「YZだから符号はこれ」とは決められない。主軸側立ち面を採用するなら、S面外向きは＋Z、計器本体はS面から＋Z側、測定子は−Z向きと明示する。

## 単純な接近・離脱

上面をy=0、計器本体をy=10 mm、測定子を下向きとする。上面を1 mm上げれば露出長は10→9 mmで＋1000 µm。上面を1 mm下げれば10→11 mmで−1000 µm。現接触関数はどちらにも一致した。押込み差を返す共通関数の符号反転は、この監査では正当化されない。

YZ断面の座標を(y,z)とし、頭のY方向をu=(cosθ,sinθ)、テーブルZ方向をv=(sinφ,cosφ)とする。θ>0は頭Yが奥へ倒れること、φ>0はテーブルが奥へ進むほど上がること。走査長L=300 mm。

- 監査開始時の上面/Z送り法では、計器に近づく量が `L sin(θ+φ)`。
- 主軸側立ち面/Y送り法では、計器が面から離れる量が同じ `L sin(θ+φ)` なので指示は負。

θ=＋1 mrad、φ=0の明確な反例では、現コードは＋299.999950 µmで前者に一致。後者の独立期待値は−299.999950 µm。同じ測定と説明してはいけない。

## Rを実際に動くパレットで合わせる検算条件

頭固定計器の両端等指示では、測定子先端の世界座標Cが始終点で同じになる。パレットの位置と姿勢を開始(p0,F0)、終端(p1,F1)とし、Cをマスタ座標へ戻す。

`c0 = F0ᵀ(C − p0)`

`c1 = F1ᵀ(C − p1)`

R面が両端でCを通る必要十分条件は `nR · (c1 − c0) = 0`。したがってRの＋Z接線方向を `unit(c0 − c1)` として選び、上向きをこの方向に直交化してR法線を作れば、S法線は＋Z接線になる。パレットが回転する場合も、単なる鼻端接線・代表案内方向へ置換せず、同じ式で実端点の等指示を検算できる。

確認するのは両端の実伸びと世界接触点。途中のR指示0は要求せず、途中の有限面接触と0〜20 mm伸びは別に確認する。R合わせ終了後に開始Z位置へ戻してSを測る設計なら、その戻し操作を説明に含める。
