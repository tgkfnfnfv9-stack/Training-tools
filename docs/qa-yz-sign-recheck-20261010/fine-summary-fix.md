# 横形の微調整欄と上段測定値の改善判定

2026-10-10。修正前は PR #32 の `874d659`。これは YZ の接触面・送り配置の選択とは別に確定した、表示対象の取り違えである。

## 修正前の問題

`finePrecisionSummary` は `diagramComparison` の局所軸角度を比較し、単に「YZ：初期より直角に近づいた／離れた」と表示していた。上段に出ている有限長 300 mm の接触測定とは別の量なので、実際の支持操作で上段の絶対値が悪化しても「近づいた」となる。

標準寸法、中古個体、X=Y=0、Z=75、初期支持から実 UI の「粗調整の手本」（全支持0）を適用する。

|seed|初期 YZ 生値 µm|操作後 YZ 生値 µm|整数表示|旧判定|修正後|
|---|---:|---:|---|---|---|
|2|+24.577125133814|−10.358999998043|+25 → −10|直角から離れた|YZ測定：初期よりゼロに近づいた|
|3|+2.123664650865|+7.426999999616|+2 → +7|直角に近づいた|YZ測定：初期よりゼロから離れた|

旧判定は局所角度の比較としての値をそのまま使っていた。しかし、どの測定を評価したか示さず上段の改善と読める表示にしていた点が矛盾だった。

## 変更

- 横形のこの欄だけ、上段表示を作る際に既に求めた現在・初期の有限走査結果を再利用する。姿勢・接触・測定値を二重に再計算しない。
- 同じ現在軸位置・寸法・個体に対して、現在支持と初期支持それぞれで R を合わせ、接触ゼロを取った 300 mm 走査を比較する。判定は `abs(現在の生値) − abs(初期の生値)`。±0.005 µm の範囲を「ほぼ同じ」とする。
- 「XY測定」「XZ測定」「YZ測定」と対象を明示する。整数表示が同じでも、生値の差がしきい値を超えれば変化とする。
- 片方が無効接触または非有限値なら「測定が成立しないため比較できない」。ゼロとして比較しない。
- 理想個体は `machineProfile` と初期支持の記録を持たない既存仕様なので、「初期との比較基準なし」とする。現在値で初期値を代用しない。

上段の数値、局所角度図、総合評価、参考探索、3D模型、支持・姿勢・測定式、整数丸め、保存形式を変更していない。縦面 S・頭 Y 送りへの配置案も採用していない。保存の数値移行や新しい再ゼロ操作は不要で、既存の自動 R 合わせ・ゼロ結果の表示上の再利用だけである。他5機種と旋盤は従来の処理を通る。
