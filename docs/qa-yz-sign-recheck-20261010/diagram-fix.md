# 横形の測定子描画：生値と伸縮の逆転を修正

この修正は、現在の XY/XZ/YZ の配置と接触計算を維持し、小図の測定子と計器本体の描画を修正したもの。YZ の接触面・送りを変更する [未実装の別案](proposal.md) は含めていない。

## 確認した問題

修正前の `referenceDiagram` は、本体の法線方向変位を 1 µm 当たり 1/6 図単位、測定子の傾きを約 1000 倍にして別々に描いていた。測定子の終点をこの独立した 2 成分から作るため、実際は縮んでも、傾きによる線の伸びが勝って長く見えることがあった。

`af8d079` と `874d659` はこの描画が同一で、「前回に伸びと連動する描画へ直した」という前提は誤りだった。修正前の説明「法線変位と傾きを別々に誇張」は当時の実装とは一致していたが、その描画方法自体に符号矛盾が残っていた。

理想個体、X=Y=Z=0、指定支持以外 0 mm：

|支持高さ|YZ 生値 µm|整数|実測定子の伸び mm|修正前の図の長さ|修正後の図の長さ|
|---|---:|---:|---|---|---|
|A +0.050、E +0.091|+0.033566085703|0|10 → 9.999966433914|11 → 11.012564337023|11 → 10.994405652383|
|B +0.200、G/H −0.129|+0.029355550201|0|10 → 9.999970644450|11 → 11.031609244215|11 → 10.995107408300|

いずれも操作刻み内で到達できる状態。上段は独立ブラウザー担当が支持ボタン 15 回の実操作でも再現した。整数が + と表示される例ではなく、丸め前の正の指示に対して図が逆に伸びて見える例である。生値を変えたり整数変化を作ったりする処理は入れていない。

## 変更

横形だけ、接触計算から得た始終点の伸び差を使って描画長を決める。

```text
図の測定子長 = 11 + clamp((終点伸び − 始点伸び) × 10⁶ / 6, −4, +4)
図の本体位置 = 図の接触点 + 図の測定子長 × 強調した傾きの単位方向
```

測定子の線、本体位置、本体の回転は同じ端点を使う。正の指示なら線が短く、負なら長くなり、伸びが同じなら角度が変わっても長さは 11 のまま。計器角度の強調は維持した。これは指示差と角度を見やすくした模式図であり、器具全体が同じ実寸縮尺という意味ではない。横形の説明もこの内容へ変更した。

対象ファイルは `src/reference-measurement-ui.js` と生成 `index.html`。測定配置、姿勢関数、contact/compare、生値、丸め、保存形式はこの修正では変更していない。他 5 機種と旋盤は従来の描画を維持する。

## 検証

[回帰テスト](../../tests/check-horizontal-probe-diagram-20261010.cjs) は、実支持反例とその正負、平坦、微小な伸び差、角度だけ変わる配置、伸び 0/20 mm の限界、表示の上下限、無効接触を調べる。期待する伸縮の正負は、捕捉した実体の姿勢から別の平面・直線交点式で求める。

- [修正前](diagram-regression-before.json)：34 条件のうち 8 件が失敗。実支持反例の逆転と、角度だけで長さが変わる問題を検出。
- [修正後](diagram-regression-after.json)：34 条件すべて通過。他の実在 6 機種 × 3 指示条件の 18 SVG は、固定した `874d659` の HTML に含まれる旧描画と文字列が完全一致。
- [既存の器具回帰](diagram-fixture-regression.json)：96 状態、288 器具、10,224 接触の数値・有限面・世界座標変換・小図条件はすべて通過。ただし実行中に別担当の `src/accuracy-ui.js` が更新されたため、ソース固定検査だけが失敗した。最終統合ビルドの合格記録とは扱わず、この経緯を残す。
- [統合ソース凍結後の器具回帰](diagram-fixture-regression-final.json)：同じ 96 状態・288 器具・10,224 接触とソース固定検査がすべて通過。実行中のソース SHA256 は始終とも `7200d78e53bd640013640e61641500f9d4378d5fb2d3b34af42de0bcdc58f953`。
- 実ブラウザーの修正前後画像と独立確認は [browser/README.md](browser/README.md) に記録する。
