## 測り方による逆符号

現行は、パレット上のマスタの立ち面 R を頭の Y 送りで合わせ、上面 S に上から当て、パレットを Z＋へ送る。主軸側の縦面 S に奥から計器を当てて頭を Y＋へ送る方法とは逆の指示になる。

理想個体、標準寸法、X=Y=0、Z=−100、G/H だけ＋0.010 mmの場合：

|方法|生値 µm|整数 µm|
|---|---:|---:|
|現在の上面 S・パレット Z＋|−2.445652173675|−2|
|主軸側縦面 S・頭 Y＋の独立期待|＋2.445652173866|＋2|

この違いは、押込みを＋とする共通計算の誤りではない。面・測定子方向・動かす部材を変えずに最後の値を反転してはならない。

**縦面 S・頭 Y＋への配置変更は未採用。** ユーザーへ接触面と送りを確認しており、返答前に製品の測定法を変更していない。[未実装提案](proposal.md)には R の移動マスタ校正、S の再取付けとゼロ、保存への影響を記録した。

## 配置の選択と独立に見つかった描画矛盾

理想個体、XYZ中央、A＋0.050 mm・E＋0.091 mm・他支持0の PR 版で、YZ 生値は＋0.0335660857 µm（整数0）。実際の伸びは10→9.9999664339 mmと減るが、SVG測定子の長さは11→11.012564337と増えた。独立した平面交点計算も押込み増加と一致した。

原因は、法線方向の本体変位と測定子の傾きを別倍率で強調していたため、描かれた測定子の全長の増減が実伸びと逆になること。これは整数丸めの問題ではない。修正担当へ、接触計算の伸縮差から模式図の長さを決め、本体・測定子・接触点を同じ端点で結ぶ修正を指示した。数値の計算や現配置は変えない。

修正後の図の長さは10.994405652となり、実伸びと同じ短縮になった。Eを微調整で1回下げると生値−0.0533931421 µm、図の長さ11.008898857となり、両方とも伸長する。[修正担当記録](diagram-fix.md)と[別担当の前後画像・再確認](browser/after-independent-review.md)を保存した。899姿勢の2,697測定を同じ入力で比較し、図の方向不一致は18→0件。測定値は変えていない。

## 上段と逆になる改善表示の修正

横形の調整欄は局所軸角度で「YZ：直角に近づいた／離れた」を判定していたが、上段は300 mm有限測定なので、同じ状態で反対の判定が出た。中古個体、X=Y=0、Z=75で初期支持から実UIの「粗調整の手本」を適用する反例：

|個体seed|上段YZ 生値 µm|整数|旧調整欄|修正後|
|---|---|---|---|---|
|3|＋2.123665→＋7.427|＋2→＋7|直角に近づいた|YZ測定：ゼロから離れた|
|2|＋24.577125→−10.359|＋25→−10|直角から離れた|YZ測定：ゼロに近づいた|

上段と同じ現在／初期の有限測定を再利用して、絶対生値を比較するよう変更した。0.005 µm以内の差は「ほぼ同じ」。初期記録がなければ「比較基準なし」、接触不成立なら「比較できない」とし、0と扱わない。局所角度図、総合評価・参考探索は変更していない。初期と現在のどちらも現在の軸位置に対応する同じ区間でR合わせ・始点ゼロを取り直して比較する。
