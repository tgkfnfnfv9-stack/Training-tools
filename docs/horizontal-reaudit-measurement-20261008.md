# 横形測定の再監査：R方向合わせと実器具の未定義箇所

調査基準は開始時の最新main `edda2f88e05ffdca556af269838393607157cd28`。前回の5記録を読み、接触式・支持材料点・頭の剛体取付点を読み直した。**この担当は本番の測定計算・保存形式を変更していない**。横形の既存詳細文だけに未定義器具とYZの仮想面高さを明記した。本記録の「有限弦」は診断候補であり、承認・実装済みの測定仕様ではない。他担当による模型修正、実ブラウザー、独立確認は総合再監査記録を参照。

## 座標と搭載の区別

内部 `(x,y,z)` は模型の右・上・奥。Xはコラムと頭、Yは頭、Zはパレットを動かす部材スライダー名。NCの指令正方向は本診断では未検証。Z部材が奥へ動くと、ワークから見た工具は手前へ動く。カメラ投影、工具/ワークの相対変位、計器の接触方向、指示の符号は別々に扱う。

|面/項目|基準軸・走査軸|基準器搭載/計器固定|現行方向合わせ|ゼロ接触位置|動く部材・実方向|基準器から見た計器|接触側・本体への引込み|＋の読み|小図|未確認事項|
|---|---|---|---|---|---|---|---|---|---|---|
|XY|X・Y|マスタ:パレット/計器:頭|Rを開始時の代表X方向へ|下・右。絶対取付位置未定義|頭が上へ300 mm|上|右から左に接触・引込み右|本体が固定Sへ左に寄る|右=模型右、上=模型上|実R送り、R/Sの取付腕・寸法|
|XZ|X・Z|マスタ:パレット/計器:頭|Rを開始時の代表X方向へ|奥・右。上面中心を仮想原点|パレットが奥へ300 mm|手前|右から左・引込み右|Sが右へ寄る|右=模型右、上=模型奥|実R送り、有限厚マスタ、腕|

|Z平行a|主軸中心線・Z|バー:主軸/計器:パレット|バーは主軸姿勢に固定|先端から10 mm内側・左9時|パレットが奥へ300 mm|主軸側|左から右・引込み左|本体がバーへ右に寄る|円=先端から主軸を見る、長手の右=主軸|腕・バーたわみ、実装着・干渉|

「＋の読み」欄は接触面/バーが固定している場合か表記した側だけが動く場合。実装は双方の姿勢と位置から伸びを解く。反対側から測れば一次の符号が逆になるが、円筒の曲率による二次項まで一律反転とは限らない。

## 現行の式と原因コード

`src/reference-measurement-ui.js:referenceScan` は

```
n0 = first.directions[基準軸]     // 代表案内
u0 = -n0
p0 = (0,0,0)                    // 相対座標
b0 = 0.010 n0
e = n·(p-b) / (n·u)
指示 = (e0-e1) × 10^6 µm
```

XZ/YZでは `horizontalPalletPoint([0,1.27,-.85], ...)` の材料点移動を `p` に加える。支持基準は0.66 mなのでこの点は0.61 m高い。マスタ法線はパレットの始終姿勢で輸送する。XYでは頭Yの代表送りを `b` に加え、絶対原点・X方向合わせを実行しない。

原因は `normal=first.directions.find(a=>a.key===setup.base).direction` と、方向合わせ用の固定ブラケット・有限送りが存在しないこと。`ReferenceMeasurement.contact/compare` の押込み符号を反転して解決する問題ではない。

`horizontalParallelism` は別配置。主軸鼻から手前310 mmを始点とし、直径50 mm・全長320 mmの仮想バーを用いる。パレット上面からa/b本体へ届く腕全体をパレット姿勢で輸送し、円筒への最初の交点を解く。上面中心をバーの接触点と取り違えてはいない。

## 具体的反例と診断式

診断用 [スクリプト](../tests/diagnose-horizontal-alignment-20261008.cjs) と [全入力/数値](horizontal-alignment-diagnostic-20261008.json)。実行:

```
node tests/diagnose-horizontal-alignment-20261008.cjs docs/horizontal-alignment-diagnostic-20261008.json
```

既存の仮想原点を絶対的なパレット材料点Pへ埋め込み、主軸鼻Nに固定した腕の接触材料点とみなす診断を作った。鼻は回転中心線上の基準位置であり、鼻の接線を測定方向として直接採用しない。頭の剛体姿勢をT、S測定開始状態をsとする。

```
腕の固定座標 r = T(s)^−1 [P(s)-N(s)]
R方向合わせで送られる接触材料点 Q(t) = N(t)+T(t) r
有限弦 v = Q(基準軸終点)-Q(基準軸始点)
候補S法線 nS = v/|v|
候補R法線 nR = normalize(走査軸方向 - nS·走査軸方向 nS)
```

基準軸の区間は300 mmを確保するため現在部材位置から始め、上端に近ければ始点を戻す。S走査と同様の端処理である。区間と腕はJSONに記録した。これは微分接線でなく有限弦である。

R用計器を同じ材料点に到達させ、伸び10 mmでゼロしたとき、終点でも同じ伸びになる必要条件は `nR·v=0`。終点で計器本体・測定子も頭姿勢により回転するため、それらを別々に輸送して接触式で確認した。この候補ではR用とS用の向き変更を暗黙に必要とする。実物の形状・別のR/S接触位置を定義した最終仕様ではない。

固有誤差なし、中央、支持面 `h=0.01xz mm`:

|比較|XY µm|XZ µm|YZ µm|
|---|---:|---:|---:|
|現行のS測定|+0.138000|−1.830000|+0.000043|
|現行代表方向にRを置き、上記の実体腕を基準軸300 mm送ったR指示差|+6.414003|+1.829990|0|
|同じ仮想点を有限弦で方向合わせした候補のS測定|+6.552003|−3.659990|+0.000043|
|接触点を50 mm上げるだけ、現行代表方向合わせを維持|+0.138000|−1.980000|+0.000046|
|50 mm上げた点を有限弦で方向合わせする候補|+6.552003|−3.959990|+0.000046|

このR指示差は丸め前で数µmあり、「物理的なR面方向合わせを省略しても同じ」とは扱えない。`h=±0.05xz` では現行XY=±0.69に対し有限弦候補は約±32.76 µm。XZは現行∓9.15に対し候補は約∓18.30 µm。**これらを修正後の正解値とはしない**。

50 mm上げた比較は厚みへの感度だけを切り分ける。XZの一次差は `−0.05 × k × 0.3 ×1000 µm`、k=.01で−.15 µm。XY/XZ/YZ全てを「厚み50 mmの実体L形マスタ」の結果として宣言してはいけない。

模式比較:

```
現行:   代表X案内 ──────→    Rをこの方向へ数学的に合わせる
        頭N ─ 固定腕 r ─ P  X送り時のPは別の経路を通る
        Rを実計器で送る工程はない

診断:   頭N0 ─ 腕r ─ Q0  → 頭N1 ─ 同じ腕r ─ Q1
        弦 Q1−Q0 とR面を平行にして始終の等指示を解く
        SはRに直角、S側へ計器を付け替えてゼロ
        ただし実体R/Sの寸法・位置を確定する必要が残る
```

## 数値が変わる理由/変わらない理由

- used/seed123456、平坦: XY/XZ/YZ=16.959/8.129/14.120、a/b=8.125811/14.118678 µm。50 mm高点・有限弦候補とも平坦では現行と同値。姿勢が一定なら腕を設置し直しただけで誤差を作らない。
- Bだけ+0.010 mm: 現行は16.959/8.561676/11.932497、a/b=9.467583/11.563849 µm。表示は17/9/12/9/12。XZの50 mm高点だけの差は約+0.035466 µmで、整数丸めでは同じになりうる。
- `h=.05xz`、X−100→+100: YZは22.370697→5.870697、bは14.111148→14.111150。バーの傾き変化とパレット側の横持出し腕の上下移動が一次で相殺する配置。一般の支持分布でbが一定になる保証ではない。
- 同じ捻れのY−100→+100: aは−15.722647→−24.722647。腕がバー高さに合わせて長くなり、パレットの姿勢変化に対する横変位も変わる。bも14.114349→14.107138と丸め前では変化する。
- 理想・共通剛体平面 `.03x+.04z mm` は本診断の全候補で数値ゼロ（残差1e−8 µm未満）。これは支持補間を含む全実機の剛体不変性を独立証明したという意味ではない。

独立検証と区別する。本診断は製品の支持/主軸姿勢APIを利用して候補を比較する。独立担当のスカラー支持からの接触計算は別記録にある。

## 再方向合わせ、再ゼロ、保存への影響

現行は支持・軸位置・寸法・個体の変更ごとに全配置と接触ゼロを再計算する。実計器を固定して全操作を続けた履歴ではない。カメラ、ズーム、図の誇張は配置を変えない。

実有限器具方式を採用するなら、支持・X/Y/Z・取付位置・腕・基準軸区間が変わるとR方向合わせを取り直し、S側へ付け替えた後にSゼロも取り直す。同じ固定器具のまま始終点を交換し、指示だけ新始点でゼロする場合は `(e1-e0)=−(e0-e1)`。Rからやり直す逆走は別配置となり、この符号反転を要求できない。

現保存は `calculationModel: horizontal-guide-v2`、支持・個体・位置等を記録し、有限測定値や腕は保存していない。今回本番計算を変更していないため旧JSONの意味・再計算値は不変。将来方向合わせ方式を変更すると同じ旧JSONでも値が変わる。読み込み構造を維持する案でも、旧測定値を保持できたとは言えない。新しい測定モデル識別子を記録し、旧状態を新方式で再測定したと明示する移行が必要。単に `calculationModel` を変えると現 `validLevelRecord` が旧JSONを拒否するため、移行方針も同時に定める。

## 本番変更を見送った範囲と次の具体的設計

ユーザーは「今回の依頼を包括的な新仕様承認として扱わない」「別の測定方式へ黙って置き換えない」と指定している。この制約に従い、未定義の器具を正解として追加しない。現行の代表案内方式は実送りR合わせ未再現のまま残り、測定全体の監査完了とはしない。

50 mmの足を持つL形マスタは検討可能だが、各面について①パレット上でのR/S実表面座標、②R用/S用の計器固定点と腕、③R有限送り区間と内点接触、④直角保証面の外形と到達・干渉、を揃える前に採用できない。特にXYのR底側、YZのS上側、XZのR前側は同じ原点/同じ腕にできると仮定しない。既存面名と基準軸/走査軸は維持し、弾性モデルや未実装B軸は加えない。

この担当で完了したのは、現式の原因特定、実送りに相当する反例、有限取付点候補と高さ感度の具体的診断、互換性方針の提示まで。本番の方向合わせ式を新方式へ変更する作業は未実施である。

`src/reference-measurement-ui.js` の横形限定の既存詳細文に、R/S器具の厚み・R接触点・腕が未定義であることと、YZのS面がパレット上面と同高の仮想面であることを追記。新しい枠・見出し・操作は追加しない。この説明追記をR方向合わせの実装解決とは扱わない。
