# 横形・旋盤の支持姿勢と3D部材の修正

開始点は最新 `origin/main` として統括担当が確認した `cbdcf81`。構造修正担当と独立幾何確認担当は別である。これは構造担当の実装・自検証記録であり、測定の独立再確認は別記録を参照する。

## 再現した不整合と修正

|原因|旧状態|修正|
|---|---|---|
|D1: ベッドと剛体の座標写像が別|旋盤の主軸台・往復台・模型だけの心押は共通平面を外側の剛体回転とするが、ベッドだけは世界yへ支持高さを足す。理想、標準寸法、`h=.08x+.06z mm`、誇張倍率257.2768345693で、心押の座面材料点`[1.8,.66,0] m`と同じベッド点が0.3812219194 mm離れる|ベッドの高さ写像と厚み方向も同じ共通・残差変換に揃えた。この点の差は0|
|D2: 横形の共通傾斜と局所姿勢が別の扱い|座面の原点は世界yへの高さ、剛体は絶対勾配で回転。平面を足す操作が全体の共通剛体変換にならない|物理側は測定担当が共通・残差変換に統一。構造側は同じ`horizontalToolPoint` / `horizontalPalletPoint`を直接使う。主軸鼻の材料点は測定と完全共有|
|D3: 支持寸法で回転断面を伸縮|横形の支持幅を2倍にすると鼻円筒半径はx=400/y=200 mm。旋盤奥行2倍ではチャック半径y=400/z=800 mm|円筒の中心・軸長は支持寸法に従わせ、半径の非等方伸縮のみ除く。横形主軸/鼻、旋盤チャック、クイル/センタ。既存のφ50テストバーも維持。通常表示と理想輪郭に同じ補正を適用|
|D4: 旋盤チャックの後端が浮く|主軸台右端x=−1.350 m、チャック後端−1.325 mで25 mmの空間。両方が同じ剛体なので支持調整では消えない|測定鼻端/バー始端−1.075 mを保持し、チャック長.25→.28 m、中心を−.015 m移す。後端−1.355 mで主軸台へ5 mm重なる|
|D5: 支持補間境界の最終bit|同じ境界点へ異なる加算経路で到達すると最後の浮動小数bitだけで左/右セルが変わり、局所姿勢が変わる。測定独立担当が途中接触点の約3.7 µm差を検出|横形・旋盤の`machineSolution().slopeAt`だけ、支持格子から1e−12 m以内の引数を実格子座標へ正規化。既存の右/奥セル規則を安定させる。±1e−8 mの別側の試料は維持|

D1の修正前座標（クリアランスを含む描画m）は心押座`[1.7996188588024329, .8582370518826414, 0]`、ベッド同点`[1.8, .8582448965867082, 0]`。表示誇張を弱めて隠した修正ではない。D1は描画を既存の旋盤物理姿勢へ揃える修正、D2は物理姿勢も変更する修正である。統括担当が変更前に説明し、測定担当と同じ座標定義を使用した。

## 支持から剛体への写像

支持入力の単位はmm、x/zと部材寸法はm。最小二乗平面を`P=a x+b z+c`、残差を`r=h−P`、共通回転を`C=R(a,b)`、取付点`q`での残差回転を`L=R(hx−a,hz−b)`とする。勾配は回転前にmm/mからm/mへ変換する。

座面原点は `O=C[qx,r(q)/1000,qz]+[0,.66+c/1000,0]`。剛体の材料点は `O+C L B (p−q)`。`B`は既存個体の固有姿勢であり再抽選しない。表示誇張は共通勾配・残差勾配・残差高さに同じ倍率を与える別表示で、物理測定は倍率1。ベッドの厚みは局所法線に沿って移す。カメラと床とのクリアランスは測定に入れない。

横形Xのコラム座面は内部xへ、Yの頭はコラムに沿って上下へ、Zパレットは内部zへ動く。旋盤Xは往復台に対して内部z（奥側）へ、Zは内部xへ動く。Xスライドによって往復台のベッド参照点は移さない。主軸台・主軸固定バー・心押模型は軸操作で移動させない。共通の支持変化には各自の取付座で追従する。

心押し台は3Dのみに存在し、検査項目や測定式へ追加していない。センタとバー先端の公称空間は115 mmで、バーを支持しない。タレットは奥側。タレット・ホルダ・工具・ボルトは従来の同じ寸法写像を維持し、支持/軸操作時は剛体として移動する。寸法設定に対してすべての部材の寸法を固定したわけではない。円断面の保持対象を「全円筒」とは扱わない。

## 証拠

- [実Chromiumの前画像](qa-posture-20261009/structure/before/) / [後画像](qa-posture-20261009/structure/after/): 横形・旋盤それぞれ平坦、正負ねじれ、平面傾斜、寸法変更。`observations.json`に支持入力・寸法・軸位置・表示倍率・部品名の材料点・測定幾何を保存。画像は実キャンバスであり合成図ではない。
- [構造検査結果](qa-posture-20261009/structure/checks.json): 1008状態。入力支持格子から独立双一次補間と平面/残差/正規直交基底を作り、2520座面/法線、100800円断面頂点、475776剛体長を比較。最大座面差2.23e−16 m、最大半径差1.89e−15 m。パレット/心押の案内との最小重なり8.45 mm。他5機種の生メッシュは開始版と完全一致。[検証対象の全ソースハッシュ](qa-posture-20261009/structure/source-manifest.json)も記録。
- [理想輪郭検査](qa-posture-20261009/structure/ideal-circles.json): 2機種×3寸法×2軸位置、3888頂点。通常模型と理想輪郭の差は最大4.48e−16 m。
- [境界検査](qa-posture-20261009/structure/boundaries.json): 実格子±machine epsilonは同じ局所姿勢、−1e−8 mの手前/左セルは異なる勾配を保持。
- [寸法変更時の間隔](qa-posture-20261009/structure/clearances.json): 支持寸法0.5〜2倍、used/123456、正負`h=.05xz`、軸両端の32状態で、低Yの頭/主軸とワーク、バーと心押模型が分離する投影区間を確認。最小の分離は57.31 mm。これは指定した部材対の検査で、全機構・全設定値の連続干渉検査ではない。

既存`check-model-posture.cjs`のハーネスも修正した。従来は実描画APIを通らず、旧式の`levelMappedBodyVisualPoint(displayTransformedPoint(...))`を期待頂点としていた。また汎用DOM環境は旋盤の現行Assemblyをロードせず、フォールバック描画を検査していた。実ページと同じAssemblyをロードし、`displayedModelPoint(..., face.circular)`の頂点を独立した画面投影へ渡すように変更した。支持法線の期待は、支持入力から独立に平面を求め、数値微分した全勾配から平面を引き、残差回転と共通回転を組み合わせる。期待定数の書換えではなく、検査対象の呼出経路と教材幾何の定義を一致させた変更である。旧ハーネス実行は統括担当が停止して記録を保持し、更新後の[全7機種Canvas検査](qa-posture-20261009/structure/legacy-canvas-check.json)へ置換した。更新後は全件成功、失敗0。

実ブラウザーの支持上下、各軸スライダー/デモ、整数表示、保存読込、他5機種の画面比較は統括担当側の記録と区別する。ここでは支持高さを既知の解析式で設定する幾何実験も含む。実機の弾性、荷重、全連続行程の治具干渉、実iPhone Safariを認証する試験ではない。
