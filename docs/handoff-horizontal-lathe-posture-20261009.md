# 指示・統括役への引き継ぎ：横形・旋盤の座標系、精度値、レベル調整、3D模型の矛盾を修正する

## 依頼の目的と今回の作業範囲

ユーザーの最新指摘：

> 次のセッションは指示役で
> 3dの絵だけではなく、座標系の精度数字、レベルいじると変わらない！矛盾の部分がある！これを直したい！もう一回引き続き文章作成

この文書を作る回では、プログラムの修正・計算変更・新しい模型検証を行わない。**次セッションの主担当は指示・統括役**とする。修正担当と独立確認担当に具体的な調査・修正を指示し、提出された根拠を確認して、必要なら再修正を指示する。

目的は、**横形と旋盤の座標系、精度の数値、レベル調整への反応、3D模型の姿勢の矛盾を解消すること**。ユーザーは、ねじれ・コラムなどの倒れの違和感に加え、「レベルをいじっても精度の数字が変わらない」問題を報告している。見た目の手直しだけで完了にしない。支持操作から測定値の計算・画面更新までを調査対象とする。

ただし、すべての値をレベル操作のたびに変える依頼ではない。本来変わる値が変わっていないのか、幾何上不変なのか、丸めで見えないのかを実操作と独立計算で判定する。「丸め」「相殺」「固有値だから」で未調査の挙動を説明済みにしない。

前回までの説明、対応表、テストの期待値を正解と決めつけない。過去の検証は、そのとき定義した教材内の配置と検査範囲での確認であり、模型全体、測定モデルそのもの、実機の再現が正しいという認定ではない。今回の違和感・数値不変の具体的な再現条件と原因は未特定。後述のR方向合わせの既知問題とは分けて調査する。

変更対象は **横形と旋盤**。それ以外の5機種、関係のないUIは変更しない。最初の依頼の「横形のみ／他6機種不変」は、その後の旋盤変更依頼を含めてこの範囲に更新されている。

## 指示役としての進め方

- 構造・座標・描画の担当と、測定計算・画面更新の担当に調査を割り振り、両者の取付点・姿勢・符号の定義を揃える。最低限、修正担当と独立確認担当は別にする。
- 指示には対象機種・測定項目、入力状態、実操作、取得する生値と座標、期待値の求め方、変更可能なファイル、完了条件を含める。「全体を直して」だけで任せない。
- 独立確認担当には、実装の符号表や計算関数を期待値として渡さず、入力支持高さ・機械構造・測定配置から判定させる。
- 報告を受け取ったら、3Dと測定で同じ物理状態を参照しているか、数値不変の理由を実証したかを確認する。矛盾が残れば再現条件を添えて再修正を指示する。
- 次セッションは計画作成や担当への指示だけで終わらず、調査→修正→独立再確認→再修正→再確認を統括する。未解決項目は理由・不足する仕様・次に必要な判断を具体的に残す。

### 横形

- 支持A〜Hの位置と左右前後、実際の上下が一致するか。現資料ではA/Bが左右手前、G/Hが左右奥。ラベルの並びを答えにせず、座標から再確認する。
- コラムの左右倒れ・前後倒れ、パレット姿勢が、それぞれの取付座での支持面勾配と整合するか。
- ベッドの変形表示と、剛体として動くコラム・案内・主軸頭・パレットの取付部が接続しているか。模型の部材が不自然に曲がる、離れる、食い込む状態を調べる。
- X移動で座面姿勢が変わるとき、鼻端・工具・計器取付点も同じ回転中心と剛体変換で動くか。
- Y移動の取付高さ、Z移動の支持補間境界が、描画と測定で一致するか。
- 主軸回転中心線、Z送り、代表案内方向、材料点の移動接線を混同していないか。

### 旋盤

- 横形の「コラムの倒れ」をそのまま旋盤へ当てはめない。旋盤では主軸台・主軸中心線、往復台、Xスライド、タレットの各姿勢を個別に確認する。
- 奥側のタレット、ホルダ、工具、往復台の位置と姿勢が一貫するか。図だけ鏡映して計算側や部品名が旧位置に残っていないか。
- ベッドがねじれたとき、固定主軸台と移動する往復台が、それぞれ正しい取付座の姿勢を参照するか。Z送りとX送りで取付座の位置がどう変わるかを分ける。
- テストバーが主軸台と同じ姿勢で動き、円断面を保つか。タレット本体やホルダが剛体として保たれるか。
- 心押し台・クイル・センタの模型がベッド上に据わり、軸操作では移動しないか。測定用バーとの接触・支持を勝手に追加しない。
- 穴芯図、タレット面X／Z、バー側面／上面の小図と3Dの方向関係が一致するか。

### 原因候補として調べる実装。現時点では未確定

- ベッドは頂点ごとに支持面へ写し、剛体部材は取付座の姿勢で回している。その違いが取付部の離脱や不自然な傾きになっていないか。
- 共通の剛体傾斜と局所傾斜を二重に掛ける／片方を落とす／順序を誤る問題がないか。
- 回転中心、単位、法線の向き、左右前後、表示倍率の適用回数が正しいか。垂直部材の傾斜と水平主軸の傾斜を同じ変換にしていないか。
- 表示誇張を掛ける前の物理方向は正しいか。誇張を弱めるだけで原因を隠さない。
- 支持寸法による非等方拡大で、円筒・案内・取付寸法を不自然に変えていないか。
- 矢印、部品名、理想輪郭が本体と別の姿勢や原点を参照していないか。

全体の共通剛体移動・剛体傾斜で、相対精度やねじれ不良を作らない。同じ支持入力から独立に高さ・勾配・剛体変換を求め、模型の頂点座標と比較する。「見た目が変」だけでも「計算が通る」だけでも結論を出さない。

### 横形のR方向合わせは未解決

現行は代表案内方向でR面を合わせ、実際の頭固定ブラケットを基準軸に有限送りして合わせる工程を再現していない。代表案内方向、鼻端の局所接線、計器取付点の有限300 mm走査は同じではない。

前回の独立診断：`h=0.01xz mm`、固有誤差なし、軸中央。現行XYは約+0.138 µm。そのR面に対して、仮想の頭固定腕をXへ300 mm送ると約+6.414 µmの指示差が残る。有限走査の弦へ合わせた候補はXY約+6.552 µm、XZは現行約−1.830から候補約−3.660 µm。取付高さを50 mm変えれば候補XZも約−3.960 µmへ変わる。

これは前回の仮想配置で実証した問題で、最終的な実器具配置の採用結果ではない。鼻端接線への単純置換で解決したことにしない。実際のR/S面、有限厚マスタ、取付点と腕、方向合わせ区間、固定する配置を具体化する必要がある。

XZ/YZの現原点は支持基準から0.61 mのパレット上面中心。有限厚マスタの接触面と同じ高さとは限らない。横形バー中心は理想・中央Yで約1.89 mであり、パレット上面の材料点をそのままバー接触点にしない。

### 旋盤の現測定設定

バーはφ50 mmの理想円筒、主軸固定。計器は別々の側面・上面取付けで、本体と測定子方向を同じ往復台の剛体姿勢で輸送する。始点でゼロ、走査途中は再ゼロしない。支持・軸位置を変えた状態同士の比較では、現仕様は取付けと始点ゼロを取り直す。

指示は `(始点の測定子の伸び−終点の伸び)×10^6 µm`。加工径差の2倍処理ではない。支持基準から主軸中心までは標準で0.84 m、接触点は中心から半径25 mm、本体はさらに外側。これらを同じ座標にしない。心押し台はこの計算に含めない。

## 変わる値・変わらない値の調査用記録

### 最優先：「レベルをいじっても数字が変わらない」の再現と原因切り分け

まず画面にある精度項目を全件列挙する。横形のXY/XZ/YZ・Z平行a/b、旋盤のタレット面X／Z・穴芯・バー側面／上面を含め、支持に依存する相対精度と、個体固有で保持する振れなどを区別する。項目名だけから依存・不変を決めず、定義と計算経路を確認する。

各支持を実際の上下ボタンで操作し、次の経路を追う。

`選択支持と粗微操作 → 保存される支持高さ → 支持補間と共通・局所姿勢 → 基準器と計器の位置・方向 → 接触・始終点・ゼロ → 丸め前の測定値 → 整数表示`

|確認箇所|取得する証拠・原因候補|
|---|---|
|入力|選んだ支持と更新された支持が一致するか。0.001／0.010 mm、符号、単位が正しいか|
|支持・座面|水準器、3D、測定計算が同じ支持状態を読むか。理想状態・初期比較・読込前の状態を誤参照していないか|
|座標と取付け|基準器と計器が別の座面に属するとき、その局所姿勢差と腕の変位を落としていないか。軸・成分・符号・高さを混同していないか|
|測定計算|固有誤差だけを表示して支持による相対変位を足し忘れていないか。共通傾斜を除く処理が必要な局所差まで消していないか|
|方向合わせ・ゼロ|毎回の再方向合わせ・再取付け・再ゼロが何を消すか。誤って終点でもゼロを取る、同じ点を始終点に使うなどがないか|
|画面更新|生値は変わるのに再計算・再描画・キャッシュ更新が止まる、別項目を表示する、以前の値が残る問題がないか|
|整数表示|生値の変化が整数µmに現れる大きさか。単位変換・丸めが正しいか。表示は整数を維持する|
|固定個体|支持操作で個体乱数や固有誤差が再生成されないか。固定されるべき値と相対測定値を一括して固定していないか|

理想個体と `used / seed 123456` を分け、軸中央だけでなく端・非対称位置でも調べる。支持の正負、対角ねじれ、単純平面傾斜、支持を元へ戻す操作を比較する。一度の微調整だけで結論を出さず、現行の操作範囲で粗調整も行い、変化量を確認する。

各項目について次の比較表を作る。

|機種・測定項目|支持と軸の条件|操作前後の生値|操作前後の整数表示|独立幾何による期待変化|判定と原因コード|
|---|---|---|---|---|---|
|調査時に記入|支持番号、増減量、座標、個体|µm、小数を保持|利用者が見る値|変わる／不変とその根拠|未更新、計算不整合、丸め、幾何上不変など|

不変が妥当なら、その配置の相対運動・相殺または固定固有値の定義から説明する。変わるべき生値が変わらない、変化の軸や符号が違う、生値と画面が違う場合は修正する。変化を見せるための係数追加や、固有値を支持操作に連動させる処理は入れない。

## 修正・独立再確認の進め方

サブエージェントを使い、最低限、修正担当と独立確認担当を分ける。調査→修正→独立再確認→問題があれば再修正→再確認を行う。説明追記だけで終えない。

1. 最新状態と引き継いだ差分を報告し、現状の実ブラウザー画像を残す。可動部材・ねじれ・倒れと、支持操作による精度値の変化を同じ状態で記録する。
2. 問題ごとに入力支持高さ、軸位置、個体、表示倍率、カメラを記録する。主要取付点・鼻端・バー端・タレットの座標、上向き／主軸／案内ベクトル、測定生値を対応させる。
3. 期待値は描画関数や実装の符号表から作らず、支持入力と独立した剛体・接触幾何から求める。
4. 理想0、既知の正負角度差・ねじれ、接近／離脱、反対側接触、固定配置の始終点交換と再ゼロ、方向合わせからのやり直し、取付高さ、共通剛体変換を確認する。
5. 軸端、支持境界、支持上下往復、保存・読込、カメラ・ズーム・表示誇張の数値不変、実スライダーとデモの一致を確認する。
6. 横形と旋盤以外の5機種の表示・数値を比較する。共通関数の変更で巻き込まない。
7. 原因コードと修正前後の実ブラウザー画像を残す。精度値が変わらないという指摘に対し、項目ごとの再現結果・生値・独立期待値・画面の結果を示す。既存テストは補助にし、誤った前提に合わせて期待値だけを書き換えない。

**計算変更が必要なら、変更前に現在の式と具体的反例、変更式と測定配置、方向合わせ・接触ゼロを取り直す条件、測定値・保存互換性・既存説明への影響を説明する。** 別方式・弾性モデルへの置換を黙って行わない。今回の依頼を包括的な新仕様承認として扱わない。

今回の次セッション依頼は表示修正に限定されていない。既存の意図した測定方式に対する計算・座標・更新処理の不具合も修正対象である。過去の回で「式は変更しなかった」ことを、今回の計算修正を禁止する指示として扱わない。一方、未定義の測定配置を新しく決めることと、既存配置の実装誤りを直すことは区別する。
