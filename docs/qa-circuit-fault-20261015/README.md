# テスターの練習を「断線探し」に変更（2026-10-15）

## 内容
- 「テスターの使い方」ページを断線探しだけに変更。以前の単体練習（DC電圧・AC電圧・DC電流・抵抗・導通）と、そのコード（src/tester.js）・テスト（check-tester-lesson / check-electrical-full）は削除した。
- ページを開くたびに新しい問題になる。
- テスターのリードを端子に当て、電源ONで電圧、OFFで抵抗を測って断線を見つける練習。
- 回路（ランダム）：自己保持回路／インターロック回路（正転・逆転）／信号機回路（タイマ2個、教本の1級例題ケース2の構成）／スター・デルタ始動回路（制御回路）／電動機の主回路（3相200V、操作回路R-S 200V）。
- 電源（ランダム）：AC100V・AC200V・AC24V（主回路は3相200V）。
- 断線：1本か2本（初期は2本）をランダムな配線（母線・渡り線を含む）に設定。
- 図はJIS C 0617の記号に近い教材用の描き方（a接点・b接点・押しボタン・限時接点・熱動継電器・コイル・ランプ・MCCB・主接点・電動機）。小さな数字は線番。

## 計算（src/circuit-fault.js、circuit-fault-v1）
- 端子と配線（各1本が断線可能）、閉じた接点・ヒータは導体、コイル・ランプ・巻線は抵抗負荷。
- 電圧：交流をフェーザ（複素数）の節点解析で計算。電流が流れない負荷の先にも電源電圧が出る、主回路の欠相端子は線間電圧の半分（200V→100V）など、実際の盤と同じ読み。どこにもつながらない点は「≈0 V（浮き・ふらつく）」。
- 抵抗：電源を切った状態の直流抵抗（コイル・ランプの抵抗は電圧ごとの教材値）。通電中のΩレンジは警告して測らない。
- シーケンス：リレーはコイル電圧（定格の70%以上）で動作、タイマはオンディレー（実時間で進む）。
