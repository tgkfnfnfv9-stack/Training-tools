# 横形の正面円とゼロ位置

作業開始mainは b1e5cca00377252c6b04879bee13fe60eb3543d3。remote mainも同一で、作業ツリーはクリーンだった。

ユーザーの参考画像に合わせ、既存の右上「Z平行」枠内だけを変更。従来の長手略図だけでは正面の接触側が分からなかったため、正面円を追加した。

- a：円の左（9時）へ左から接触、a 0。
- b：円の下（6時）へ下から接触、b 0。
- 両測定の軸方向のゼロはバー先端寄り。右の長手図で始点0と主軸側への300 mm走査を維持。

正面の橙点はそれぞれの測定子の接触位置。円の全周でゼロになるという意味ではない。aとbは同じ長手位置で別々にゼロを取る。

変更箇所は src/spindle-sweep-ui.js の horizontalParallelMiniMarkup と生成index.htmlだけ。数値計算、押込み符号、保存形式、枠外のUI、展開後の既存詳細図は変更しない。小図56×31、外枠64×77を維持。

修正担当と独立確認担当を分離。初回確認でSVGの文字領域が上下端を越えることを検出し、文字位置を再修正して再確認。証拠と最終結果は qa-horizontal-front-zero-20261007/README.md を参照。

既存の独立幾何テスト check-horizontal-parallel-independent.cjs は478件成功。今回の検証は表示の一致確認であり、実機精度の検証ではない。実iPhone Safariでの確認は未実施。
