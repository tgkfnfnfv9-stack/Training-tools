# 常時表示する直角図の拡大・独立確認

対象は <https://tgkfnfnfv9-stack.github.io/Training-tools/>。作業開始時に remote main を確認し、`d4e9e1e47bbd6fcbf846d76d21e4b7b08a20a04a` が最新で後続変更がないことを確認した。依頼文にある添付画像はこの会話では受領していないため、添付を見たとは扱わず、同コミットの公開HTMLを変更前の実ブラウザー画面として比較した。

修正担当と独立確認担当を分け、最終ソースを固定してから再検証した。最終アプリHTML SHA-256 は `79d493538b295bf4453d63ffdd8d97edc20494a0445a81b260c99654a333c3ce`。アプリ公開コミットは `ffd1544f4ba123a23cc72c0b98f87d8beecdde96`。公開後の独立再検証も成功した。

## 変更内容と測定基準

- 常時表示の図外見出し「XY 基準X」「XZ 基準X」「YZ 基準Y」をDOMから削除。繰り返しの基準0説明は視覚表示を抑え、読み上げ用の文脈として保持した。
- 見出しの高さをSVGに振り分け、板を中心にviewBoxを詰めた。板・軸・矢印の画面寸法そのものを増やした。
- 奥行きの固定投影を調整し、YZなどの板幅を確保。投影は表示だけに使用し、方向・符号・数値へ戻していない。
- 各図と同じ項目枠に現在値とµmを表示。図内の2軸名・O・0・黒い基準辺・測定方向矢印・300 mm換算点・理想と現在の線・＋／−を保持。軸文字を現在の終点から板の固定位置へ移し、正負の変化時も符号と重ならないようにした。
- 説明は既存の開閉欄を利用。短い横画面の微小変化説明は視覚的に抑え、操作後にも模型・水準器の領域を確保する。

計算エンジン、保存形式、保存キー、計算モデルIDに変更はない。値は既存の「現在位置における局所的な2軸方向の角度差の300 mm換算」で、300 mm実走査の説明には変更していない。直角図O・基準0とダイヤルの手前0は別の基準のまま。基準位置を変更する操作は追加していない。

変更前後に同じ個体seed、支持高さ、軸位置を投入し、全7機種の `levelRecord()` 全体、計算 `pairs` 全体、ダイヤルcardinal全体、DOMの実値が完全一致した。表示投影の変更による数値変化は0件。詳細は [calculation-invariance.json](calculation-invariance.json)。
