# ねじれの水準器を追加（2026-10-13）

## 変更
- 機械の右枠（平均・左右、平均・前後の下）に「ねじれ · 奥−手前」の水準器を追加。
- 値は支持面のねじれ（奥の左右傾き − 手前の左右傾き、mm/m）。同じ水準器を手前と奥に置き換えて左右を読み比べる手順を1本で表す。
- 気泡は右へ＝奥が右高（手前より）、左へ＝奥が左高。表示幅・目盛は平均の水準器と同じ（0.02 mm/mで6 %、約0.1 mm/mで端）。0.02 mm/m以内は「目安内」。
- 3本とも中央 → 水平かつねじれなし。4点支持ではこれが「全支持点が同じ高さ」と同じ。
- 計算・測定値は変更なし（表示の追加のみ）。

## 注意
- 6点・8点・15点支持では、ねじれは四隅で決まる。中間の支持点が面からずれている（面のずれ）分は、この3本では見えない。「レベルが出ました」の判定（全支持点が同じ高さ）には含まれる。

## 確認
- ブラウザ（PC・スマホ）：ページエラー0。`browser/before`（main）・`browser/after`。小型立形の例では、平均2本がほぼ中央でもねじれの気泡が「奥が左高」に振れ、XZ +36 µm が出ている状態を確認。
