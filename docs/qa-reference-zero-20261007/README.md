## ユーザー指定との対応

小型立形・移動コラム・5軸A=C=0では、画面の接触ゼロと矢印を直接確認した。

|面|ゼロ位置|相対走査|
|---|---|---|
|XY|手前・右側|奥へ|
|XZ|上・右側|下へ|
|YZ|上・奥側|下へ|

XYのゼロ点は展開図の下側、XZ/YZのゼロ点は上側。計器本体側か基準器側かに応じ、部材の移動は相対走査と同方向／反対方向となる。試験の期待値は修正対象の描画関数や指示符号表から生成していない。

横形・門形・旋盤では既存の軸の役割を交換していない。横形XYは下→上、横形XZ/YZは奥→手前。門形XYは左→右、XZ/YZは上→下。旋盤は主軸基準XZのX径方向を手前へ走査する（訂正：現模型の手前側工具では内→外。旧記載「外→内」は誤り）。横形や旋盤の水平面に存在しない下降軸を表示していないことを、独立した実方向表で確認した。

## 単純な符号反転ではないことの検証

小型立形XY、支持高さ `[+0.5,−0.5,−0.5,+0.5] mm`、X=100、Y=0、個体seed 78612の例。

- v1：−24.540253536865µm
- v2：＋24.550656106527µm
- 新始点・新終点、支持勾配から独立に作った面法線、既存P軌跡を使った交点計算：＋24.550656106525µm
- v2と単純な「−v1」の差：0.010402569662µm

新始点で方向合わせを取り直すため、非一様な支持姿勢では旧値の符号反転だけと一致しない。独立計算は新しい `referenceScan` の返す読み・面法線・描画から期待値を作らず、既存の支持勾配とP軌跡を用いて接触式を別に解いた。旧モデルとの端点照合は旧コミットのコードを別の実行環境へ読み込んだもの。
