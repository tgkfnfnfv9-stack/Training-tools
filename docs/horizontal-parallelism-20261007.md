# 横形：Z方向平行度の追加

開始main：ceb0cba3f77be0a82848d916bcf0edd478b279a5。作業ツリーはクリーンで、前回の小型YZ/触れ共通姿勢を維持して追加した。

## 表示と測定

ユーザー提示の「Z軸方向の平行度」を参考に、横形の右上の既存触れ枠を再利用して「Z平行」を表示する。a 左右、b 上下、始点0、走査300 mm。枠を押すと既存の開閉領域に測定図と説明を表示する。常設パネルは増やしていない。

|項目|基準|計器|移動・ゼロ|正の読み|
|---|---|---|---|---|
|a 左右|主軸固定テストバーの左側面|パレット上、左側から右向きに接触|先端寄りで0、パレットの部材＋Zで主軸側へ300 mm|測定子の伸びが減る／本体へ縮む|
|b 上下|同バーの下面|パレット上、下側から上向きに接触|同じ300 mm区間、bも独立に始点0|同上|

主軸は回転させない。4方向旋回ではなく、Z送りに対する平行度の2方向走査。部材＋ZとNC指令の符号を区別する。主軸軸線は模型の横向き主軸、Z送りはパレットの移動であり、別に求める。

## 計算仕様

新規モデル horizontal-parallelism-v1。半径25 mmの仮想円筒バーに、左・下からそれぞれ測定子のレイを当てる。バー軸をu、軸上原点o、計器本体位置b、測定子方向pとしたとき、軸からの垂直距離がrとなる `|perp(b−o+e p)|²=r²` を解き、手前側の接触までの伸びeを求める。読みは `(e始点−e終点)×10^6 µm`。後掛けの増幅倍率は設けない。

計算は模型の倍率1の主軸鼻端・中心線と一致させる。校正区間は鼻端前方320 mmから鼻端まで。測定始点は鼻端前方310 mm、終点の目安は10 mm前方。主軸内部へバーを置かない。

パレット材料点は上面中心（支持基準から0.61 m）。実際の計器本体はそこからバーへ届く取付け腕の先端で、腕の高さ・前後オフセットを含む全ベクトルをパレットの姿勢変化に追従させる。0.61 m位置だけの移動に置き換えていない。

支持・軸位置の変更ごとに取付けと始点ゼロを取り直す仮想配置。Z端では300 mmを確保できる始点へ戻した区間を測る。計器の伸び範囲は0〜20 mm、初期10 mm。校正範囲外・接触不能はa/bごとに数値を抑止する。16分割の内部点に加え支持補間境界の両側を検査する。

## 独立確認と修正往復

実装、独立数値、UI、実ブラウザーの担当を分離した。独立確認で次を修正した。

1. 初期配置案ではバーが主軸内部へ入ったため、鼻端の前方に固定した区間へ変更。
2. 初回横形選択の初期化前に計算を呼ぶ例外を、未初期化時の数値抑止で修正。
3. 図の0が接触点から離れていたため、接触位置へ●0を追加。
4. 移動端で開始位置を戻す仮定を既存説明へ明記。

独立純幾何478件、機械との結合553件を確認。円筒式とは別の外積距離と二分探索、既知正負角の手計算、実際の模型鼻端と軸線、鞍面と取付け高さを期待値に使用した。テストが通るだけで実機の正しさを主張していない。
