# 測定のゼロ位置と走査方向の変更（reference-scan-v2）

> v2の履歴です。現在の取付点・表示修正は[reference-scan-v3](reference-fixtures-20261007.md)。

変更開始時の最新main：`4faa776b31516aa98c7815a382fcd9b82a090a95`。
ユーザー指定：XYは手前でゼロ→奥、XZは右上でゼロ→下、YZは奥上でゼロ→下。既存UIの3枠内のゼロ・移動矢印・接触位置・数値と、その説明を変更する。

## 標準立形配置

小型立形・移動コラム・5軸（A=C=0）は次の配置。

|面|接触ゼロ|基準器に対する計器の走査|当てる側|押込み＋|
|---|---|---|---|---|
|XY|手前・右側|手前→奥|右から左|右|
|XZ|上・右側|上→下|右から左|右|
|YZ|上・奥側|上→下|奥から手前|奥|

XYでテーブルが動く小型・5軸はテーブルを−Y（手前）へ動かし、計器の相対接触は奥へ進む。移動コラムは計器側を＋Y（奥）へ動かす。XZ・YZは頭を−Z（下）へ動かす。図だけの鏡映や数値への符号乗算ではなく、実際に選ぶ有限区間の始点・終点を入れ替えて接触式を再計算する。

## 他機種の実方向

軸の役割は交換しない。展開図のXYは比較軸＋方向、XZ・YZは比較軸−方向へ進む。旋盤XZだけは従来どおり主軸Zを基準、比較軸Xを径方向に走査する。

|機種|XY：ゼロ→相対走査|XZ：ゼロ→相対走査|YZ：ゼロ→相対走査|
|---|---|---|---|
|小型立形|手前・右→奥|上・右→下|上・奥→下|
|移動コラム|手前・右→奥|上・右→下|上・奥→下|
|5軸 A=C=0|手前・右→奥|上・右→下|上・奥→下|
|固定門形|左・奥→右|上・奥→下|上・右→下|
|移動門形|左・奥→右|上・奥→下|上・右→下|
|横形|下・右→上|奥・右→手前|奥・上→手前|
|旋盤|対象外|奥・右→手前（X径方向、手前側工具では内→外（旧記載を訂正））|対象外|

横形XYに奥方向、横形XZと旋盤XZに上下方向の直線軸はない。その面を「奥へ」「下へ」と誤表示しない。門形はXが奥、Yが右。展開図の上向きと実機の上向きを混同しないよう、実方向を図中の矢印脇・開閉説明へ表示する。フランジ、直角マスタ、計器固定先、接触側、方向合わせの基準軸はv1から維持する。

## 区間・計算・保存

1. 物理的な可動部位置の300 mm区間 `[low, high]` はv1と同じ。`low=clamp(現在位置, -halfStroke, halfStroke-0.3)`、`high=low+0.3`。スライダー端でも全区間を可動範囲内に保つ。
2. 相対走査の希望符号rはXYで＋1、XZ/YZで−1。本体側が動く場合の部材走査符号はr、基準器側が動く場合は−r。これは移動構成から導くもので、ダイヤル指示値の符号表ではない。
3. 部材の正走査ならlowでゼロ→high、負走査ならhighでゼロ→low。負方向でも長さは300 mm。新しい始点で方向合わせと接触ゼロをやり直す。
4. `λ=n·(P−B)/(n·u)`、`I=(λstart−λend)×10^6 µm` を維持。接触基準点の軌跡・取付姿勢・面法線を新しい順序で計算する。小型Yは有限P軌跡の端点差、数値積分は符号付き区間、面内判定は希望する相対走査方向で評価する。
5. 固定姿勢、q=＋10 µmの例：小型XYは旧−10→新＋10、XZ/YZは旧＋10→新−10。曲がりや姿勢変化があれば新しい始点の方向合わせも変わり、新値が単純に旧値の負とは限らない。

表示測定の仕様IDを`reference-scan-v2`へ更新。機械の局所角度差・支持評価・4方向ダイヤル・保存JSONは変更しない。旧保存の機械・支持・軸位置を同じ意味で復元し、新配置の仮想測定値を再計算する。ゼロの保持履歴を新規に追加しない。画面に出る読みは配置変更により変わるが、旧機械データを別の精度モデルへ置換しない。
