# 微調整の廃止・レベル調整だけで0.02 mm以内（2026-10-13）

ブランチ `feat/level-only-20261013`（main c2d166b から）。

## 変更
- 画面：粗調整／微調整の切替ボタンを外し、調整は 0.01 mm 刻みのレベル調整1本。設定内の微調整パネルは非表示（要素は残す）。
- 目標：全支持点が同じ高さ（平均の左右・前後の傾き、ねじれ、面のずれがすべて0）で「レベルが出ました」。ヒントは平均高さから最も離れた支持点を示す（高さのばらつきが減る向き）。
- 個体の抽選（machine-accuracy v3）
  - 据付の初期高さを 0.01 mm 刻みにし、0.01 mm 操作でちょうど揃えられるようにした。
  - 採用条件：据付状態でどれかの測定値が 20 µm 超、かつ **レベルが出た状態（全支持同じ高さ）で、支持で変わる測定値がすべて 20 µm 以内**。固有の振れ・上面・ガイドも 20 µm 以内。条件を満たすまで最大200回引き直し、保存は採用した種のみ。
  - 対象の測定値：直角XY/XZ/YZ、触れ（右・奥・左）、横形Z平行（横・縦）、旋盤の刃物台X送り・往復台Z送り・テストバー側面/上面・穴芯X/高さ。
- 旋盤（lathe-testbar-v4）
  - 中古の固有値（端面・Z面の角度、穴芯）の範囲を ±30 → ±15 µm。
  - 穴芯は往復台をチャック近く（テストバーaと同じZ・主軸端から約90 mm）へ寄せて測る。Zスライダーに依存しない。以前は現在Z（主軸から約0.9 m）で測っていたため、主軸の固有の向きの差がそのまま 40 µm 以上の芯差になり、レベルで直せなかった。
- 微調整用の探索・ヒントのコードを削除。

- ブラウザ（PC・スマホ）：ページエラー0。`browser/before`（main）・`browser/after`。
