# 横形 独立幾何監査 2026-10-08

対象は b56dbbd を開始点とする横形だけ。実装担当とは別に、構造・相対運動から期待値を組み立てた。過去のテスト結果を正解の根拠とはしていない。

## 今回の独立数値比較

`tests/check-horizontal-audit-independent-20261008.cjs` は支持面のスカラー値（高さ・勾配）だけをアプリから取得する。描画関数、`geometryModel` の姿勢・軸、測定の符号表は期待値に使わない。

- 上向き法線を `(-∂h/∂x, 1, -∂h/∂z)` から組み立てる。
- パレット原点は支持基準から 0.61 m。支持面上の移動と剛体姿勢変化を分ける。
- 直角マスタと計器について、固定面への距離を自作の内積で計算する。
- 主軸バーでは計器をバー高さまで届かせた全取付ベクトルをパレットに固定し、始終点で輸送する。中心位置で支持基準からの高さは 1.89 m。
- 円筒接触は製品コードの二次方程式を使わず、外積距離と二分探索で求める。
- 理想、正負の剛体平面、正負の鞍面、全 8 支持点それぞれ正負 0.04 mm、Z の 5 位置（両端を含む）、既知の正負の単独角度差を確認。

531 比較が一致した。これは現在の仮想配置の内部整合の証拠であり、実際の測定器の取付けや実機の弾性を証明しない。

## 接触から決まる読み

|項目|物理的に動く部材|基準器に対する計器の移動|計器位置・接触|ゼロ|
|---|---|---|---|---|
|XY|主軸頭を Y の上へ|上へ|X の正側に本体、負向きに測定子を出す|下側接触点|
|XZ|パレットとマスタを部材 Z の奥へ|固定主軸頭の計器はマスタに対して手前へ|X の正側に本体、負向きに測定子を出す|奥側接触点|
|YZ|パレットとマスタを部材 Z の奥へ|固定主軸頭の計器はマスタに対して手前へ|Y の上側に本体、下向きに測定子を出す|奥側接触点|
|Z 平行 a|パレット上の計器をバー先端から主軸側へ|固定バーに対して奥へ|バーの左側から右向きに接触|先端寄りの左側接触点|
|Z 平行 b|パレット上の計器をバー先端から主軸側へ|固定バーに対して奥へ|バーの下側から上向きに接触|先端寄りの下面接触点|

全て伸びの減少がプラス。XZ/YZ と Z 平行では基準器と計器の搭載先が逆なので、同じ矢印や同じ数値を要求してはいけない。Z 平行 a の左側 0 と b の下側 0 は異なる接触点であり、円周上の同じ点の二つの読みではない。

## 確認した矛盾と重要な限界

1. XY の小図で「頭固定」は、頭を Y に動かす説明と矛盾する。「頭に計器固定」の省略とも読めるが、移動しないとの誤解を招く。横形だけ明確化する必要がある。
2. R 面の方向合わせは、現在は **代表案内方向に合わせた仮想配置**。実際の主軸頭に付けた計器を X に動かして R を合わせた状態とは一般に異なる。

例として支持面 `h = 0.01 x z` mm、固有誤差ゼロ、中央 X では、代表 X 案内の上下成分は約 +12.88 µrad。一方、剛体コラム上の主軸鼻端の X 移動接線の上下成分は約 −9.30 µrad、前後成分は約 −18.90 µrad になる。単純な「案内方向=任意材料点の移動接線」は成立しない。

実際の R 方向合わせに変更するなら、鼻端方向に置換するだけでは足りない。計器の固定部と腕、R 接触点の高さ・前後位置、X 方向合わせ区間、ゼロ操作を定義し、その材料点の移動と面への接触から校正を求める必要がある。これは新たな測定仕様になるので、今回の表示の修正に紛れて変更しない。

## 未確認・主張しないもの

- 支持面補間そのものは本テストの独立期待値の対象外。スカラー高さ・勾配を入力として検証した。
- パレットの主軸側への移動と、工具に対するワークの相対移動は逆だが、ここから EC-630 の NC 各軸正方向や機械座標右手系を認証していない。
- 原点から離れた計器や主軸の有限 X 移動を使う実物 R 方向合わせ、マスタ・計器の取付け寸法と干渉、バーの自重たわみ、ベッド剛性と荷重、実機の測定値は未確認。
- カメラの画面右と機械の X 正、円の正面と側面の投影を同一視しない。小図にはどの方向の模式図か分かる説明が必要。
- 上面精度と主軸回転振れの固有値表示は、この Z 送り平行度とは別の検査。両者を「同じ振れ」と説明してはいけない。

## X位置でYZが変わってもZ平行bがほぼ同じになる例

乱数 seed=123456（used）、`h=0.05xz` mm、Y=Z=0で追加確認した。

|Xスライダー|YZ µm|Z平行 a µm|Z平行 b µm|
|---|---:|---:|---:|
|−100|22.370697|−20.223647|14.111148|
|0|14.120697|−20.222647|14.111149|
|+100|5.870697|−20.221647|14.111150|

整数表示ではYZが22→14→6、bは14のままになる。これはコラム姿勢を読み落とした結果ではない。

`h=kxz` では、コラムの左右位置を c、走査長を L とすると、主軸バーの上下勾配は約 `kc/1000`。一方、パレットがZにL進む間の左右傾斜変化は `Δθ≈kL/1000` で、バーへ届く取付け腕の左右張り出し c により計器本体の高さが約 `cΔθ` 変わる。バーの高さ変化 `kcL/1000` と一致し、b方向の一次成分が相殺する。YZの仮想マスタ原点はパレット中心 x=0で、この左右張り出しを持つバー測定配置とは異なる。

固有誤差なし・X=0で正負のk=0.05を与えると、aは∓28.35 µm、bはいずれも−0.015861830 µmとなる。bの微小な負値は、円筒面の曲率と計器の剛体回転が合成された二次成分。単にaの二乗を半径で割った値と同一ではない。

支持基準からバー中心までの高さを H=1.89 m、半径 r=0.025 m、パレットの回転差をΔθとすると、固定バーの断面で独立に解いた読みは

`H(1−cos Δθ) + sqrt(r²−H²sin² Δθ) − r`

（単位m）。小角近似は `−H(H−r)Δθ²/(2r)`。実装とは別のこの式で正負両方を照合した。

**取付高さの区別**：理想支持・中央Yではバー中心とa計器本体の高さが支持基準から1.89 m。b計器本体はそこから半径25 mm＋初期測定子伸び10 mmだけ下の **1.855 m**。bの初期接触点は1.865 m。両計器本体を一律1.89 mと説明しない。

`tests/check-horizontal-twist-cancellation-20261008.cjs`：7比較一致。これは上記配置固有の相殺であり、一般の捻れ・全支持調整・全個体でbが不変という主張ではない。
