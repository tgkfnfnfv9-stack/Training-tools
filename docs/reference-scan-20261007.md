# 基準器による3枠の仮想測定（2026-10-07）

開始時の最新mainは `f63d5d2029bca07f97adc564c0253c41b3676a83`。ユーザーがASCII図を承認後に実装。変更は既存のXY/XZ/YZ欄の図・数値と、その開閉説明。元のUI配置、模型、固定水準器、支持操作、軸操作、4方向ダイヤルを維持する。

## 数値の意味の変更

従来の主数値は現在位置の局所軸角度差 `q=300000*(angle(a,b)-π/2)` µm。新しい主数値は、図の固定配置で開始接触をゼロとした、300 mm仮想走査の指示差 `I`。**qの符号だけを反転した数値ではない。** 「仮想測定」と常時表示し、開閉欄でqも別記する。

これは教材の有限幾何モデル `reference-scan-v1`。実機の測定結果や合否ではない。旧局所モデルに計算不具合があるとして修正したものでもない。従来の角度差、調整評価、初期比較、参考探索、保存モデルIDは維持した。

- 各支持・軸位置の変更ごとに基準器の方向合わせ、開始接触のゼロ合わせをやり直す。固定したゼロを持ち越す動作ではない。
- スライダーの範囲は既存の可動部座標。NCの符号と混同しない。`levelCoordinates` で横寸法を物理mへ変換する。
- 走査軸の現在位置から正方向へ300 mm。残り範囲が不足すれば**始点も手前へ戻して**300 mm確保。全ストロークが不足すれば「—」。開閉欄に実際の開始・終了の部材位置（mm、中央0）を示す。
- 姿勢は非誇張。カメラ、模型拡大、表示誇張、既存の評価長設定は測定計算へ入力しない。

## 測定配置

q−の一定姿勢例では表の読みを逆にする。実装はこの表を符号乗数として使用せず、本体と面の相対幾何を解く。姿勢変化や設置誤差がある一般の有限経路でこの表だけから読みは決まらない。

ゼロはS面の走査開始点。部材が基準器を動かす配置は＋走査軸側でゼロ、相対的に逆へ進む。計器側が動く配置は−走査軸側でゼロして＋へ進む。方向合わせとゼロ合わせは別工程。

5軸はA=C=0以外で3枠の数値を抑止。A/Cを勝手に戻さず、4方向測定は従来どおり旋回姿勢を反映。旋盤はZ送りとの直角度ではなく**主軸中心線に直角な校正済みフランジ面**をXで走査する。フランジの平面度と主軸中心線への直角性は別条件。面振れ確認後に主軸位相を固定する教材配置で、Y軸検査は追加しない。

## 接触式と運動の仮定

単位m。面の点P・単位法線n、計器本体B、測定子の伸び方向uについて、

```
λ = n · (P − B) / (n · u)
I = (λ_start − λ_end) × 10^6 [µm]
```

始点でP=0、n=基準軸の単位方向a、B=0.01a、u=−a。これは測定専用の相対座標で、模型の原点や機械のゼロとは別。

移動側の接触基準点に対し、各時点の局所送り方向を物理送り距離で積分する。**小型Yは既存P（支持基準から高さ0.50m）の有限軌跡を直接使う**。既にPの接線に含まれる姿勢効果を重ねて足さない。他機種では代表接触点の速度を既存軸方向とする新しい教材仮定。接触基準点の高さを変更する機能はない。描画中の任意頂点すべての軌跡と一致するとは主張しない。

剛体取付姿勢は接触基準点まわりに輸送。門形の非直交な変形写像を剛体回転と誤認しないよう、upを維持してrightを直交化したブラケット姿勢を別に作る。初期取付ベクトルvの輸送は `R_end R_start^T v`。基準器の法線も剛体姿勢で輸送する。

支持姿勢が変わる横形Z・5軸Yの代表軌跡は支持格子の境界で区間を分割し、区間内部のGauss4点積分を1→32分割まで細分化、連続する結果の差が1nm未満で収束。境界の不連続な勾配を隣の区間へ混ぜない。収束しなければ数値を抑止。小型Yは直接差分、それ以外の今回の走査軸は既存幾何の支持参照点を動かさないため一定方向の有限移動を使う。未知の固定guide PV値から曲線を捏造しない。

面は走査方向300mm＋始終端10mmの余裕、幅50mmの仮想校正面。計器の初期伸び10mm、計算上の伸び範囲0〜20mm。面と測定子が平行、面外、ストローク外では抑止。これらの仮想寸法は採用機の製品寸法や実物取付可能性を保証しない。旋盤のフランジにも同じ教材用接触帯を仮定し、実機で300mm半径差を確保できるとは扱わない。衝突・荷重・測定力・球先半径・器差・熱変形は扱わない。

## 具体例と保存互換性

- 平面x=0、本体x=10mm、測定子−x。終点の本体x=9.99mmなら＋10µm、10.01mmなら−10µm。
- 同じ正の広がり角10/300000 radで、一定姿勢の小型XYは約−10µm、XZ/YZは約＋10µm。従来qはどちらも＋10µm。
- 曲線x(y)=−0.0001y² mの0→0.3mは有限読み＋9µm、始点局所換算0、終点局所換算約18µm。符号反転だけでは有限値にならない。
- 1µmの対称丸めを維持（−0.5→−1、＋0.5→＋1、±0.49→0）。生値を丸めて保存しない。

旧JSONは同じ機械・個体・支持・軸位置として復元。測定固有の手動設定や保持ゼロは今回追加しないため、旧JSONに存在しないゼロ履歴を捏造・移行しない。`levelRecord` は変更しない。新しい有限値は機械状態から派生計算し `data-measurement-model=reference-scan-v1` として区別。旧値は開閉説明の「従来の局所角度差」に残す。調整目標は従来の局所評価のままなので、1枠の有限読みを0にしても総合評価の完了とは限らない。
