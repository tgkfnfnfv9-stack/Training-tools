## 計算と限界

4点計算エンジンに既存の不具合修正は加えていない。追加4機種について、既存の支持姿勢・固有姿勢・送り位置から主軸鼻点、代表主軸方向、テーブル面と有限範囲を求める測定用変換を追加した。描画誇張・高さの見かけ上の余白・カメラ・ズームを読み込まない。小型立形の従来の計算経路は保持した。

門形の測定軸は既存の `bodyCombinedDirection` が表す固有姿勢込みの代表方向であり、模型外形は支持姿勢だけを示す既存の簡略表現。5軸は実寸化後にC回転と親のA傾斜を反映し、有限な円形テーブルを既存寸法で写像した楕円として面外を判定する。意図的なA傾斜も相対読みへ含む。

5軸の3点支持では機械全体の共通傾きとなるため、A/C固定時に支持調整で相対読みが変わらないのが正しい。移動門形も、主軸とテーブルの支持姿勢が一致する位置では変化しない場合がある。支持操作を必ず悪化や変化へ結びつける処理は入れない。

理想平面と理想主軸の関係を扱う教材であり、上面の凹凸、実主軸の回転振れ、測定子の荷重、ゲージの可動量は再現しない。
