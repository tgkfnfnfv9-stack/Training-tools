# 修正後の独立幾何確認

実装担当と別の担当が、アプリを編集せず検証した。期待値は描画関数・実装の符号表から生成していない。

実行：

```
node tests/check-reference-fixtures.cjs
node tests/check-measurement-reference.cjs
```

`check-reference-fixtures.cjs` は独立幾何の数値比較317件、旧v2の回帰比較233件、および追加の接触有効性・SVG・全7機種保存互換性のassertを通過した。317は数値比較件数であり、全assertの合計ではない。

最終実装で再実行し、両端有効・中間だけ接触範囲外となる診断fixtureも通過した。小型P経路を一時的に `P_x(t)=−25mm*sin(πt)` へ差し替えると、伸びは両端10mm・中間35mmになる。両端の線面交点が有効でも、途中サンプルの範囲外により走査値が抑止されることを確認し、元の経路を復元した。これはサンプリング検査の回帰確認であり、現支持操作でその経路を生成できることや連続接触の保証ではない。

## 期待幾何

横形の支持面をメートル単位で `h(x,z)=x*g(z)` とし、x=0を移動するパレットの支持点より高さHの材料点を考える。横断傾斜は `θ(z)=atan(g(z))` だから、点は

```
P_H(z) = [−H sin θ(z), 0.66 + H cos θ(z), z]
```

となる。初期面法線をn₀、パレット姿勢変化をΔθ、本体B=0.01n₀、測定子−n₀とすると、読みは `I=n_end・(P_end−P_start)/cos(Δθ)×10^6`。この解析式から直接期待値を算出した。

- 正負の双一次ねじれ、理想、区分線形の支持傾斜を確認。
- スライダー両端と中央、支持セル境界の両側を確認。
- H=0、0.61、1.22mで回転に伴う取付高さの影響を確認。
- 点検時の反例は解析で−14.625958965µm。現修正の値と一致。
- 隔離した旧127b3ecへ同じテストを実行すると、最初の非ゼロ例で旧0µmに対し解析＋14.639999528µmとなって失敗。新実装では通過する。

純角度誤差は `a・b=−sinδ`、相対走査符号rに対し `I=r*0.3*sinδ*10^6` から全19面の理想・正負を確認した。固定した同じ配置の逆走・再ゼロは、測定子姿勢が変化していても厳密に指示が反転する。共通剛体移動でも指示は不変。

## 保存と模型の維持

`git archive 127b3ece7da64cab5d1fb9bbb998313d739fd905` で隔離した旧ソースから、seedを固定した全7機種の保存レコード・局所角度・軸方向・支持評価を捕獲した。現コードは全旧レコードを `validLevelRecord` で受理し、再適用後に保存内容・局所角度・方向・評価が完全一致した。横形XZ/YZ以外の有限読みも従来と一致。

さらに旧パレット模型の24状態（2寸法、平面／非一様支持、誇張有無、Z両端／中央）×3材料点×3座標を保存。関数共有後の模型が216比較すべて1e−10m以内で一致した。これら旧値との比較は**回帰検証**であり、物理的な期待値にはしていない。

## 図

測定子のみを傾け、本体の面法線距離を一定にすると、伸び・指示は変わるが図の本体xは動かない。計算済み幾何を維持して表示指示値だけ9999に変更しても図は変わらない。本体がS面へ近づけば本体図はSへ寄り、測定子の沿い方向が正なら接触点は本体より展開図上側へ出ることを確認した。

測定SVGから旧局所図の `zero-location`、`positive-direction`、`negative-direction`、`projection`、`tip-x/y` 属性が除かれ、測定仕様IDが `reference-scan-v3` になることも確認。

図の始終位置を結ぶ線は曲線経路全体の再現ではない。法線変位と姿勢は別々に誇張される。途中接触検査も有限サンプリングであり、連続経路全域の接触・衝突保証ではない。実機の固定具取付可否、測定力、器差、機種固有NC規約は今回の独立幾何検証では保証しない。
