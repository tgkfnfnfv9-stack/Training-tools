# 横形・旋盤：支持から接触・整数表示までの測定修正

本記録は修正担当の設計と実装観測。独立期待値・実ブラウザー操作・前後画像の記録は統括記録に合流する。過去テストの期待値を新配置の正解にしていない。

## 確認した旧式の問題

横形は、非平面の支持では取付原点を世界座標の `y = .66 + h/1000` に置き、部材には支持面の全勾配を回転として掛けていた。共通傾斜を残差形状と一緒に剛体回転していないため、全体の傾きを変えるだけで相対測定が変化した。旧版を再計算すると、標準寸法・理想個体・軸位置X57/Y43/Z29（スライダー％）・`h=.05xz mm` の旧XZは−9.1499999401 µm、共通平面 `x+.7z mm` を加えた場合は−8.9233152005 µmとなる（x/zはm）。この大きな共通平面は支持高さがUIの±0.5 mmを超える数理診断であり、実操作範囲の例とは区別する。同じ軸位置でUI範囲内の `.1x+.1z mm` を加えた場合も−9.1446178550 µmへ変化する。後者は整数表示が−9のままだが、生値の変化は丸めによって発生したものではない。

また、横形R面を代表案内に合わせる旧式は、頭に固定した計器の有限送りを行っていなかった。`h=.01xz mm`、理想・中央で旧XYは約+0.138 µmだったが、旧仮想接触点へ届く頭固定腕をXに300 mm送るとRの始終指示に絶対値約6.414 µm差が残る。旧XZ/YZのS原点はパレット上面そのもので、有限厚マスタの面ではなかった。

## 支持姿勢の修正

支持高さは従来どおりmm。内部座標はm。支持補間・平均平面・個体固有値の抽選は変えない。

平均平面 `h = ax+bz+c` と残差 `r=h-(ax+bz+c)` を分け、平均傾斜の回転を `C`、残差勾配の回転を `L` とする。取付座の原点を `C[x,r/1000,z]+[0,.66+c/1000,0]`、部材姿勢を `C L` として同じ物理状態を描画と測定で共用する。X代表案内にも同じ平均回転を使う。鼻端・主軸固定バー・計器取付点は、横形の共通材料点写像 `horizontalToolPoint` から得る。

平面か非平面かでパレット材料点の式を切り替えない。支持の微小変更で別の幾何へ切り替わる分岐を除き、同じ写像で連続的に運ぶ。旋盤は既存の主軸台・往復台の平均＋残差姿勢を維持し、描画のベッド側を整合させる。心押し台は測定に含まない。

## 独立再確認からの境界修正

支持の区分双一次面は内部境界で右／奥セルの勾配を使う仕様。しかし軸位置を％からmへ往復すると、厳密節点が浮動小数の最後のbitだけ前後し、異なる側の局所姿勢を選ぶ不具合が見つかった。横形A−0.010 mm、X57/Y43/Z29のXZ走査途中 `t=.5788043478260868` では、面原点のzに約3.667 µmの差が出た。これは表示の整数丸めではない。

支持奥行2.7 mでは、理論節点z=−.45 mに対し、元の支持座標を寸法換算すると−.45000000000000007 mとなる例も独立担当が確認した。横形／旋盤の支持解だけに、`slopeAt`の照会座標が実際の支持節点から1e−12 m以内なら節点へ一致させる処理を加え、既存の右／奥セル規約を安定させる。他5機種や連続な高さ補間は変えない。境界前後の検査点±1e−8tは±3e−9 mで、補正範囲の3000倍離れており、両側の異なる勾配を保持する。

## 有限R/S器具の教材仮定

既存の「パレット上マスタ／主軸頭固定計器／300 mm走査」を具体化した。実機器具の採寸値ではない。320×320 mm、厚み50 mmの直角マスタをXYは立て、XZは寝かせ、YZは立てて使う。器具の取付けと腕は各検査で別設定。

S走査開始状態のパレット上面中心をP、その基底をright/up/backとする。R最初の接触材料点Q0を以下に置く。

|検査|Q0−P（right/up/back成分、m）|基準送り|Sの相対走査|理想時Sの高さ（パレット上面から）|
|---|---|---|---|---|
|XY|−.15 / +.05 / 0|頭・X＋|頭・Y＋|+60→360 mm|
|XZ|−.15 / +.05 / +.16|頭・X＋|マスタから見て−Z|+50 mm|
|YZ|0 / +.05 / +.16|頭・Y＋|マスタから見て−Z|+360 mm|

Rの頭固定腕はQ0に届く接触材料点を固定し、基準軸へ300 mm送ってQ1を得る。S面法線を `nS=unit(Q1−Q0)` とし、R面の方向は、表のS相対走査方向をnSに直交投影して得るnRとする。R面はQ0を含む。厚み方向はnSとnRの外積。

器具の範囲はQ0からnS方向−10→310 mm、nR方向0→320 mm、厚み方向±25 mm。R始終は両端10 mmの余白を持つ。R計器本体を `Q0−.01 nR`、測定子を+nR向きに取り付け、同じ頭剛体で輸送する。R始終は10 mmの伸びで等指示になる。途中の指示まで0とは断定せず、途中接触と残差を記録する。

S面はnS座標310 mm、Sゼロ点は `Q0+.31 nS+.01 nR`。S用の腕へ付け替え、本体をゼロ点+.01nS、測定子を−nSに向ける。Sの相対走査は面上の10→310 mm。実際の本体と測定子を頭の同一剛体姿勢で運ぶ。XZ/YZでは面自体もパレットの材料点・姿勢で運ぶ。

器具下面の理想時のすき間はXY 50 mm、XZ 25 mm、YZ 40 mm。これを取付脚で確保する教材仮定であり、厚み50 mmやR接触点の高さと同じ量ではない。全治具干渉、支持脚の実設計、腕の弾性は未再現。

RとSはそれぞれ300 mmを軸範囲内に確保し、端では開始点を内側に戻す。R0の基準軸位置とS0の基準軸位置が異なる場合も、S用腕はS0の頭姿勢に取り付け直す。Pは入力Zそのままでなく、実際のS0のZ位置から得る。

接触は `e = n·(p−b)/(n·u)`、指示は `(e0−e1)×10^6 µm`。伸び0〜20 mm、有限面の範囲、16分割と支持補間境界両側の接触を確認する。途中で接触が外れると数値を出さない。支持または軸位置を変えるとR方向合わせとSの付替え・始点ゼロを取り直す。S走査中は再ゼロしない。

## 更新経路と不変値

支持上下は `setSupportHeight` がmm単位で0.001 mmに丸めて保存値を更新し、`updateLeveling` が同じsupportHeightsから支持解を作り直す。`updateAccuracy`のキーは支持全値・寸法・個体・軸位置を含む。横形は接触生値を `data-reading-microns` に、整数化した値を既存測定欄に出す。整数化は `round(abs(value))` に符号を付け、負の0を表示しない。支持変更を丸ごと無視する固定キャッシュは見つからなかった。

旋盤のX面は、始点面法線に計器を合わせ、同じ剛体内のX送りと面の固有角の差を測る。支持姿勢を変えて方向合わせを取り直したときに不変であることを、同一剛体の面と送りの接触から検査する。Z面・穴芯・バー側面／上面の計算は支持姿勢を参照する。小さい上面バー値が整数0に残る場合も生値を保持する。回転TIRなど個体固有値は同一seedに固定し、支持連動の係数や乱数再生成を加えない。

XZ/YZとZ平行a/bは基準器・計器の搭載先が逆で、取付高さと腕も異なる。これらを同じ表示値に合わせ込まない。

## 保存と変更範囲

保存形式、支持高さ、個体seed、固有値、軸位置は変更しない。旧保存も受け入れ、横形測定は新姿勢と新有限器具配置で再計算する。過去のXY/XZ/YZ数値の再現互換ではない。整数µm・支持／軸操作・既存UIを維持し、説明は既存詳細欄、小図はXZ/YZのRを実配置に合う上辺へ修正した。

他5機種は新経路へ入れない。旧横形の代表案内・厚みゼロ面を期待値にしたテストは新器具の正しさの根拠にせず、独立した有限器具・支持剛体・接触計算による再確認を行う。

既存旋盤独立テストには後続の「心押し台は模型だけ復帰」を反映せず、模型からの削除を要求する旧断言が残っていた。数値期待値を変更せず、この断言を「模型に存在／X・Z送りで固定／模型から一時的に除いても全測定結果が同一」に更新した。古い監査文書は履歴として保持する。
