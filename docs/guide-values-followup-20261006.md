# 部位姿勢と300 mm直角差表示の追加修正

この文書は数値表示追加時の記録。後続の `compact-table-path-v3` では、小型立形をテーブル上面Pの送り角へ変更した。本書の「小型立形のXYは不変」は旧モデルの同時点のサドル姿勢に関する説明で、現在のPの送り角には適用しない。最新の原因・修正・限界は [compact-table-path-20261006.md](compact-table-path-20261006.md) を参照。

基準main：`7047a65f5da1b3a92eb76cd3cd70304950adf815`。ユーザーのASCII案承認後に実装した。

## 変更内容

|機種|計算の見直し|
|---|---|
|小型立形・4点|Xテーブルの移動でYサドルの支持参照まで左右移動していた挙動を修正。支持参照はXで固定、Yサドル送りで移動する。|
|横形・8点|Xを描画される二本の走行レールの平均姿勢、Yをコラム取付部、Zをパレット側から計算する。|
|移動コラム・6点|XYZ全てを同じ姿勢に固定せず、X走行案内とコラム側Y/Zを別の参照にする。|
|固定門形・15点|既存の柱天端と平均倒れによるせん断モデルを維持。|
|移動門形・8点|既存の左右レールと門形の参照関係を維持。|
|5軸・3点|三点が作る平面上の共通剛体回転を維持。内部XYZ角が変わらないことはこの仮定で正しい。|
|旋盤・6点|径送りXで往復台の据付参照まで移動していた挙動を修正。描画往復台中心を基準に、長手Zだけで移動する。|

横形・移動コラムで案内とコラム姿勢を別参照とするのは、取付ベースの相対変形を表す幾何的な教材仮定。微小な角度変化を強制的に増幅したり、全ての軸対を必ず変化させたりしない。模型・矢印・直角度は同じ部位姿勢を参照する。

## 数値の読み方

主画面のXY/XZ/YZ図直下に「X基準 0／Y直角差 -20」等を表示。旋盤のみ「主軸Z基準 0／X直角差 ±値」。単位はµm、1 µm＝0.001 mm。

- 現在の角度偏差を300 mmへ換算した値。初期からの差分やNCの移動座標ではない。
- 基準0はゼロ合わせであり、その軸の固有精度がゼロという意味ではない。
- 正は直角より広い、負は狭い。これは図の角度偏差の符号で、画面上の終点横座標の符号とは区別する。
- 1 µm刻み、絶対値を四捨五入して符号を付ける。丸め後は負のゼロを表示しない。
- 表示倍率・ズーム・回転・設定評価長は数値に混ぜない。図が表示範囲外でも値は省略しない。
- 支持調整量、初期値・差分、倍率などの数値は引き続き非表示。

## 不変のまま残る範囲

全支持の同量上昇や共通平面の傾きは、内部角度を変えない。同一部位の軸対も共通回転では角度を保つ。小型立形のXY、移動コラムのYZなどにはこの不変が残る。

鉛直の支持高さ場だけでは水平面内の案内の曲がりを全て表せないため、横形や旋盤の水平軸間角は変化が小さい場合がある。旋盤のベッドロールによる刃先高さ差・実切削テーパ、回転軸誤差、荷重・剛性・接触による変形は未解析。数値は教材の計算値であり、実機の調整量や検査値の予測ではない。

## 保存

計算の変わる4機種だけ仕様IDと保存領域を更新。旧保存は削除せず、旧仕様のJSONは説明付きで拒否する。門形2機種と5軸の計算IDは維持する。

## 検証

新しい独立テストは、描画位置に対応する解析的な支持面から軸方向と角度を求める213条件と、数値表示・丸め・単位・読み上げ説明・表示条件不変を確認する104条件。構造担当は別に柱姿勢・柱脚・案内方向の54条件と門形接続290条件を確認した。

全33本を実行し、初回は31本成功。旧支持参照を前提にした2本の個体例を更新し、実際に「総合改善でも現在位置は悪化」となる大小関係、および独立した二乗差残差式を検証する形を保った。対象2本と関連4本を再実行し、最終的に全33本が成功した。最終再実行は調整フロー152、乱数個体164、統合158、数値表示104、案内姿勢213、学習フロー91条件。確認担当による最終差分レビューでも追加の問題はなかった。

公開版でPCと携帯縦横、320px幅を確認した。数値欄追加で短い画面の模型が縮みすぎる問題を発見し、短縦の調整欄を独立スクロール、短横の数値を横並びにして修正した。320×568の横形模型高さは46pxから161pxへ改善した。ボタン44px、数字、気泡は維持している。
