# 小型立形のコラム前後倒れを見える表示へ

## 問題と修正

公開mainは作業開始時97297100d21d6292567e664a7ccd1763e116d9de。ローカルd9e5318までの修正は未公開だった。d9e5318では、誇張した3D模型がYZの改善方向を逆転させる問題を避けるため、小型の模型姿勢を実寸にしていた。その結果、前後倒れが見えにくかった。

今回、模型の上に小型専用の「コラムの前後倒れ」側面拡大図を追加した。オレンジの柱、床基準の鉛直破線、手前／奥、実角を表示する。実模型の姿勢は実寸のまま。これは床基準の姿勢図であり、YZの相対直角やダイヤル値ではない。

修正前：微小角の実寸模型のみ → 修正後：実寸模型＋同じ柱姿勢の側面拡大図。
前倒れ：柱上端が手前（図の左）。後ろ倒れ：柱上端が奥（図の右）。

## 計算・互換性

表示だけの修正。物理角θを角度2000倍で描き、±65度を超える表示には「図の範囲外」を明記する。支持入力、補間、直角測定、YZの符号、µm値、保存形式は変更していない。支持共通傾斜は柱も基準器も同じように傾けるため、柱が床に対して倒れてもYZが改善するとは限らない。

原因・変更コード：src/accuracy-ui.js の updateColumnLeanInset、src/index.html の columnLeanInset、src/style.css の column-lean-inset。固定コラムの姿勢は軸送りで変えない。短い縦画面で既存の支持選択行が上下操作行に隠れる問題も、小型の高さ配分を変えて修正した。

## 確認

製品修正担当と独立確認担当を分離。独立担当はh=bzの解析法線から期待角atan(b/1000)を求め、実模型の上下頂点とSVG変換後の柱頂点を照合した。正負傾斜、ゼロ、実際の粗微操作、固定柱、表示操作、保存復元、他6機種を確認。詳細・画像は [独立報告](qa-visible-column-lean-20261007/independent-browser.md)、数値は同フォルダのbrowser-after/results.json。回帰はregression.jsonに記録する。

## 限界

- 拡大図は主模型そのものを誇張する変更ではない。床基準の倒れと基準器に対する直角を区別する。
- 支持Aの粗1回で約1.93 µrad、図の上端約0.21px、微1回では約0.021px。実角の数値は更新するが毎回の輪郭変化が大きく見えるとは限らない。
- 320×480の極短画面は支持操作を確保する一方、模型領域が狭い。390×844、320×568、PCを別々に確認。
- 実機の弾性・荷重・接触の再現を証明したものではない。教材モデル内の表示整合の確認。
- iOS実機は未確認。携帯寸法のChromiumブラウザーで検証。
