## 独立期待値の構成

内部座標を右=x、上=y、奥=z と明記し、物理支持座標に `h=kxz` mm、`k=-0.06,0,+0.06 mm/m²` を与えた。4点以上の矩形格子では支持点間の鞍面を解析的に作り、柱姿勢は高さ勾配から直接計算した。

```
h_x=kz, h_z=kx
上向き法線 = normalize(-h_x/1000, 1, -h_z/1000)
x案内接線 = normalize(1, h_x/1000, 0)
```

正の k では左手前・右奥が高い。奥へ移るほど右高勾配が増し、柱上端は左へ倒れる。右側ほど奥高勾配が増し、柱上端は手前へ倒れる。**支持高さの対角符号と柱倒れの符号は同符号ではない。** 全7機種の tool/work 法線と全線形軸代表方向を各条件で比較した。門形は左右の柱法線も個別比較した。

- 小型立形: `compact-bending-oracle.cjs` の閉形式曲率積分から2モード係数を得る。製品の剛性値とは扱わない。高さ0.50 mのPの位置を独立に構成し、Y接線はその位置関数の5点差分から求めた。走査はPの始終位置差で計算した。
- 横形: `h=x*g(z)` でパレット中心の高さHの点は `(-H sin θ, H cos θ, z)`、`θ=atan(g(z)/1000)`。H=0,0.61,1.22 mで取付高さによる横変位を独立比較した。
- 移動コラム: Xは2本の案内の平均傾き、Y/Zは後方のコラム座面から独立に姿勢を作った。Xの代表方向と任意高さのコラム材料点接線を同一視していない。
- 固定門形: 全15点の最小二乗共通平面を独立の線形消去で計算。構造ベッド9点の鞍面、左柱3点・右柱3点の座面平面を別々に作る。座面から高さ2.51 mの柱天端を結んで梁方向を得る。ラム方向は両柱の法線平均。全15点TPS面を構造ベッドや柱座面に代用しない。このテストだけでは全15点TPS補間関数そのものの独立証明にはならない。
- 移動門形: 左右柱天端の実座標と法線から梁・ラムを構成。走行Xの代表レール方向と門骨格のせん断を区別した。
- 5軸: 入力3点から平面を独立に決める。鞍面の4点目を仮定しない。A/C=0の19面群に含め、非ゼロのAまたはCでは線形有限測定を抑止することを確認した。
- 旋盤: 固定主軸の回転中心線Zと、往復台に載る刃物台Xを比較。X走査で往復台の支持参照点は移動せず、Z位置を変えた3位置で確認。往復台Z送りを主軸中心線に置き換えていない。Yは検査していない。

有限読みの期待値は面と測定子の交点から作った。

```
面: n・(Q-P)=0, 測定子: Q=B+λu
λ = n・(P-B)/(n・u)
指示 = (λ開始-λ終了)×10⁶ µm
```

左右反対側の接触は B と u の向きから符号が変わる。NCの＋、部材の＋、相対走査の＋、押込み指示の＋を同じ変数にしていない。
