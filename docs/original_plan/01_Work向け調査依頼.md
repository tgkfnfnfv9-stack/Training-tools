# 01_Work向け調査依頼

## 依頼目的

社内向け **機械訓練ツール** を作る前提で、まず対象となる工作機械・加工機械を徹底調査してください。

---

## 依頼内容

以下を深く調査して整理してください。

### 1. 機械の種類をできるだけ網羅的に洗い出す
最低でも以下を起点に広げること。

- 縦型NCフライス
- 横型
- 立形マシニングセンタ
- 横形マシニングセンタ
- 門型マシニングセンタ
- ダブルコラム
- 移動コラム型
- 移動門型
- 5軸加工機
- 旋盤
- NC旋盤
- 複合加工機
- 研削盤
- ボーリングマシン
- 専用機
- その他関連工作機械

### 2. 名前だけでなく「構造」で分類する
機械名だけでなく、以下の観点で分類してほしい。

- 主軸方向（縦 / 横）
- コラム位置
- コラム本数
- 門型かどうか
- テーブル移動か、コラム移動か、門移動か
- 固定テーブルかどうか
- 直線軸構成
- 回転軸構成
- 5軸構成（トラニオン / スイベルヘッド など）
- 支持点 / 据付 / レベル出しの考え方に違いが出るか

### 3. 各タイプごとに整理してほしい内容
各機械タイプについて、最低でも以下を整理してください。

- 日本語名
- 英語名
- 機械の概要
- 構造の特徴
- どこが移動するか
- 代表的な用途
- レベル出しで重要になる場所
- レベル不良時に影響を受けやすい精度項目
- 訓練ツールに入れるべき表示項目
- 3D表示時に最低限必要な構成要素

### 4. UI / 3D訓練ツールの観点でも整理
調査結果は単なる機械一覧ではなく、訓練ツールに落とし込める形でまとめてください。

特に以下を考慮してください。

- どの機械タイプを初期版に入れるべきか
- どの機械タイプは後回しでよいか
- 似たタイプは共通モデル化できるか
- 3D表示に向いているもの
- レベル出し訓練との相性が良いもの
- 支持点やボルト調整をどう見せるべきか

### 5. 初期版の優先候補を提案してほしい
最終的に、初期版として採用すべき機械タイプを優先順位付きで提案してください。

例：
1. 標準立形
2. 横形
3. 移動コラム立形
4. 固定門型
5. 移動門型
6. 5軸トラニオン
7. 5軸スイベルヘッド

---

## 求める成果物

以下の形式でまとめてください。

### A. 機械タイプ一覧表
表形式で、主要項目を見やすく整理。

### B. 分類体系
階層構造で整理。

例：
- マシニングセンタ
  - 立形
    - 標準立形
    - 移動コラム立形
  - 横形
  - 門型
    - 固定門型
    - 移動門型
  - 5軸
    - トラニオン
    - スイベルヘッド

### C. 訓練ツール向け提案
- まず何を作るべきか
- UIではどう見せるべきか
- 3Dモデルでは何が必要か

### D. 不明点 / メーカー差 / 呼び方の差
名称の違い、似ているが別構造のもの、注意点も記載。

---

## 最重要ポイント

単なる「機械名の調査」ではなく、**将来3Dで左右回転できるレベル出し訓練ツールを作るための前提整理**として調査してください。

つまり最終的には、

- 機械タイプ選択
- 3Dモデル表示
- 左右回転
- 拡大縮小
- 支持点表示
- レベル出し調整
- 変形イメージ
- 精度影響

につながるように、構造・支持・調整・精度の関係が分かる調査にしてください。
