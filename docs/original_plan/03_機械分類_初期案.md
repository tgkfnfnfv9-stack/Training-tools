# 03_機械分類_初期案

## 1. 初期の大分類

```text
工作機械
├─ フライス系 / マシニング系
│  ├─ 立形
│  │  ├─ 標準立形
│  │  └─ 移動コラム立形
│  ├─ 横形
│  ├─ 門型
│  │  ├─ 固定門型
│  │  └─ 移動門型
│  └─ 5軸
│     ├─ トラニオン
│     └─ スイベルヘッド
├─ 旋盤系
│  ├─ 汎用旋盤
│  ├─ NC旋盤
│  └─ 複合加工機
├─ 研削系
├─ ボーリング系
└─ その他専用機
```

---

## 2. まず重点的に扱いたい候補

### 1) 標準立形
- 一番分かりやすい
- 初学者向け
- レベル出しの基本を説明しやすい

### 2) 横形
- 主軸方向が異なる
- B軸やパレットとの関係が学べる

### 3) 移動コラム立形
- 長尺機の考え方を入れられる
- ベッド長手方向の影響を説明しやすい

### 4) 固定門型
- 左右コラム差の考え方を入れられる
- 大型機訓練に向く

### 5) 移動門型
- 左右レール差の影響を学べる
- 3D表示との相性が良い

### 6) 5軸トラニオン
- 高度だが教育価値が高い
- 回転軸まで含めた考え方に広げられる

### 7) 5軸スイベルヘッド
- 主軸側回転の考え方
- 5軸の別タイプとして比較できる

- 支持点
- レベリングボルト
- 固定部
- 移動部
- ワーク

---

## 4. 3Dモデルで最低限必要なこと

各機械タイプで、最初から細かすぎるモデルにする必要はない。

最低限、以下が見えればよい。

- 外形の違い
- 主軸方向
- コラム位置
- テーブル位置
- 門 / レール / ベース
- 支持点位置
- 調整箇所位置
