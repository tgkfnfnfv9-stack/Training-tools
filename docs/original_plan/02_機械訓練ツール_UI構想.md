# 02_機械訓練ツール_UI構想

## 1. 大枠

機械訓練ツールは、以下のような構成を想定する。

```text
機械訓練ツール
├─ 機械カテゴリ選択
├─ 機械タイプ選択
├─ 構造説明
├─ 3D表示
├─ レベル出し訓練
└─ 精度影響表示
```

---

## 2. 初期UIイメージ

### 画面1：カテゴリ選択

```text
[ 電気訓練ツール ]   [ 機械訓練ツール ]
```

### 画面2：機械タイプ選択

```text
[ 立形 ] [ 横形 ] [ 門型 ] [ 移動コラム ] [ 5軸 ] [ 旋盤 ]
```

### 画面3：機械詳細

- 簡単な説明
- 2D模式図
- 3Dプレビュー
- 特徴
- レベル出しで重要な点

### 画面4：3Dレベル出し訓練

3D表示で以下を実現したい。

- 左右回転
- 上下回転
- 拡大縮小
- 平行移動（可能なら）
- 支持点表示
- レベリングボルト表示
- 調整対象ハイライト

### 画面5：結果表示

- 現在のレベル状態
- 前後左右差
- ねじれ
- 精度影響
- 推奨調整箇所

---

## 3. 3D機能でやりたいこと

### 必須
- マウスドラッグで左右回転
- タッチ操作で回転
- ホイール / ピンチで拡大縮小

### できれば欲しい
- 部品の選択
- 機械内部の簡易表示
- 支持点クリック
- 透明表示切替
- X/Y/Z軸表示

---

## 4. 技術的な方向性（初期案）

Webブラウザ上で動かすなら、以下のような方向性がある。

- HTML / CSS / JavaScript
- 3D表示は WebGL 系
- three.js などを使う構成が有力
- 初期版は精密CADではなく簡易3Dモデルで良い

---

## 5. UI上の重要ポイント

- 実機そっくりより、学習しやすさ優先
- どこが固定で、どこが移動するか分かること
- どこをレベル調整するか見えること
- 不具合時にどこがどう狂うか見えること
- 3Dでも操作が難しすぎないこと

---

## 6. 初期版でおすすめの対象

- 標準立形
- 横形
- 移動コラム立形
- 固定門型
- 移動門型

この5つをまず作り、その後に5軸や旋盤へ広げるのが現実的。
