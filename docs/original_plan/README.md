# 訓練ツール開発パッケージ

このZIPは、社内向けの **電気訓練ツール / 機械訓練ツール** の企画整理と、
ChatGPT Work などにそのまま渡して調査・設計を進めてもらうための資料です。

## 同梱ファイル

- `README.md`
- `00_プロジェクト概要.md`
- `01_Work向け調査依頼.md`
- `02_機械訓練ツール_UI構想.md`
- `03_機械分類_初期案.md`

## 目的

まずは大きく以下の2系統の訓練ツールを作る想定です。

1. 電気訓練ツール
2. 機械訓練ツール

その中でも、今回の重点は **機械訓練ツール** です。

## 機械訓練ツールの方向性

- 縦型NCフライス
- 横型
- 門型
- 移動コラム
- 5軸
- その他の主要な加工機械

などを分類し、まず「どんな機械があるか」を徹底調査します。

その上で、各機械タイプに対して

- レベル出し（レベリング）
- 機械構造
- どこを調整するか
- レベル不良時にどこへ影響が出るか
- 精度や加工結果にどう影響するか

を学べる訓練ツールを作ります。

## 重要な最終イメージ

- 機械タイプを選べる
- 3Dで機械を表示
- マウス / 指操作で左右回転・視点変更できる
- 支持点やレベリングボルトを操作できる
- レベル不良時のねじれや変形イメージを見られる
- 精度影響を視覚的に理解できる

## 次のアクション

まずは `01_Work向け調査依頼.md` を Work に渡して、
対象機械の洗い出しと分類の深掘りを依頼してください。
