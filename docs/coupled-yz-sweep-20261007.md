# 小型YZと触れの共通仮想姿勢への再調整

## 開始状態と依頼

作業開始時mainはe1170706a6d3c3215e4fb895f73fe8d7cc0ddc22、作業ツリーはクリーン。ユーザーは前回のYZ支持変化50倍を大きすぎると指摘し、触れも同時に連動するよう再調整と独立再確認を依頼した。

## 問題と修正

前回はYZの数字だけを `I0+50(I−I0)` に置き換え、触れは元の主軸姿勢のままだった。今回この数値後掛けを完全に撤去。小型の前後支持応答を中央で約5倍にする共通仮想主軸姿勢を設け、Z送りの有限測定と4方向の触れの両方を、その姿勢と各基準面との接触から計算し直す。

```text
前：元の接触計算 → YZ数字だけ支持分×50
                  → 触れは元の姿勢
後：支持から求めた固定の追加回転 R
      ├ Z送り・計器取付姿勢 → 300 mm有限走査 → YZ（XZも同じ姿勢）
      └ 主軸軸線・計器位置 → 上面との接触 → 右・奥・左・手前
```

黄色で指定され撤去した追加欄は復活させていない。元のUI内で「仮想測定（触れと共通姿勢）」を表示し、式・模型との違いを既存の説明へ記載した。

## 式と測定仕様

支持状態・寸法を固定し、軸中央X=Y=Z=0、固有誤差なしの方向X/Y/Zを求める。Y/Zを基準Xに垂直な面へ投影し、その直角からの符号付き差δを算出。同じ支持平均平面だけの差を除く。

追加回転は `R = 基準X軸まわりの回転(4δ)`。この同じRをZ送り方向、主軸中心線、取付姿勢、支持基点から計器本体への位置ベクトルへ適用する。支持・寸法ごとに固定し、現在のテーブル位置やカメラではRを変えない。固有誤差は元の姿勢に一度だけ含め、増幅しない。

中央では支持由来の前後応答が約5倍になる。全移動域の数値を厳密5倍にする仕様ではない。共通の剛体傾斜には追加補正なし。これは新しい実機弾性モデルではなく、測定専用の仮想姿勢という教材上の規則。

YZは測定PのY送りとZ送り、触れは主軸とテーブル上面を基準にするので、YZと奥の値を強制的に同じにしない。触れは手前0、右・奥・左は手前差。奥側の変化と右・左の手前差が同時に変わり、丸め前は右＋左＝奥を維持。手前が面外なら全数値を抑止する。

## 例・変更の影響

標準寸法・中央・固有XY=33/XZ=75/YZ=−15の例：Aの粗+0.01 mmで、YZ変化は前回約−1.189 µmから約−0.119573 µmへ。奥の触れ変化は約−0.119735 µm。右−0.411430、左+0.291695、手前0 µm。右/左には元の左右方向の支持効果もある。

整数µm表示なので1回ごとに必ず数字が変わるとは限らない。連続操作ではYZと触れの両方の変化を確認できる。微調整0.001 mmの量は維持。

単一の固定姿勢を優先するため、中央以外のXZには微小な交差影響がある。今回の120条件では最大0.0000301 µm。全許容状態でこの最大値以下という証明ではない。XYの送りと基準は元のまま。他6機種の仕様を変えず、横形・旋盤へ触れを追加していない。

## 元モデル・保存との区別

生の `geometryModel`、`referenceScan`、既定の `spindleSweepGeometry` は元の物理幾何を保持。UIの有限測定は `referenceDisplayScan → compactMeasurementGeometry`、小型の触れUIは `spindleSweepGeometry(..., 1, true)` を使う。

模型の柱・部材姿勢、支持面、水準器、局所角度、調整評価、参考最良は元の教材モデルであり、測定専用の仮想姿勢とは別。画面説明にこの違いを明記した。固定コラムがテーブル送りで傾く処理は入れていない。

保存形式・高さ・個体・軸位置は変更しない。旧保存を読むと測定欄は今回の共通姿勢で再計算されるので、前回50倍表示とは異なる。保存復元・初期比較・ページ再入場時のリセット/再抽選を維持。新測定表示識別子はcompact-shared-posture-v1。

## 独立確認と再修正

修正担当と独立数値担当・実ブラウザー担当を分離した。

1. 独立担当が、主軸方向だけを回して計器位置のZ移動が元の方向に残る不一致を検出。計器位置も同じ基点回転に修正し、Z移動接線＝仮想主軸軸線を再確認。
2. 携帯実ブラウザーで「触れ（共通）」が不自然に折り返す問題を検出。見出しを元の「触れ」へ戻し、共通姿勢の説明は既存の測定注記とARIAへ移した。
3. 既存の物理スイープ検証は維持し、UI値が元模型と同じという旧期待だけ、独立に求めた共通仮想姿勢の面接触期待へ更新した。

新規独立検証は120ケース・2755比較。計器接触の独立平面交点、正負支持、既知角、固有誤差、剛体傾斜、反対接触側、始終点交換、固定姿勢、面外抑止などを確認。既存フレ323件も成功。実ブラウザー画像と詳細は [QA記録](qa-coupled-yz-sweep-20261007/) を参照。
