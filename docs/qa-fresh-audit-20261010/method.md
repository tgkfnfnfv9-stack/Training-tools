# 横形の測定方法を物理から確認する — 2026-10-10

対象は横形のみ。初期導出はソース・過去QA表を読まず、指定された機械構成から行った。その初期成果を主担当へ送った後、引継ぎと現行ソースを照合した。製品コードは変更していない。確認対象HEADは `5d95690c5875efe53268d319efcac62dce22cce8`。この文書は実機の規格適合や特定メーカーの検査標準を認定するものではなく、**成立する測定配置と、その配置で必要な符号条件**を記録する。

## 先に確定できること

- 横形Xはコラムと主軸側、Yは主軸頭、Zはテーブル／パレットが動く。
- 直角マスタはテーブル側、計器は主軸側。バー検査では搭載先が逆で、バーは主軸固定、計器はテーブル側。
- 主軸は検査中に回転させない。a/bは別々の取付けであり、主軸を回して計器を9時から6時へ移す測定ではない。
- **XY/XZ/YZという平面名だけでは読みの正負は決まらない。** Rに合わせる軸、Sを走査する軸、接触側、正方向の定義、再取付け／ゼロの扱いが必要。
- 現行YZは古い引継ぎと測定方法が異なる。旧方式の期待符号を現在のYZへそのまま移せない。

## 座標・押込み・NCを分ける

ここで `x右、y上、z奥／主軸側` は図を読むための名目物理方向とする。現在のアプリの「部材＋X／＋Y／＋Z」もこの向き。これはNC指令符号の認定ではない。

|操作|動く部材|動かない部材|名目の部材＋|注意|
|---|---|---|---|---|
|X|コラム、Y案内、主軸頭、主軸、取り付けた計器／バー|テーブル、パレット、そこに固定した器具|右|Yの現在位置は保持する|
|Y|主軸頭、主軸、取り付けた計器／バー|コラム、テーブル、パレット|上|コラム全体を上げる操作ではない|
|Z|テーブル／パレット、その上のマスタまたは計器|コラム、主軸頭、主軸固定バー|奥・主軸側|工具側とワーク側の相対運動は逆向きになる|

実機NCの＋を決めるには、その機械の座標定義と実移動を別途確認する。例えば「工具のワークに対する＋z」をNC＋Zとする定義では、工具が止まってテーブルだけ動く場合、テーブルの物理＋zはNC−Zとなる。この条件例を、現在アプリの部材＋Zや個別実機のNCへ無条件に当てはめない。

`u` を「計器本体から接触面へ向く測定子」、`b` を本体位置、`q` を面上の点、`n` を面法線とすると、平面接触での測定子の伸びは

```text
伸び s = n・(q − b) / (n・u)
読み I = 始点の伸び s0 − 終点の伸び s1
```

したがって測定子が縮めば＋。本体／面の姿勢が固定され、測定子が面に直角な局所例では、`ΔI = u・(Δb − Δq)`。対象面へ本体が10 µm近づく、本体へ対象面が10 µm近づく、どちらも＋10 µmとなる。回転する腕や面には姿勢変化と接触位置の移動も入るため、この並進例だけで任意のねじれ状態の数値を予測しない。

「測定子が本体へ引っ込む向き」と「本体を固定面へ近づける向き」は反対。例えば右側本体から左へ測る場合、測定子が本体へ引っ込む矢印は右向き、本体を面へ近づける矢印は左向きである。

## 成立する方法は一通りではない

ソースを読む前に導いた一例は、XY＝R:X／S:Y、XZ＝R:X／S:Z、YZ＝R:Y／S:Zである。YZにはR:Z／S:Yも成立する。一般に、直角マスタのRを一方の相対送りに合わせ、直角なSを他方の相対送りで比較する方法が考えられる。

ただし、RとSを交換すると次が変わる。

- 計器とマスタのどちらが走査中に動くか。
- 計器を当てる面とその側、正の走査方向。
- マスタを合わせる送り区間、接触高さ、腕の長さ、支持姿勢変化の影響。

理想的な直線軸・一定姿勢なら同じ直角関係を検査できても、符号や有限区間の数値を無条件に同一視できない。「相反方法だから必ず反転」とするのも不正確であり、接触側と走査向きを固定して比較する必要がある。

## 現行方式を図で確認する

下図は機械カメラとは独立した方向図。`[D]` は計器本体、矢印 `←/→` は測定子が本体から面へ向く向き。器具寸法・腕は模式化している。

### XY — RをX送りで合わせ、右側SをY送りで測る

```text
               y上
                ↑           主軸頭・計器のY部材＋
          S     │                 ↑ 300 mm
       マスタ   │ ←──[D]          終点
                │
                ● ←──[D]          始点0
         R ─────┘
           テーブル固定                    → x右

R合わせ：主軸側のR用計器をXへ300 mm送り、Rの両端を等指示。
S測定 ：S用の腕へ付替え、下側で0。計器は右から左へ接触。
```

主軸頭が上昇しながら、固定Sに対して本体が右へ10 µm離れれば−10 µm、左へ10 µm近づけば＋10 µm。これはR合わせ済み・面／腕の姿勢一定という単純例。

### XZ — RをX送りで合わせ、右側SをテーブルZ送りで測る

```text
                z奥・主軸側
                ↑     マスタ／テーブルのZ部材＋ 300 mm
          S     │     ↑
       マスタ   ● ←──[D]  主軸側計器は固定
                │
         R ─────┘
                ↓ マスタから見た計器は手前へ300 mm
                                               → x右

R合わせ：主軸側のR用計器をXへ300 mm送り、両端を等指示。
S測定 ：S用へ付替え、相対的に奥側で0。右から左へ接触。
```

Z送りに伴ってSが右側の本体へ10 µm寄れば＋10 µm、左へ10 µm離れれば−10 µm。XYと同じ右側接触でも、S測定で動くのは面側である。

### 現行YZ — 上面RをZ送りで合わせ、主軸側SをY送りで測る

```text
                y上
                ↑
         R ─────┐       R用計器は上から接触
       マスタ   │ S ←──[D]  終点
                │       ↑ 主軸頭・計器のY部材＋300 mm
                ●   ←──[D]  始点0
         テーブル固定                         → z奥・主軸側

R合わせ：主軸側の計器を止め、テーブルをZ部材＋300 mm。
        上面Rの両端を等指示にし、厚み中央線も両端で合わせる。
        マスタ固定を維持し、選択Z位置へ戻す。
S測定 ：S用の腕へ付替え、下側で0。奥から手前へ接触。
```

Y送りで本体がSから奥へ10 µm離れれば−10 µm、手前へ10 µm近づけば＋10 µm。**S測定中にテーブルをZ送りする方式ではない。**

### Zバーa/b — 主軸固定バーを、テーブル側計器で測る

```text
先端側から主軸を見る接触配置           長手方向

             y上                 先端側               主軸側
              ↑                   0 ●================● [主軸]
       [Da] → ○ バー                [D] ─────────────→
              ↑                        テーブル＋計器
             [Db]                  部材＋Z、300 mm、バー固定
                 → x右

a：左9時から右へ接触。  b：下6時から上へ接触。
主軸を回さず、a/bそれぞれ先端寄りで0を取る。
```

姿勢固定の単純例では、aの本体が固定バーへ右に10 µm寄れば＋10 µm、bの本体が上に10 µm寄れば＋10 µm。反対側から接触するなら、この同じ偏りに対する読みは逆になる。テーブルにマスタを載せるXZと、テーブルに計器を載せるaで、**搭載先が逆という理由だけで必ず符号が逆になるわけではない**。例えばテーブルの純粋な右ずれ10 µmでは、現在の接触側なら両方＋10 µmとなる。

## 現在の全5項目の固定条件

|項目|R方向合わせ|Sまたはバー接触|本測定で動く部材|計器から面への測定子|開始→終了|
|---|---|---|---|---|---|
|XY|下面Rへ下から上向きに接触し、主軸側計器をX＋、300 mm|マスタ右側縦面S|主軸頭＋計器をY＋|左 −x|下→上、300 mm|
|XZ|奥側Rへ奥から手前向きに接触し、主軸側計器をX＋、300 mm|寝かせたマスタ右側S|テーブル＋マスタをZ＋|左 −x|マスタ上では奥→手前、300 mm|
|YZ|上面Rへ上から下向きに接触し計器固定。テーブルZ＋、300 mm。厚み中央線を両端で合わせる|マスタ主軸側縦面S|主軸頭＋計器をY＋|手前 −z|下→上、300 mm|
|a|R/Sなし。主軸固定円筒バー|左側9時|テーブル＋a用計器をZ＋|右 ＋x|先端寄り→主軸寄り、300 mm|
|b|R/Sなし。主軸固定円筒バー|下面6時|テーブル＋b用計器をZ＋|上 ＋y|先端寄り→主軸寄り、300 mm|

全測定とも本走査の始点で0、途中で再ゼロしない。直角3項目は支持・軸位置・寸法・個体が変わるたびにR方向合わせ、S腕の付替え、始点ゼロをやり直す。バーa/bもその状態の始点でバーへ合わせた計器位置を作り直してゼロとする。スライダー現在位置が走査始点と一致するとは限らず、300 mmを確保するため端では始点を制限する。

**付けたまま支持をいじった直後の指示**と、**その支持状態で取付け・方向合わせ・始点ゼロをやり直した300 mm指示差**は別の観測量。現在の数値は後者である。同じ器具・同じ姿勢で始終点を入れ替えてゼロを取り直す逆走なら指示差は反転するが、器具の再方向合わせからやり直す別測定の数値まで単純に反転する保証はない。

## 一次の角度式で符号を比較できる範囲

以下は直線送り、走査中の部材姿勢一定、マスタR完全合わせ、一定の接触側、小角、腕の回転なしに限定する。`eX/eY` は主軸側の物理＋X/＋Y方向、`vZ` はテーブルの物理＋Z方向、長さ `L = 300 mm`。

|現在の配置|一次の指示差|具体的な＋方向の横ずれと読み|
|---|---|---|
|XY、右から接触、頭Y＋|`I ≈ −L (eX・eY)`|Y送りが右へ10 µm偏ると−10 µm|
|XZ、右から接触、テーブルZ＋|`I ≈ ＋L (eX・vZ)`|Zテーブル送りが右へ10 µm偏ると＋10 µm|
|YZ、奥から接触、頭Y＋|`I ≈ −L (eY・vZ)`|Y送りが奥へ10 µm偏ると−10 µm|
|旧YZ、上から接触、テーブルZ＋|`I ≈ ＋L (eY・vZ)`|同じ軸関係でも現行YZと一次符号が逆|

旧YZから現行YZへの符号反転は、この条件では方法変更から導かれる。現在の符号を誤りと断定する根拠にはならない。ねじれ、案内の曲がり、送りに伴うパレット姿勢変化、長い取付腕の回転がある場合は、有限面との接触を追う必要がある。

バーの場合は、姿勢固定・小角で、`Z＋送りに伴う計器本体の右／上偏り − 同じ走査位置でのバー表面の右／上偏り` がa/bの＋方向の指示差になる。パレット基準点の移動量だけでは不足し、バー高さへ達する腕の運動を含める。

## 修正判断前に必要な最小確認

1. 5項目それぞれで、器具を固定したまま本体または対象面を既知量近づけて押込み＋となることを独立確認する。
2. 現在のR/S方式で、XYのY送り右ずれ、XZのZテーブル右ずれ、YZのY送り奥ずれ、a/bのテーブル右／上ずれを、既知の±入力で比較する。
3. 方式を固定した逆走と、方向合わせから取り直す別走査を分ける。
4. ねじれ状態では取付高さと腕を固定し、R合わせ・S走査・途中接触を含めて比較する。局所角度の符号表を有限測定の正解にしない。

この段階の結論は、**古いYZ方式の期待を現在へ持ち込むことと、部材＋／NC＋／押込み＋を一つの符号にまとめることが誤判定の原因になる**という点。現在の全数値が正しいという認定も、全項目の符号を反転すべきという認定もしていない。
