再現: 上記の平坦中央状態を両版で開き、上段YZ図と▽のYZ説明を比較する。

|画面から確認した内容|公開版|PR32|

証拠: [公開の3図](public-diagrams-flat.png)、[PRの3図](pr-diagrams-flat.png)、[公開の手順](public-YZ-movement-steps.png)、[PRの手順](pr-YZ-movement-steps.png)。

観測と期待の差: 利用者には同じ「YZ」と「300 mm」の数字として見えるが、実際はR/S、接触面、送り、図の投影まで違う。数値の単純な誤反転と扱うのも、符号が変わったから修正成功と扱うのも不適切。取付先だけを同じにしても測定法は一意に決まらない。方法を固定してから計算の良否を判定する必要がある。

現図は展開図として説明と合っているが、小図だけでは「マスタが動くのか計器が動くのか」が直接明示されない。XZの『相対 手前』を、スライダーの『部材＋ 奥』と同じ対象への矢印だと読む余地がある。詳細には相対移動と部材移動の区別がある。この説明を読まずに図から実部材を特定できる状態ではない。

## 優先2 — 同じ画面でXZが+8と−8になる

再現: PRの上記平坦中央状態で▽を開き、下の詳細欄を末尾までスクロールする。上段のXZは **+8 µm**、下のXZ欄末尾は **「従来の局所角度差：−8 µm／300 mm換算。上の表示値とは別です。」** になる。

証拠: [同じ画面に+8と−8](pr-detail-XZ-bottom.png)。上段の生値は+8.128999999 µm。公開版にも同種の対比がある: [公開版](public-detail-XZ-bottom.png)。

観測と期待の差: 「別です」という注記は存在する。一方、この場所に局所角度の正負定義や、接触指示と符号が異なる理由は書かれていない。同じXZ、同じµm、同じ300 mmとして上下に現れるので、利用者が『数字が逆になった』と読む具体的な経路がある。これは同一接触量の計算反転を確認した結果ではない。局所角度を現在の測定結果の補助として並べる必要性と、並べるなら両者の関係をどう示すかが未解決。

## 優先3 — 主軸頭が上へ動いても測定区間と数字は変わらない

再現: PRの平坦中央でY軸を選び、「設定」→「軸位置・デモ」を開く。Yスライダーを中央から上端へ移す。設定を閉じ、▽内のYZ測定区間を見る。

|入力・観測|Y中央|Y上端|
|---|---|---|
|スライダー値|0|+100|
|模型|中央高さ|主軸頭が上昇。コラム・パレットは同じ位置|
|XY生値|16.958999991522823|16.958999991522823|

証拠: [中央の模型と区間](pr-Y-central-range.png)、[上端の模型と同じ区間](pr-Y-plus-range.png)、[Y上端の操作欄](pr-Y-plus-controls.png)、[補助ログ](focused-observations.json)。

観測と期待の差: 「スライダーの現在位置と接触ゼロ位置は同じとは限りません」という説明は詳細中にある。しかし上段小図の0と現在の模型に別々の位置表示がなく、画面だけでは『今ここから測っている』と受け取りやすい。現在位置から300 mmを走査する表示と受け取れば、Yを上げても数字・小図が不変なことは停止に見える。実際の観測は同じ区間の測定であり、この例を未更新バグとは判定しない。模型の現在位置と自動で確保した測定区間の区別を表に出す必要がある。

また、現在の3Dには計器、取付腕、直角マスタが表示されず、ワークが残る。説明では測定時にワークを外す。主軸頭の現在位置から、その図のS面に測定子がどの腕で届くかを画面で照合できない。取付高さの成立判断は別担当の幾何照合が必要であり、この見た目だけで成立としない。

## 実部材の動きで確認できたこと

中央→各軸の部材＋端を順に操作した。画面の部品ラベルと模型から、Xではコラムと主軸頭が一緒に横移動、Yでは主軸頭だけ上昇、Zではパレット台・パレット・ワークが主軸側へ移動した。固定ベースが軸送りに追従する異常はこの操作では見られなかった。

証拠: [中央](pr-flat.png)、[X部材＋](pr-X-plus.png)、[Y部材＋](pr-Y-plus.png)、[Z部材＋](pr-Z-plus.png)、[Zの説明・操作](pr-Z-plus-controls.png)。スライダー説明は部材方向であり、NC指令符号ではないと明記している。実機NCの＋／−へ読み替える根拠は今回確認していない。

Z平行度の展開にはPRで「バー:主軸に固定」「計器:テーブルに固定 → 主軸側へ」がある: [PR展開](pr-bar-detail.png)。取付先とテーブル側が動くことは文章・小図で確認できたが、3D模型上にこの測定器具はない。XY/XZ/YZとの配置の違いを実機配置として視覚的に照合できる証明にはならない。

## 支持操作の小さい追加確認

平坦中央からB（右・手前）を選び、粗調整で上げる→下げる、微調整で上げる→下げるを実クリックした。選択支持と実際の保存高さは一致し、戻すと生値は復帰した。

|PRの入力|XY生値 → 整数|XZ生値 → 整数|YZ生値 → 整数|
|---|---:|---:|---:|
|全0|16.959 → +17|8.129 → +8|−14.120 → −14|
|B +0.010 mm|16.959 → +17|8.597 → +9|−12.544 → −13|
|B +0.001 mm|16.959 → +17|8.176 → +8|−13.962 → −14|

証拠: [B粗+0.010](pr-B-coarse-plus.png)、[B微+0.001](pr-B-fine-plus.png)。この微操作では生値更新はあるが整数表示は変わらない。粗操作ではXZ/YZ整数も更新された。したがってこの例の『変わらない』を更新停止とは呼べない。粗微の主画面は小さい上段図と整数しか見えず、微操作の変化量をそこで読み取れないという操作上の限界は残る。

支持全点総当り、寸法変更の全境界、実機NC符号、実治具の干渉・剛性、実携帯端末は今回の範囲では未確認。微調整の総合評価と測定値の関係は計算追跡担当の報告を参照する。このブラウザー監査では製品変更、式変更、公開をしていない。
