## 独立な定義と式

面上の点P、法線n、計器本体B、測定子の**伸び方向**単位ベクトルdを使う。接触点は `B+λd` なので、

```
n・(B+λd−P)=0
λ = n・(P−B) / (n・d)
I = (λ開始−λ終了) × 10^6 µm
```

押込み方向は `−d`。これは計器本体が固定面に近づく移動方向と反対になることがある。例：面x=0、本体x=10mm、測定子は−x。本体がx=9.99mmへ移動すると伸びが10µm減り、指示＋10µm。測定子自身の本体に対する押込みは＋x。従って「本体＋X移動」と「ダイヤル＋」は別。

反対側で本体x=−10mm、測定子＋xなら、同じ本体＋10µmの世界x移動が押込み＋10µmになる。

固定された同じ機械・基準器・計器配置の端点A,Bを交換し、新しい開始点で**指示だけ**ゼロにする場合、姿勢変化があっても `I_BA=λB−λA=−I_AB` は厳密に成立する。これに対し、基準器の方向合わせ・計器本体の取り付け位置まで変更すると別配置なので、負号だけでは予測できない。

傾いた面 `x=βy` と本体経路 `x=h+αy`、測定子−x、走査Lなら `I=(β−α)L×10^6`。αは機械経路、βは基準器方向合わせ誤差。L=0.3m、α=20µrad、β=50µradなら機械のみ−6µm、合わせ誤差のみ＋15µm、両方では＋9µm。一つの指示値だけではαとβを分離同定できない。

経路 `x=h+ky²`、k=0.0001/m、0→0.3mなら有限値−9µm。始点局所接線の300mm換算は0、終点では約−18µm。局所と有限値は等しくない。

本体と面の距離が10mmのままでも、測定子が面法線からθ傾くと `λ=0.01/cosθ`。θ=0.04radでは約−8.005µm。従って指示値だけから本体の法線方向移動量を一意には描けない。

共通剛体変換 `P'=RP+t, B'=RB+t, n'=Rn, d'=Rd` は内積を保存し、λとIを変えない。純粋なカメラ変更・ズーム・描画誇張も測定値へ入れてはならない。

## 修正範囲の提案

表示だけで直せる事項：押込み方向と本体接近方向の区別、固定配置逆走と再設置の区別、方向合わせ面Rと読み面Sの明示、5軸支持境界の記録訂正、旋盤の内外呼称、旧局所値と有限走査の意味・属性の分離。機種固有の投影を物理方向として明記する。

計算変更の判断が必要な事項：全機種で模型の特定固定点に基準器・計器を取り付けた共通運動学にするか、現在の仮想代表点を維持するか。前者は固定点の座標、取付オフセット、軸送りの速度定義、姿勢輸送が必要。指示式自体は維持できても `P(s),B(s),n(s),d(s)` が変わり、既存有限値が変わる。既存局所評価・固有誤差・保存JSONを同時に改変する必然性はない。読みの定義・運動学を変更するなら派生測定の仕様IDを明示し、旧保存が同じ機械状態として復元されることを別に検証する。

本担当ではアプリ・公開indexを変更していない。取付可能性、衝突、現場測定としての妥当性、全支持状態の途中接触継続は未確認。130件の成功は、以上の仮定が現実の全7機種に適切であることの証明ではない。
