# 測定配置・図の修正（reference-scan-v3）

開始時main：`127b3ece7da64cab5d1fb9bbb998313d739fd905`。全面点検結果の提出後、ユーザーの「修正して」を受けて実装した。元のUI、全7機種、支持数4/8/6/15/8/3/6、軸の部材座標、局所角度・支持調整評価、保存JSON、既存5機種の4方向測定は維持する。

点検時の不一致と全19面の対応は[点検報告](coordinate-audit-20261007.md)を参照。報告は修正前の記録であり、以下が修正後の仕様となる。

## 修正したもの

1. 新測定SVGから旧局所角度図のゼロ・正負方向・投影・先端位置属性を除いた。局所図の属性は局所図だけに残す。新図は測定ゼロ、基準/走査軸、展開図の上/右、有限指示値を専用属性で持つ。
2. R（方向合わせ面）とS（読みを比較する面）を識別。Rは破線、Sは実線。旋盤はSのみ。小図上端の↑は展開図の上の実方向、オレンジ矢印は計器の相対走査、下段の押込＋は測定子が本体へ戻る方向。
3. 図の本体変位を指示値Iから逆算する方式を廃止。S面に固定した座標で計算済みの本体位置・接触点・測定子方向から描画する。法線変位は6µm/SVG単位、測定子傾きは1000倍を基準とし、枠内に制限。破線は本体の始終位置を結ぶ目安で、連続軌跡ではない。純粋な測定子傾きで指示だけ変わる場合、本体が横に動いた図を作らない。
4. 部材符号とNC指令を区別。スライダー端を部材−／＋と機械の実方向に変更し、現在位置の表示・読み上げも左右/前後/上下に対応。A/Cは部材負側/正側。保存するpositionsの符号・値は変えていない。
5. 旋盤の部材−X・手前を、現模型の手前側工具では径外向きと訂正。主軸基準XZと往復台Z送りを引き続き区別し、Y検査を追加しない。
6. 横形Z走査の基準器原点をパレット上面中心に定義。小型Yの既存測定Pと同様、模型上の同一点の有限変位を使う。横形用の変換は模型と測定で共有し、表示誇張は測定に入れない。
7. 姿勢が変わる走査では端点に加えて16分割の内部点を確認。横形は支持補間境界と両側も確認する。測定子範囲外・面外があれば数値を抑止する。有限サンプリングであり、連続経路・干渉の完全検査ではない。

## 維持する測定配置

|機種|XYの計器相対走査|XZ|YZ|
|---|---|---|---|
|小型立形|手前右ゼロ→奥|上右ゼロ→下|上奥ゼロ→下|
|横形|下右ゼロ→上|奥右ゼロ→手前|奥上ゼロ→手前|
|移動コラム|手前右ゼロ→奥|上右ゼロ→下|上奥ゼロ→下|
|固定門形|左奥ゼロ→右|上奥ゼロ→下|上右ゼロ→下|
|移動門形|左奥ゼロ→右|上奥ゼロ→下|上右ゼロ→下|
|5軸 A=C=0|手前右ゼロ→奥|上右ゼロ→下|上奥ゼロ→下|
|旋盤|対象外|主軸Z基準、刃物台Xを奥→手前|対象外|

基準軸と走査軸は交換しない。旋盤以外はXY=X基準/Y走査、XZ=X基準/Z走査、YZ=Y基準/Z走査。5軸A/C非ゼロでは3面の値を抑止し、既存4方向測定だけが旋回姿勢を反映する。

300mmのlow/high区間と再方向合わせ・再ゼロはv2のまま。スライダー位置が必ず接触ゼロ位置になるわけではない。R面は始点の基準軸局所接線へ合わせ、Sは校正された直角面を仮定する。平定盤側面の直角精度は仮定しない。同じ固定配置で指示だけ再ゼロして逆走することと、方向合わせから取り直すことは別。

## 横形の変更式

基準器取付原点の模型座標は `[0,1.27,-0.85]`。高さの支持基準は0.66mなので、腕長は0.61m。寸法変更では横方向座標を従来の物理寸法へ変換し、高さは従来どおり保持する。

非一様支持の場合、部材位置の支持点O、姿勢R、原点に固定されたオフセットhに対し、`P=O+R h`。固有Z方向の偏差も模型と同じように加える。`horizontalPalletPoint(raw,state,solution,profile,factor)` は旧模型の変換を抽出した純粋な点変換で、測定はfactor=1、模型は表示誇張倍率を使う。旧模型との86,400点比較は最大差3.58×10⁻¹⁵mだった。

始点原点からの差 `P(s)−P(s₀)` と、始点から輸送した法線n・測定子方向u・本体Bで次を解く。

```
λ = n·(P−B) / (n·u)
I = (λ始−λ終) × 10⁶ µm
```

接触式は維持。固有誤差なし、軸中央、支持値 `[.2,-.2,.067,-.067,-.067,.067,-.2,.2] mm` の横形XZ例では、旧モデル約0µmから **−14.612552µm（画面−15µm）** になる。これは模型上面の移動に基づく変更であり、画面だけの符号反転ではない。

小型Yは既存のPをそのまま使い、同じ高さ効果を二重加算しない。その他の対象走査は現機種の姿勢一定区間の代表点を維持。5軸は3点支持の一定平面なので、Yに支持格子境界があるという旧記録を訂正した。基準器の実寸・固定具の干渉・旋盤の絶対接触半径は引き続き再現しない。

## 保存互換性

機械計算ID、保存version、キー、支持高、個体、軸位置、局所角度、支持最適化は変更しない。`reference-scan-v3`は派生する表示測定の仕様ID。旧JSONから同じ機械状態を復元でき、横形XZ/YZの有限値を新しい取付点で再計算する。旧有限値そのものの再現は約束しない。手動の保持ゼロ履歴・新規固定具入力・新規ガイド曲線は追加していない。
