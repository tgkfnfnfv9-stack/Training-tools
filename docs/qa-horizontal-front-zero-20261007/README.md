# 横形 Z 平行度・正面接触位置の独立確認（2026-10-07）

対象は既存の右上 Z 平行度枠内だけ。提供画像と同じく、円の左側から右向きの接触を **a 0（9 時）**、下側から上向きの接触を **b 0（6 時）** と表示する。右の長手方向略図は先端寄りの共通ゼロ位置と主軸側への 300 mm 走査を示す。円周上の接触方向と、長手方向のゼロ位置を別の図で表した。

## 検証方法と結果

- 修正担当と別の確認担当が、修正前 `b1e5cca` の公開用 HTML を `git show` から固定し、Chromium 実ブラウザーで比較した。
- `node tests/browser-horizontal-front-zero.cjs before` と `after`。7 機種 × 幅 1280 / 390 / 320 px、固定支持・固定固有誤差・固定軸位置。
- **127 / 127 成功**。横形では枠外の全画素、他 6 機種ではページ全画素が修正前と一致。数値、枠外の要素位置、既存の詳細図も一致。
- 横形の枠は従来どおり **64 × 77 px**。図は **56 × 31 px**。
- a 接触点が円の左端、b 接触点が下端であること、両方に 0 表記があることを確認。全テキストの SVG 境界内収容を実ブラウザーの getBBox で確認。
- 原寸ページ、枠の画像、4 倍密度のブラウザー描画で、矢印が左から円へ・下から円へ向くこと、ラベルの欠け・矢印との重なりがないことを目視確認。

## 検出して再修正した点

最初の案では a 0 の文字領域が SVG 上端を 2 px、b 0 と 300 mm が下端を 1 px 超えていた。独立確認で指摘後、文字の基準位置と矢印の尾部・矢頭を修正し、上記 127 項目を再実行して成功した。
