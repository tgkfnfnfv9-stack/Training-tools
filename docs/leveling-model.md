# レベル出しの学習用計算モデル

## 座標と単位

- 支持点は `{x,z,h}`。`x` は右が正、`z` は奥が正で単位は m。`h` は相対高さで単位は mm。
- この `x,z` は支持点配置の座標であり、機種ごとの工作機械 X/Y/Z 軸名とは別。
- 高さの一様な増減は全体位置だけを変え、傾き・ねじれ・平面偏差は変えない。
- 実機の支持点位置・荷重・剛性・基礎を再現していない。画面寸法は学習用寸法。

## 抽選した初期精度

`MachineAccuracy.generate(condition,seed,keys,count)` は32bitの種を持つ決定的抽選。機械／方式ごとに生成直後から自動保存し、軸移動・高さ調整・再表示で引き直さない。「別の個体を抽選」または新品／中古変更で新しい種を作る。各項目の抽選率は下表の**教材設定**であり、製造品質や中古市場の実測統計ではない。

|状態|一般的な誤差帯|大きい誤差帯|さらに大きい誤差帯|
|---|---|---|---|
|新品|95%：1〜20 µm|5%：20〜40 µm|—|
|中古|60%：5〜20 µm|30%：20〜60 µm|10%：60〜150 µm|

軸間直角度と、全直線軸のガイド真直度PVを個別に抽選する。表の確率は機械全体の良否割合ではなく、各誤差項目ごと。各帯の値は一様抽選し0.001 µmに丸め、直角度の符号は別に50%ずつ抽選する。

- 固有直角度は**300 mmの評価長**でのµm換算。1〜20 µm = 0.001〜0.020 mm。角度は `microns / 0.3 / 10^6` radで、現在表示の評価長を変えても角度・個体・練習目標を変えない。
- ガイドPVは仮想移動全域について抽選した固有の曲がり成分で、このモデルでは固定する。位置に依存する曲線や据付による案内真直度の変化、荷重変化は計算しない。実機の真直度がレベル調整で不変という意味ではない。A/Cの旋回精度は対象外。
- 初期支持高さは±0.150 mmで抽選し、最初の2点は−0.150/+0.150 mmとして据付時の誤差を保証。固有精度と据付の悪さは別の情報。
- ガイドPVと支持点の平面偏差は別の指標。ガイドPVを支持面のresidualから算出しない。

## レベル調整で精度の変化を学ぶ

学習の主画面は粗／精の独立パネルと共通の上下操作。新規は粗0.01 mm、精は0.001 mm。旧保存のstepを維持し、0.01 mm以上を粗、未満を精として推定する。明示切替は操作量のみを変え、個体・高さ・初期基準は更新しない。学習画面は現在・初期・差分・操作量・単位を数字で示さず、旧数値DOMをhiddenで保持する。保存形式と実計算値は維持する。

粗の判定は平均左右／前後の各±0.020000001 mm/m。気泡も同じ平均を参照し、感度や局所測定位置によらない。精は後述の既存参考targetを使う。参考目的では平均傾きに15%の重みを与えているため、精の支持姿勢が粗目安を少し外れることがある。粗完了を精切替の必須条件にせず、平均の状態を精画面に明示する。

粗ヒントは実候補の `lr²+fb²`、精ヒントは全代表位置の既存 `machineEvaluation().objective` を評価する。今の操作量で各支持点の上下候補を計算し、実改善がある候補だけ案内。単独候補がなければ複数支持の関係や参考例を案内し、成功扱いにはしない。粗手本は同高0、精手本は既存 `machineBestHeights()` を実際に適用して再評価する。

精目安内は参考との差であり、完全直角／全軸改善／実機合格ではない。全代表位置の合成直角差（300 mm換算）または固定ガイドPVが20.000001 µmを超えると残る誤差の注意を強める。この合成値は支持姿勢も含むので、本体だけを原因とはしない。合成倒れの定性区分は各20.000001 µrad、支持ねじれは±0.020000001 mm/mで小さめとする。これらは教材表示用でメーカー許容値ではない。

精開始時の総合objectiveをUIだけに記録し、以後の実objectiveと比較する。初期図の基準は抽選時のまま。個体・寸法・配置・評価長の変更、JSON読込（同じ個体でも）、初期戻し、別支持問題でUI基準を破棄する。UI基準は保存schemaに追加しない。保存fineの読込時は開始時比較が未取得として表示する。

抽選帯は固有成分の大きさであり、主画面の「抽選時」は据付姿勢も重ねた値。固有直角差の300 mm基準に対して、主画面では選んだ評価長を使うため、調整前の直角度が抽選帯の20 µm等を超える場合がある。

比較基準は個体の `initialHeights`、現在は `supportHeights`。両方を**同じ現在の軸位置、支持寸法、コラム配置、評価長**で計算する。

- 初期支持面：`machineSolution(machineProfile.initialHeights)`。
- 初期の姿勢・直角度：`geometryModel(positions, initialSolution, machineProfile, levelConfig.offset)`。
- 現在の姿勢・直角度：`geometryModel()`。
- 変化量：丸める前の `現在 − 初期`。表示値の差から計算しない。
- 90°との差が小さくなったか：`abs(現在の直角差) − abs(初期の直角差)`。負なら改善、正なら悪化。表示上は±0.005 µm以内の差を「ほぼ同じ」とまとめる。例えば+10→−20 µmは変化−30 µmでも、90°との差は10 µm大きくなる。丸め前の変化量・絶対差は保持する。

直角差の＋は90°より広く、−は狭い方向。倒れの＋は前／右、−は後／左を示す。支持面ねじれは奥の左右勾配−手前の左右勾配であり、部品のねじり角そのものではない。倒れの減少やねじれの減少だけで、全ての精度が改善したとは判定しない。

軸移動やコラム配置を変えたときも、初期と現在を同じ条件で再計算する。比較値は調整1回ごとの増分ではなく、抽選時の支持高さからの累積変化。「同じ個体で別の支持状態を試す」でも、比較基準は抽選時の支持高さを維持する。初期へ戻すと同条件の差は0になる。別の個体を抽選した場合は、新しい固有精度と初期支持高さへ切り替わる。

全代表位置の300 mm集約評価を、今の軸位置での初期直角度として流用しない。現在位置の直角度や姿勢は軸移動中も更新する。小さい差は定性的な増減を併記し、計算上の不変を誤って動かさない。直角図の広がる／狭まる方向はsigned差、近づく／離れるは絶対偏差の差として区別する。

## 平均傾きと平面偏差

全支持点に対して `h = a*x + b*z + c` の最小二乗平面を求める。座標と高さを正規化して計算する。

| 出力 | 定義 | 単位 |
|---|---|---|
| `lr` | 平面の `a`。右が高いと正 | mm/m |
| `fb` | 平面の `b`。奥が高いと正 | mm/m |
| `residual` | 支持点高さと最小二乗平面の高さの差の最大絶対値 | mm |
| `twist` | 奥の左右勾配 − 手前の左右勾配 | mm/m |

`twist` の左右勾配はそれぞれ、支持範囲の左端と右端の高低差を全幅 m で割った値。途中の支持点の盛り上がりは `twist` だけでは検出できないので、`residual` と位置ごとの勾配も併せて確認する。

## 位置ごとの学習用面

3点支持は一意の平面。`twist` と `residual` は 0 で、位置ごとの勾配は一定。

4点以上は、欠けのない長方形格子に配置した全支持点を使う。各セルで双線形補間するため、6点・8点の中間支持点の高さも面に反映する。`heightAt(x,z)` は mm の高さ、`slopeAt(x,z)` は `{lr,fb}` の局所勾配 mm/m を返す。入力の配列順には依存しない。

セル境界の高さは連続だが勾配は変わることがある。境界上では右／奥側のセル、最外境界では内側のセルの勾配を採る。支持範囲外では最外セルを双線形延長する。実際の据付評価の外挿ではなく、模式図が範囲外に張り出した部分に高さを与えるための便宜的な処理。

この面は「支持点に与えた高さをつなぐ教材」であり、ベースや案内面がそのとおり変形する物理計算ではない。下記の姿勢・直角度モデルの入力として使うが、剛性、荷重、接触、ねじの締付量、実機加工誤差は計算しない。

## コラム・案内の姿勢と直角度

`geometry(solution,{toolPoints,workPoints,axes,length})` は、工具側とテーブル／案内側が、指定した支持面の局所姿勢に従うという仮定の幾何教材。`length` は評価長 m。複数の `toolPoints` がある門形は、平均姿勢と個別コラムの姿勢を両方保持する。

`a=lr/1000`、`b=fb/1000` とし、上方向の単位ベクトルを `n=normalize([-a,1,-b])`、右方向を `ex=normalize([1,a,0])`、奥方向を `ez=ex×n` とする。3本は互いに直交する。固有誤差を持たない基準モデルの同じ傾斜面では工具側・案内側とも同じ回転になり、共通の床に対する傾きから直角不良は発生しない。

参照姿勢で回した各機械軸の単位方向ベクトルを `u`、`v` とすると：

- `δ = −asin(u·v)`：90°からの符号付き角度差 rad。正は90°より広い、負は狭い。
- 直角度の表示角度：`90 + δ*180/π` 度。
- 直角差：`δ*10^6` µrad。
- 評価長でのずれの微小角換算：`δ*10^6*length` µm。画面の評価長を変えても姿勢角は変わらない。
- 支持による床基準の前倒れ（既存 `toolLean`）：`atan(fb/1000)*10^6` µrad。奥高ならコラム上端は手前へ倒れる。
- 支持による床基準の右倒れ（既存 `toolLean`）：`−atan(lr/1000)*10^6` µrad。右高なら上端は左へ倒れる。
- 支持による相対姿勢差（既存 `relativeLean`）：工具側の前倒れ／右倒れ − テーブル側の同指標。

### 固有直角差の合成

固有直角差は単なる絶対値の加算ではなく、非直交の軸方向を作ってから各参照姿勢で回す。名目方向Xを固定し、YをXY誤差分だけX方向へ傾ける。ZはXZ/YZの内積がそれぞれ `−sin(δXZ)` / `−sin(δYZ)` となるようGram構成し正規化する。2軸はXZのみ。同じ支持回転なら内積が保持され、初期固有直角差がそのまま残る。

UIの「固有／支持姿勢」の内訳は各微小角換算の参考値。合計の角度は合成後の方向から正確に算出するため、内訳の数値和は厳密な回転合成ではない。支持調整は固有角度の一部を相殺できるが、同じ参照剛体にある軸間の誤差やガイドPVをすべて除去することはできない。

### 構造別の参照位置・軸の仮定

|構造|工具側の姿勢を採る位置|テーブル／案内側の基準位置|工具側の参照姿勢を使う軸|案内側の参照姿勢を使う軸|
|---|---|---|---|---|
|立形・標準／小型|後方コラムの根元（配置を変更可）|XYで動くテーブルの基準点|Z|X・Y|
|横形|Xで動くコラムの根元|Zで動くパレットの基準点|X・Y|Z|
|移動コラム|Xで動くコラムの根元|固定テーブル側の代表基準点|Y・Z|X|
|固定門形・長手方式|左右コラムの根元とその平均|Xで動くテーブルの基準点|Y・Z|X|
|固定門形・テーブルXY|左右コラムの根元とその平均|XYで動くテーブルの基準点|Z|X・Y|
|移動門形|Xで動く左右コラムの根元とその平均|固定テーブル側の代表基準点|Y・Z|X|
|5軸テーブル旋回形|後方コラムの根元|XYで動くトラニオンの支持基準点|Z|X・Y|
|2軸旋盤|固定主軸台の根元|X/Zで動く刃物台側の基準点|主軸基準Z|X|

水平案内全体の姿勢を代表点で表す仮定であり、実際の軸真直度や移動中の荷重による変形を算出するものではない。移動コラム・門形の主軸側で同じ姿勢を採る軸間の直角度は、この仮定では保たれる。それでも工具とワークの相対姿勢、左右コラムの倒れ差が残る場合があるため、軸の直角差が0だけで「同じ姿勢」と判定しない。

5軸の数値は直線軸の支持姿勢の比較で、A/Cの旋回誤差は含まない。旋盤は主軸台のZ基準と刃物台側のX方向を比較し、NCの2軸案内の全幾何精度を再現するものではない。Y軸・YZ指標は表示しない。

### 四点ねじれとコラムの位置

四点の純ねじれ `h=k*x*z` では、左右傾き `lr=k*z`、前後傾き `fb=k*x`。コラムが後方、テーブルが前方ならXZの関係が変わる。左右位置が同じ中央ならYZ差は0でも、テーブルをX方向へ動かす／コラムの左右配置を変えるとYZ差が現れる。中央でYZが0であることから全体の精度を判断しない。

コラムの据付配置は、模式図の左右幅の±20%、前後幅の±10%の範囲で変更する。固定コラムの構造比較用で、実機にコラムをスライド調整する機構があるという意味ではない。可動コラム／門は既存の軸スライダーの位置にも追従する。

### 代表位置の比較と調整練習

全直線軸を端1・中央・端2に設定した27位置（旋盤は9位置）を比較し、各直角差の最小〜最大を表示。現在位置は別計算。この比較は全ストローク走査ではなく、途中の局所的な最大誤差を保証しない。

調整評価は固定300 mmで、各位置の直角差、左右コラムの前後倒れ差、25%重みの工具／案内の相対前後・左右姿勢差を列ベクトルにし、平均左右・前後傾きの換算値へ15%重みと `sqrt(位置数)` をかけた2要素を追加。その二乗平均平方根を小さくする。ガイドPVは不変なので最適化目標に足して調整差を隠さず、別列で残留量を示す。

0高さで±0.05 mmの中央差分から二次目的の近似行列を作り、0高さと初期高さの2開始点から有界座標降下。±0.500 mm内・0.001 mm格子で単独支持の最良値と二点±0.001 mmの組合せを探索し、最後に厳密な回転モデルで探索値・0高さ・初期高さを再評価する。現在の手動調整がより良ければ参考値も更新する。探索結果は**参考最良**であり、非線形の全離散組合せに対する全球最適の証明ではない。

精度は全支持点の一様な高さ変更では変わらない。参考最良の適用とヒントは、相対高さを保ったまま現在の平均高さへ最も近い共通オフセットを使う。±0.500 mm内・0.001 mm刻みで調整し、参考と同じ高さの関係なら全点の不要な上下を勧めない。

「調整前」は抽選時の支持高さを、現在と同じ支持寸法・コラム配置で評価。「現在」と「参考最良」も同条件。残りは `sqrt(max(0,現在評価²−参考最良評価²))` とし0.1 µm以内を練習達成とする。固定の固有直角差が大きい中古でRMS差が縮む効果を取り除き、残る調整余地を評価する。進みは初期の残りに対する現在残りの減少割合（0〜100%、達成時100%）。全指標0や新品共通の絶対許容値を目標にしない。ガイドPVはどの状態でも残る。個体は同じまま支持状態だけ出し直す練習も可能。

### 合成倒れと3Dの代表姿勢

本体の固有倒れは、既存の個体・非直交軸方向から導く。新たな乱数や保存項目は追加しない。立形・門形・5軸は描画の鉛直に対応するZ方向、横形はY方向を代表とする。固有方向 `v0` を工具側の支持フレームで回した `v = toolFrame.rotate(v0)` に対して、合成前倒れは `atan2(-v.z,v.y)*10^6`、合成右倒れは `atan2(v.x,v.y)*10^6` µrad。左右コラムは個別支持フレームで同じ固有方向を回す。`bodyLean`・`bodyPosture` はこの合成姿勢、従来の `toolLean`・`relativeLean`・`columns` は支持による姿勢のままにして精度計算・参考探索を維持する。

旋盤の固有XZ差は水平面内の主軸方向のずれで、鉛直コラムの倒れではない。公称Z方向 `[1,0,0]` から固有方向へ最小回転を作り支持姿勢を重ね、主軸の上下方向差を `atan2(v.y,hypot(v.x,v.z))`、水平面の方向差を `atan2(v.z,v.x)` で表示する。

コラム／主軸の実体は、公称代表方向から固有方向への最小剛体回転を加え、その後に局所支持姿勢で回す。テーブル／案内側は支持姿勢で回す。門の左右コラムは個別支持姿勢、梁・主軸側は平均支持姿勢を使う。非直交のXYZ全てを一つの剛体回転で再現することはできないため、実体は代表方向の模式姿勢である。軸間の精度計算は既存の個々の非直交方向で行い、実体の固有回転を精度計算や矢印方向に重ね直さない。門の弾性変形・梁のねじり解析は行わない。

ベース・支持面の高さは、描画座標を仮想支持座標へ換算した `heightAt` に合わせる。平均回転の描画高さを差し引いた残差を加えるため、支持寸法を変えても同じ入力高さの支持点は同じ表示高さになる。外観の幅・奥行は変えないので、支持面の高さ図と部品の姿勢は実寸断面図としては扱わない。

「姿勢差を強調」は最大1000倍。倍率は個体・現在の寸法／配置を基準に固定する。抽選時の全軸代表位置に加え、支持高さ±0.500 mmの許容範囲で起こり得る勾配を各支持の基底係数の絶対和から評価し、表示勾配を約0.2以下に収める上限を設定する。支持高さ・軸位置を変えても倍率を再正規化しないため、粗レベルを合わせると実体の傾きも小さくなる。寸法／配置・個体の変更では倍率を設定し直す。角度・µm・µradの計算値は常に誇張前の値を保持し、学習画面では数字を非表示にする。選択した軸の矢印は、固有角度も表示倍率で強調した非直交方向を参照姿勢で回す。矢印の中心は実際の可動部をその実体姿勢で変換した中心へ追従し、方向の精度参照姿勢と分ける（例えば旋盤Zの精度参照は主軸側、動く実体は往復台側）。固有角度の最大誇張値は0.15 radで、ベクトル構成が破綻しないよう抑える。ガイドPVの曲線は3Dに描かない。部品の並進は公称の軸構成を表し、固有誤差を強調した矢印は数値モデルの方向を表す。弾性変形・誤差付き移動軌跡を完全に再現する3Dではない。別の2D直角度図は初期・現在の角度差を5000倍固定で拡大する。基準軸を右向きにし、比較軸の端点を `[x−L*sin(dev/1e6*5000),y−L*cos(...)]` とする。正偏差は直角より広い左側、負は狭い右側。角度は±0.65 radへclampし、初期と現在の両方の範囲外を明示する。薄い変化面は両端点を結び、dev差が1e−6 µrad以内の不変では生成しない。近づく／離れるの定性判定は従来と同じ0.005 µmの絶対差境界を使う。

## 保存と旧データ

JSONは `version:2` に `machineProfile` を追加。個体の種・条件・初期支持高さ、現在の支持高さ（0.001 mm刻み）、寸法、軸位置、配置、表示設定を保存する。個体は種から再生成した全内容と一致するか厳格に検証し、別軸の項目・変更された固有値・不適合な支持点数を拒否。参考最良の支持高さも同じ寸法・配置に結びつけて保存し、復元時は保存例と再探索結果を厳密モデルで比較する。手動で見つけた改善は、その後に調整を悪化させても同じ条件で再表示すれば保持する。寸法・配置変更では別条件として参考を再探索する。探索値やスコアそのものは外部JSONから信用せず再計算する。

旧 `version:1` は高さ・配置・軸位置を維持し、固有精度は新規抽選してversion 2で保存する。旧データにない配置・軸位置は標準／中央。旧版を再度外部から読むと個体を新しく抽選するが、一度ブラウザ保存した個体は復元する。v2で個体を欠いたデータは拒否。

非同期読込はrequest ID、機械セッション世代、状態revisionで順序を確認。最新ファイル以外、新しい個体・問題・手動入力・機械再表示の前に始めたファイルは反映しない。読込開始時に軸デモを止め、旧アニメーションの上書きも防止する。

## 幾何ずれの数値例

`impact(solution,{span,offset})` の `span` と `offset` は m。返り値はすべて µm。

| 出力 | 数式 | 学習上の意味 |
|---|---|---|
| `tiltOffsetMicrons` | `hypot(lr,fb) * offset * 1000` | 傾きと距離 offset による幾何ずれの大きさの例 |
| `twistOffsetMicrons` | `abs(twist) * span * 1000` | 幅 span に対する手前と奥の高低差の変化の例 |
| `straightnessMicrons` | `residual * 1000` | 支持点の平面偏差を µm に換算した例 |

`straightnessMicrons` はAPI内の短い名称。**実機の真直度測定値でも加工精度の予測値でもない。** UI では「支持点の平面偏差」と説明する。メーカー合否、精度保証、調整手順の判定には使わない。

## 入力検証

3点未満、重複座標、非数値・NaN・無限大、一直線またはほぼ一直線の支持点、4点以上の欠けた格子は例外。浮動小数点で計算可能な範囲を超える値も例外。負の高さは有効な相対高さである。`span` と `offset` は有限の0以上の数値。

## 検証

`node tests/check-leveling-engine.cjs` で、一様上昇、傾斜の符号、平面の保持、4点ねじれ、6/8点の中間支持、3点支持、範囲外の延長、単位換算、入力不変性、大きな座標原点と極端な値、不正入力を確認する。

`tests/check-accuracy-engine.cjs` は直交フレーム・共通傾斜・四点ねじれ・符号・評価長を検証。`tests/check-accuracy-review.cjs` は独立レビューの再現検証、`tests/check-accuracy-render.cjs` はCanvasの全描画経路を3寸法・全構造／方式で実行する。

`tests/check-leveling-learning.cjs` は抽選時と現在の同条件比較、0.001 mm調整の可視性、符号付き変化と絶対ずれ増減の区別、軸位置・配置・評価長の変更、3点／門形／旋盤、保存・再抽選・初期復帰を独立確認する。

`tests/check-level-stages.cjs` は既存14種類に追加する検証。独立した支持面の勾配・Gram構成・四元数回転で合成姿勢を確認し、粗／微の量切替、平均目安と残存誤差、調整中固定倍率、実体の方向、矢印中心と方向の分離、保存復元を全9構造／方式で検証する。
