# レベル出しの学習用計算モデル

## 座標と単位

- 支持点は `{x,z,h}`。`x` は右が正、`z` は奥が正で単位は m。`h` は相対高さで単位は mm。
- この `x,z` は支持点配置の座標であり、機種ごとの工作機械 X/Y/Z 軸名とは別。
- 高さの一様な増減は全体位置だけを変え、傾き・ねじれ・平面偏差は変えない。
- 実機の支持点位置・荷重・剛性・基礎を再現していない。画面寸法は学習用寸法。

## 平均傾きと平面偏差

全支持点に対して `h = a*x + b*z + c` の最小二乗平面を求める。座標と高さを正規化して計算する。

| 出力 | 定義 | 単位 |
|---|---|---|
| `lr` | 平面の `a`。右が高いと正 | mm/m |
| `fb` | 平面の `b`。奥が高いと正 | mm/m |
| `residual` | 支持点高さと最小二乗平面の高さの差の最大絶対値 | mm |
| `twist` | 奥の左右勾配 − 手前の左右勾配 | mm/m |

`twist` の左右勾配はそれぞれ、支持範囲の左端と右端の高低差を全幅 m で割った値。途中の支持点の盛り上がりは `twist` だけでは検出できないので、`residual` と位置ごとの勾配も併せて確認する。

## 位置ごとの学習用面

3点支持は一意の平面。`twist` と `residual` は 0 で、位置ごとの勾配は一定。

4点以上は、欠けのない長方形格子に配置した全支持点を使う。各セルで双線形補間するため、6点・8点の中間支持点の高さも面に反映する。`heightAt(x,z)` は mm の高さ、`slopeAt(x,z)` は `{lr,fb}` の局所勾配 mm/m を返す。入力の配列順には依存しない。

セル境界の高さは連続だが勾配は変わることがある。境界上では右／奥側のセル、最外境界では内側のセルの勾配を採る。支持範囲外では最外セルを双線形延長する。実際の据付評価の外挿ではなく、模式図が範囲外に張り出した部分に高さを与えるための便宜的な処理。

この面は「支持点に与えた高さをつなぐ教材」であり、ベースや案内面がそのとおり変形する物理計算ではない。下記の姿勢・直角度モデルの入力として使うが、剛性、荷重、接触、ねじの締付量、実機加工誤差は計算しない。

## コラム・案内の姿勢と直角度

`geometry(solution,{toolPoints,workPoints,axes,length})` は、工具側とテーブル／案内側が、指定した支持面の局所姿勢に従うという仮定の幾何教材。`length` は評価長 m。複数の `toolPoints` がある門形は、平均姿勢と個別コラムの姿勢を両方保持する。

`a=lr/1000`、`b=fb/1000` とし、上方向の単位ベクトルを `n=normalize([-a,1,-b])`、右方向を `ex=normalize([1,a,0])`、奥方向を `ez=ex×n` とする。3本は互いに直交する。同じ傾斜面では工具側・案内側とも同じ回転になり、共通の床に対する傾きから直角不良は発生しない。

参照姿勢で回した各機械軸の単位方向ベクトルを `u`、`v` とすると：

- `δ = −asin(u·v)`：90°からの符号付き角度差 rad。正は90°より広い、負は狭い。
- 直角度の表示角度：`90 + δ*180/π` 度。
- 直角差：`δ*10^6` µrad。
- 評価長でのずれの微小角換算：`δ*10^6*length` µm。画面の評価長を変えても姿勢角は変わらない。
- 床基準の前倒れ：`atan(fb/1000)*10^6` µrad。奥高ならコラム上端は手前へ倒れる。
- 床基準の右倒れ：`−atan(lr/1000)*10^6` µrad。右高なら上端は左へ倒れる。
- 相対姿勢差：工具側の前倒れ／右倒れ − テーブル側の同指標。

### 構造別の参照位置・軸の仮定

|構造|工具側の姿勢を採る位置|テーブル／案内側の基準位置|工具側の参照姿勢を使う軸|案内側の参照姿勢を使う軸|
|---|---|---|---|---|
|立形・標準／小型|後方コラムの根元（配置を変更可）|XYで動くテーブルの基準点|Z|X・Y|
|横形|Xで動くコラムの根元|Zで動くパレットの基準点|X・Y|Z|
|移動コラム|Xで動くコラムの根元|固定テーブル側の代表基準点|Y・Z|X|
|固定門形・長手方式|左右コラムの根元とその平均|Xで動くテーブルの基準点|Y・Z|X|
|固定門形・テーブルXY|左右コラムの根元とその平均|XYで動くテーブルの基準点|Z|X・Y|
|移動門形|Xで動く左右コラムの根元とその平均|固定テーブル側の代表基準点|Y・Z|X|
|5軸テーブル旋回形|後方コラムの根元|XYで動くトラニオンの支持基準点|Z|X・Y|
|2軸旋盤|固定主軸台の根元|X/Zで動く刃物台側の基準点|主軸基準Z|X|

水平案内全体の姿勢を代表点で表す仮定であり、実際の軸真直度や移動中の荷重による変形を算出するものではない。移動コラム・門形の主軸側で同じ姿勢を採る軸間の直角度は、この仮定では保たれる。それでも工具とワークの相対姿勢、左右コラムの倒れ差が残る場合があるため、軸の直角差が0だけで「同じ姿勢」と判定しない。

5軸の数値は直線軸の支持姿勢の比較で、A/Cの旋回誤差は含まない。旋盤は主軸台のZ基準と刃物台側のX方向を比較し、NCの2軸案内の全幾何精度を再現するものではない。Y軸・YZ指標は表示しない。

### 四点ねじれとコラムの位置

四点の純ねじれ `h=k*x*z` では、左右傾き `lr=k*z`、前後傾き `fb=k*x`。コラムが後方、テーブルが前方ならXZの関係が変わる。左右位置が同じ中央ならYZ差は0でも、テーブルをX方向へ動かす／コラムの左右配置を変えるとYZ差が現れる。中央でYZが0であることから全体の精度を判断しない。

コラムの据付配置は、模式図の左右幅の±20%、前後幅の±10%の範囲で変更する。固定コラムの構造比較用で、実機にコラムをスライド調整する機構があるという意味ではない。可動コラム／門は既存の軸スライダーの位置にも追従する。

### 代表位置の比較と調整練習

水平移動に関わる軸を端1・中央・端2に設定した3または9位置を比較し、各直角差の最小〜最大を表示する。現在位置の値は別に計算する。この比較は全ストローク走査ではなく、途中の局所的な最大誤差を保証しない。

教材の目標は、全支持列の局所傾き・ねじれ0.02 mm/m以内、支持点の平面偏差0.01 mm以内に加え、代表位置の直角差・相対姿勢差・左右コラム前後倒れ差20 µrad以内。実機の許容値ではない。

### 3Dの表示

コラム・主軸側、テーブル／案内側をそれぞれ局所姿勢で剛体回転する。門の左右コラムは個別の姿勢を使い、梁・主軸側は平均姿勢を使う。ベースの表示は平均の剛体傾斜と高さ残差を合成するため、平面の一様傾斜では全機械の直角関係を維持する。門の弾性変形・梁のねじり解析は行わない。

「姿勢差を強調」は最大1000倍。極端な傾斜では表示勾配を約0.2までに抑えるため倍率を下げる。画面の角度・µm・µradは常に誇張前の値。選択した軸の矢印も同じ参照姿勢で描く。別の2D直角度図は角度差を1000倍にし、表示範囲外の差を端に収める。

## 保存と旧データ

JSONの `version:1` を維持し、任意項目 `columnX`、`columnZ`、`axisPositions` を追加した。旧JSONにこれらがない場合は、標準のコラム配置・軸中央として復元する。新JSONは軸位置も復元し、同じ姿勢・精度表示を再現する。機械・方式・軸名・数値範囲を検証してから反映する。読込成功時は動作デモを止め、旧アニメーションが軸位置を上書きしないようにする。

## 幾何ずれの数値例

`impact(solution,{span,offset})` の `span` と `offset` は m。返り値はすべて µm。

| 出力 | 数式 | 学習上の意味 |
|---|---|---|
| `tiltOffsetMicrons` | `hypot(lr,fb) * offset * 1000` | 傾きと距離 offset による幾何ずれの大きさの例 |
| `twistOffsetMicrons` | `abs(twist) * span * 1000` | 幅 span に対する手前と奥の高低差の変化の例 |
| `straightnessMicrons` | `residual * 1000` | 支持点の平面偏差を µm に換算した例 |

`straightnessMicrons` はAPI内の短い名称。**実機の真直度測定値でも加工精度の予測値でもない。** UI では「支持点の平面偏差」と説明する。メーカー合否、精度保証、調整手順の判定には使わない。

## 入力検証

3点未満、重複座標、非数値・NaN・無限大、一直線またはほぼ一直線の支持点、4点以上の欠けた格子は例外。浮動小数点で計算可能な範囲を超える値も例外。負の高さは有効な相対高さである。`span` と `offset` は有限の0以上の数値。

## 検証

`node tests/check-leveling-engine.cjs` で、一様上昇、傾斜の符号、平面の保持、4点ねじれ、6/8点の中間支持、3点支持、範囲外の延長、単位換算、入力不変性、大きな座標原点と極端な値、不正入力を確認する。

`tests/check-accuracy-engine.cjs` は直交フレーム・共通傾斜・四点ねじれ・符号・評価長を検証。`tests/check-accuracy-review.cjs` は独立レビューの再現検証、`tests/check-accuracy-render.cjs` はCanvasの全描画経路を3寸法・全構造／方式で実行する。
