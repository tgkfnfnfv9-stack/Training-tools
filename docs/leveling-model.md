# レベル出しの学習用計算モデル

2026-10-06更新。門形2機種の計算仕様は `portal-shear-v2`、小型立形は `compact-table-path-v3`、移動コラムは `travel-guide-v2`、横形は `horizontal-guide-v2`、旋盤は `lathe-carriage-v2`、5軸は `connected-frames-v1`。実機資料との比較・全7機種の限界は [構造点検](structural-audit-20261006.md) を参照。

## 座標と単位

- 支持点は `{x,z,h}`。`x` は右が正、`z` は奥が正で単位は m。`h` は相対高さで単位は mm。
- この `x,z` は支持点配置の座標であり、機種ごとの工作機械 X/Y/Z 軸名とは別。
- 高さの一様な増減は全体位置だけを変え、傾き・ねじれ・平面偏差は変えない。
- 実機の支持点位置・荷重・剛性・基礎を再現していない。画面寸法は学習用寸法。

## 抽選した初期精度

`MachineAccuracy.generate(condition,seed,keys,count)` は32bitの種を持つ決定的抽選。機械／方式ごとに生成直後から自動保存し、軸移動・高さ調整・再表示で引き直さない。「別の個体を抽選」または新品／中古変更で新しい種を作る。各項目の抽選率は下表の**教材設定**であり、製造品質や中古市場の実測統計ではない。

|状態|一般的な誤差帯|大きい誤差帯|さらに大きい誤差帯|
|---|---|---|---|
|新品|95%：1〜20 µm|5%：20〜40 µm|—|
|中古|60%：5〜20 µm|30%：20〜60 µm|10%：60〜150 µm|

軸間直角度と、全直線軸のガイド真直度PVを個別に抽選する。表の確率は機械全体の良否割合ではなく、各誤差項目ごと。各帯の値は一様抽選し0.001 µmに丸め、直角度の符号は別に50%ずつ抽選する。

- 固有直角度は**300 mmの評価長**でのµm換算。1〜20 µm = 0.001〜0.020 mm。角度は `microns / 0.3 / 10^6` radで、現在表示の評価長を変えても角度・個体・練習目標を変えない。
- ガイドPVは仮想移動全域について抽選した固有の曲がり成分で、このモデルでは固定する。位置に依存する曲線や据付による案内真直度の変化、荷重変化は計算しない。実機の真直度がレベル調整で不変という意味ではない。A/Cの旋回精度は対象外。
- 初期支持高さは±0.150 mmで抽選し、最初の2点は−0.150/+0.150 mmとして据付時の誤差を保証。固有精度と据付の悪さは別の情報。
- ガイドPVと支持点の平面偏差は別の指標。ガイドPVを支持面のresidualから算出しない。

## レベル調整で精度の変化を学ぶ

学習の主画面の調整欄には「粗調整／微調整」、支持点の選択、選択した点を上げ下げする共通ボタンを置く。粗は0.01 mm、微は0.001 mm。以下の計算説明でいう「精調整」は画面の「微調整」に対応する。旧保存のstepを維持し、0.01 mm以上を粗、未満を微として推定する。明示切替は操作量のみを変え、個体・高さ・初期基準は更新しない。主画面の直角図には基準軸0と現在の300 mm直角差を1 µm刻みで表示する。初期・差分の精度値や操作量は数字で示さず、旧数値DOMをhiddenで保持する。測定位置の始点0／O（0,0）・300 mm終点も表示する。保存形式には計算仕様IDを加える（下記参照）。

細かい設定と説明は左上の設定メニューへ集約する。模型表示、軸位置・動作デモ、機械・方式、支持設定、個体と調整例、保存・読込、図の見方をここから操作する。メニューを開くと主画面を右へ縮小し、模型・水準器・直角図・軸選択バーを一緒に確認できる。閉じると通常表示へ戻る。この縮小は表示専用で、模型のズーム値、支持高さ、軸位置、精度、初期比較、保存JSONを変更しない。

粗の判定は平均左右／前後の各±0.020000001 mm/m。気泡も同じ平均を参照し、感度や局所測定位置によらない。精は後述の既存参考targetを使う。参考目的では平均傾きに15%の重みを与えているため、精の支持姿勢が粗目安を少し外れることがある。粗完了を精切替の必須条件にせず、平均の状態を精画面に明示する。

粗ヒントは実候補の `lr²+fb²`、精ヒントは全代表位置の既存 `machineEvaluation().objective` を評価する。今の操作量で各支持点の上下候補を計算し、実改善がある候補だけ案内。単独候補がなければ複数支持の関係や参考例を案内し、成功扱いにはしない。粗手本は同高0、精手本は既存 `machineBestHeights()` を実際に適用して再評価する。

精目安内は参考との差であり、完全直角／全軸改善／実機合格ではない。全代表位置の合成直角差（300 mm換算）または固定ガイドPVが20.000001 µmを超えると残る誤差の注意を強める。この合成値は支持姿勢も含むので、本体だけを原因とはしない。合成倒れの定性区分は各20.000001 µrad、支持ねじれは±0.020000001 mm/mで小さめとする。これらは教材表示用でメーカー許容値ではない。

精開始時の総合objectiveをUIだけに記録し、以後の実objectiveと比較する。初期図の基準は抽選時のまま。個体・寸法・配置・評価長の変更、JSON読込（同じ個体でも）、初期戻し、別支持問題でUI基準を破棄する。UI基準は保存schemaに追加しない。保存fineの読込時は開始時比較が未取得として表示する。

抽選帯は固有成分の大きさであり、主画面の「抽選時」は据付姿勢も重ねた値。固有直角差の300 mm基準に対して、主画面では選んだ評価長を使うため、調整前の直角度が抽選帯の20 µm等を超える場合がある。

比較基準は個体の `initialHeights`、現在は `supportHeights`。両方を**同じ現在の軸位置、支持寸法、コラム配置、評価長**で計算する。

- 初期支持面：`machineSolution(machineProfile.initialHeights)`。
- 初期の姿勢・直角度：`geometryModel(positions, initialSolution, machineProfile, levelConfig.offset)`。
- 現在の姿勢・直角度：`geometryModel()`。
- 変化量：丸める前の `現在 − 初期`。表示値の差から計算しない。
- 90°との差が小さくなったか：`abs(現在の直角差) − abs(初期の直角差)`。負なら改善、正なら悪化。表示上は±0.005 µm以内の差を「ほぼ同じ」とまとめる。例えば+10→−20 µmは変化−30 µmでも、90°との差は10 µm大きくなる。丸め前の変化量・絶対差は保持する。

直角差の＋は90°より広く、−は狭い方向。倒れの＋は前／右、−は後／左を示す。支持面ねじれは奥の左右勾配−手前の左右勾配であり、部品のねじり角そのものではない。倒れの減少やねじれの減少だけで、全ての精度が改善したとは判定しない。

軸移動やコラム配置を変えたときも、初期と現在を同じ条件で再計算する。比較値は調整1回ごとの増分ではなく、抽選時の支持高さからの累積変化。「同じ個体で別の支持状態を試す」でも、比較基準は抽選時の支持高さを維持する。初期へ戻すと同条件の差は0になる。別の個体を抽選した場合は、新しい固有精度と初期支持高さへ切り替わる。

全代表位置の300 mm集約評価を、今の軸位置での初期直角度として流用しない。現在位置の直角度や姿勢は軸移動中も更新する。小さい差は定性的な増減を併記し、計算上の不変を誤って動かさない。直角図の広がる／狭まる方向はsigned差、近づく／離れるは絶対偏差の差として区別する。

直角図の測定位置は共通始点O（0,0）から固定300 mmの仮想終点へ伸ばした局所角度の模式比較。始点のゼロ合わせは測定線を同じ位置へ重ねる意味で、個体の固有精度・支持高さをゼロ化しない。XYはXを基準にY、XZはXを基準にZ、YZはYを基準にZ、旋盤の主軸基準XZは主軸軸線を基準にX送りを測る。測る軸の方向を矢先で示し、理想終点（白）と現在終点（軸色）を結ぶ細線で直角との差を示す。初期↔現在の変化面とは区別する。

300 mmの非誇張換算はエンジンと同じ小角式 `errorMicrons = deviationMicroradians * 0.3`。初期・現在・差分をUIのdata属性へ持ち、現在値だけを図下に1 µm刻みで表示する。基準軸0はゼロ合わせで、比較軸の正は直角より広い、負は狭い。絶対値を四捨五入して符号を付け、負のゼロは表示しない。図の端点は従来の固定5000倍の角度・±0.65 rad上限で描くため、画面上の差線は実寸ではない。範囲外でも数値は省略しない。`levelConfig.offset`、現在位置での精度評価長、代表位置の集約評価、この300 mm表示設定自体は計算モデルや保存内容を変更しない。実NC座標やYの始点から終点までの実移動、ガイド真直度の全域走査を計算している図ではない。

## 平均傾きと平面偏差

全支持点に対して `h = a*x + b*z + c` の最小二乗平面を求める。座標と高さを正規化して計算する。

| 出力 | 定義 | 単位 |
|---|---|---|
| `lr` | 平面の `a`。右が高いと正 | mm/m |
| `fb` | 平面の `b`。奥が高いと正 | mm/m |
| `residual` | 支持点高さと最小二乗平面の高さの差の最大絶対値 | mm |
| `twist` | 奥の左右勾配 − 手前の左右勾配 | mm/m |

`twist` の左右勾配はそれぞれ、支持範囲の左端と右端の高低差を全幅 m で割った値。途中の支持点の盛り上がりは `twist` だけでは検出できないので、`residual` と位置ごとの勾配も併せて確認する。

## 位置ごとの学習用面

3点支持は一意の平面。`twist` と `residual` は 0 で、位置ごとの勾配は一定。

4点以上は、欠けのない長方形格子に配置した全支持点を使う。各セルで双線形補間するため、6点・8点の中間支持点の高さも面に反映する。`heightAt(x,z)` は mm の高さ、`slopeAt(x,z)` は `{lr,fb}` の局所勾配 mm/m を返す。入力の配列順には依存しない。

セル境界の高さは連続だが勾配は変わることがある。境界上では右／奥側のセル、最外境界では内側のセルの勾配を採る。支持範囲外では最外セルを双線形延長する。実際の据付評価の外挿ではなく、模式図が範囲外に張り出した部分に高さを与えるための便宜的な処理。

この面は「支持点に与えた高さをつなぐ教材」であり、ベースや案内面がそのとおり変形する物理計算ではない。下記の姿勢・直角度モデルの入力として使うが、剛性、荷重、接触、ねじの締付量、実機加工誤差は計算しない。

## コラム・案内の姿勢と直角度

`geometry(solution,{toolPoints,workPoints,axes,length})` は、工具側とテーブル／案内側が、指定した支持面の局所姿勢に従うという仮定の幾何教材。`length` は評価長 m。門形は柱根元の平均勾配ではなく、左右柱の天端を結ぶ梁の姿勢を工具側へ渡す。

部位単体の支持姿勢は、`a=lr/1000`、`b=fb/1000` とし、上方向の単位ベクトルを `n=normalize([-a,1,-b])`、右方向を `ex=normalize([1,a,0])`、奥方向を `ez=ex×n` とする。3本は互いに直交する。門形の梁・案内は後述の非直交変換を使う。固有誤差を持たない基準モデルの一枚の共通傾斜面では全てが同じ回転になり、共通の床に対する傾きから直角不良は発生しない。

参照姿勢で変換して正規化した各機械軸の単位方向ベクトルを `u`、`v` とすると：

- `δ = −asin(u·v)`：90°からの符号付き角度差 rad。正は90°より広い、負は狭い。
- 直角度の表示角度：`90 + δ*180/π` 度。
- 直角差：`δ*10^6` µrad。
- 評価長でのずれの微小角換算：`δ*10^6*length` µm。画面の評価長を変えても姿勢角は変わらない。
- 支持による床基準の前倒れ（`toolLean`）：姿勢フレームの上向き `u` から `atan2(-u.z,u.y)*10^6` µrad。奥高なら柱上端は手前へ倒れる。
- 支持による床基準の右倒れ（`toolLean`）：`atan2(u.x,u.y)*10^6` µrad。右高なら上端は左へ倒れる。
- 支持による相対姿勢差（既存 `relativeLean`）：工具側の前倒れ／右倒れ − テーブル側の同指標。

### 固有直角差の合成

固有直角差は単なる絶対値の加算ではなく、非直交の軸方向を作ってから各参照姿勢で変換・正規化する。名目方向Xを固定し、YをXY誤差分だけX方向へ傾ける。ZはXZ/YZの内積がそれぞれ `−sin(δXZ)` / `−sin(δYZ)` となるようGram構成し正規化する。2軸はXZのみ。同じ支持回転なら内積が保持され、初期固有直角差がそのまま残る。門形の梁・案内には支持によるせん断変形も重なるため、Y/Zの合成角は変わり得るが、保存した固有誤差を書き換えるものではない。

UIの「固有／支持姿勢」の内訳は各微小角換算の参考値。合計の角度は合成後の方向から正確に算出するため、内訳の数値和は厳密な回転合成ではない。支持調整は固有角度の一部を相殺できるが、同じ参照剛体にある軸間の誤差やガイドPVをすべて除去することはできない。

### 移動コラム・横形の案内と取付部、位置を動かさない参照

移動コラムのX案内は、描画の2本のレール（内部座標 `z=D*0.22±0.1`）の現在X位置で勾配を平均して作る。コラムは描画根元の代表位置（`z=D*0.29+配置オフセット`）で姿勢を作る。寸法は教材模型由来であり、メーカーの案内間隔ではない。横形も同じ考え方で、2本のXレール（`z=D*0.28±0.13`）とYを担うコラム根元（`z=D*0.29+配置オフセット`）を区別する。これらの違いは、案内からコラムへつながる取付ベースが支持面の局所形状に応じて相対変形する、という幾何的な仮定である。移動コラムの剛体コラム上のY/Zは同じ姿勢を使う。

これによりベッドのねじれなどでX案内とZ倒れの関係が変わり得る。XYも両方向の内積から決まり、水平ヨーを持たない高さ場では変化がないか、高次の小さい変化だけになることがある。YZを支持操作で強制的に変えない。一枚の平面支持では案内とコラムが共通回転となり、内部角度は保存される。有限幅の案内ブロック接触、足元全域の平面当てはめ、取付部剛性、荷重によるコラム変形は未再現である。軸矢印は案内の代表方向であり、走行中に姿勢が変わるコラムの全頂点の軌跡微分ではない。

小型立形はXテーブルがYサドル上を走るため、支持面のサドル参照を `x=0` に固定しYだけ移す。旋盤もX径送りで往復台のベッド参照を動かさず、描画往復台の中心 `z=-0.15` をZ長手位置だけ移す。これらは荷重変形を追加する変更ではなく、親部品の実際の移動に参照を合わせる修正である。

横形はX案内とYコラムの相対姿勢がXYへ伝わり得る。レール中心とコラム参照の奥行差は既存模型の `0.01D` を使い、変化を見せるために増幅しない。XZなどの水平軸同士は、水平ヨーを持たない高さ場では不変か高次の小さい変化となる場合がある。実機の水平ヨーや個別の案内取付変形を、この高さだけの幾何モデルで定量再現したとは扱わない。

### 門形の幾何的な結合

固定門形は15点全体の従来解法を平均平面・残差などの評価に残すが、模型の構造面と部位姿勢は長手ベッド9点の格子面と左右各3点の平面へ分ける。薄板スプラインの全体勾配を柱姿勢へ割り当てない。ベッドと柱座をつなぐ描画部分は滑らかな補間帯で連続させるが、この帯の曲線も鋳物の弾性解析ではない。詳細欄の中心線の局所水準器はベッド側の姿勢、主画面の平均水準器は全支持の平均平面を示す。柱の前後2点差と内外点差を別々に反映し、無関係なベッド点からスプラインの微分を介して柱の倒れを決めない。移動門形は既存格子面を現在の左右走行位置で採る。

門形では全支持の平均平面を共通回転とし、各部位の残差高さ・残差勾配をその中で扱う。各柱の足元と高さ方向から天端を求め、左天端から右天端への単位ベクトルを梁のY方向とする。Z方向は左右柱の上方向を等しい重みで平均して正規化する。**ZをYに直交させる補正はしない。** 奥行方向はYとZの外積を正規化して定める。これらを列に持つ一定の変換を、梁・工具側の模型、移動方向、精度の計算へ共用する。内部座標の左右・上下はNC Y・Zに対応するため、YとZが直交しないと模型の断面にも同じ角度変化が現れる。

この処理は、支持差から生じる柱の前後・左右倒れと関連する直角差を理解するための**幾何的なせん断モデル**である。固有軸方向を同じ変換で写して正規化し、X案内・Y・Zの内積からXY/XZ/YZを算出する。操作名により特定の精度を強制的に改善・悪化させる規則はない。

左右柱の高さ差は梁Yの傾き、前後倒れ差は天端の前後差と梁の水平ヨーへ伝わる。柱の平均前後倒れはZと長手Xの関係へ、平均左右倒れはZと門幅Yの関係へ影響する。したがって以前の直交梁モデルで不変だったYZも、柱の左右倒れや左右高さ差に応じて変わり得る。片柱の全点同量上げは、その柱を必ず倒す操作ではない。柱姿勢と梁Yの姿勢を区別する。ベッド側だけの調整はテーブル側の姿勢を変え、梁との相対角へ伝わる。左右の変化が相殺する場合や、特定の軸対に成分がない場合は、その直角差が変わらなくても正常である。

**梁・案内は一つの一定アフィン変換で表す。** 梁の横方向を天端間の長さに合わせ、角度のせん断を許容して、柱天端中心と梁側の同じ中心位置をつなぐ。両端で柱と梁の断面回転まで連続させる拘束、締結剛性、反力、曲げ・ねじり・弾性せん断剛性は計算しない。表示上の変形量は実機の応答量ではない。

Z方向は常に左右柱の等重み平均であり、Y移動位置によって重みを変えない。Yの左右移動やZの上下移動に伴う荷重たわみ、梁長手に沿うねじれ分布は未再現。固定門形の位置比較はXによるベッド局所姿勢の変化、移動門形はXによる左右走行位置の変化を比較する。これらと未再現のY位置依存を混同しない。

移動門形の既存2列格子では、同じ長手位置の左右レールの横勾配が同じになる。この横断面で左右柱の上方向を平均すると、天端間方向との直交が保たれてYZが不変になる場合がある。固定門形の独立した柱3点座面と同じ応答を強制しない。姿勢を変えたら全ての直角差も必ず変わる、という教材にはしない。

門形と小型立形以外の機種は局所の総勾配を直接姿勢へ変換する。一様高さ加算と一枚の平面支持では内部直角差を保つが、非平面高さ場へ平面勾配を加えることは厳密な共通剛体回転操作と同じではない。有限角の高次差まで構造解析として保証するモデルではない。

### 小型立形のテーブル上面P

`compact-table-path-v3` は、テーブルに固定した上面中心PのX/Y送り接線と、柱側Z送りを比較する。Pの高さは既存模型の支持姿勢基準から0.50 mであり、実機の案内高さではない。Yサドルの参照は従来どおりYだけに追従するが、ねじれ面を移動すると姿勢も変わり、Pにはその回転による横移動が加わる。この局所送り方向を模型・軸矢印・XY/XZ/YZで共用する。300 mmの数値は局所角の換算で、実際の300 mm走査やAbbe補正済みの軸固有直角度ではない。

小型立形でも平均平面の共通剛体回転を外側へ分離し、残差の高さ・姿勢変化だけから部位間の変化を求める。一様な持ち上げや共通の傾きは直角差を変えない。旧 `compact-saddle-v2` の同時点のサドルX/Y内積は不変だったが、有限高さのPの送り接線とは一致していなかった。資料、独立した幾何式、未再現現象は [compact-table-path-20261006.md](compact-table-path-20261006.md) を参照。

### 四点ねじれとコラムの位置

四点の純ねじれ `h=k*x*z` では、左右傾き `lr=k*z`、前後傾き `fb=k*x`。コラムが後方、テーブルが前方ならXZの関係が変わる。小型立形ではPの高さによってXYへ、Pの横位置によってY送りの上下成分とYZへ影響し得る。Xテーブル移動でサドルの据付参照を左右へ動かす旧処理は廃止したままであり、Pの移動と混同しない。特定位置である直角差が0でも、全位置の精度が0とは限らない。

コラムの据付配置は、模式図の左右幅の±20%、前後幅の±10%の範囲で変更する。固定コラムの構造比較用で、実機にコラムをスライド調整する機構があるという意味ではない。可動コラム／門は既存の軸スライダーの位置にも追従する。

### 代表位置の比較と調整練習

全直線軸を端1・中央・端2に設定した27位置（旋盤は9位置）を比較し、各直角差の最小〜最大を表示。現在位置は別計算。この比較は全ストローク走査ではなく、途中の局所的な最大誤差を保証しない。

調整評価は固定300 mmで、各位置の直角差、左右コラムの前後倒れ差、25%重みの工具／案内の相対前後・左右姿勢差を列ベクトルにし、平均左右・前後傾きの換算値へ15%重みと `sqrt(位置数)` をかけた2要素を追加。その二乗平均平方根を小さくする。ガイドPVは不変なので最適化目標に足して調整差を隠さず、別列で残留量を示す。

0高さで±0.05 mmの中央差分から二次目的の近似行列を作り、0高さと初期高さの2開始点から有界座標降下。±0.500 mm内・0.001 mm格子で単独支持の最良値と二点±0.001 mmの組合せを探索し、最後に近似していない現在の幾何モデルで探索値・0高さ・初期高さを再評価する。現在の手動調整がより良ければ参考値も更新する。探索結果は**参考最良**であり、非線形の全離散組合せに対する全球最適の証明ではない。

精度は全支持点の一様な高さ変更では変わらない。参考最良の適用とヒントは、相対高さを保ったまま現在の平均高さへ最も近い共通オフセットを使う。±0.500 mm内・0.001 mm刻みで調整し、参考と同じ高さの関係なら全点の不要な上下を勧めない。

「調整前」は抽選時の支持高さを、現在と同じ支持寸法・コラム配置で評価。「現在」と「参考最良」も同条件。残りは `sqrt(max(0,現在評価²−参考最良評価²))` とし0.1 µm以内を練習達成とする。固定の固有直角差が大きい中古でRMS差が縮む効果を取り除き、残る調整余地を評価する。進みは初期の残りに対する現在残りの減少割合（0〜100%、達成時100%）。全指標0や新品共通の絶対許容値を目標にしない。ガイドPVはどの状態でも残る。個体は同じまま支持状態だけ出し直す練習も可能。

### 合成倒れと3Dの代表姿勢

本体の固有倒れは、既存の個体・非直交軸方向から導く。新たな乱数や保存項目は追加しない。立形・門形・5軸は描画の鉛直に対応するZ方向、横形はY方向を代表とする。固有方向 `v0` を工具側の支持フレームで変換した `v = toolFrame.rotate(v0)` に対して、合成前倒れは `atan2(-v.z,v.y)*10^6`、合成右倒れは `atan2(v.x,v.y)*10^6` µrad。`bodyLean`・`bodyPosture` はこの合成姿勢、`toolLean`・`relativeLean`・`columns` は支持による姿勢。門形の左右コラム実体と柱別の姿勢表示は個別支持フレームを使い、梁と別の固有回転を重ねて接続を壊すことはしない。

旋盤の固有XZ差は水平面内の主軸方向のずれで、鉛直コラムの倒れではない。公称Z方向 `[1,0,0]` から固有方向へ最小回転を作り支持姿勢を重ね、主軸の上下方向差を `atan2(v.y,hypot(v.x,v.z))`、水平面の方向差を `atan2(v.z,v.x)` で表示する。

コラム／主軸の実体は、公称代表方向から固有方向への最小剛体回転を加え、その後に局所支持姿勢で回す。テーブル／案内側は支持姿勢で回す。門の骨格は個別の柱支持姿勢と天端間の梁姿勢を共用して接続する。門の固有軸差は軸矢印と直角図で表し、骨格全体を別々に固有回転させない。非直交のXYZ全てを一つの剛体回転で再現することはできないため、実体は代表方向の模式姿勢である。軸間の精度計算は既存の個々の非直交方向で行い、実体の固有回転を精度計算や矢印方向に重ね直さない。門の弾性変形・梁のねじり解析は行わない。

ベース・支持面・部材を同じ仮想支持座標へ換算してから描画する。門形と小型立形以外の支持面は `S(x,z) = [x, .66 + C + F*heightAt(x,z)/1000, z]`、局所法線は `normalize([-F*lr/1000, 1, -F*fb/1000])`。`F` は表示上の強調倍率。厚みはこの法線方向へ付け、部材の支持姿勢も同じ局所勾配を使う。寸法を変えた場合も高さ図と柱の傾きを別々の縮尺で描かない。門形と小型立形では共通平面の回転と残差を分けた上記の写像を使う。A/Cの剛体回転は座標換算後に適用する。

床は固定し、支持足の底を床面に置く。支持ねじの上端はベッド下面へ接続する。`C` は許容支持高さと支持範囲外の外挿を含む形状から決める描画用の固定余裕で、調整中の高さや軸位置に合わせて動かさない。これは接触・荷重の物理解析ではなく、相対高さの教材図を床上に収めるための配置である。

訓練模型は正投影とし、真に鉛直な柱に遠近法だけによる見かけの倒れが発生しないようにする。表示設定で正面（左→右）・側面（手前→奥）・斜めを選べる。床に対する鉛直／水平の破線を部材のそばへ表示する。観察方向とズームは表示専用で、計算・初期比較・保存JSONには加えない。

水準器は支持全体の最小二乗平均を示し、柱はその場所の支持勾配と本体固有姿勢を合成する。一様な傾きでは気泡は高い側、固有差のない柱の上端は低い側へ動く。ねじれ面では平均と柱の局所勾配が逆符号になることもあるため、気泡と柱上端が常に逆方向に動くとは限らない。「平均が目安内」は厳密な傾きゼロを意味しない。

「姿勢差を強調」は最大1000倍（門形は接続形状を保つため最大30倍）。倍率は個体・現在の寸法／配置を基準に固定する。抽選時の全軸代表位置に加え、支持高さ±0.500 mmの許容範囲で起こり得る勾配を各支持の基底係数の絶対和から評価し、表示勾配を約0.2以下に収める上限を設定する。支持高さ・軸位置を変えても倍率を再正規化しないため、粗レベルを合わせると実体の傾きも小さくなる。寸法／配置・個体の変更では倍率を設定し直す。角度・µm・µradの計算値は常に誇張前の値を保持し、主画面には現在の300 mm直角差だけを数字で表示する。選択した軸の矢印は、固有角度も表示倍率で強調した非直交方向を参照姿勢で回す。矢印の中心は実際の可動部をその実体姿勢で変換した中心へ追従し、方向の精度参照姿勢と分ける（旋盤の主軸基準XZ図は主軸側、NC送りZ矢印と動く実体は往復台側）。固有角度の最大誇張値は0.15 radで、ベクトル構成が破綻しないよう抑える。ガイドPVの曲線は3Dに描かない。平坦・共通平面の支持では、可動部の並進方向も固有角度を含む軸矢印と一致させる。ねじれや局所勾配差のある面では、移動する柱根元の支持面への追従を優先する。小型立形のX/Y矢印はPの局所送り接線を示す。他機種の軸矢印は代表位置での案内方向であり、局所姿勢の変化も重なる全頂点の軌跡方向とは区別する。弾性変形・実際の誤差付き移動軌跡を完全に再現する3Dではない。別の2D直角度図は初期・現在の角度差を5000倍固定で拡大する。基準軸を右向きにし、比較軸の端点を `[x−L*sin(dev/1e6*5000),y−L*cos(...)]` とする。正偏差は直角より広い左側、負は狭い右側。角度は±0.65 radへclampし、初期と現在の両方の範囲外を明示する。薄い変化面は両端点を結び、dev差が1e−6 µrad以内の不変では生成しない。近づく／離れるの定性判定は従来と同じ0.005 µmの絶対差境界を使う。

### 現在の模型と理想の輪郭

現在の模型は、支持点の調整に従ってベッドの局所形状とコラムなどの姿勢が変わる。支持による傾き・ねじれと本体の固有誤差を合成する既存の描画・計算を維持する。

「理想の輪郭」は、同じ機種・寸法・配置・軸位置で、支持の傾き・ねじれと本体固有誤差を除いた比較専用の破線。面は塗らず、現在の模型へ薄く重ねる。回転、ズーム、XYZの移動、5軸のA/C回転は両方に適用する。高さだけは現在の平均支持高さへ合わせ、一様な持ち上げを姿勢差として表示しない。

理想の輪郭は床に対する水平・鉛直と公称の直角関係を示す。抽選時の姿勢でも、支持調整だけで到達できる参考最良の姿勢でもない。現在の模型には固有誤差が残るため、粗調整を終えても輪郭と完全に重ならない場合がある。直角図の薄い面は従来どおり抽選時からの変化であり、この理想輪郭とは別の比較である。

表示切替は初期状態でオン。左上の設定メニューの模型表示へ置く。切替と理想描画は表示だけに作用し、支持高さ・個体・精度・初期比較・参考最良・保存JSONを変更しない。

## 保存と旧データ

記録には `calculationModel` を必須として保存する。固定・移動門形は `portal-shear-v2`、小型立形は `compact-table-path-v3`、移動コラムは `travel-guide-v2`、横形は `horizontal-guide-v2`、旋盤は `lathe-carriage-v2`、5軸は `connected-frames-v1`。`version` は支持配置・個体形式の識別（従来の1/2/3）であり、計算仕様の識別とは別。現在の支持高さ、個体の種・固有精度・初期高さ、寸法、軸位置、配置、調整量、表示設定を保存する。参考最良の支持例は同じ計算条件で再評価する。

ブラウザーの保存先も計算仕様ごとのキーに分ける。旧キーは削除・上書きせず、新しい模型へ自動適用しない。門形せん断モデルと今回の4機種の参照変更では、それぞれ以前の `connected-frames-v1` 保存を別扱いとする。5軸の同仕様保存と門形の `portal-shear-v2` 保存は引き続き使える。旧保存の検出時には保持したことを案内する。外部JSONで計算仕様が欠ける／異なる場合も説明を表示して拒否し、現在の状態を変更しない。計算仕様IDを手作業で書き足すことは正規のデータ移行ではない。

新形式の記録は全7機種で保存・復元できる。個体は乱数種から再生成した内容と厳密に照合し、異なる支持配置・支持点数・固有値の変更・不正な軸位置・範囲外高さは拒否する。旧24点を15点に間引いて無言適用する処理も行わない。

非同期読込はrequest ID、機械セッション世代、状態revisionで順序を確認。読込開始後の別ファイル、機種変更、個体抽選、手動操作に古い読込が割り込まないようにする。読込開始時に軸デモを止める。

## 幾何ずれの数値例

`impact(solution,{span,offset})` の `span` と `offset` は m。返り値はすべて µm。

| 出力 | 数式 | 学習上の意味 |
|---|---|---|
| `tiltOffsetMicrons` | `hypot(lr,fb) * offset * 1000` | 傾きと距離 offset による幾何ずれの大きさの例 |
| `twistOffsetMicrons` | `abs(twist) * span * 1000` | 幅 span に対する手前と奥の高低差の変化の例 |
| `straightnessMicrons` | `residual * 1000` | 支持点の平面偏差を µm に換算した例 |

`straightnessMicrons` はAPI内の短い名称。**実機の真直度測定値でも加工精度の予測値でもない。** UI では「支持点の平面偏差」と説明する。メーカー合否、精度保証、調整手順の判定には使わない。

## 入力検証

3点未満、重複座標、非数値・NaN・無限大、一直線またはほぼ一直線の支持点、4点以上の欠けた格子は例外。浮動小数点で計算可能な範囲を超える値も例外。負の高さは有効な相対高さである。`span` と `offset` は有限の0以上の数値。

`tests/check-accuracy-engine.cjs` は直交フレーム・共通傾斜・四点ねじれ・符号・評価長を検証。`tests/check-accuracy-review.cjs` は独立レビューの再現検証、`tests/check-accuracy-render.cjs` はCanvasの全描画経路を3寸法・全構造／方式で実行する。

`tests/check-level-stages.cjs` は既存14種類に追加する検証。独立した支持面の勾配・Gram構成・四元数回転で合成姿勢を確認し、粗／微の量切替、平均目安と残存誤差、調整中固定倍率、実体の方向、矢印中心と方向の分離、保存復元を既存構造／方式で検証する。

- [Haas：VS-Series - Installation - NGC](https://www.haascnc.com/service/troubleshooting-and-how-to/how-to/vs-series---installation---ngc.html)：コラム位置の変化による水準の比較、コラム／テーブルの姿勢と直角度の確認。
- [Renishaw：Geometric machine errors](https://www.renishaw.com/media/pdf/en/3c32fc848b9944daa56567253a396169.pdf)：軸の姿勢・真直度・軸間直角度の区別。

資料で確認した検査の区別を参考にした教材であり、メーカーの据付手順・機械剛性・許容値を再現した計算ではない。

`tests/check-adjustment-flow.cjs` は粗／精の非数値フロー、実評価ヒント、実際の手本適用、全位置総合と現在位置／初期差の違い、平面支持の不変、全legacy step、UIだけの開始基準の破棄を確認する。
