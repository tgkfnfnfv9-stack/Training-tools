LEVELING / MACHINE TYPES

機械の構造を選ぶ

メーカー名だけでなく、主軸の向きと支え方で比べてみましょう。

3Dは外装を省いた構造模式図です。代表機の寸法・支持点・据付仕様を再現したものではありません。

分類の考え方・調査資料

「立形／横形」は主軸の向き、「門形／片持ち」は構造、「5軸」は制御軸の構成です。これらは重なります。立形でも門形構造の機械があり、門形にも5軸機があります。

追加候補：NCフライス、ヘッド旋回式5軸、複合加工機、平面・円筒研削盤、テーブル形／床上形横中ぐり盤。詳しくは同梱の調査資料をご覧ください。

現在は表示項目の配置のみです。メーカー別の支持点・調整手順、実機の加工誤差や合格判定は未実装です。

次の段階で追加する訓練内容
  1. 支持点を上げ下げし、全体の傾きが変わる様子を確認。
  2. 手前・中央・奥の水準器を比べ、中央だけでは判断できないねじれを学習。
  3. 多点支持の機械で、中間支持の調整による変化を確認。
  4. 水平・ねじれ・真直度・直角度の関係を段階的に学習。

今回の確認対象は画面構成と操作導線です。訓練ロジックと実機別の仕様は、UIを固めた後に追加します。
